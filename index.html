#🎓 Yangi: 8-sinf «Web Full-stack dasturlash» kursi

Rasmiy 8-sinf o'quv dasturi (66 soat, 5 bob) asosidagi alohida kurs: 42 ta mavzu — HTML/CSS, JavaScript, Python, PostgreSQL, Django, DRF va deploy. Har mavzuda sodda tushuntirish, o'xshatishlar, jonli kod maydoni, testlar va uy vazifasi bor. Har bir mavzu uchun tayyor taqdimot (brauzerda va PowerPoint) ham bor.

#Full-stack dasturchi kim?

Har bir veb-ilova ikki katta qismdan iborat:

🖥️ FrontendHTML · CSS · JavaScript · React
⇄ HTTP / JSON ⇄
⚙️ BackendNode.js · Express · REST API · Auth
⇄ SQL ⇄
🗄️ Ma'lumotlar bazasiPostgreSQL · MongoDB
Full-stack dasturchi shu zanjirning barcha bo'g'inlarida ishlay oladi

Frontend — foydalanuvchi ko'radigan va bosadigan hamma narsa. Backend — ko'rinmaydigan qism: ma'lumotlarni saqlash, tekshirish, xavfsizlik va biznes-mantiq. Full-stack dasturchi ikkala tomonni ham tushunadi va ilovani g'oyadan ishlab turgan saytgacha yolg'iz o'zi olib chiqa oladi.

#Barcha darslar

Darslar ketma-ket o'qish uchun mo'ljallangan — har biri oldingisiga tayanadi. Har bir darsda: batafsil nazariya, 3–4 ta real amaliy misol, mustaqil mashqlar va xulosa bor.

🌐
01-dars

Web qanday ishlaydi

Internet, mijoz-server modeli, DNS, HTTP protokoli, so'rov va javoblar, status kodlari hamda brauzer sahifani qanday chizishi.

Boshlang'ich · ~60 daqiqa
🧱
02-dars

HTML — sahifa tuzilishi

Teglar, atributlar, semantik HTML, formalar, jadvallar, media, accessibility va SEO uchun meta-teglar.

Boshlang'ich · ~90 daqiqa
🎨
03-dars

CSS — dizayn va maket

Selektorlar, kaskad va spetsifiklik, box model, Flexbox, Grid, pozitsiyalash, responsiv dizayn, CSS o'zgaruvchilari va animatsiyalar.

Boshlang'ich · ~120 daqiqa
⚡
04-dars

JavaScript asoslari

O'zgaruvchilar, ma'lumot turlari, operatorlar, shartlar, sikllar, funksiyalar, scope va closure, massiv va obyekt metodlari, sinflar, modullar va xatolar bilan ishlash.

Boshlang'ich–O'rta · ~150 daqiqa
🖱️
05-dars

DOM va hodisalar

DOM daraxti, elementlarni topish va o'zgartirish, hodisalar (events), bubbling va delegatsiya, formalar bilan ishlash, localStorage.

O'rta · ~120 daqiqa
⏳
06-dars

Asinxron JavaScript va Fetch API

Event loop, callback, Promise, async/await, fetch bilan API'ga so'rov yuborish, xatolarni boshqarish, parallel so'rovlar va so'rovni bekor qilish.

O'rta · ~120 daqiqa
🌿
07-dars

Git va GitHub

Versiyalarni boshqarish: commit, branch, merge, konfliktlarni hal qilish, remote repozitoriya, Pull Request, jamoaviy ish oqimi va GitHub Pages.

Boshlang'ich–O'rta · ~90 daqiqa
🟢
08-dars

Node.js va npm

Node.js nima, modullar tizimi (CommonJS va ESM), npm va package.json, fs, path, events, http modullari, muhit o'zgaruvchilari va CLI dasturlar.

O'rta · ~100 daqiqa
🚂
09-dars

Express.js va REST API

Express asoslari, marshrutlash, middleware zanjiri, REST API dizayni, validatsiya, xatolarni markazlashgan boshqarish, CORS va loyiha tuzilmasi (MVC).

O'rta · ~140 daqiqa
🗄️
10-dars

Ma'lumotlar bazasi: SQL va PostgreSQL

Relyatsion bazalar, jadvallar va bog'lanishlar, SQL (SELECT, JOIN, GROUP BY), indekslar, normalizatsiya, tranzaksiyalar, Node.js'dan PostgreSQL bilan ishlash, SQL injection va MongoDB bilan taqqoslash.

O'rta · ~150 daqiqa
🔐
11-dars

Autentifikatsiya va avtorizatsiya

Parollarni xeshlash (bcrypt), sessiya va JWT, httpOnly cookie, himoyalangan marshrutlar, rollar va ruxsatlar, access/refresh tokenlar hamda frontendda tokenlar bilan ishlash.

O'rta–Yuqori · ~130 daqiqa
⚛️
12-dars

React asoslari

Komponentlar, JSX, props, state, hodisalar, ro'yxatlar va key, formalar, useEffect va ma'lumot yuklash, custom hook'lar, Context va React Router.

O'rta · ~150 daqiqa
🏗️
13-dars

Yakuniy loyiha: full-stack "Eslatmalar" ilovasi

Barcha bilimlarni birlashtiramiz: PostgreSQL + Express API + JWT autentifikatsiya + React frontend. Loyihalash, backend, frontend va ularni bog'lash bosqichma-bosqich.

Yuqori · ~4–6 soat amaliyot
🚀
14-dars

Deploy, xavfsizlik va testlash

Ilovani internetga chiqarish (PaaS, VPS, Docker, Nginx, HTTPS), CI/CD, OWASP asosiy zaifliklari (XSS, SQLi, CSRF), unumdorlik hamda avtomatik testlar (node:test, Supertest, Vitest).

Yuqori · ~150 daqiqa

#Qanday o'qish kerak?

Eng samarali usul Har bir kod misolini o'zingiz qo'lda yozing (nusxa olmasdan), ishga tushiring, keyin ataylab o'zgartirib buzing va nima bo'lishini kuzating. Dasturlash — o'qish orqali emas, yozish orqali o'rganiladi.

Kerakli dasturlar

  • Brauzer — Google Chrome yoki Firefox (DevTools uchun: F12)
  • Kod muharriri — Visual Studio Code
  • Node.js — nodejs.org dan LTS versiya
  • Git — git-scm.com
  • PostgreSQL — 10-darsda kerak bo'ladi

Saytdagi o'qish holatingiz brauzeringizda saqlanadi — har bir dars oxiridagi «Darsni o'qib bo'ldim» tugmasini bosib boring.

Ushbu qo'llanma ochiq manba. Xato topsangiz yoki qo'shimcha kiritmoqchi bo'lsangiz — GitHub repozitoriyasida issue yoki pull request oching.
