Transition — silliq o'tish

9-mavzuda :hover holatini o'rgandik — lekin rang keskin o'zgarardi. transition o'zgarishni silliq qiladi.

O'xshatish: chiroq Oddiy chiroq bir zumda yonadi (transition'siz). Kinoteatrdagi chiroqlar esa asta-sekin so'nadi va yonadi (transition bilan). Siz faqat boshlang'ich va oxirgi holatni berasiz, oradagi barcha "kadrlar"ni brauzer o'zi chizadi.



transition: background-color 0.3s ease 0s;
/*          │                 │    │    └ kechikish (delay) — qachon boshlanishi
            │                 │    └ tezlik egri chizig'i (timing function)
            │                 └ davomiyligi (s — soniya, ms — millisoniya)
            └ qaysi xossa o'zgarishi (all — hammasi)                         */

  • linear — bir tekis tezlikda (robotdek).
  • ease — sekin boshlanib, tezlashib, sekin tugaydi (standart, tabiiy).
  • ease-in — sekin boshlanadi; ease-out — sekin tugaydi.
transition ni oddiy holatga yozing (.tugma), :hover ga emas. Aks holda effekt faqat bir tomonga silliq bo'ladi — sichqoncha ketganda keskin qaytadi.

Animation — o'zi harakatlanuvchi effektlar

transition faqat holat o'zgarganda (hover, click) ishlaydi va faqat A dan B ga. Animatsiya esa o'zi boshlanadi, ko'p bosqichli bo'lishi va cheksiz takrorlanishi mumkin.

1-qadam: @keyframes — "ssenariy" yozish

@keyframes sakrash {
  0%   { transform: translateY(0); }       /* boshlanish */
  50%  { transform: translateY(-40px); }   /* o'rtasida — tepada */
  100% { transform: translateY(0); }       /* oxiri — yana pastda */
}
/* Faqat ikki bosqich bo'lsa: from { ... } to { ... } */

3. Porlovchi tugma
Unumdorlik va foydalanuvchilar haqida qayg'urish
  • Animatsiya uchun eng yaxshi xossalar — transform va opacity: ular tez ishlaydi. width, top, margin ni animatsiya qilish sahifani sekinlashtiradi.
  • Animatsiyani me'yorida ishlating: hamma narsa sakrab tursa, ko'z charchaydi.
  • Ba'zi odamlarda harakatdan bosh aylanadi. Ular uchun: @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }

Amaliy mashg'ulot

  1. Portfolio saytingizdagi barcha tugma va havolalarga transition bilan silliq :hover effektlari qo'shing.
  2. Loyiha kartalari hover'da 8px tepaga ko'tarilsin va soyasi kuchaysin.
  3. Hero bo'limidagi sarlavha va tugma sahifa ochilganda pastdan yuqoriga "paydo" bo'lsin (@keyframes paydo + kechikish).
  4. Profil rasmingizga sekin "nafas olish" effekti: scale(1) → scale(1.03) → scale(1), 4 soniya, cheksiz.
  5. Ijodiy topshiriq: faqat CSS bilan "Quyosh tizimi" yarating: markazda quyosh ☀️, atrofida 2 ta sayyora turli tezlikda aylanadi. (Maslahat: sayyorani o'zidan katta shaffof doira ichiga qo'ying va doirani aylantiring.)

Ko'p uchraydigan xatolar

  • ❌ Bir elementga ikkita transform yozish — ikkinchisi birinchisini o'chiradi. Bittada yozing: transform: rotate(10deg) scale(1.2);
  • ❌ transition: all ni hamma joyda ishlatish — kutilmagan xossalar ham animatsiya bo'ladi; aniq xossani ko'rsating.
  • ❌ @keyframes nomi va animation dagi nom mos emas (masalan, aylanish va aylanis).
  • ❌ display: none ni animatsiya qilishga urinish — u animatsiya bo'lmaydi; opacity va visibility ishlating.

O'zingizni tekshiring

Elementni 1.2 barobar kattalashtiruvchi kod?

  1. transform: size(1.2)
  2. zoom: 120px
  3. transform: scale(1.2)
  4. transform: grow(20%)

Hover effekti silliq bo'lishi uchun transition qayerga yoziladi?

  1. Elementning oddiy holatiga
  2. Faqat :hover ga
  3. @keyframes ichiga
  4. body ga

Animatsiyani cheksiz takrorlash uchun qaysi qiymat?

  1. repeat
  2. loop
  3. forever
  4. infinite

transition va animation ning asosiy farqi?

  1. Farqi yo'q
  2. transition holat o'zgarganda ishlaydi; animation o'zi boshlanadi va ko'p bosqichli bo'lishi mumkin
  3. animation faqat ranglar uchun
  4. transition faqat telefonda ishlaydi

Qaysi xossalarni animatsiya qilish eng tez (unumdor)?

  1. width va height
  2. transform va opacity
  3. margin va padding
  4. top va left

✅ Yodda tuting

  • transform: translate, scale, rotate, skew — boshqa elementlarga ta'sir qilmaydi.
  • transition: xossa vaqt tezlik; — oddiy holatga yoziladi, holat o'zgarishini silliq qiladi.
  • @keyframes nom { 0% {...} 100% {...} } + animation: nom 2s infinite; — o'zi ishlaydigan animatsiya.
  • Unumdorlik: transform va opacity. Me'yorni saqlang.
