JavaScript nima?

JavaScript (JS) — veb-sahifalarga harakat va mantiq qo'shuvchi dasturlash tili. HTML va CSS'dan farqli o'laroq, unda hisob-kitob, shartlar, takrorlanishlar bor — ya'ni u haqiqiy dasturlash tili.

O'xshatish: uy (davomi) HTML — devorlar, CSS — bo'yoq va mebel. JavaScript — elektr tarmog'i va "aqlli uy" tizimi: tugma bosilsa chiroq yonadi, eshik oldiga kelsangiz qo'ng'iroq chalinadi, harorat pasaysa isitish yoqiladi.

JavaScript bilan nimalar qilinadi?

  • Tugma bosilganda biror narsa sodir bo'lishi (menyu ochilishi, rasm almashishi);
  • Formani yuborishdan oldin tekshirish ("Parol juda qisqa!");
  • Kalkulyator, o'yinlar, testlar, taymerlar;
  • Sahifani qayta yuklamasdan yangi ma'lumot olish (Instagram lentasi, ob-havo).
JavaScript ≠ Java Nomlari o'xshash, lekin bu ikki butunlay boshqa til — xuddi "olma" va "olmos" kabi. JavaScript 1995-yilda atigi 10 kunda yaratilgan va hozir dunyodagi eng mashhur dasturlash tillaridan biri. U nafaqat brauzerda, balki serverda (Node.js) va mobil ilovalarda ham ishlaydi.

O'zgaruvchilar

O'zgaruvchi — ma'lumotni saqlash uchun nomlangan "quti". Unga qiymat qo'yasiz va keyinroq nomi orqali ishlatasiz.

O'xshatish: yorliqli qutilar Javonda qutilar turibdi. Har biriga yorliq yopishtirilgan: "ism", "yosh", "ball". "ism" qutisiga "Malika" qog'ozini, "yosh" qutisiga 14 raqamini soldingiz. Endi "yosh qutisida nima bor?" deb so'rasangiz — 14. Yorliq — o'zgaruvchi nomi, ichidagi narsa — uning qiymati.
let ism = "Malika";        // "ism" qutisini yaratdik va ichiga "Malika" ni soldik
let yosh = 14;
console.log(ism);           // Malika
console.log(yosh);          // 14

yosh = 15;                  // qiymatni o'zgartirish (let ni qayta yozmaymiz!)
console.log(yosh);          // 15

let shahar;                 // e'lon qilindi, lekin qiymat berilmadi
console.log(shahar);        // undefined
  • let — o'zgaruvchi e'lon qilish kalit so'zi.
  • = — tayinlash belgisi ("tenglik" emas!): "o'ngdagi qiymatni chapdagi qutiga sol".
  • Satr oxirida ; (nuqta-vergul) — buyruq tugadi.

let, const va var

const PI = 3.14;            // const — o'zgarmas (constant)
const tugilganYil = 2012;
// PI = 5;                  // ❌ Xato! const qiymatini o'zgartirib bo'lmaydi

let ball = 0;               // let — o'zgaradigan qiymat
ball = ball + 10;
console.log(ball);          // 10

Ma'lumot turlari

Har bir qiymatning turi bor. Tur — bu qiymat bilan nima qilish mumkinligini belgilaydi: sonlarni qo'shish mumkin, matnni katta harfga aylantirish mumkin.

1. String — matn (satr)

const ism = "Aziz";                 // qo'sh tirnoq
const familiya = 'Karimov';         // bitta tirnoq
const shahar = `Toshkent`;          // teskari tirnoq (backtick) — eng qulayi

// Satrlarni birlashtirish
console.log(ism + " " + familiya);                  // Aziz Karimov

// Shablon satr (template literal): ${} ichiga o'zgaruvchi qo'yiladi
const yosh = 14;
console.log(`Mening ismim ${ism}, ${yosh} yoshdaman, ${shahar}da yashayman.`);

// Foydali imkoniyatlar
console.log(ism.length);            // 4 — harflar soni
console.log(ism.toUpperCase());     // AZIZ
console.log(ism.toLowerCase());     // aziz
console.log(familiya[0]);           // K — birinchi harf (sanash 0 dan boshlanadi!)
console.log("salom dunyo".includes("dunyo"));   // true
O'zbekcha apostrof bilan ehtiyot bo'ling 'O'zbekiston' ❌ — birinchi ' satrni ochadi, ikkinchisi yopadi va xato chiqadi. Yechim: qo'sh tirnoq yoki backtick ishlating: "O'zbekiston" yoki `O'zbekiston` ✅.

2. Number — son

const butun = 42;
const kasr = 3.14;            // o'nlik kasr NUQTA bilan (vergul emas!)
const manfiy = -10;
console.log(butun + kasr);    // 45.14
console.log(10 / 3);          // 3.3333333333333335
console.log(10 / 0);          // Infinity — cheksizlik
console.log("olma" * 2);      // NaN — "Not a Number" (son emas)

3. Boolean — mantiqiy qiymat

Faqat ikki qiymat: true (rost, ha) yoki false (yolg'on, yo'q). Shartlarda ishlatiladi (16-mavzu).

const tizimgaKirgan = true;
const darsTugadi = false;
console.log(5 > 3);           // true
console.log(10 === 7);        // false

4. Undefined va null

  • undefined — "qiymat hali berilmagan" (bo'sh quti, ichiga hech narsa solinmagan).
  • null — "qiymat ataylab bo'sh" (dasturchi qutini o'zi bo'shatib qo'ygan).

Murakkab turlar (oldinda)

Array (massiv, ro'yxat) [1, 2, 3] va Object (obyekt) { ism: "Ali" } — 18-mavzuda batafsil.

Turni aniqlash: typeof

console.log(typeof "Salom");     // string
console.log(typeof 25);          // number
console.log(typeof true);        // boolean
console.log(typeof undefined);   // undefined
console.log(typeof null);        // object  ← JavaScript'ning mashhur "tarixiy xatosi"!
console.log(typeof [1, 2]);      // object

Turlarni o'zgartirish

// Matn + son = matn (son matnga aylanadi)
console.log("5" + 3);           // "53"  😮
console.log("5" - 3);           // 2     (ayirishda matn songa aylanadi)

// Aniq o'zgartirish
console.log(Number("42") + 8);  // 50
console.log(String(100) + "%"); // "100%"
console.log(parseInt("15px"));  // 15
console.log(parseFloat("3.5"));  // 3.5
Foydalanuvchi kiritgan har qanday ma'lumot (prompt, forma) doim matn bo'lib keladi. Hisoblashdan oldin Number() bilan songa aylantiring!

Foydalanuvchi bilan muloqot

const ism = prompt("Ismingiz nima?");                  // matn kiritish oynasi
const tugilganYil = Number(prompt("Qaysi yilda tug'ilgansiz?"));

alert(`Salom, ${ism}! Siz ${yosh} yoshdasiz.`);
const tasdiq = confirm("Dasturlashni yoqtirasizmi?");   // OK → true, Cancel → false
console.log("Javob:", tasdiq);

Amaliy mashg'ulot

  1. js-darslar/ papkasida index.html va app.js yarating, skriptni </body> oldidan ulang.
  2. "Men haqimda" dasturi. O'zingiz haqingizda 5 ta o'zgaruvchi yarating (ism, familiya, yosh, sinf, sevimli fan) va shablon satr bilan bitta chiroyli gapni konsolga chiqaring.
  3. Yosh kalkulyatori. prompt bilan tug'ilgan yilni so'rang va: yoshni, 2030-yilda necha yoshda bo'lishini, necha kun yashaganini (taxminan, × 365) hisoblang.
  4. Do'kon cheki.

  5. Tur detektivi. 8 ta turli qiymat (matn, son, kasr, true, undefined, null, "123", 0) uchun typeof natijalarini oldindan daftarga yozing, so'ng konsolda tekshiring.

Ko'p uchraydigan xatolar

  • ❌ Uncaught SyntaxError — qo'shtirnoq yopilmagan yoki o'zbekcha apostrof satrni "sindirib" qo'ygan.
  • ❌ ReferenceError: x is not defined — o'zgaruvchi nomi noto'g'ri yozilgan (katta-kichik harf!) yoki e'lon qilinmagan.
  • ❌ TypeError: Assignment to constant variable — const qiymatini o'zgartirishga urinish.
  • ❌ prompt dan olingan sonni qo'shish: "10" + 5 = "105". Number() unutilgan.
  • ❌ Bitta o'zgaruvchini ikki marta let bilan e'lon qilish: let a = 1; let a = 2;
Xatolarni o'qishni o'rganing Konsoldagi qizil xabar — dushman emas, yordamchi! U xato turini va qaysi faylning qaysi qatorida ekanini aytadi (masalan, app.js:12). Ustiga bossangiz, o'sha qatorga olib boradi.

✅ Yodda tuting

  • JavaScript — sahifaga mantiq va harakat qo'shuvchi dasturlash tili; alohida .js fayl </body> oldidan ulanadi.
  • console.log() — natijani konsolga chiqarish (F12 → Console).
  • const — o'zgarmas, let — o'zgaruvchan; var ishlatmang. Nomlar — camelCase.
  • Turlar: string, number, boolean, undefined, null (+ array, object). typeof — turini aniqlash.
  • Shablon satr: `Salom, ${ism}!`. Kiritilgan ma'lumot matn — Number() bilan songa aylantiring.
