Massiv nima?

Sinfdagi 25 o'quvchi ismini saqlash uchun 25 ta o'zgaruvchi yaratish (ism1, ism2...) noqulay. Massiv — qiymatlarning tartiblangan ro'yxati, bitta o'zgaruvchi ichida.

O'xshatish: poyezd vagonlari Massiv — poyezd. Har bir vagonda bitta qiymat. Vagonlar raqamlangan, lekin raqamlash 0 dan boshlanadi: birinchi vagon — 0-vagon. Bu raqam indeks deyiladi. Vagonlar soni — length.
const mevalar = ["olma", "nok", "uzum", "anor"];
//                 0       1       2       3      ← indekslar

console.log(mevalar);
console.log(mevalar[0]);                  // olma  — birinchi element
console.log(mevalar[2]);                  // uzum
console.log(mevalar.length);              // 4    — elementlar soni
console.log(mevalar[mevalar.length - 1]); // anor — OXIRGI element
console.log(mevalar[10]);                 // undefined — bunday element yo'q

mevalar[1] = "shaftoli";                  // elementni o'zgartirish
console.log(mevalar);

const aralash = [14, "Ali", true, null];  // turli turlar ham bo'lishi mumkin

Massiv metodlari

Qo'shish va o'chirish

const navbat = ["Ali", "Vali"];

navbat.push("Gani");        // OXIRIGA qo'shish    → ["Ali", "Vali", "Gani"]
navbat.unshift("Sobir");    // BOSHIGA qo'shish    → ["Sobir", "Ali", "Vali", "Gani"]
console.log(navbat);

const oxirgi = navbat.pop();      // OXIRIDAN olish   → "Gani"
const birinchi = navbat.shift();  // BOSHIDAN olish   → "Sobir"
console.log(oxirgi, birinchi, navbat);   // Gani Sobir ["Ali", "Vali"]

// splice — o'rtadan o'chirish: (qaysi indeksdan, nechta)
const sonlar = [10, 20, 30, 40, 50];
sonlar.splice(1, 2);        // 1-indeksdan 2 ta element o'chdi
console.log(sonlar);        // [10, 40, 50]

const fanlar = ["matematika", "fizika", "informatika", "tarix"];

console.log(fanlar.includes("fizika"));      // true  — bormi?
console.log(fanlar.indexOf("informatika"));  // 2     — qaysi indeksda?

const sonlar = [5, 1, 10, 3];

Sonlarni sort() bilan qavssiz saralasangiz, ular matn sifatida saralanadi: [5, 1, 10, 3].sort() → [1, 10, 3, 5] 😱. Sonlar uchun doim sort((a, b) => a - b) yozing (kamayish tartibi uchun b - a).

const ballar = [85, 92, 78, 95, 60];

Kuchli massiv metodlari

Bu metodlar professional JavaScript'ning yuragi. Ular asl massivni o'zgartirmaydi — yangi natija qaytaradi.

MetodSavolNatija
map"Har birini qanday o'zgartiray?"Xuddi shuncha elementli yangi massiv
filter"Qaysilari shartga mos?"Faqat mos kelganlardan iborat massiv
find"Shartga mos birinchisi qaysi?"Bitta element (yoki undefined)
some / every"Kamida bittasi / hammasi mosmi?"true / false

O'xshatish: mevalar savati map — har bir mevani to'g'rash (5 meva → 5 to'g'ralgan meva). filter — faqat pishganlarini tanlab olish. find — birinchi uchragan olmani olish. reduce — hammasidan bitta sharbat tayyorlash.
const narxlar = [12000, 45000, 8000, 30000];

const chegirmali = narxlar.map(n => n * 0.9);          // har biriga 10% chegirma
console.log(chegirmali);                               // [10800, 40500, 7200, 27000]

const arzonlar = narxlar.filter(n => n < 20000);       // 20 000 dan arzonlari
console.log(arzonlar);                                 // [12000, 8000]

const birinchiQimmat = narxlar.find(n => n > 25000);
console.log(birinchiQimmat);                           // 45000

console.log(narxlar.some(n => n > 40000));             // true — kamida bittasi
console.log(narxlar.every(n => n > 5000));             // true — hammasi

const jami = narxlar.reduce((yigindi, n) => yigindi + n, 0);   // 0 — boshlang'ich qiymat
console.log(jami);                                     // 95000

Obyektlar

Massiv — ko'p bir xil narsalar ro'yxati. Obyekt esa bitta narsaning turli xususiyatlarini nomlari bilan saqlaydi.

O'xshatish: o'quvchi anketasi Anketada: "Ism: Dilnoza", "Yosh: 14", "Sinf: 8-A", "To'garak: shaxmat". Har bir qator — kalit: qiymat jufti. Obyekt — aynan shunday anketa.
const oquvchi = {
  ism: "Dilnoza",          // kalit (xossa nomi): qiymat
  yosh: 14,
  sinf: "8-A",
  alochi: true,
  fanlar: ["matematika", "ingliz tili"],    // qiymat massiv ham bo'lishi mumkin
};

// Xossani o'qish — ikki usul
console.log(oquvchi.ism);          // nuqta orqali — ko'p ishlatiladi
console.log(oquvchi["sinf"]);      // kvadrat qavs orqali

// O'zgartirish, qo'shish, o'chirish
oquvchi.yosh = 15;
oquvchi.shahar = "Namangan";        // yangi xossa
delete oquvchi.alochi;
console.log(oquvchi);

// Barcha kalitlar va qiymatlar
console.log(Object.keys(oquvchi));
console.log(Object.values(oquvchi));
for (const kalit in oquvchi) {
  console.log(`${kalit}: ${oquvchi[kalit]}`);
}

Metodlar — obyekt ichidagi funksiyalar

const hisob = {
  egasi: "Jasur",
  balans: 50000,
  toldirish(summa) {
    this.balans += summa;            // this — "shu obyektning o'zi"
    console.log(`+${summa}. Balans: ${this.balans}`);
  },
  yechish(summa) {
    if (summa > this.balans) {
      console.log("❌ Mablag' yetarli emas");
      return;
    }
    this.balans -= summa;
    console.log(`-${summa}. Balans: ${this.balans}`);
  },
};

hisob.toldirish(20000);
hisob.yechish(100000);
hisob.yechish(30000);

Obyektlar massivi — real ma'lumotlar

Haqiqiy dasturlarda ma'lumotlar deyarli doim shunday ko'rinishda bo'ladi: mahsulotlar ro'yxati, o'quvchilar ro'yxati, xabarlar ro'yxati. Serverdan keladigan ma'lumot ham (JSON, 39-mavzu) aynan shunday tuzilgan.

const mahsulotlar = [
  { nomi: "Daftar", narx: 5000, soni: 120, toifa: "kanselyariya" },
  { nomi: "Ruchka", narx: 3000, soni: 0, toifa: "kanselyariya" },
  { nomi: "Ryukzak", narx: 180000, soni: 7, toifa: "sumka" },
  { nomi: "Kalkulyator", narx: 95000, soni: 15, toifa: "texnika" },
];

// Omborda bor mahsulotlar nomlari
const mavjud = mahsulotlar.filter(m => m.soni > 0).map(m => m.nomi);
console.log("Mavjud:", mavjud);

// Nomi bo'yicha qidirish
const topilgan = mahsulotlar.find(m => m.nomi === "Ryukzak");
console.log(topilgan.narx);

// Ombordagi umumiy qiymat
const omborQiymati = mahsulotlar.reduce((jami, m) => jami + m.narx * m.soni, 0);
console.log(`Ombor qiymati: ${omborQiymati.toLocaleString()} so'm`);

// Narx bo'yicha saralash (qimmatdan arzonga)
const saralangan = [...mahsulotlar].sort((a, b) => b.narx - a.narx);
saralangan.forEach(m => console.log(`${m.nomi}: ${m.narx} so'm`));

Amaliy mashg'ulot: o'quvchilar bahosini hisoblovchi dastur (14-loyiha)

const oquvchilar = [
  { ism: "Akmal", ballar: [92, 85, 78] },
  { ism: "Barno", ballar: [67, 88, 95] },
  { ism: "Davron", ballar: [45, 52, 60] },
  { ism: "Gulnoza", ballar: [98, 94, 91] },
  { ism: "Erkin", ballar: [73, 39, 70] },
];

// 1. Yordamchi funksiyalar
const ortacha = (sonlar) => sonlar.reduce((a, b) => a + b, 0) / sonlar.length;

function baho(ball) {
  if (ball >= 86) return 5;
  if (ball >= 71) return 4;
  if (ball >= 56) return 3;
  return 2;
}

// 2. Har bir o'quvchi uchun natija
const natijalar = oquvchilar.map(o => {
  const ort = Math.round(ortacha(o.ballar));
  return { ism: o.ism, ortacha: ort, baho: baho(ort) };
});

// 3. Reyting (o'rtacha ball bo'yicha)
natijalar.sort((a, b) => b.ortacha - a.ortacha);

console.log("🏆 REYTING");
natijalar.forEach((n, i) => {
  console.log(`${i + 1}. ${n.ism} — ${n.ortacha} ball, baho: ${n.baho}`);
});

// 4. Statistika
const alochilar = natijalar.filter(n => n.baho === 5).map(n => n.ism);
const sinfOrtachasi = ortacha(natijalar.map(n => n.ortacha));
console.log(`\nA'lochilar: ${alochilar.join(", ") || "yo'q"}`);
console.log(`Sinf o'rtachasi: ${sinfOrtachasi.toFixed(1)}`);
console.log(`Qoniqarsiz baho olganlar: ${natijalar.filter(n => n.baho === 2).length} nafar`);

Topshiriqlar:

  1. Har bir o'quvchiga 4-fan bahosi qo'shing va natijani qayta hisoblang.
  2. Eng past ball olgan o'quvchini reduce yoki saralash bilan toping.
  3. "Yangi o'quvchi qo'shish" funksiyasini yozing: qosh(ism, ballar) u push qilsin.
  4. Ismi bo'yicha qidirish funksiyasi: izla("barno") — katta-kichik harfga e'tibor bermasin.

Ko'p uchraydigan xatolar

  • ❌ Indeks 1 dan boshlanadi deb o'ylash: arr[1] — bu ikkinchi element!
  • ❌ Oxirgi elementga arr[arr.length] deb murojaat — to'g'risi arr[arr.length - 1].
  • ❌ map ichida return ni unutish (jingalak qavs bilan yozilganda) — natija [undefined, undefined...].
  • ❌ Obyekt xossasi nomidagi xato: oquvchi.Ism — undefined, chunki kalit ism.
  • ❌ reduce da boshlang'ich qiymatni (, 0) unutish.

O'zingizni tekshiring

const a = [10, 20, 30]; — a[1] nimaga teng?

  1. 10
  2. 20
  3. 30
  4. undefined

Massiv oxiriga element qo'shuvchi metod?

  1. push()
  2. pop()
  3. shift()
  4. add()

[1, 2, 3, 4].filter(x => x % 2 === 0) natijasi?

  1. [1, 3]
  2. [2, 4, 6, 8]
  3. [2, 4]
  4. 2

[1, 2, 3].map(x => x * 10) natijasi?

  1. 60
  2. [1, 2, 3]
  3. 30
  4. [10, 20, 30]

const k = { ism: "Ali", yosh: 14 }; — yoshni o'qishning to'g'ri usuli?

  1. k[yosh]
  2. k.yosh
  3. k(yosh)
  4. k->yosh

k["yosh"] ham to'g'ri — qo'shtirnoq bilan.

Massivdagi barcha sonlar yig'indisini bitta qiymatga yig'uvchi metod?

  1. map
  2. find
  3. reduce
  4. join

🏠 Uyga vazifa

  1. Kitoblar javoni: 6 ta kitobdan iborat obyektlar massivi (nomi, muallif, yil, sahifalar, o'qilganmi). Chiqaring: o'qilmagan kitoblar, eng qalin kitob, 2000-yildan keyin chiqqanlar, umumiy sahifalar soni.
  2. Takrorlarni olib tashlash: [1, 2, 2, 3, 1, 4] → [1, 2, 3, 4] (filter + indexOf yoki new Set()).
  3. So'zlar statistikasi: gapni so'zlarga ajratib (split(" ")), eng uzun so'zni va so'zlar sonini toping.

✅ Yodda tuting

  • Massiv: [a, b, c], indeks 0 dan; length, push/pop/shift/unshift, includes, indexOf, sort((a,b)=>a-b).
  • Aylanish: for, for...of, forEach.
  • map — o'zgartirish, filter — tanlash, find — birinchisi, reduce — yig'ish.
  • Obyekt: { kalit: qiymat }; obj.kalit yoki obj["kalit"]; metodlarda this.
  • Obyektlar massivi — real dasturlardagi ma'lumotlarning asosiy shakli.
