CSS nima?

CSS (Cascading Style Sheets) — "kaskadli uslublar jadvali". HTML sahifaning tuzilishini yaratsa, CSS uning ko'rinishini belgilaydi: ranglar, shriftlar, o'lchamlar, joylashuv, animatsiyalar.

O'xshatish HTML — odamning skeleti va tanasi. CSS — kiyimi, soch turmagi, rangi. Bir odam turli kiyimda butunlay boshqacha ko'rinadi — xuddi shunday, bitta HTML sahifa turli CSS bilan butunlay boshqacha ko'rinadi. Buni CSS Zen Garden saytida o'zingiz ko'ring: HTML bir xil, faqat CSS fayl almashadi!

CSS qoidasining tuzilishi

h1 {
  color: blue;
  font-size: 32px;
}
/*
 h1             — selektor: QAYSI elementlarga
 { ... }        — deklaratsiyalar bloki
 color          — xossa (property): NIMANI o'zgartiramiz
 blue           — qiymat (value): QANDAY qilib
 color: blue;   — bitta deklaratsiya. Oxirida nuqta-vergul (;) majburiy!
*/
CSS'da izohlar /* ... */ ko'rinishida yoziladi (HTML'dagi <!-- --> emas).

Kaskad: qaysi qoida g'olib?

Bir elementga bir nechta qoida to'g'ri kelsa, brauzer quyidagi tartibda hal qiladi:

  1. Aniqlik (spetsifiklik) — aniqroq selektor yutadi: inline > id > class > teg.
  2. Tartib — aniqlik teng bo'lsa, keyinroq yozilgan qoida yutadi.



Men qizilman (ikkala teg qoidasidan keyingisi yutdi)


Men yashilman (class tegdan kuchli)


Men to'q sariqman (id class'dan kuchli)


Men binafshaman (inline eng kuchli)
O'xshatish: ko'rsatmalar Direktor (inline) "Ali, sen bugun navbatchisan" desa, bu sinf rahbari (id) yoki sinf sardori (class) aytganidan ustun. Umumiy maktab qoidasi (teg) esa eng kuchsiz — maxsus ko'rsatma bo'lmagandagina amal qiladi.

Meros (inheritance)

Ba'zi xossalar (asosan matnga oid: color, font-family, font-size) ota elementdan ichidagi elementlarga meros bo'lib o'tadi. Shuning uchun shriftni bir marta body ga berish kifoya — butun sahifaga tarqaladi.

Shriftlar

body {
  font-family: "Segoe UI", Arial, sans-serif;  /* birinchisi bo'lmasa — keyingisi (zaxira) */
  font-size: 16px;                             /* shrift o'lchami */
  font-weight: 400;                            /* qalinlik: 100..900 (400 = normal, 700 = bold) */
  font-style: normal;                          /* normal | italic */
  line-height: 1.6;                            /* o'qish uchun qulay qator oralig'i */
}
h1 {
  font-family: Georgia, "Times New Roman", serif;
  font-weight: 700;
}

Shrift oilalari:

  • serif — harflarida "oyoqchalari" bor (Times New Roman, Georgia). Kitob uslubi.
  • sans-serif — oyoqchasiz, zamonaviy (Arial, Roboto). Ekranda o'qish uchun qulay.
  • monospace — har bir harf bir xil kenglikda (Courier). Dastur kodi uchun.

Ro'yxat oxiriga doim umumiy oilani (sans-serif) yozing — agar foydalanuvchi kompyuterida birorta shrift bo'lmasa, brauzer shu oiladan biror shriftni tanlaydi.

Google Fonts — bepul chiroyli shriftlar

  1. fonts.google.com saytiga kiring va shrift tanlang (masalan, Montserrat). O'zbekcha harflar uchun Latin Extendedni qo'llab-quvvatlaydiganini tanlang.
  2. "Get font" → "Get embed code" bosing va <link> kodini nusxalang.
  3. Uni HTML'ning <head> qismiga, o'z CSS faylingizdan oldin qo'ying:
  4. CSS'da ishlating: body { font-family: "Montserrat", sans-serif; }

O'lcham birliklari (qisqacha)

  • px — piksel, aniq o'lcham.
  • em — ota element shrift o'lchamiga nisbatan (2em = 2 barobar).
  • rem — sahifaning asosiy shrifti (odatda 16px) ga nisbatan: 1.5rem = 24px. Shriftlar uchun tavsiya etiladi.
  • % — ota elementga nisbatan foiz.

Batafsil 8-mavzuda.

Amaliy mashg'ulot: vizitka saytiga dizayn

  1. vizitka/ papkasida css/style.css faylini yarating.
  2. Har bir HTML sahifaning <head> qismiga ulang: <link rel="stylesheet" href="css/style.css"> (ichki papkadagi sahifalarda — ../css/style.css!).
  3. Google Fonts'dan ikkita shrift ulang: sarlavhalar uchun bittasi, matn uchun boshqasi.

Ko'p uchraydigan xatolar

  • ❌ Nuqta-vergulni unutish: color: red font-size: 20px; — ikkala xossa ham ishlamaydi.
  • ❌ Class selektorida nuqtani unutish: muhim { } o'rniga .muhim { }.
  • ❌ HTML'da class=".muhim" deb yozish — HTML'da nuqtasiz: class="muhim".
  • ❌ CSS fayl yo'li noto'g'ri — F12 → Console'da "404 style.css" xatosini ko'rasiz.
  • ❌ Xossa nomida xato: colour, font-colour, text-color — to'g'risi color.

O'zingizni tekshiring

Butun saytga bitta dizayn berishning eng to'g'ri usuli qaysi?

  1. Inline CSS
  2. Internal CSS
  3. External CSS (alohida .css fayl)
  4. Har sahifaga <style>

Bitta fayl — barcha sahifalar. O'zgartirish oson va brauzer faylni keshlaydi.

class="karta" bo'lgan elementlarni tanlovchi selektor qaysi?

  1. #karta
  2. .karta
  3. karta
  4. *karta

Nuqta — class, panjara — id.

<p class="a" id="b"> uchun p {color:red}, .a {color:green}, #b {color:blue} yozilgan. Matn qanday rangda?

  1. Qizil
  2. Yashil
  3. Qora
  4. Ko'k

ID selektori class va tegdan kuchliroq.

nav a selektori nimani tanlaydi?

  1. nav ichidagi barcha havolalarni
  2. nav va barcha a larni
  3. Faqat birinchi havolani
  4. a ichidagi nav ni

Bo'sh joy — "ichidagi" (avlod) selektori. Vergul esa "va" (guruh) bo'lardi.

Matnni markazga tekislovchi xossa qaysi?

  1. align: center
  2. font-align: center
  3. text-align: center
  4. center: true

font-family: "Roboto", Arial, sans-serif; — agar kompyuterda Roboto bo'lmasa?

  1. Matn ko'rinmaydi
  2. Arial ishlatiladi
  3. Xato chiqadi
  4. Times New Roman ishlatiladi

🏠 Uyga vazifa

  1. CSS Diner o'yinida kamida 12-darajagacha o'ting (selektorlarni o'yin orqali mashq qilish).
  2. Vizitka saytingiz uchun 4–5 rangdan iborat palitra tanlang (coolors.co) va barcha sahifalarga qo'llang.
  3. 5-mavzudagi "Sinfimiz gazetasi" sahifasiga gazeta uslubida dizayn bering: serif shrift, markazdagi katta sarlavha, ustunlar orasida chiziq.

✅ Yodda tuting

  • Qoida: selektor { xossa: qiymat; }.
  • External CSS (<link rel="stylesheet" href="style.css">) — asosiy usul.
  • Selektorlar: teg, .class, #id, *, a, b (guruh), a b (ichidagi), a > b (bevosita farzand).
  • Ustuvorlik: inline > id > class > teg; teng bo'lsa — keyingisi yutadi.
  • Matn: color, text-align, text-decoration, line-height; shrift: font-family, font-size, font-weight.
