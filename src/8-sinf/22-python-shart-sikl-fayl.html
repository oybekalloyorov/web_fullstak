Chekinish (indentatsiya) — Python'ning eng muhim qoidasi

JavaScript'da kod bloklari { } bilan belgilanadi. Python'da esa ikki nuqta : va undan keyingi qatorlarning 4 ta bo'sh joy bilan ichkariga surilishi bilan.

yosh = 15
if yosh >= 14:
    print("Pasport olish mumkin")      # ← if ichida (4 bo'sh joy)
    print("Tabriklaymiz!")             # ← if ichida
print("Bu har doim chiqadi")           # ← if TASHQARISIDA (chekinishsiz)
IndentationError Chekinish noto'g'ri bo'lsa, Python ishlamaydi: IndentationError: expected an indented block. Bitta faylda bo'sh joy va Tab'ni aralashtirmang. VS Code Tab bosganda avtomatik 4 bo'sh joy qo'yadi.
O'xshatish: kitob mundarijasi Mundarijada bo'lim nomlari chapda, ularning ichidagi kichik bo'limlar esa o'ngroqqa surilgan. Qaysi kichik bo'lim qaysi bo'limga tegishli ekanini siljishdan bilasiz. Python ham kod "ierarxiyasini" xuddi shunday — siljish orqali tushunadi.

Fayllar bilan ishlash

O'zgaruvchilardagi ma'lumot dastur yopilganda yo'qoladi. Uni saqlab qolish uchun faylga yozish kerak (keyinroq — ma'lumotlar bazasiga).

Faylga yozish

with open("eslatma.txt", "w", encoding="utf-8") as f:
    f.write("Birinchi qator\n")         # \n — yangi qatorga o'tish
    f.write("Ikkinchi qator\n")
print("Fayl yaratildi!")
  • open(fayl_nomi, rejim, encoding) — faylni ochadi.
  • with ... as f: — ish tugagach faylni avtomatik yopadi (yopilmagan fayl ma'lumot yo'qolishiga olib kelishi mumkin).
  • encoding="utf-8" — o'zbekcha harflar (o', g') va emoji to'g'ri saqlanishi uchun. Doim yozing!

Amaliy mashg'ulot: Python kalkulyatori (15-loyiha)

from datetime import datetime

TARIX_FAYLI = "tarix.txt"

def son_sora(matn):
    """To'g'ri son kiritilmaguncha so'raydi."""
    while True:
        try:
            return float(input(matn))
        except ValueError:
            print("  ⚠️ Iltimos, son kiriting (masalan: 12 yoki 3.5)")

print("=" * 32)
print("   🧮 PYTHON KALKULYATORI")
print("=" * 32)

while True:
    a = son_sora("Birinchi son: ")
    amal = input("Amal (+ - * / // % **): ").strip()
    b = son_sora("Ikkinchi son: ")

    if amal == "+":
        natija = a + b
    elif amal == "-":
        natija = a - b
    elif amal == "*":
        natija = a * b
    elif amal in ("/", "//", "%"):
        if b == 0:
            print("❌ Nolga bo'lib bo'lmaydi!")
            continue
        natija = a / b if amal == "/" else a // b if amal == "//" else a % b
    elif amal == "**":
        natija = a ** b
    else:
        print("❌ Noma'lum amal")
        continue

    # 5.0 o'rniga 5 ko'rinsin
    if natija == int(natija):
        natija = int(natija)
    yozuv = f"{a:g} {amal} {b:g} = {natija}"
    print("✅", yozuv)

    with open(TARIX_FAYLI, "a", encoding="utf-8") as f:
        f.write(f"[{datetime.now():%Y-%m-%d %H:%M}] {yozuv}\n")

    javob = input("Davom etamizmi? (ha/yo'q/tarix): ").strip().lower()
    if javob == "tarix":
        with open(TARIX_FAYLI, encoding="utf-8") as f:
            print(f.read())
    elif javob != "ha":
        print("Xayr! 👋")
        break

Topshiriqlar:

  1. Kalkulyatorni ishga tushiring va har bir amalni sinab ko'ring, xato kiritishlarni ham.
  2. Yangi amallar qo'shing: sqrt (ildiz, bitta son bilan) va %% (foizini hisoblash: a ning b foizi).
  3. "tarix" buyrug'i faqat oxirgi 5 ta yozuvni ko'rsatsin (readlines()[-5:]).
  4. .txt fayl kompyuterda qayerda yaratilganini toping va oddiy Bloknot bilan oching.

Ko'p uchraydigan xatolar

  • ❌ if, for, while qatori oxirida : unutilgan → SyntaxError.
  • ❌ else if deb yozish — Python'da elif.
  • ❌ range(1, 10) 10 ni ham beradi deb o'ylash — oxirgi son kirmaydi.
  • ❌ "w" rejimida ochib, muhim faylni o'chirib yuborish. Qo'shish uchun "a".
  • ❌ encoding="utf-8" siz o'zbekcha matn — Windows'da g'alati belgilar chiqadi.

O'zingizni tekshiring

JS'dagi else if Python'da qanday yoziladi?

  1. else if
  2. elseif
  3. elif
  4. orif

list(range(2, 8, 2)) qanday sonlarni beradi?

  1. 2, 4, 6, 8
  2. 2, 4, 6

  4. 8, 6, 4, 2

Python kod bloklarini qanday belgilaydi?

  1. Jingalak qavslar {}
  2. begin / end so'zlari
  3. Nuqta-vergul
  4. Ikki nuqta va chekinish (bo'sh joylar)

Fayl mazmunini o'chirmasdan, oxiriga yozish rejimi?

  1. "a"
  2. "w"
  3. "r"
  4. "x"

int("abc") qanday xato beradi?

  1. ZeroDivisionError
  2. IndentationError
  3. ValueError
  4. TypeError

with open(...) ning afzalligi nimada?

  1. Faylni tezroq o'qiydi
  2. Ish tugagach faylni avtomatik yopadi
  3. Faylni shifrlaydi
  4. Faylni o'chiradi

✅ Yodda tuting

  • if / elif / else: — oxirida ikki nuqta, ichidagi kod 4 bo'sh joy surilgan.
  • for i in range(boshi, oxiri, qadam): — oxiri kirmaydi; while shart:; break, continue.
  • try: ... except ValueError: ... — xatolarni ushlab, dasturni "yiqilish"dan saqlash.
  • with open("f.txt", "r/w/a", encoding="utf-8") as f: — read(), write(), readlines().
