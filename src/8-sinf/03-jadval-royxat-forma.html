Tanlash ro'yxati va katta matn maydoni
  • <select> — ochiladigan ro'yxat; har bir variant <option>. Serverga value qiymati yuboriladi, foydalanuvchi esa teg ichidagi matnni ko'radi.
  • <textarea> — ko'p qatorli matn (izoh, xat). rows — balandlik (qatorlarda), cols — kenglik.
  • <button type="submit"> — formani yuboradi; type="reset" — barcha maydonlarni tozalaydi.

Brauzer tekshiruvi (validatsiya)

Brauzer ba'zi tekshiruvlarni o'zi bajaradi va xato bo'lsa formani yubormaydi:

  • required — bo'sh bo'lmasin;
  • minlength="8", maxlength="20" — matn uzunligi;
  • min, max — son yoki sana chegarasi;
  • type="email" — email formati.
Bu tekshiruvlar faqat foydalanuvchiga qulaylik uchun. Ayyor foydalanuvchi ularni chetlab o'tishi mumkin, shuning uchun ma'lumotlar serverda ham tekshiriladi (37-mavzu, Django Forms).

Ko'p uchraydigan xatolar

  • ❌ <li> ni ul/ol siz yozish — ro'yxat bandi doim ro'yxat ichida bo'ladi.
  • ❌ Radio tugmalarga turli name berish — hammasini birdaniga belgilash mumkin bo'lib qoladi.
  • ❌ <label for="..."> dagi qiymat input'ning idsiga mos kelmasligi.
  • ❌ Input'da name yo'qligi — ma'lumot serverga bormaydi.
  • ❌ Jadvalda <td> ni <tr> siz to'g'ridan-to'g'ri <table> ichiga yozish.

O'zingizni tekshiring

Retsept qadamlari uchun qaysi ro'yxat mos?

  1. <ul>
  2. <ol>
  3. <dl>
  4. <table>

Qadamlar tartibi muhim — shuning uchun tartibli ro'yxat (ol).

Jadvalda yangi qator qaysi teg bilan boshlanadi?

  1. <td>
  2. <th>
  3. <tr>
  4. <row>

tr = table row. Kataklar (td/th) uning ichida.

Katakni ikki ustun kengligida birlashtirish uchun qaysi atribut kerak?

  1. colspan="2"
  2. rowspan="2"
  3. span="2"
  4. width="2"

col = ustun (gorizontal), row = qator (vertikal).

"Jinsingiz" savoliga faqat bitta javob tanlash uchun qaysi input turi kerak?

  1. checkbox
  2. text
  3. select multiple
  4. radio

Radio — bir guruhdan bitta tanlov. Guruhdagi barcha radiolarning namei bir xil bo'lishi kerak.

Forma ma'lumoti serverga qaysi atribut nomi bilan boradi?

  1. id
  2. name
  3. placeholder
  4. class

Server name=qiymat juftliklarini oladi. id esa label va CSS uchun.

Parol yuboradigan forma uchun qaysi method to'g'ri?

  1. GET
  2. SEND
  3. POST
  4. PUT

GET'da ma'lumot manzil satrida ochiq ko'rinadi va brauzer tarixida saqlanadi.

🏠 Uyga vazifa

  1. O'z sinfingizning to'liq haftalik dars jadvalini HTML jadval sifatida yarating (caption, thead, tanaffuslar uchun colspan).
  2. 2-mavzudagi retsept sahifangizni yangilang: masalliqlarni ul, tayyorlash bosqichlarini ol bilan yozing.
  3. "Kutubxonaga a'zo bo'lish" formasini yarating: ism, tug'ilgan sana, email, sevimli janr (select), qaysi tillarda o'qiydi (checkbox), izoh (textarea).

✅ Yodda tuting

  • ul — tartibsiz, ol — tartibli ro'yxat; bandlar li.
  • Jadval: table → tr (qator) → td/th (katak); colspan — gorizontal, rowspan — vertikal birlashtirish.
  • Forma: action (qayerga), method (GET/POST), har bir maydonda name va label.
  • radio — bitta tanlov (bir xil name), checkbox — bir nechta, select — ro'yxatdan, textarea — ko'p qatorli matn.
