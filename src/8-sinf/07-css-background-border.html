cover va contain farqi







cover (chapda): butun qutini to'ldiradi, ortiqcha qismi kesiladi.

contain (o'ngda): rasm to'liq ko'rinadi, lekin bo'sh joy qolishi mumkin.
O'xshatish cover — telefonga devor qog'ozi (oboy) qo'yish: ekran to'ladi, rasmning chetlari kesiladi. contain — rasmni ramkaga qo'yish: rasm butunligicha ko'rinadi, lekin atrofida bo'sh joy qoladi.
Fon rasmi yo'li url() ichidagi yo'l CSS faylga nisbatan hisoblanadi. Agar CSS css/style.css da, rasm rasmlar/fon.jpg da bo'lsa: url("../rasmlar/fon.jpg").

Qisqa yozuv (shorthand)

/* Uzun yozuv */
.banner {
  background-color: #1e293b;
  background-image: url("fon.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
/* Qisqa yozuv — hammasi bitta qatorda (size "/" belgisidan keyin) */
.banner {
  background: #1e293b url("fon.jpg") no-repeat center / cover;
}

Ko'p uchraydigan xatolar

  • ❌ Fon rasmi ko'rinmayapti — url() dagi yo'l CSS faylga nisbatan emas, HTML'ga nisbatan yozilgan. Yoki elementning balandligi 0 (ichida mazmun yo'q va height berilmagan).
  • ❌ border: 2px red; — uslub (solid) unutilgan, chegara ko'rinmaydi.
  • ❌ Doira chiqmayapti — width va height teng emas, natijada oval bo'ladi.
  • ❌ Juda qora, qattiq soya (box-shadow: 5px 5px 0 black) — zamonaviy dizaynda yumshoq, shaffof soyalar ishlatiladi.

O'zingizni tekshiring

Fon rasmi butun maydonni to'ldirishi (ortig'i kesilishi) uchun qaysi qiymat kerak?

  1. background-size: contain
  2. background-size: cover
  3. background-repeat: repeat
  4. background-position: fill

border: 3px ____ blue; — bo'sh joyga nima yozilsa shtrixli chiziq bo'ladi?

  1. solid
  2. dotted
  3. double
  4. dashed

Kvadrat rasmni doiraga aylantirish uchun nima kerak?

  1. border-radius: 50%
  2. border: circle
  3. shape: round
  4. border-radius: 10px

margin: 10px 20px 30px 40px; da chap tomon necha piksel?

  1. 10px
  2. 20px
  3. 40px
  4. 30px

Tartib: tepa (10) → o'ng (20) → past (30) → chap (40).

box-shadow: 0 10px 20px rgba(0,0,0,.2) da 20px nima?

  1. O'ngga siljish
  2. Xiralik (blur)
  3. Pastga siljish
  4. Soya rangi

🏠 Uyga vazifa

  1. Vizitka saytingiz bosh sahifasiga gradient ustidagi fon rasmli "banner" qo'shing (ismingiz va qisqa shiorga).
  2. Sinfdoshlaringizdan 3 nafari uchun o'quvchi kartochkalarini yarating (har biri boshqa rang sxemasida).
  3. cssgradient.io saytida o'z gradientingizni yarating va ishlating.

✅ Yodda tuting

  • Fon: background-color, background-image: url(), -repeat, -position, -size: cover/contain; qisqasi — background.
  • Gradient: linear-gradient(yo'nalish, rang1, rang2), radial-gradient().
  • Chegara: border: qalinlik uslub rang; tomonlar tartibi — tepa, o'ng, past, chap.
  • border-radius — yumaloq burchak (50% = doira); box-shadow — soya.
