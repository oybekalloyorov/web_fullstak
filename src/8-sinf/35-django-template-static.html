Template nima?

34-mavzuda HTML'ni Python satri ichida yozdik — noqulay va xavfli. Template (shablon) — oddiy HTML fayl, lekin unda "bo'sh joylar" bor, ularni Django ma'lumot bilan to'ldiradi.

O'xshatish: tabriknoma shabloni Do'konda tayyor tabriknoma: "Hurmatli ________, sizni ________ bilan tabriklaymiz!" Siz faqat bo'sh joylarni to'ldirasiz. Shablon bir xil, ism va sabab har safar boshqa. Django template ham shunday: <h1>{{ sarlavha }}</h1> — har bir maqola uchun o'z sarlavhasi qo'yiladi.

Shablonlar papkasi va render()

  1. Papkalar tuzilmasini yarating (ilova nomini ikki marta takrorlash — nomlar to'qnashmasligi uchun Django an'anasi): 
    blog/
└── templates/
    └── blog/
        ├── bosh_sahifa.html
        └── maqola.html
  2. View'da render ishlating: 
    from django.shortcuts import render
from django.http import Http404

MAQOLALAR = [ ... ]   # 34-mavzudagi ro'yxat

def bosh_sahifa(request):
    kontekst = {                                  # shablonga yuboriladigan ma'lumotlar (dict)
        "sarlavha": "Maktab blogi",
        "maqolalar": MAQOLALAR,
    }
    return render(request, "blog/bosh_sahifa.html", kontekst)

def maqola(request, id):
    for m in MAQOLALAR:
        if m["id"] == id:
            return render(request, "blog/maqola.html", {"maqola": m})
    raise Http404("Maqola topilmadi")

render(request, shablon_yo'li, kontekst) — shablonni topadi, kontekstdagi ma'lumotlar bilan to'ldiradi va tayyor HTML javob qaytaradi.

Amaliy mashg'ulot

  1. base.html, bosh_sahifa.html, _karta.html, maqola.html shablonlarini yarating va view'larni render ga o'tkazing.
  2. Static papkada style.css yarating va ulang. Sahifa 8-mavzudagi portfolio kabi chiroyli ko'rinishiga erishing.
  3. haqida.html sahifasini base.html dan meros olib yarating.
  4. main.js da kichik interaktivlik qo'shing: "🌙" tugmasi bosilganda tungi rejim (19-mavzu).
  5. Kategoriya sahifasini (kategoriya.html) yarating: sarlavha {{ nomi|title }} va shu kategoriyadagi maqolalar (_karta.html ni include qilib).
  6. Bosh sahifada maqolalar sonini ko'rsating va oxirgi kartadan keyin chiziq chizilmasin (forloop.last).

Ko'p uchraydigan xatolar

  • ❌ TemplateDoesNotExist — shablon yo'li noto'g'ri yoki papka nomi template (s harfisiz). To'g'risi: blog/templates/blog/fayl.html.
  • ❌ Invalid block tag 'static' — shablon boshida {% load static %} yo'q.
  • ❌ {% endfor %}, {% endif %}, {% endblock %} ni unutish — TemplateSyntaxError.
  • ❌ {% extends %} birinchi qatorda emas.
  • ❌ {{ maqola[sarlavha] }} — DTL'da kvadrat qavs yo'q, faqat nuqta: {{ maqola.sarlavha }}.

O'zingizni tekshiring

Shablonda o'zgaruvchi qiymatini chiqarish sintaksisi?

  1. {% ism %}
  2. {{ ism }}
  3. ${ism}
  4. <?= ism ?>

View'dan shablonga ma'lumot qanday uzatiladi?

  1. Global o'zgaruvchi orqali
  2. URL orqali
  3. render(request, "shablon.html", kontekst_dict)
  4. localStorage orqali

Umumiy skeletdan meros olish uchun qaysi teg?

  1. {% extends "base.html" %}
  2. {% include "base.html" %}
  3. {% import base %}
  4. {% inherit base %}

Shablonda CSS faylni to'g'ri ulash?

  1. href="style.css"
  2. href="/blog/style.css"
  3. href="{{ static.css }}"
  4. href="{% static 'blog/css/style.css' %}"

{{ matn|truncatewords:10 }} nima qiladi?

  1. Matnni 10 marta takrorlaydi
  2. Matnning birinchi 10 so'zini ko'rsatadi
  3. 10 ta belgini o'chiradi
  4. Matnni 10 ga bo'ladi

Sikl ichida ro'yxat bo'sh bo'lgandagi holat uchun qaysi teg?

  1. {% else %}
  2. {% none %}
  3. {% empty %}
  4. {% null %}

🏠 Uyga vazifa

  1. Blog dizaynini to'liq responsiv qiling (10-mavzu): telefonda bitta ustun, burger menyu.
  2. Maxsus 404 sahifa: templates/404.html yarating (u DEBUG=False bo'lganda ko'rinadi — 41-mavzuda tekshiramiz).
  3. pages ilovasidagi sahifalarni ham umumiy base.html dan meros oladigan qiling (Maslahat: config/settings.py → TEMPLATES[0]["DIRS"] = [BASE_DIR / "templates"] va loyiha darajasidagi templates/base.html).

✅ Yodda tuting

  • Shablonlar: ilova/templates/ilova/*.html; view'da render(request, "ilova/fayl.html", {...}).
  • DTL: {{ o'zgaruvchi }}, {% teg %}, {{ x|filtr }}; {% if %}, {% for %}...{% empty %}, {% url 'app:nom' arg %}.
  • Meros: base.html da {% block content %}; bolada {% extends %} + {% block %}; bo'laklar — {% include %}.
  • Static: ilova/static/ilova/..., shablonda {% load static %} + {% static 'yo'l' %}.
  • Django matnni avtomatik ekranlaydi — XSS'dan himoya.
