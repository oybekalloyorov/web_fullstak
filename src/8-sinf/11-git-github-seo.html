Versiyalarni boshqarish nima?

Tanish vaziyat: referat.docx, referat_yangi.docx, referat_yangi_OXIRGI.docx, referat_yangi_OXIRGI_2.docx... Qaysi biri haqiqatan oxirgisi? Kecha nimani o'zgartirgan edingiz? Dasturchilar bu muammoni versiyalarni boshqarish tizimi bilan hal qiladi.

Git — eng mashhur versiyalarni boshqarish tizimi. U loyihangizning har bir saqlangan holatini ("surat"ini) eslab qoladi.

O'xshatish: o'yindagi saqlash nuqtalari Kompyuter o'yinlarida qiyin bosqichdan oldin "save" qilasiz. Yutqazsangiz — o'sha nuqtaga qaytasiz. Git'dagi commit — xuddi shunday saqlash nuqtasi. Har bir commit'ga izoh yozasiz ("Menyu qo'shildi") va istalgan paytda istalgan nuqtaga qaytishingiz mumkin.

Git nima beradi?

  • 📜 Loyihaning to'liq tarixi: kim, qachon, nimani o'zgartirgan.
  • ⏪ Xato qilsangiz — oldingi ishlaydigan holatga qaytish.
  • 👥 Jamoa bo'lib bitta loyihada bir vaqtda ishlash (13-mavzu).
  • ☁️ GitHub orqali kodni internetda saqlash — kompyuter buzilsa ham loyiha yo'qolmaydi.

Git'ni o'rnatish va sozlash

  1. git-scm.com dan yuklab, o'rnating (barcha sozlamalarni standart holda qoldiring).
  2. VS Code'da terminalni oching: Terminal → New Terminal (Ctrl+`).
  3. Tekshiring va o'zingizni tanishtiring (bir marta qilinadi): 
    git --version
git config --global user.name "Ismingiz Familiyangiz"
git config --global user.email "sizning@gmail.com"

Git'ning asosiy buyruqlari

Uchta hudud

📁 Ishchi papkasiz tahrirlayotgan fayllar
— git add →
📋 Staging (tayyorlash)"suratga" kiradiganlar
— git commit →
🗄️ Repozitoriyasaqlangan tarix
O'xshatish: guruh surati Ishchi papka — sinf xonasi, hamma o'z ishi bilan band. git add — suratga tushadiganlarni oldinga chaqirish. git commit — "chik!" — surat olindi va albomga (tarixga) qo'shildi.
# 1. Loyiha papkasida Git'ni ishga tushirish (bir marta)
git init

# 2. Holatni ko'rish: qaysi fayllar yangi, qaysilari o'zgargan
git status

# 3. Fayllarni "suratga" tayyorlash
git add index.html          # bitta fayl
git add .                   # barcha o'zgarishlar (nuqta = hammasi)

# 4. Saqlash nuqtasi (commit) yaratish — izoh bilan!
git commit -m "Bosh sahifa va menyu qo'shildi"

# 5. Tarixni ko'rish
git log --oneline
a3f9c2e Bosh sahifa va menyu qo'shildi
1b7d004 Loyiha boshlandi
Yaxshi commit izohi Nima qilinganini aniq yozing: "fix", "o'zgarish", "asdf" ❌ → "Aloqa sahifasiga forma qo'shildi", "Telefonda menyu xatosi tuzatildi" ✅. Kichik, mantiqiy qadamlar bilan tez-tez commit qiling.
VS Code'da chap paneldagi Source Control belgisi (shoxlangan chiziqlar) orqali ham xuddi shu ishlarni sichqoncha bilan qilish mumkin: "+" — add, matn yozib ✓ — commit.

GitHub'ga yuklash

  1. github.com da ro'yxatdan o'ting (foydalanuvchi nomini jiddiy tanlang — u portfoliongiz manzili bo'ladi).
  2. O'ng yuqoridagi + → New repository. Nom bering (masalan, portfolio), Public tanlang, "Add a README" belgisini qo'ymang → Create repository.
  3. GitHub ko'rsatgan buyruqlarni terminalda bajaring: 
    git branch -M main
git remote add origin https://github.com/USERNAME/portfolio.git
git push -u origin main
    Birinchi marta brauzer orqali GitHub'ga kirish so'raladi — ruxsat bering.
  4. GitHub sahifasini yangilang — fayllaringiz internetda! 🎉
  5. Keyingi o'zgarishlardan so'ng uchta buyruq yetarli: 
    git add .
git commit -m "Loyihalar bo'limi qo'shildi"
git push

Boshqa loyihani yuklab olish — clone

git clone https://github.com/USERNAME/portfolio.git
# Maktab kompyuteridan uyga: o'zgarishlarni olish
git pull
GitHub'ga nimani yuklamaslik kerak Parollar, shaxsiy ma'lumotlar, juda katta fayllar (videolar). Ochiq (public) repozitoriyani butun dunyo ko'radi.

Hosting: GitHub Pages

1-mavzuda hosting — sayt fayllari saqlanadigan server ekanini bildik. HTML/CSS/JS saytlar uchun GitHub Pages — bepul hosting:

  1. Repozitoriyada Settings → Pages bo'limiga kiring.
  2. Source: "Deploy from a branch", Branch: main, papka / (root) → Save.
  3. 1–2 daqiqadan so'ng saytingiz https://USERNAME.github.io/portfolio/ manzilida ochiladi. Havolani do'stlaringizga yuboring!

Muhim: bosh sahifa fayli index.html deb nomlangan bo'lishi kerak. 13-mavzuda Netlify va Vercel'ni ham o'rganamiz.

Amaliy mashg'ulot (6 va 7-loyihalar)

  1. Git'ni o'rnating va sozlang (user.name, user.email).
  2. 8-mavzudagi portfolio/ papkasini VS Code'da oching, terminalda git init.
  3. git status → git add . → git commit -m "Portfolio: birinchi versiya".
  4. GitHub'da portfolio repozitoriyasini yarating va push qiling.
  5. Biror o'zgarish kiriting (masalan, yangi loyiha kartasi), yana add → commit → push. GitHub'da commits tarixini oching.
  6. GitHub Pages'ni yoqing va saytingizni telefoningizdan oching.
  7. Barcha sahifalarga title va description qo'shing, Lighthouse bilan SEO ballini tekshiring va 90+ ga yetkazing.
  8. Repozitoriyaga README.md fayl qo'shing — loyiha haqida qisqacha: 
    # Mening portfoliom

Ko'p uchraydigan xatolar

  • ❌ git commit qilishdan oldin git add ni unutish — "nothing added to commit" xabari.
  • ❌ git init ni noto'g'ri papkada (masalan, butun "Ish stoli"da) bajarish. Doim loyiha papkasi ichida.
  • ❌ GitHub Pages'da sahifa ochilmayapti — bosh fayl index.html emas (masalan, Index.html yoki bosh.html).
  • ❌ Rasmlar GitHub Pages'da ko'rinmayapti — fayl nomida katta-kichik harf farqi (Logo.PNG ≠ logo.png).
