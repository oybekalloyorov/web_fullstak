🎯 Bu darsda nimani o'rganasiz

  • Arifmetik amallar va qoldiqli bo'lish (%);
  • Qiymatlarni taqqoslash va == bilan === farqini;
  • Mantiqiy operatorlar: VA (&&), YOKI (||), EMAS (!);
  • Dasturga "qaror qabul qildirish": if, else if, else, switch;
  • Baho hisoblovchi, parolni tekshiruvchi va boshqa amaliy dasturlarni.

Operator va ifoda

Operator — qiymatlar ustida amal bajaruvchi belgi (+, >, &&). Ifoda — natijada qiymat beradigan kod bo'lagi: 5 + 3 → 8, yosh >= 18 → true.

Arifmetik operatorlar

const a = 17;
const b = 5;
console.log(a + b);    // 22  qo'shish
console.log(a - b);    // 12  ayirish
console.log(a * b);    // 85  ko'paytirish
console.log(a / b);    // 3.4 bo'lish
console.log(a % b);    // 2   QOLDIQ: 17 = 5·3 + 2
console.log(a ** 2);   // 289 daraja: 17²
console.log((a + b) * 2);  // 44 — qavslar avval bajariladi

Qoldiq operatori % — juda foydali!

  • Juft yoki toq? son % 2 === 0 bo'lsa — juft.
  • Bo'linadimi? son % 3 === 0 — 3 ga qoldiqsiz bo'linadi.
  • Oxirgi raqam: 1234 % 10 → 4.
  • Vaqt: 135 daqiqa = Math.floor(135 / 60) soat va 135 % 60 daqiqa → 2 soat 15 daqiqa.

Math obyekti

console.log(Math.round(4.6));   // 5   — yaxlitlash
console.log(Math.floor(4.9));   // 4   — pastga yaxlitlash
console.log(Math.ceil(4.1));    // 5   — yuqoriga yaxlitlash
console.log(Math.max(3, 9, 2)); // 9   — eng kattasi
console.log(Math.min(3, 9, 2)); // 2
console.log(Math.sqrt(81));     // 9   — kvadrat ildiz
console.log(Math.abs(-7));      // 7   — modul
console.log(Math.random());     // 0 va 1 orasidagi tasodifiy son
console.log(Math.floor(Math.random() * 6) + 1);  // 1 dan 6 gacha — o'yin kubigi 🎲

Tayinlash operatorlari

let ball = 10;
ball += 5;    // ball = ball + 5  → 15
ball -= 3;    // ball = ball - 3  → 12
ball *= 2;    // ball = ball * 2  → 24
ball /= 4;    // ball = ball / 4  → 6
ball++;       // ball = ball + 1  → 7  (inkrement)
ball--;       // ball = ball - 1  → 6  (dekrement)
console.log(ball);

Taqqoslash operatorlari

Natijasi doim true yoki false:

== va === — muhim farq!

console.log(5 == "5");    // true  😱 — turni o'zgartirib taqqoslaydi
console.log(5 === "5");   // false ✅ — son va matn har xil narsa
console.log(0 == false);  // true  😱
console.log(0 === false); // false ✅
Qoida Doim === va !== ishlating. == turlarni "o'zicha" o'zgartiradi va kutilmagan xatolarga olib keladi. Va yana: = — tayinlash, === — taqqoslash. Ularni adashtirmang!

const yosh = 15;
const ruxsatnoma = true;

console.log(yosh >= 14 && ruxsatnoma);   // true  — ikkalasi ham rost
console.log(yosh >= 18 && ruxsatnoma);   // false — birinchisi yolg'on
console.log(yosh >= 18 || ruxsatnoma);   // true  — ikkinchisi rost
console.log(!ruxsatnoma);                // false

// Oraliqni tekshirish: 10 va 20 orasidami?
const son = 15;
console.log(son >= 10 && son <= 20);     // true

Shart operatori: if

Dastur hamma vaqt bir xil ishlamaydi — u vaziyatga qarab qaror qabul qiladi.

if (shart) {
  // shart TRUE bo'lsa bajariladi
} else {
  // shart FALSE bo'lsa bajariladi
}
const harorat = 28;

if (harorat > 25) {
  console.log("Issiq! Kepka kiying 🧢");
} else {
  console.log("Havo salqin 🧥");
}

else if — bir nechta variant

Shartlar yuqoridan pastga tekshiriladi va birinchi rost shart bajariladi — qolganlari tekshirilmaydi.

const ball = 78;
let baho;

if (ball >= 86) {
  baho = 5;
} else if (ball >= 71) {
  baho = 4;
} else if (ball >= 56) {
  baho = 3;
} else {
  baho = 2;
}

console.log(`${ball} ball → ${baho} baho`);

Tartib muhim! Agar ball >= 56 shartini birinchi yozsangiz, 95 ball ham "3" bo'lib qoladi — chunki 95 ≥ 56 rost va dastur shu yerda to'xtaydi. Shartlarni kattadan kichikka (yoki aniqroqdan umumiyroqqa) yozing.

Ichma-ich shartlar

const login = "admin";
const parol = "12345";

if (login === "admin") {
  if (parol === "12345") {
    console.log("✅ Xush kelibsiz, admin!");
  } else {
    console.log("❌ Parol noto'g'ri");
  }
} else {
  console.log("❌ Bunday foydalanuvchi yo'q");
}

Ternary (uchlik) operator — qisqa if

const yosh = 16;
// shart ? rost_bo'lsa : yolg'on_bo'lsa
const holat = yosh >= 18 ? "katta" : "voyaga yetmagan";
console.log(holat);

const son = 7;
console.log(`${son} — ${son % 2 === 0 ? "juft" : "toq"} son`);

Oddiy, ikki variantli tanlovlar uchun qulay. Murakkab shartlar uchun oddiy if o'qilishi osonroq.

switch — ko'p variantli tanlov

Bitta qiymatni ko'p aniq variantlar bilan solishtirish kerak bo'lganda if...else if zanjiridan qulayroq:

const kun = 3;
let kunNomi;

switch (kun) {
  case 1:
    kunNomi = "Dushanba";
    break;
  case 2:
    kunNomi = "Seshanba";
    break;
  case 3:
    kunNomi = "Chorshanba";
    break;
  case 4:
    kunNomi = "Payshanba";
    break;
  case 5:
    kunNomi = "Juma";
    break;
  case 6:
  case 7:
    kunNomi = "Dam olish kuni 🎉";   // 6 va 7 uchun bir xil natija
    break;
  default:
    kunNomi = "Bunday kun yo'q";      // hech biri mos kelmasa
}

console.log(kunNomi);
break ni unutsangiz, dastur keyingi case larni ham bajarib ketadi! switch qat'iy taqqoslash (===) bilan ishlaydi.

Amaliy mashg'ulot

  1. Juft yoki toq. Foydalanuvchidan son so'rang va uning juft/toq, musbat/manfiy/nol ekanini aniqlang.
  2. Baho aniqlovchi. 0–100 oralig'idagi ballni so'rang. Agar ball shu oraliqda bo'lmasa — "Noto'g'ri ball!" deb chiqaring. Aks holda bahoni va izohni ("A'lo!", "Yaxshi", ...) chiqaring.
  3. Kirish tizimi: 
    const TOGRI_LOGIN = "malika";
const TOGRI_PAROL = "qwerty123";

const login = prompt("Login:");
const parol = prompt("Parol:");

if (login === null || parol === null) {
  alert("Kirish bekor qilindi");
} else if (login === "" || parol === "") {
  alert("⚠️ Login va parol bo'sh bo'lmasligi kerak");
} else if (login.toLowerCase() === TOGRI_LOGIN && parol === TOGRI_PAROL) {
  alert(`✅ Xush kelibsiz, ${login}!`);
} else {
  alert("❌ Login yoki parol noto'g'ri");
}
    Nima uchun loginni toLowerCase() bilan, parolni esa aynan solishtiryapmiz? Muhokama qiling.
  4. Kabisa yili. Yil 4 ga bo'linsa va 100 ga bo'linmasa, yoki 400 ga bo'linsa — kabisa yili. Foydalanuvchi kiritgan yilni tekshiring (2024 ✅, 1900 ❌, 2000 ✅).
  5. Chipta narxi. Kinoteatr: 7 yoshgacha — bepul, 7–17 — 20 000, 18–59 — 35 000, 60+ — 15 000 so'm. Seshanba kuni hammaga 50% chegirma. Yosh va hafta kunini so'rab, narxni hisoblang.
  6. Hafta kuni (switch). 1–12 raqamini so'rab, oy nomini va qaysi faslga tegishli ekanini chiqaring.

Ko'p uchraydigan xatolar

  • ❌ if (ball = 100) — bu taqqoslash emas, tayinlash! To'g'risi: if (ball === 100).
  • ❌ if (10 < son < 20) — JS'da bunday yozib bo'lmaydi. To'g'risi: if (son > 10 && son < 20).
  • ❌ prompt natijasini Number()siz taqqoslash: "9" > "10" → true (matnlar alifbo bo'yicha taqqoslanadi!).
  • ❌ switch da break unutilgan.
  • ❌ Jingalak qavslarni yopishni unutish — VS Code qavslarni rangli qilib juftlab ko'rsatadi, kuzating.

🏠 Uyga vazifa

  1. BMI kalkulyatori: vazn (kg) va bo'y (m) so'rab, BMI = vazn / bo'y² ni hisoblang va natijani izohlang (kam vazn, me'yorda, ortiqcha).
  2. Uchburchak: uch tomon uzunligini so'rab, bunday uchburchak mavjudmi (har bir tomon qolgan ikkitasi yig'indisidan kichik) va qanday turda (teng tomonli, teng yonli, turli tomonli) ekanini aniqlang.
  3. Tosh-qaychi-qog'oz: foydalanuvchi tanlaydi, kompyuter Math.random() bilan tanlaydi, g'olibni aniqlang.

✅ Yodda tuting

  • Arifmetika: + - * / % **; % — qoldiq (juft/toq tekshirish).
  • Taqqoslash: > < >= <= === !== — doim ===.
  • Mantiq: && (ikkalasi), || (bittasi), ! (teskari).
  • if / else if / else — birinchi rost shart bajariladi; tartibga e'tibor bering.
  • Ternary: shart ? a : b; switch — ko'p aniq variantlar uchun, break bilan.
