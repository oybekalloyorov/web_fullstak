🎯 Bu darsda nimani o'rganasiz

  • View — so'rovni qabul qilib, javob qaytaruvchi funksiya ekanini;
  • URL'larni view'larga bog'lash (marshrutlash) va ilovaga alohida urls.py yaratishni;
  • Manzildan qiymat olish: /maqola/5/ → id = 5;
  • Qidiruv parametrlari (?q=...), 404 xatosi va qayta yo'naltirishni;
  • Funksiya va Class asosidagi view'lar farqini.

So'rov va javob

Har bir view — bu funksiya: u brauzerdan kelgan so'rov (request) obyektini oladi va javob (response) obyektini qaytaradi.

from django.http import HttpResponse

def salom(request):
    # request — so'rov haqida hamma narsa: metod, manzil, foydalanuvchi, parametrlar...
    print(request.method)          # "GET" yoki "POST"
    print(request.path)            # "/salom/"
    return HttpResponse("Salom!")  # javob — brauzerga qaytadigan matn/HTML
O'xshatish: pochta oynasi Pochtaga xat (so'rov) berasiz: unda kimdan, qayerga, nima so'ralgani yozilgan. Xodim (view) xatni o'qiydi, kerakli ishni qiladi va sizga javob xatini (response) qaytaradi. Har bir oyna (URL) o'z xizmatiga mas'ul.

URL marshrutlash

Django har bir so'rov uchun urlpatterns ro'yxatini yuqoridan pastga ko'rib chiqadi va birinchi mos kelgan yo'lning view'ini chaqiradi.

Ilova uchun alohida urls.py

Barcha URL'larni bitta config/urls.py ga yozish katta loyihada chalkashadi. To'g'ri usul: har bir ilova o'z urls.py siga ega bo'ladi, asosiy fayl esa ularni include bilan ulaydi.

from django.urls import path
from . import views

app_name = "blog"                                     # nomlar maydoni

urlpatterns = [
    path("", views.bosh_sahifa, name="bosh"),                          # /
    path("haqida/", views.haqida, name="haqida"),                      # /haqida/
    path("maqola//", views.maqola, name="maqola"),             # /maqola/5/
    path("kategoriya//", views.kategoriya, name="kategoriya"),   # /kategoriya/sport/
    path("qidiruv/", views.qidiruv, name="qidiruv"),                   # /qidiruv/?q=...
]
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("blog.urls")),          # blog ilovasining barcha URL'lari
]

View'lar yozish

Hozircha ma'lumotlar bazasi o'rniga oddiy Python ro'yxatidan foydalanamiz (36-mavzuda haqiqiy modelga almashtiramiz):

from django.http import HttpResponse, Http404, JsonResponse
from django.shortcuts import redirect

# Vaqtinchalik "baza"
MAQOLALAR = [
    {"id": 1, "sarlavha": "Bilimlar bellashuvi", "kategoriya": "tadbirlar", "matn": "8-sinflar o'rtasida..."},
    {"id": 2, "sarlavha": "Yangi kompyuter xonasi", "kategoriya": "maktab-hayoti", "matn": "20 ta kompyuter..."},
    {"id": 3, "sarlavha": "Futbol bo'yicha g'alaba", "kategoriya": "sport", "matn": "Shahar chempionati..."},
]


def bosh_sahifa(request):
    html = "
Maktab blogi
    "
    for m in MAQOLALAR:
        html += f'
  • {m["sarlavha"]}
    • '
    html += "
"
    return HttpResponse(html)


def haqida(request):
    return HttpResponse("
Biz haqimizda
5-maktab o'quvchilarining blogi.
")


def maqola(request, id):                       # id — URL'dagi  dan keladi
    for m in MAQOLALAR:
        if m["id"] == id:
            return HttpResponse(f"
{m['sarlavha']}
{m['matn']}
← Orqaga")
    raise Http404("Bunday maqola topilmadi")    # 404 sahifa


def kategoriya(request, nomi):
    topilganlar = [m for m in MAQOLALAR if m["kategoriya"] == nomi]
    if not topilganlar:
        return redirect("blog:bosh")            # bosh sahifaga qayta yo'naltirish
    royxat = "".join(f"
  • {m['sarlavha']}
    • " for m in topilganlar)
    return HttpResponse(f"
    Kategoriya: {nomi}
      {royxat}
    ")


def qidiruv(request):
    q = request.GET.get("q", "").strip()        # /qidiruv/?q=futbol
    natija = [m for m in MAQOLALAR if q.lower() in m["sarlavha"].lower()] if q else []
    return HttpResponse(f"
    '{q}' bo'yicha {len(natija)} ta natija
    ")


def api_maqolalar(request):
    return JsonResponse({"maqolalar": MAQOLALAR})    # JSON javob (39-mavzuga muqaddima)

    Sinab ko'ring:

    • http://127.0.0.1:8000/ — ro'yxat
    • /maqola/2/ — maqola; /maqola/99/ — 404
    • /kategoriya/sport/; /kategoriya/yoq/ — bosh sahifaga qaytaradi
    • /qidiruv/?q=futbol
    Diqqat View ichida HTML'ni satr sifatida yozish — faqat o'rganish uchun. U noqulay va xavfli (foydalanuvchi matni tekshirilmay HTML'ga qo'shilyapti). Keyingi mavzuda HTML'ni shablonlarga (templates) ko'chiramiz — Django ularda matnni avtomatik xavfsiz qiladi.

    Nomlangan URL'lar

    Har bir yo'lga name= berdik. Endi manzilni qo'lda yozish o'rniga nomi bo'yicha yasash mumkin:

    from django.urls import reverse

reverse("blog:maqola", args=[5])     # "/maqola/5/"
redirect("blog:haqida")              # /haqida/ ga yo'naltirish
# Shablonlarda: {% url 'blog:maqola' 5 %}  (35-mavzu)

    Afzalligi: kelajakda "maqola/<int:id>/" ni "post/<int:id>/" ga o'zgartirsangiz, faqat urls.py da bitta qator o'zgaradi — butun saytdagi havolalar o'zi yangilanadi.

    Class Based View (CBV) — klass asosidagi view'lar

    Hozirgacha funksiya asosidagi view (Function Based View, FBV) yozdik. Django yana bir usulni taklif qiladi — view'ni klass sifatida yozish (25-mavzudagi OOP!). Ko'p uchraydigan vazifalar uchun Django tayyor klasslar beradi va siz ulardan meros olasiz.

    from django.views import View
from django.views.generic import TemplateView

class SalomView(View):
    def get(self, request):                       # GET so'rov uchun metod
        return HttpResponse("Salom, GET!")

    def post(self, request):                      # POST so'rov uchun metod
        return HttpResponse("Salom, POST!")


class AloqaView(TemplateView):                    # tayyor klass: shablonni ko'rsatadi
    template_name = "blog/aloqa.html"             # 35-mavzuda yaratamiz
    path("salom/", views.SalomView.as_view(), name="salom"),     # CBV uchun .as_view()

    YozilishiOddiy, aniq, boshlovchilar uchun tushunarliQisqa, lekin "sehr" ko'p
    GET/POST ajratishif request.method == "POST":Alohida get(), post() metodlar
    Qayta ishlatishQiyinroqMeros orqali oson; tayyor ListView, DetailView, CreateView...

    Bu kursda asosan FBV ishlatamiz (tushunish oson), 38-mavzuda esa tayyor CBV'lar bilan CRUD qanchalik qisqa bo'lishini ko'rasiz.

    Amaliy mashg'ulot

    1. blog/urls.py yarating va config/urls.py da include qiling.
    2. Yuqoridagi view'larni yozing va har bir manzilni brauzerda sinab ko'ring. /maqola/abc/ ni ham oching — nima uchun 404? (int converter harflarni qabul qilmaydi.)
    3. Bosh sahifadagi havolalarni reverse("blog:maqola", args=[m["id"]]) bilan yasang.
    4. Yangi yo'llar qo'shing:
      • /kalkulyator/<int:a>/<int:b>/ — ikki sonning yig'indisi, ayirmasi, ko'paytmasini ko'rsatsin;
      • /salom/<str:ism>/ — "Salom, Ali!" deb javob bersin;
      • /api/maqolalar/ — JSON qaytarsin (JsonResponse).
    5. /tasodifiy/ — tasodifiy maqolaga redirect qilsin (random.choice).

    Ko'p uchraydigan xatolar

    • ❌ Page not found (404) — URL'da yakuniy / yo'q yoki yo'l urlpatterns da ro'yxatdan o'tmagan. Django xato sahifasida barcha mavjud yo'llar ro'yxatini ko'rsatadi — tekshiring.
    • ❌ maqola() got an unexpected keyword argument 'pk' — URL'dagi nom (<int:pk>) va funksiya parametri (id) mos emas.
    • ❌ View return qilmaydi — The view didn't return an HttpResponse object.
    • ❌ NoReverseMatch — reverse/redirect dagi URL nomi noto'g'ri yoki app_name: unutilgan.
    • ❌ CBV'da .as_view() unutilgan.

    O'zingizni tekshiring

    Django view'i nimani qabul qilib, nimani qaytaradi?

    1. HTML qabul qilib, SQL qaytaradi
    2. request (so'rov) qabul qilib, response (javob) qaytaradi
    3. URL qabul qilib, model qaytaradi
    4. Hech narsa qabul qilmaydi

    path("maqola/<int:id>/", views.maqola) — /maqola/7/ so'ralganda view nima oladi?

    1. id="7" (matn)
    2. Hech narsa
    3. id=7 (son)
    4. maqola=7

    Ilova URL'larini asosiy urls.py ga ulash uchun?

    1. include("blog.urls")
    2. import blog
    3. connect("blog")
    4. urls.add(blog)

    /qidiruv/?q=futbol dagi "futbol" ni view'da qanday olasiz?

    1. request.POST["q"]
    2. request.q
    3. request.path
    4. request.GET.get("q")

    Boshqa sahifaga qayta yo'naltiruvchi funksiya?

    1. HttpResponse()
    2. redirect()
    3. Http404()
    4. goto()

    Class Based View'ni URL'ga ulashda nima yoziladi?

    1. views.SalomView
    2. views.SalomView()
    3. views.SalomView.as_view()
    4. views.SalomView.get

    ✅ Yodda tuting

    • View: def view(request): return HttpResponse(...).
    • Ilovada urls.py + app_name; asosiy faylda path("", include("blog.urls")).
    • Converterlar: <int:id>, <str:nom>, <slug:nomi> — view parametriga keladi.
    • request.GET.get("q"), raise Http404, redirect("app:nom"), JsonResponse, name= + reverse.
    • CBV: class V(View): def get(self, request) → V.as_view().
