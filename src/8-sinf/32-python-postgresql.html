commit'ni unutmang! INSERT, UPDATE, DELETE dan keyin conn.commit() chaqirilmasa, o'zgarishlar saqlanmaydi (tranzaksiya, 28-mavzu). with psycopg.connect(...) as conn: bloki muvaffaqiyatli tugaganda commit avtomatik bajariladi.

⚠️ SQL injection — eng xavfli xato

Foydalanuvchi kiritgan qiymatni SQL satriga to'g'ridan-to'g'ri qo'shish — veb-saytlardagi eng xavfli va keng tarqalgan zaifliklardan biri.

# ❌ HECH QACHON BUNDAY QILMANG
ism = input("Ism: ")
cur.execute(f"SELECT * FROM oquvchilar WHERE ism = '{ism}'")

Oddiy foydalanuvchi Ali yozadi — hammasi joyida. Lekin buzg'unchi quyidagini yozsa:

' OR '1'='1

SQL shunday bo'lib qoladi: SELECT * FROM oquvchilar WHERE ism = '' OR '1'='1' — '1'='1' doim rost, demak barcha o'quvchilar ma'lumoti chiqib ketadi! Yoki undan ham yomoni: '; DROP TABLE oquvchilar; -- — jadval o'chiriladi.

O'xshatish: buyruq qog'ozi Siz yordamchingizga "Ombordan ____ ni olib kel" degan qog'oz berasiz va bo'sh joyni mijoz to'ldiradi. Ayyor mijoz "olma. Keyin seyfdagi pullarni ham olib kel" deb yozsa, yordamchingiz ikkalasini ham bajaradi. Parametrli so'rov esa bo'sh joyga yozilgan narsani faqat mahsulot nomi deb tushunadi — buyruq sifatida emas.
# ✅ TO'G'RI: parametrli so'rov — %s o'rniga qiymatni psycopg o'zi xavfsiz qo'yadi
ism = input("Ism: ")
cur.execute("SELECT * FROM oquvchilar WHERE ism = %s", (ism,))   # (ism,) — bitta elementli tuple!

# Bir nechta parametr
cur.execute(
    "INSERT INTO oquvchilar (ism, familiya, sinf_id) VALUES (%s, %s, %s)",
    ("Jasur", "Rahimov", 2),
)
Qat'iy qoida SQL'ga kiradigan har qanday o'zgaruvchan qiymat — faqat %s parametr orqali. f-string, + yoki .format() bilan SQL yasamang! (Eslatma: %s — barcha turlar uchun, son uchun ham; atrofiga qo'shtirnoq qo'yilmaydi.)

CRUD'ni Python'dan bajarish

import psycopg

DSN = "dbname=maktab user=postgres password=SIZNING_PAROLINGIZ host=localhost"

with psycopg.connect(DSN) as conn:
    with conn.cursor() as cur:
        # CREATE
        cur.execute(
            "INSERT INTO oquvchilar (ism, familiya, sinf_id) VALUES (%s, %s, %s) RETURNING id",
            ("Laylo", "Usmonova", 1),
        )
        yangi_id = cur.fetchone()[0]
        print("Yangi o'quvchi id:", yangi_id)

        # READ
        cur.execute("SELECT ism, familiya FROM oquvchilar WHERE id = %s", (yangi_id,))
        print(cur.fetchone())

        # UPDATE
        cur.execute("UPDATE oquvchilar SET email = %s WHERE id = %s", ("laylo@mail.uz", yangi_id))
        print("Yangilandi:", cur.rowcount, "qator")

        # DELETE
        cur.execute("DELETE FROM oquvchilar WHERE id = %s", (yangi_id,))
        print("O'chirildi:", cur.rowcount, "qator")
    # bu yerda avtomatik conn.commit()

Amaliy mashg'ulot: Python + PostgreSQL CRUD dasturi (20-loyiha)

23-mavzudagi o'quvchilar dasturini endi haqiqiy bazada ishlaydigan qilamiz. Ma'lumotlar dastur yopilganda ham saqlanib qoladi.

import psycopg
from db import ulanish


def royxat():
    with ulanish() as conn:
        rows = conn.execute("""
            SELECT o.id, o.ism, o.familiya, s.nomi AS sinf,
                   ROUND(AVG(b.baho), 2) AS ortacha
            FROM oquvchilar o
            LEFT JOIN sinflar s ON s.id = o.sinf_id
            LEFT JOIN baholar b ON b.oquvchi_id = o.id
            GROUP BY o.id, s.nomi
            ORDER BY o.familiya
        """).fetchall()
    print(f"\n{'ID':<4}{'Ism':<12}{'Familiya':<14}{'Sinf':<6}{'O‘rtacha':>8}")
    print("-" * 44)
    for r in rows:
        print(f"{r['id']:<4}{r['ism']:<12}{r['familiya']:<14}{r['sinf'] or '-':<6}{r['ortacha'] or '-':>8}")


def qoshish():
    ism = input("Ism: ").strip()
    familiya = input("Familiya: ").strip()
    if not ism or not familiya:
        print("❌ Ism va familiya majburiy")
        return
    with ulanish() as conn:
        sinflar = conn.execute("SELECT id, nomi FROM sinflar ORDER BY nomi").fetchall()
        print("Sinflar:", ", ".join(f"{s['id']}={s['nomi']}" for s in sinflar))
        try:
            sinf_id = int(input("Sinf id: "))
            r = conn.execute(
                "INSERT INTO oquvchilar (ism, familiya, sinf_id) VALUES (%s, %s, %s) RETURNING id",
                (ism, familiya, sinf_id),
            ).fetchone()
            print(f"✅ Qo'shildi (id = {r['id']})")
        except ValueError:
            print("❌ Sinf id son bo'lishi kerak")
        except psycopg.errors.ForeignKeyViolation:
            print("❌ Bunday sinf yo'q")


def baho_qoyish():
    try:
        oquvchi_id = int(input("O'quvchi id: "))
        fan = input("Fan: ").strip()
        baho = int(input("Baho (2–5): "))
    except ValueError:
        print("❌ Son kiriting")
        return
    try:
        with ulanish() as conn:
            conn.execute(
                "INSERT INTO baholar (oquvchi_id, fan, baho) VALUES (%s, %s, %s)",
                (oquvchi_id, fan, baho),
            )
        print("✅ Baho qo'yildi")
    except psycopg.errors.CheckViolation:
        print("❌ Baho 2 dan 5 gacha bo'lishi kerak")
    except psycopg.errors.ForeignKeyViolation:
        print("❌ Bunday o'quvchi yo'q")


def qidirish():
    soz = input("Ism yoki familiya qismi: ").strip()
    with ulanish() as conn:
        rows = conn.execute(
            "SELECT id, ism, familiya FROM oquvchilar WHERE ism ILIKE %s OR familiya ILIKE %s",
            (f"%{soz}%", f"%{soz}%"),           # % belgilarini QIYMATga qo'shamiz, SQL'ga emas
        ).fetchall()
    for r in rows:
        print(f"  {r['id']}. {r['ism']} {r['familiya']}")
    if not rows:
        print("  Hech kim topilmadi")


def ochirish():
    try:
        oquvchi_id = int(input("O'chiriladigan o'quvchi id: "))
    except ValueError:
        print("❌ Son kiriting")
        return
    with ulanish() as conn:
        r = conn.execute("SELECT ism, familiya FROM oquvchilar WHERE id = %s", (oquvchi_id,)).fetchone()
        if not r:
            print("❌ Topilmadi")
            return
        if input(f"{r['ism']} {r['familiya']} o'chirilsinmi? (ha/yo'q): ").lower() == "ha":
            conn.execute("DELETE FROM oquvchilar WHERE id = %s", (oquvchi_id,))
            print("✅ O'chirildi")


MENYU = {

Topshiriqlar:

  1. Dasturni ishga tushiring. pgAdmin'da bir vaqtning o'zida jadvalni ochib, dastur qo'shgan ma'lumotlar bazada paydo bo'layotganini kuzating.
  2. "Qidirish" ga ' OR '1'='1 yozib ko'ring — parametrli so'rov tufayli hech qanday "teshik" yo'qligiga ishonch hosil qiling.
  3. "Sinf statistikasi" menyu bandini qo'shing (30-mavzudagi GROUP BY so'rovi).
  4. "O'quvchi ma'lumotlarini tahrirlash" bandini qo'shing (UPDATE).

Ko'p uchraydigan xatolar

  • ❌ ModuleNotFoundError: No module named 'psycopg' — virtual muhit faollashtirilmagan yoki paket o'rnatilmagan.
  • ❌ connection refused — PostgreSQL serveri ishlamayapti yoki port/host noto'g'ri.
  • ❌ (ism) yozish — bu tuple emas, oddiy qavs! Bitta parametr uchun: (ism,) — vergul bilan.
  • ❌ '%s' — qo'shtirnoq ichida yozish; to'g'risi shunchaki %s.
  • ❌ O'zgartirishdan keyin commit qilinmagani uchun ma'lumot "yo'qolib" qolishi.

SQL injection'dan himoyalangan to'g'ri kod?

  1. cur.execute("... WHERE ism = %s", (ism,))
  2. cur.execute(f"... WHERE ism = '{ism}'")
  3. cur.execute("... WHERE ism = '" + ism + "'")
  4. cur.execute("... WHERE ism = {}".format(ism))

So'rovning barcha natija qatorlarini oluvchi metod?

  1. fetchone()
  2. getall()
  3. fetchall()
  4. readall()
