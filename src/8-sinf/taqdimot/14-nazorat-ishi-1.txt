# 1-topshiriq: nazariy savol
= https://maktab.uz yozilganda sahifa ekranga chiqquncha nima bo'ladi?
1. **DNS** domenni IP-manzilga aylantiradi
2. Brauzer serverga **HTTPS** bilan ulanadi
3. Brauzer **HTTP so'rov** yuboradi
4. Server **200 + HTML** javob qaytaradi
5. Brauzer CSS, rasm, JS ni qo'shimcha so'raydi
6. Hammasini birlashtirib sahifani **chizadi**
note: Baholash: 5 — barcha bosqichlar to'g'ri tartibda; 3–4 — 1–2 bosqich tushib qolgan; 1–2 — umumiy tasavvur.
---
# 2-topshiriq: 5 ta xatoni toping
```html
<head>
  <title>Kutubxona
</head>
<body>
  <h1>Kitoblarimiz</h1>
  <img src="rasmlar/kitob.jpg">
  <ul>
    <li>O'tkan kunlar</li>
    <li>Mehrobdan chayon
  </ul>
  <a href="www.kitob.uz">Kitob do'koni</a>
  <p><strong>Telefon:</p></strong>
</body>
```
::
- `</title>` yopilmagan
- `img` da `alt` yo'q
- 2-`<li>` yopilmagan
- `href` da `https://` yo'q
- `strong` va `p` noto'g'ri tartibda yopilgan
- ⭐ Bonus: `meta charset` va `viewport` yo'q
---
# 3-topshiriq: forma yarating
- "Olimpiadaga ro'yxatdan o'tish": ism (majburiy), sinf (`select`), fan (`radio`), email, izoh, tugma
```html
<form action="/olimpiada" method="POST">
  <label for="ism">To'liq ism</label>
  <input type="text" id="ism" name="ism" required>
  <label for="sinf">Sinf</label>
  <select id="sinf" name="sinf"><option>7</option><option>8</option></select>
  <label><input type="radio" name="fan" value="info"> Informatika</label>
  <label><input type="radio" name="fan" value="fiz"> Fizika</label>
  <input type="email" name="email" required>
  <button type="submit">Yuborish</button>
</form>
```
note: Baholash: forma va method — 1; maydon turlari — 2; label va name — 1; required va radio'larda bir xil name — 1.

# 4–5-topshiriqlar: Flexbox va Grid
```css 4: Flex header

  display: flex;
  justify-content: space-between;

  display: grid;

  gap: 20px;

  box-shadow: 0 6px 18px rgba(0,0,0,.1);
}
@media (max-width: 768px) {
  .kartalar { grid-template-columns: 1fr; }
}
```
