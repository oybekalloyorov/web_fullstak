# Bugun nimani o'rganamiz?
- Shartlar: `if`, `elif`, `else` va **chekinish** qoidasi
- Sikllar: `for` + `range()`, `while`, `break`, `continue`
- Xatolarni ushlash: `try` / `except`
- **Fayllar:** yaratish, yozish, o'qish, qo'shish
- **Python kalkulyatori** (15-loyiha)
note: JavaScript'dagi g'oyalar bir xil — faqat yozilishi boshqacha, shuning uchun mavzu tez o'tadi.
---
# if, elif, else
```python
ball = int(input("Ballingiz: "))

if ball >= 86:
    print("A'lo! 🏆")
elif ball >= 71:              # JS'dagi "else if"
    print("Yaxshi 👍")
elif ball >= 56:
    print("Qoniqarli")
else:
    print("Qoniqarsiz 😔")
```
- Shart oxirida **ikki nuqta** `:`
- `else if` emas — **`elif`**
---
# Chekinish — Python'ning eng muhim qoidasi
```python
yosh = 15
if yosh >= 14:
    print("Pasport olish mumkin")    # ← if ichida (4 bo'sh joy)
    print("Tabriklaymiz!")           # ← if ichida
print("Bu har doim chiqadi")         # ← tashqarida
```
- JS'da bloklar `{ }` bilan, Python'da — `:` va **4 bo'sh joy**
> **Kitob mundarijasi:** kichik bo'limlar o'ngroqqa surilgan — qaysi bo'limga tegishli ekanini siljishdan bilasiz.
! `IndentationError` — chekinish noto'g'ri. Bo'sh joy va Tab'ni aralashtirmang

# for va range()
```python
for i in range(5):            # 0 1 2 3 4   (5 kirmaydi!)
    print(i, end=" ")
for i in range(1, 6):         # 1 2 3 4 5
    ...
for i in range(10, 0, -2):    # 10 8 6 4 2
    ...
for harf in "Python":         # har bir harf
    print(harf, end="-")
```
| JavaScript | Python |
|---|---|
| `for (let i = 0; i < 5; i++)` | `for i in range(5):` |
| `for (let i = 1; i <= 10; i += 2)` | `for i in range(1, 11, 2):` |
| `for (const x of arr)` | `for x in arr:` |

# Yig'indi va ko'paytirish jadvali
```python
jami = 0
for i in range(1, 101):
    jami += i
print("1..100 yig'indi:", jami)   # 5050

son = int(input("Qaysi sonning jadvali? "))
for i in range(1, 11):
    print(f"{son} × {i:2} = {son * i:3}")   # :2, :3 — tekislash
```

# while, break, continue
```python
import random
yashirin = random.randint(1, 20)
urinish = 0

while True:                       # break bilan chiqamiz
    taxmin = int(input("1–20 oralig'ida son: "))
    urinish += 1
    if taxmin == yashirin:
        print(f"🎉 Topdingiz! {urinish} ta urinishda")
        break
    elif taxmin < yashirin:
        print("⬆️ Kattaroq")
    else:
        print("⬇️ Kichikroq")
```
- `continue` — keyingi qadamga o'tish

# try / except — xatolarni ushlash
```python
try:
    son = int(input("Son kiriting: "))
    print("Natija:", 100 / son)
except ValueError:
    print("❌ Bu son emas!")
except ZeroDivisionError:
    print("❌ Nolga bo'lib bo'lmaydi!")
finally:
    print("Dastur tugadi")        # har doim bajariladi
```
```output
Son kiriting: abc
❌ Bu son emas!
Dastur tugadi
```
- `int("salom")` dasturni to'xtatadi — `try` uni **"yiqilish"dan saqlaydi**

# Faylga yozish
```python
with open("eslatma.txt", "w", encoding="utf-8") as f:
    f.write("Birinchi qator\n")    # \n — yangi qator
    f.write("Ikkinchi qator\n")
```
- `with ... as f:` — ish tugagach faylni **avtomatik yopadi**
- `encoding="utf-8"` — o', g' va emoji uchun. **Doim yozing!**
| Rejim | Ma'nosi | Fayl bor bo'lsa |
|---|---|---|
| `"r"` | O'qish (standart) | O'qiydi (yo'q bo'lsa — xato) |
| `"w"` | Yozish | ⚠️ Eski mazmunni **o'chiradi**! |
| `"a"` | Qo'shish | Oxiriga qo'shadi |

# Amaliyot: Python kalkulyatori (15-loyiha)
```python
def son_sora(matn):
    while True:
        try:
            return float(input(matn))
        except ValueError:
            print("  ⚠️ Iltimos, son kiriting")

while True:
    amal = input("Amal (+ - * / ** yoki 'chiqish', 'tarix'): ")
    if amal == "chiqish":
        break
    if amal == "tarix":
        with open("tarix.txt", encoding="utf-8") as f:
            print(f.read())
        continue
    a, b = son_sora("1-son: "), son_sora("2-son: ")
    natija = a + b if amal == "+" else a - b  # ... va hokazo
    with open("tarix.txt", "a", encoding="utf-8") as f:
        f.write(f"{a} {amal} {b} = {natija}\n")
```

# Amaliyot: topshiriqlar
1. Har bir amalni va **xato kiritishlarni** sinab ko'ring
2. Yangi amallar: `sqrt` (ildiz) va `%%` (foiz)
3. "tarix" faqat **oxirgi 5** yozuvni ko'rsatsin: `readlines()[-5:]`
4. `tarix.txt` ni kompyuterda topib, Bloknot bilan oching

# Ko'p uchraydigan xatolar
- ❌ `if`, `for`, `while` oxirida `:` unutilgan → `SyntaxError`
- ❌ `else if` — Python'da `elif`
- ❌ `range(1, 10)` 10 ni bermaydi
- ❌ `"w"` rejimida muhim faylni o'chirib yuborish; qo'shish — `"a"`
- ❌ `encoding="utf-8"` siz — g'alati belgilar
---

o `"w"`
