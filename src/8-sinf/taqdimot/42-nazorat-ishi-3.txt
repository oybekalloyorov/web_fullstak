---
? SQL injection'dan himoyalangan so'rov qaysi?
o `cur.execute(f"... WHERE ism='{ism}'")`
+ `cur.execute("... WHERE ism=%s", (ism,))`
o `cur.execute("... WHERE ism='" + ism + "'")`
o Hammasi xavfsiz
---
? `path("kitob/<int:pk>/", views.kitob)` — view qanday e'lon qilinadi?
o `def kitob(request):`
o `def kitob(pk):`
o `def kitob(request, id):`
+ `def kitob(request, pk):`
---
? "Kitobning bitta muallifi, muallifning ko'p kitobi" — Kitob modelida qaysi maydon?
o `ManyToManyField(Muallif)`
o `CharField`
+ `ForeignKey(Muallif, on_delete=...)`
o `OneToOneField`
---
? Narxi 50 000 dan kichik kitoblar?
o `Kitob.objects.get(narx<50000)`
+ `Kitob.objects.filter(narx__lt=50000)`
o `Kitob.objects.all(narx=50000)`
o `Kitob.filter("narx < 50000")`
---
? REST API'da resursni o'chirish metodi va javob kodi?
o GET, 200
o POST, 201
+ DELETE, 204
o PUT, 404
---
? Boshqa domendagi JS sayt API'ga murojaat qilishi uchun Django'da nima sozlanadi?
o CSRF
o ALLOWED_HOSTS

o WhiteNoise

# 2-topshiriq: model va admin
```python
class Kitob(models.Model):
    JANRLAR = [("roman", "Roman"), ("sheriyat", "She'riyat"), ("ilmiy", "Ilmiy")]
    nomi = models.CharField(max_length=200)
    muallif = models.CharField(max_length=100)
    janr = models.CharField(max_length=20, choices=JANRLAR)
    yil = models.PositiveIntegerField()
    narx = models.DecimalField(max_digits=10, decimal_places=2)
    mavjud = models.BooleanField(default=True)
    qoshilgan = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.nomi

@admin.register(Kitob)
class KitobAdmin(admin.ModelAdmin):
    list_display = ["nomi", "muallif", "janr", "mavjud"]
    list_filter = ["janr", "mavjud"]
    search_fields = ["nomi", "muallif"]
```

# 3-topshiriq: view va shablon
```python
def kitoblar(request):
    q = request.GET.get("q", "").strip()
    qs = Kitob.objects.filter(mavjud=True)
    if q:
        qs = qs.filter(nomi__icontains=q)
    return render(request, "kutubxona/kitoblar.html", {"kitoblar": qs, "q": q})
```
```django
{% extends "kutubxona/base.html" %}
{% block content %}
  <form><input name="q" value="{{ q }}"><button>Izlash</button></form>
  <ul>
    {% for k in kitoblar %}
      <li><a href="{% url 'kutubxona:kitob' k.pk %}">{{ k.nomi }}</a> — {{ k.muallif }}</li>
    {% empty %}
      <li>Kitob topilmadi</li>
    {% endfor %}
  </ul>
{% endblock %}
```

# 4–5-topshiriqlar: API va deploy
```python 4: DRF API
class KitobSerializer(serializers.ModelSerializer):
    class Meta:
        model = Kitob
        fields = "__all__"
    def validate_narx(self, v):
        if v <= 0:
            raise serializers.ValidationError("Narx musbat bo'lsin")
        return v

class KitobViewSet(viewsets.ModelViewSet):
    queryset = Kitob.objects.all()
    serializer_class = KitobSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]
    filter_backends = [filters.SearchFilter]
    search_fields = ["nomi"]

router = DefaultRouter()
router.register("kitoblar", KitobViewSet)
```
