# Git branch — parallel ish
> **Daraxt shoxlari:** `main` — tana. Har dasturchi o'z vazifasi uchun shox o'stiradi. Ish tugagach shox tanaga "payvand" qilinadi (merge). Shoxdagi xato tanaga zarar bermaydi.
```text
             o──o──o        ← feature/galereya (Madina)
            /        \
main  o──o──o──────────o──o  ← merge
            \            /
             o──o──o───o     ← feature/forma (Javohir)
```
---
# Branch buyruqlari
```bash
git branch                       # barcha branch'lar (* — joriysi)
git switch -c feature/galereya   # yangi branch yaratib o'tish
# ... ishlash, git add, git commit ...
git switch main                  # asosiy branch'ga qaytish
git merge feature/galereya       # birlashtirish
```
- `main` da doim **ishlaydigan** kod turadi
---
# Konflikt — ikki kishi bitta qatorni o'zgartirsa
```text
<<<<<<< HEAD
<h1>Bizning maktab</h1>
=======
<h1>5-maktab rasmiy sayti</h1>
>>>>>>> feature/forma
```
- `HEAD` dan `=======` gacha — **sizning** variant
- `=======` dan `>>>>>>>` gacha — **birlashtirilayotgan** variant
1. Jamoa bilan kelishib, keraklisini qoldiring
2. Barcha belgilarni o'chiring
3. `git add .` → `git commit`
! Konfliktni kamaytirish: har kim **turli fayllarda** ishlasin, tez-tez `git pull`
---
# GitHub'da hamkorlik
- **Hamkor qo'shish:** Settings → Collaborators → Add people
- **Pull Request** — "mening branch'imni main'ga qo'shing" degan so'rov:
1. `git push -u origin feature/galereya`
2. GitHub'da **"Compare & pull request"**
3. Sarlavha, tavsif, skrinshot yozing
4. Jamoadoshlar **Files changed** da izoh qoldiradi
5. Tuzatib push qilasiz — PR avtomatik yangilanadi
6. **Merge pull request** → hamma `git pull`

- **Maqtashni** unutmang: "Animatsiya zo'r chiqibdi! 👍"

# Deploy: Netlify va Vercel
| | Netlify | Vercel |
|---|---|---|
| Narxi | Bepul (shaxsiy) | Bepul (shaxsiy) |
| Manzil | `nom.netlify.app` | `nom.vercel.app` |
| HTTPS | Avtomatik | Avtomatik |
| GitHub | Har push'da yangilanadi | Har push'da yangilanadi |
| O'ziga xos | Drag & Drop, formalar | React/Next.js uchun qulay |
---
# Netlify: sudrab tashlash
1. **app.netlify.com/drop** ni oching
2. Sayt papkasini (ichida `index.html`) maydonga sudrab tashlang
3. Bir necha soniyada: `https://tasodifiy-nom-123.netlify.app`
4. **Change site name** → `maktab5-samarqand.netlify.app`
---
# GitHub orqali deploy (professional)
1. Netlify/Vercel'ga **GitHub akkaunti** bilan kiring
2. **Import an existing project** → repozitoriyani tanlang
3. HTML/CSS uchun sozlama kerak emas → **Deploy**
4. Endi har `git push` → sayt **avtomatik** yangilanadi
= Bu — CI/CD (uzluksiz yetkazib berish) ning eng oddiy ko'rinishi
- O'z domeningiz: **Add custom domain** + DNS yozuvlari (1-mavzu)

# Amaliyot: "Bizning sinf"
```text
bizning-sinf/
├── index.html        ← Sardor
├── oquvchilar.html   ← 2-a'zo
├── galereya.html     ← 3-a'zo
├── aloqa.html        ← 4-a'zo
├── css/umumiy.css    ← kelishib yoziladi
└── rasmlar/
```
::
1. Sardor repo yaratadi, hamkorlarni qo'shadi
2. `README.md` — kelishuvlar
3. Har kim: `clone` → o'z branch'i → 3+ commit → push
4. **Pull Request** + izoh + merge
5. Netlify/Vercel'ga ulash
6. Telefonda tekshirish → **Issue**
7. 3 daqiqalik taqdimot
