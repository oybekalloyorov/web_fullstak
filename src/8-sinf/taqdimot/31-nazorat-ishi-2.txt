# 1-topshiriq: JavaScript DOM
- Tugma bosilganda: maydon bo'sh — "Ismingizni kiriting!" (qizil), aks holda — "Salom, [ism]!" (yashil)
```js
document.querySelector("#btn").addEventListener("click", () => {
  const ism = document.querySelector("#ism").value.trim();
  const javob = document.querySelector("#javob");
  if (ism === "") {
    javob.textContent = "Ismingizni kiriting!";
    javob.style.color = "red";
  } else {
    javob.textContent = `Salom, ${ism}!`;
    javob.style.color = "green";
  }
});
```
note: Baholash: elementlarni topish — 1; hodisa — 1; bo'sh tekshiruvi (trim) — 1; textContent — 1; ranglar — 1.

# 4-topshiriq: SQL jadval va CRUD
```sql
CREATE TABLE kitoblar (
    id      SERIAL PRIMARY KEY,
    nomi    VARCHAR(200) NOT NULL,
    muallif VARCHAR(100),
    yil     INTEGER CHECK (yil > 1450),
    narx    NUMERIC(10, 2),
    mavjud  BOOLEAN DEFAULT TRUE
);
INSERT INTO kitoblar (nomi, muallif, yil, narx) VALUES
    ('O''tkan kunlar', 'Abdulla Qodiriy', 1926, 65000),
    ('Ufq', 'Said Ahmad', 1976, 48000);
SELECT nomi, yil, narx FROM kitoblar WHERE yil > 2000 ORDER BY narx DESC;
UPDATE kitoblar SET narx = narx * 1.1 WHERE id = 1;
```
note: Baholash: jadval va turlar — 1; cheklovlar — 1; INSERT (apostrof) — 1; SELECT — 1; UPDATE + WHERE — 1.

# 5-topshiriq: JOIN va GROUP BY
- Har sinf: nomi, o'quvchilar soni, o'rtacha baho; faqat o'rtachasi 4 dan yuqorilar
```sql
SELECT s.nomi,
       COUNT(DISTINCT o.id) AS oquvchilar,
       ROUND(AVG(b.baho), 2) AS ortacha
FROM sinflar s
JOIN oquvchilar o ON o.sinf_id = s.id
JOIN baholar b    ON b.oquvchi_id = o.id
GROUP BY s.nomi
HAVING AVG(b.baho) > 4
ORDER BY ortacha DESC;
```
- Nega `COUNT(DISTINCT o.id)`? JOIN'dan keyin o'quvchi har bahosi uchun takrorlanadi!
