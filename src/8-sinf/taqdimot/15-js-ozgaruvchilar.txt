# JavaScript nima?

# O'zgaruvchi — nomlangan quti
> **Yorliqli qutilar:** "ism" qutisiga "Malika"ni, "yosh" qutisiga 14 ni soldingiz. Yorliq — o'zgaruvchi **nomi**, ichidagi narsa — **qiymati**.
```js
let ism = "Malika";
let yosh = 14;
console.log(yosh);     // 14
yosh = 15;             // qiymatni o'zgartirish (let qayta yozilmaydi!)
let shahar;
console.log(shahar);   // undefined
```
- `=` — **tayinlash** ("o'ngdagini chapdagi qutiga sol"), tenglik emas!
---
# let, const va var
```js
const PI = 3.14;
// PI = 5;          ❌ Xato! const o'zgarmaydi
let ball = 0;
ball = ball + 10;   // ✅ 10
```
| | const | let | var |
|---|---|---|---|
| O'zgartirish | ❌ | ✅ | ✅ |
| Qachon | **Birinchi tanlov** | Qiymat o'zgarsa | Eski kod — ishlatmang |
= Oltin qoida: avval const, kerak bo'lsa let
---
# O'zgaruvchilarni nomlash
| Qoida | ✅ To'g'ri | ❌ Noto'g'ri |
|---|---|---|
| Harf, `$`, `_` bilan boshlanadi | `ism`, `_soni` | `1ism` |
| Bo'sh joy va defis yo'q | `sinfRahbari` | `sinf rahbari`, `umumiy-ball` |
| Maxsus so'zlar emas | `mening_let` | `let`, `if` |
| Apostrof yo'q | `ogil` | `o'g'il` |
- Katta-kichik harf farqlanadi: `ism` ≠ `Ism`
- **camelCase:** `oquvchiSoni`, `dasturlashTili`
- Mazmunli nomlar: `x` ❌ → `narx` ✅

# String — matn
```js
const ism = "Aziz";
const familiya = 'Karimov';
const shahar = `Toshkent`;           // backtick — eng qulayi

console.log(ism + " " + familiya);   // Aziz Karimov
const yosh = 14;
console.log(`Ismim ${ism}, ${yosh} yoshdaman`);  // shablon satr

console.log(ism.length);             // 4
console.log(ism.toUpperCase());      // AZIZ
console.log(familiya[0]);            // K — sanash 0 dan!
```
! `'O'zbekiston'` ❌ — apostrof satrni sindiradi. `"O'zbekiston"` yoki `` `O'zbekiston` `` ✅

# Number, Boolean, undefined, null
```js
const kasr = 3.14;           // kasr NUQTA bilan
console.log(10 / 3);         // 3.3333333333333335
console.log(10 / 0);         // Infinity
console.log("olma" * 2);     // NaN — "son emas"

const tizimgaKirgan = true;  // boolean: true / false
console.log(5 > 3);          // true
```
- `undefined` — qiymat **hali berilmagan** (bo'sh quti)
- `null` — qiymat **ataylab bo'sh**
- Murakkab turlar: **Array** `[1, 2, 3]`, **Object** `{ ism: "Ali" }` — 18-mavzuda
---
# typeof va turlarni o'zgartirish
```js
typeof "Salom"    // "string"
typeof 25         // "number"
typeof true       // "boolean"
typeof null       // "object" ← tarixiy xato!

"5" + 3           // "53"  😮 matnga yopishadi
"5" - 3           // 2
Number("42") + 8  // 50
parseInt("15px")  // 15
```
! Foydalanuvchi kiritgan ma'lumot **doim matn**. Hisoblashdan oldin `Number()`!

# Foydalanuvchi bilan muloqot
```js
const ism = prompt("Ismingiz nima?");
const yil = Number(prompt("Qaysi yilda tug'ilgansiz?"));
const yosh = 2026 - yil;
alert(`Salom, ${ism}! Siz ${yosh} yoshdasiz.`);

const tasdiq = confirm("Dasturlashni yoqtirasizmi?");
```
| Funksiya | Qaytaradi |
|---|---|
| `alert("...")` | Hech narsa — faqat xabar |
| `prompt("...")` | Kiritilgan matn yoki `null` |
| `confirm("...")` | `true` yoki `false` |

# Ko'p uchraydigan xatolar
- ❌ `SyntaxError` — qo'shtirnoq yopilmagan / apostrof satrni sindirgan
- ❌ `ReferenceError: x is not defined` — nom noto'g'ri yoki e'lon qilinmagan
- ❌ `Assignment to constant variable` — `const` ni o'zgartirish
- ❌ `"10" + 5 = "105"` — `Number()` unutilgan
- ❌ Bitta nomni ikki marta `let` bilan e'lon qilish
> Konsoldagi qizil xabar — **yordamchi!** U xato turi va qatorini aytadi: `app.js:12`
