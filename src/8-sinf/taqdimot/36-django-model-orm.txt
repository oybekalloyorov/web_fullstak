- **Model** — jadvalni Python klassi sifatida yozish
- Maydon turlari va **ForeignKey** bog'lanishlari
- **Migratsiya** — modeldan haqiqiy jadvalga
- **ORM:** SQL yozmasdan CRUD va filtrlash
- Blog sahifalarini haqiqiy **PostgreSQL**'ga ulash

# ORM nima?
= ORM — jadvallar = klasslar, qatorlar = obyektlar, SQL o'rniga Python
| SQL | Django ORM |
|---|---|
| `SELECT * FROM blog_maqola;` | `Maqola.objects.all()` |
| `... WHERE id = 5;` | `Maqola.objects.get(id=5)` |
| `... WHERE sarlavha ILIKE '%futbol%'` | `.filter(sarlavha__icontains="futbol")` |
| `INSERT INTO ... VALUES ...` | `Maqola.objects.create(...)` |
> **Tarjimon:** siz Python'da gapirasiz, baza faqat SQL tushunadi. ORM to'g'ri va **xavfsiz** SQL'ga o'giradi — SQL injection'dan avtomatik himoya!

# Model yaratish: Kategoriya
```python blog/models.py
from django.db import models
from django.contrib.auth.models import User
from django.urls import reverse

class Kategoriya(models.Model):
    nomi = models.CharField("Nomi", max_length=100, unique=True)
    slug = models.SlugField(unique=True)

    def __str__(self):
        return self.nomi
```
- Har bir model — `models.Model` dan meros (25-mavzu!); har atribut — ustun; `id` avtomatik

# Model yaratish: Maqola
```python blog/models.py
class Maqola(models.Model):
    sarlavha = models.CharField("Sarlavha", max_length=200)
    matn = models.TextField("Matn")
    kategoriya = models.ForeignKey(Kategoriya, on_delete=models.PROTECT, related_name="maqolalar")
    muallif = models.ForeignKey(User, on_delete=models.CASCADE)
    chop_etilgan = models.BooleanField(default=True)
    korishlar = models.PositiveIntegerField(default=0)
    yaratilgan = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ["-yaratilgan"]

    def __str__(self):
        return self.sarlavha

    def get_absolute_url(self):
        return reverse("blog:maqola", args=[self.id])
```

# Maydon turlari
| Django maydoni | PostgreSQL | Qachon |
|---|---|---|
| `CharField(max_length)` | VARCHAR | Ism, sarlavha |
| `TextField()` | TEXT | Uzun matn |
| `IntegerField()` | INTEGER | Butun son |
| `DecimalField()` | NUMERIC | Pul |
| `BooleanField()` | BOOLEAN | Ha/yo'q |
| `DateField()`, `DateTimeField()` | DATE, TIMESTAMP | Sana, vaqt |
| `EmailField()`, `SlugField()` | VARCHAR + tekshiruv | Email, slug |
| `ImageField(upload_to)` | VARCHAR (yo'l) | Rasm (Pillow) |
| `ForeignKey(Model, on_delete)` | FK `..._id` | 1:N |
| `ManyToManyField(Model)` | Oraliq jadval | N:M |
---
# Parametrlar va on_delete
- `null=True` — bazada NULL; `blank=True` — formada bo'sh qoldirish mumkin
- `default=...`, `unique=True`, `choices=[...]`
- Birinchi argument (`"Sarlavha"`) — admin va formalardagi chiroyli nom
- `id` yozilmaydi — Django avtomatik qo'shadi
| Django | SQL | Misol |
|---|---|---|
| `CASCADE` | ON DELETE CASCADE | Foydalanuvchi o'chsa — maqolalari ham |
| `PROTECT` | RESTRICT | Maqolasi bor kategoriya o'chmaydi |
| `SET_NULL` | SET NULL (`null=True`) | — |

# ORM: Read
```python
Maqola.objects.all()                                  # barchasi (QuerySet)
Maqola.objects.count()
Maqola.objects.get(id=1)                              # aynan bittasi
Maqola.objects.filter(chop_etilgan=True)
Maqola.objects.filter(kategoriya__slug="sport")       # JOIN!
Maqola.objects.filter(sarlavha__icontains="futbol")   # ILIKE
Maqola.objects.filter(korishlar__gte=100)             # >= 100
Maqola.objects.exclude(chop_etilgan=False)            # NOT
Maqola.objects.order_by("-korishlar")[:5]             # DESC LIMIT 5

m.kategoriya.nomi          # FK orqali bog'langan obyekt
sport.maqolalar.all()      # teskari yo'nalish (related_name)
```

# Lookup'lar
| Lookup | SQL |
|---|---|
| `maydon=x` | `= x` |
| `__gt` / `__gte` / `__lt` / `__lte` | `>` `>=` `<` `<=` |
| `__contains` / `__icontains` | `LIKE` / `ILIKE '%x%'` |
| `__startswith` | `LIKE 'x%'` |
| `__in=[1, 2]` | `IN (1, 2)` |
| `__isnull=True` | `IS NULL` |
| `fk__maydon` | JOIN orqali bog'langan ustun |

# Update, Delete va agregatsiya
```python
m = Maqola.objects.get(id=1)
m.sarlavha = "Futbol: shahar chempionlari!"
m.save()                                                                   # UPDATE

Maqola.objects.filter(kategoriya__slug="sport").update(chop_etilgan=False) # ko'pini birdan
Maqola.objects.get(id=2).delete()                                          # DELETE

from django.db.models import Count, Sum, Avg
Maqola.objects.aggregate(jami=Sum("korishlar"), ortacha=Avg("korishlar"))
for k in Kategoriya.objects.annotate(soni=Count("maqolalar")):            # GROUP BY
    print(k.nomi, k.soni)
```
- QuerySet **"dangasa"**: SQL faqat natija kerak bo'lganda yuboriladi

# View'larni bazaga ulash
```python blog/views.py
from django.shortcuts import render, get_object_or_404
from django.db.models import Q, F
from .models import Maqola, Kategoriya

def bosh_sahifa(request):
    maqolalar = Maqola.objects.filter(chop_etilgan=True).select_related("kategoriya", "muallif")
    return render(request, "blog/bosh_sahifa.html", {"maqolalar": maqolalar})

def maqola(request, id):
    m = get_object_or_404(Maqola, id=id, chop_etilgan=True)        # topilmasa — 404
    Maqola.objects.filter(id=m.id).update(korishlar=F("korishlar") + 1)
    return render(request, "blog/maqola.html", {"maqola": m})

def qidiruv(request):
    q = request.GET.get("q", "").strip()
    natija = Maqola.objects.filter(Q(sarlavha__icontains=q) | Q(matn__icontains=q)) if q else []
    return render(request, "blog/qidiruv.html", {"q": q, "maqolalar": natija})
```
- `select_related` — bitta JOIN bilan; usiz "N+1 muammosi" (10 maqola = 21 so'rov)

# Ko'p uchraydigan xatolar
- ❌ `relation "blog_maqola" does not exist` — `migrate` bajarilmagan
- ❌ `No changes detected` — ilova `INSTALLED_APPS` da yo'q
- ❌ `Maqola matching query does not exist` — `get_object_or_404` ishlating
- ❌ `get() returned more than one` — ko'p natija uchun `filter`
- ❌ Yangi majburiy maydon → `default=...` yoki `null=True`
