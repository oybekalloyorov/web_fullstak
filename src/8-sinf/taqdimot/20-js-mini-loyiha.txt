# Loyihani qanday boshlash kerak?
! Eng katta xato — darhol kod yozishga tushish
1. **Nima qiladi?** Funksiyalar ro'yxati: qo'shish, belgilash, o'chirish
2. **Qanday ko'rinadi?** Qog'ozga chizing: input, tugma, ro'yxat
3. **Qanday ma'lumot?** Har vazifa — `{ id, matn, bajarildi }`; hammasi — massiv
4. **Qaysi hodisalar?** submit → qo'shish; checkbox → belgilash; 🗑 → o'chirish
5. **Kichik qadamlar** bilan yozing, har qadamdan keyin tekshiring
---
# "Holat → Chizish" usuli
```text
👆 Hodisa  ──▶  📦 Holat (massiv) o'zgaradi  ──▶  🎨 render()  ──▶  💾 localStorage
 tugma bosildi     push / filter / map           sahifa massivdan     saqlash
                                                  qayta chiziladi
```
> **Doska va daftar:** daftar — holat (haqiqiy ma'lumot), doska — ekran. O'qituvchi avval daftarni yangilaydi, keyin doskani artib, daftardagini qayta yozadi — ular hech qachon farq qilmaydi.
- Aynan shu g'oya **React** kabi kutubxonalarning asosida

# To-Do: holat va amallar
```js
// 1. HOLAT
let vazifalar = JSON.parse(localStorage.getItem("vazifalar")) || [];

// 2. AMALLAR — faqat holatni o'zgartiradi
function qoshish(matn) {
  vazifalar.push({ id: Date.now(), matn, bajarildi: false });
  yangilash();
}
function almashtir(id) {
  vazifalar = vazifalar.map(v =>
    v.id === id ? { ...v, bajarildi: !v.bajarildi } : v);
  yangilash();
}
function ochir(id) {
  vazifalar = vazifalar.filter(v => v.id !== id);
  yangilash();
}
function yangilash() {
  localStorage.setItem("vazifalar", JSON.stringify(vazifalar));
  render();
}
```

# To-Do: render() — holatdan chizish
```js
function render() {
  royxat.innerHTML = "";                     // avval tozalash!
  vazifalar.forEach(v => {
    const li = document.createElement("li");
    li.classList.toggle("bajarildi", v.bajarildi);
    const span = document.createElement("span");
    span.textContent = v.matn;               // XSS'dan himoya
    const ochirish = document.createElement("button");
    ochirish.textContent = "🗑";
    ochirish.addEventListener("click", () => ochir(v.id));
    span.addEventListener("click", () => almashtir(v.id));
    li.append(span, ochirish);
    royxat.append(li);
  });
  hisob.textContent = `${vazifalar.filter(v => !v.bajarildi).length} ta qoldi`;
}
```

# Ko'p uchraydigan xatolar
- ❌ Holat o'zgardi, lekin `render()` chaqirilmadi — ekran eski holicha
- ❌ Massivni `JSON.stringify` siz saqlash → `"[object Object]"`
- ❌ `render()` da `innerHTML = ""` yo'q — elementlar ikki baravar ko'payadi
- ❌ Foydalanuvchi matni `innerHTML` bilan — XSS xavfi; `textContent`!
