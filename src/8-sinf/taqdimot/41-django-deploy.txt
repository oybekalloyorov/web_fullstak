# Development va production
| | Development | Production |
|---|---|---|
| Qayerda | Sizning kompyuteringiz | Internetdagi server |
| `DEBUG` | `True` — batafsil xatolar | `False` — xatolar yashirin! |
| Server | `runserver` | **gunicorn** |
| Statik fayllar | Django o'zi | `collectstatic` + **WhiteNoise** |
| Maxfiy kalitlar | `.env` fayl | Muhit o'zgaruvchilari |
| Manzil | `127.0.0.1:8000` | `https://maktab-blog.onrender.com` |

# Kerakli paketlar
```bash
pip install gunicorn whitenoise dj-database-url
pip freeze > requirements.txt
```
| Paket | Vazifasi |
|---|---|
| `gunicorn` | Production server (`runserver` o'rniga) |
| `whitenoise` | Statik fayllarni (CSS, JS) tez va xavfsiz berish |
| `dj-database-url` | Bazani bitta `DATABASE_URL` satridan sozlash |
- `gunicorn` Windows'da ishlamaydi — normal: u faqat serverda (Linux). Kompyuteringizda `runserver`
---
# settings.py — xavfsizlik
```python
import os
import dj_database_url

SECRET_KEY = os.environ["SECRET_KEY"]             # yo'q bo'lsa — xato (ataylab!)
DEBUG = os.getenv("DEBUG", "False") == "True"     # standart — False
ALLOWED_HOSTS = os.getenv("ALLOWED_HOSTS", "127.0.0.1,localhost").split(",")
CSRF_TRUSTED_ORIGINS = [f"https://{h}" for h in ALLOWED_HOSTS
                        if h not in ("127.0.0.1", "localhost")]

if not DEBUG:
    SECURE_PROXY_SSL_HEADER = ("HTTP_X_FORWARDED_PROTO", "https")
    SESSION_COOKIE_SECURE = True
    CSRF_COOKIE_SECURE = True
```
- Lokal `.env` ga `DEBUG=True` qo'shing — kompyuterda qulay ishlash uchun
---
# settings.py — baza va statik fayllar
```python
MIDDLEWARE = [
    "corsheaders.middleware.CorsMiddleware",
    "django.middleware.security.SecurityMiddleware",
    "whitenoise.middleware.WhiteNoiseMiddleware",     # ⬅ Security'dan keyin
    # ...
]

DATABASES = {
    "default": dj_database_url.config(
        default=f"postgres://{os.getenv('DB_USER')}:{os.getenv('DB_PASSWORD')}@"
                f"{os.getenv('DB_HOST', 'localhost')}:5432/{os.getenv('DB_NAME')}",
        conn_max_age=600,
    )
}

STATIC_URL = "static/"
STATIC_ROOT = BASE_DIR / "staticfiles"
STORAGES = {
    "default": {"BACKEND": "django.core.files.storage.FileSystemStorage"},
    "staticfiles": {"BACKEND": "whitenoise.storage.CompressedManifestStaticFilesStorage"},
}
```

# Production'ning oltin qoidalari
1. **`DEBUG = False`** — aks holda xato sahifasi buzg'unchiga kod, sozlamalar va hatto parollarni ko'rsatadi
2. **`SECRET_KEY` maxfiy va yangi** — GitHub'dagi yoki darsdagisini ishlatmang
3. **`ALLOWED_HOSTS`** — faqat sizning domeningiz
```bash Yangi SECRET_KEY yaratish
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```
---
# Build skripti va tekshiruv
```bash build.sh
#!/usr/bin/env bash
set -o errexit                       # xato bo'lsa — to'xtash
pip install -r requirements.txt
python manage.py collectstatic --no-input
python manage.py migrate
```
```bash
git update-index --chmod=+x build.sh   # Windows: bajariladigan qilish (macOS/Linux: chmod +x)
python manage.py check --deploy        # production maslahatlari
python manage.py collectstatic         # staticfiles/ (.gitignore ga!)
git add . && git commit -m "Production uchun tayyorlandi" && git push
```

# Xatolarni topish — Logs
| Belgi | Sabab |
|---|---|
| `DisallowedHost` | Domen `ALLOWED_HOSTS` da yo'q |
| CSS yo'q (oddiy matn) | WhiteNoise yoki `collectstatic` muammosi |
| `CSRF verification failed` | `CSRF_TRUSTED_ORIGINS` da `https://` domen yo'q |
| `ModuleNotFoundError` | Paket `requirements.txt` da yo'q |
| "Build failed" | Build log'ini o'qing |
! Muammoni "tuzatish" uchun serverda **hech qachon** `DEBUG=True` qo'ymang!
- Media fayllar bulutda vaqtinchalik — haqiqiy loyihada Cloudinary / S3
