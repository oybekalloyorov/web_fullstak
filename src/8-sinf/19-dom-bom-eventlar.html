DOM nima?

Brauzer HTML faylni o'qiganda, uni xotirada daraxt ko'rinishidagi obyektlarga aylantiradi. Bu daraxt DOM (Document Object Model) deyiladi. JavaScript sahifani aynan DOM orqali o'zgartiradi.

O'xshatish: oila shajarasi DOM — oila daraxti. body — bobo, ul — ota, li lar — bolalar (va o'zaro aka-uka). JavaScript shu daraxtdagi istalgan "qarindosh"ni topib, uning kiyimini (uslub), ismini (matn) o'zgartirishi, yangi farzand qo'shishi yoki olib tashlashi mumkin.

document — butun sahifani ifodalovchi obyekt, DOM bilan ishlashning kirish nuqtasi.

Elementlarni topish

// querySelector — CSS selektori bilan BIRINCHI mos elementni topadi
const sarlavha = document.querySelector("#sarlavha");   // id bo'yicha
const royxat   = document.querySelector(".royxat");     // class bo'yicha
const birinchiLi = document.querySelector("li");        // teg bo'yicha

// querySelectorAll — BARCHA mos elementlar (ro'yxat)
const hammaLi = document.querySelectorAll("li");
hammaLi.forEach(li => console.log(li.textContent));

// Eski, lekin ko'p uchraydigan usul
const s = document.getElementById("sarlavha");          // # belgisisiz!
CSS'da qanday selektor yozsangiz (#id, .class, nav a), querySelector ga ham xuddi shunday yozasiz. 6-mavzudagi bilimlar shu yerda ham ishlaydi!

BOM — brauzer bilan ishlash

BOM (Browser Object Model) — sahifaning o'zi emas, brauzer oynasi bilan ishlash vositalari. Ularning "boshlig'i" — window obyekti.

console.log(window.innerWidth, window.innerHeight);  // oyna o'lchami
console.log(location.href);         // joriy sahifa manzili
// location.href = "https://kun.uz"; // boshqa sahifaga o'tish
// location.reload();                 // sahifani yangilash
console.log(navigator.language);    // brauzer tili, masalan "uz" yoki "ru"
// history.back();                    // "Orqaga" tugmasi

// Taymerlar
setTimeout(() => {
  console.log("3 soniya o'tdi ⏰");
}, 3000);                            // bir marta, 3000 ms dan keyin

let soniya = 0;
const taymer = setInterval(() => {
  soniya++;
  console.log(`${soniya} soniya`);
  if (soniya === 5) clearInterval(taymer);   // to'xtatish
}, 1000);                            // har 1000 ms da

localStorage — brauzer xotirasi

Sahifa yangilansa, JavaScript o'zgaruvchilari "unutiladi". localStorage esa ma'lumotni brauzerda doimiy saqlaydi (brauzer yopilsa ham).

localStorage.setItem("ism", "Malika");          // saqlash (faqat matn!)
console.log(localStorage.getItem("ism"));       // o'qish → "Malika"
localStorage.removeItem("ism");                 // o'chirish

// Massiv yoki obyektni saqlash uchun — JSON ga aylantirish
const vazifalar = ["Dars qilish", "Kitob o'qish"];
localStorage.setItem("vazifalar", JSON.stringify(vazifalar));
const qaytaOlingan = JSON.parse(localStorage.getItem("vazifalar"));
console.log(qaytaOlingan[0]);

Hodisalar (events)

Hodisa — sahifada sodir bo'ladigan narsa: tugma bosildi, klavish bosildi, sichqoncha ustiga keldi, forma yuborildi. JavaScript hodisani "tinglab" turadi va sodir bo'lganda belgilangan funksiyani bajaradi.

O'xshatish: eshik qo'ng'irog'i Siz eshik oldida doim kutib turmaysiz. Qo'ng'iroq chalinganda (hodisa) eshikni ochishga borasiz (funksiya). addEventListener — "qo'ng'iroq chalinsa, menga ayt" degan kelishuv.

Kodni tahlil qiling va kengaytiring:

  1. Har bir qatorga izoh yozing: bu qator nima qiladi?
  2. Yana 2 ta valyuta qo'shing (masalan, GBP, CNY).
  3. "Tarix" bo'limi qo'shing: oxirgi 5 ta hisob ro'yxat sifatida natija ostida ko'rsatilsin (createElement + prepend).
  4. Miqdor 1 000 000 dan katta bo'lsa, natija qizil rangda ko'rinsin (classList).

Qo'shimcha mashqlar

  • Tungi rejim tugmasi: bosilganda body ga dark class qo'shilsin/olinsin, tanlov localStorage da saqlansin.
  • Burger menyu: 10-mavzudagi menyuni endi JavaScript bilan oching: ☰ bosilganda .menyu ga ochiq class.
  • Sekundomer: Start/Stop/Reset tugmalari va setInterval.

Ko'p uchraydigan xatolar

  • ❌ Cannot read properties of null — querySelector elementni topmadi: selektorda xato (# yoki . unutilgan) yoki skript HTML'dan oldin ulangan.
  • ❌ addEventListener("click", hisobla()) — qavs qo'yilsa funksiya darhol bajariladi. To'g'risi: hisobla (qavssiz).
  • ❌ input.value ni son deb o'ylash — u doim matn. Number()!
  • ❌ Formada e.preventDefault() unutilgan — sahifa yangilanib, natija bir lahzada yo'qoladi.
  • ❌ style.background-color — JS'da defisli nomlar camelCase bo'ladi: style.backgroundColor.

O'zingizni tekshiring

class="karta" bo'lgan birinchi elementni topuvchi kod?

  1. document.querySelector("karta")
  2. document.querySelector(".karta")
  3. document.getElementById(".karta")
  4. document.find("karta")

Element matnini xavfsiz o'zgartiruvchi xossa?

  1. innerHTML
  2. value
  3. src
  4. textContent

Class bor bo'lsa olib tashlaydigan, yo'q bo'lsa qo'shadigan metod?

  1. classList.toggle()
  2. classList.add()
  3. classList.switch()
  4. className.change()

Maydonga har bir belgi kiritilganda sodir bo'ladigan hodisa?

  1. click
  2. submit
  3. input
  4. load

Ma'lumotni brauzer yopilsa ham saqlab qoluvchi BOM vositasi?

  1. setTimeout
  2. localStorage
  3. console
  4. location

Forma yuborilganda sahifa qayta yuklanmasligi uchun nima chaqiriladi?

  1. e.stop()
  2. return false
  3. form.reset()
  4. e.preventDefault()

✅ Yodda tuting

  • DOM — sahifaning obyektlar daraxti; document.querySelector() / querySelectorAll() bilan topiladi.
  • O'zgartirish: textContent, innerHTML, style.xossa, classList.add/remove/toggle, atributlar.
  • Yaratish: createElement → append; o'chirish: remove().
  • BOM: window, location, setTimeout/setInterval, localStorage (JSON bilan).
  • Hodisalar: el.addEventListener("click", funksiya); formada e.preventDefault().
