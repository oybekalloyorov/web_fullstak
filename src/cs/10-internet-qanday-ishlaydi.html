Internet — tarmoqlar tarmog'i

Internet — dunyodagi millionlab kichik tarmoqlarni (uy, maktab, kompaniya, provayder tarmoqlari) bir-biriga bog'lagan global tarmoq. Ular mis simlar, optik tolali kabellar (shu jumladan okean tubidagi 1,4 million km dan ortiq kabellar!), Wi-Fi, mobil minoralar va sun'iy yo'ldoshlar orqali ulangan.

Paketlar va routerlar

Siz rasm yuborganingizda u paketlarga — mayda bo'laklarga (odatda ~1500 bayt) bo'linadi. Har bir paketda qayerdan va qayerga borishi (IP-manzillar) va tartib raqami yoziladi. Router — "chorraha boshqaruvchisi": har bir paketni manzilga yaqinroq yo'nalishga jo'natadi. Paketlar turli yo'llardan ketishi mumkin, manzilda esa yana tartib bilan yig'iladi.

O'xshatish: kitobni pochta orqali yuborish Qalin kitobni bitta konvertga sig'dira olmaysiz — har bir sahifani alohida konvertga solib, raqamlab yuborasiz. Konvertlar turli pochta bo'limlari (routerlar) orqali ketadi, ba'zilari kechikadi. Qabul qiluvchi ularni raqam bo'yicha tartiblab, kitobni qayta tiklaydi. Biror konvert yo'qolsa — faqat shuni qayta so'raydi.

Bu qoidalar to'plami TCP/IP deyiladi: IP — paketni manzilga yetkazish, TCP — paketlar yo'qolmasligi va tartibini ta'minlash. Protokol — kompyuterlar o'rtasida kelishilgan muloqot qoidalari.

IP-manzil — tarmoqqa ulangan har bir qurilmaning noyob raqamli manzili.

DNS — internetning telefon kitobi

DNS (Domain Name System) — domen nomini IP-manzilga aylantiruvchi tizim.

O'xshatish: telefondagi kontaktlar Do'stingizga qo'ng'iroq qilganda raqamni yodlab yozmaysiz — "Aziz" ni tanlaysiz, telefon raqamni o'zi topadi. DNS ham shunday: siz kun.uz deysiz, DNS uning IP-manzilini topib beradi.

DNS so'rovi bosqichma-bosqich

  1. Brauzer keshi: "Bu saytga yaqinda kirganmidim? IP-manzili esimdami?" Ha bo'lsa — darhol ishlatadi.
  2. Operatsion tizim keshi tekshiriladi.
  3. Rekursiv DNS server (provayderingiznikini yoki 8.8.8.8 — Google, 1.1.1.1 — Cloudflare) so'raladi.
  4. U kerak bo'lsa ildiz (root) server → zona serveri (.uz) → domen serveri (kun.uz) zanjiri bo'yicha javobni topadi.
  5. Javob: kun.uz → 185.x.x.x. U ma'lum muddat (TTL) keshda saqlanadi.

Butun jarayon odatda bir necha millisoniya davom etadi.

Brauzer va HTTP

Brauzer — mijoz (client); u serverga so'rov (request) yuboradi, server javob (response) qaytaradi. Ular HTTP (HyperText Transfer Protocol) "tilida" gaplashadi.

Host: www.maktab.uz
User-Agent: Chrome/130
Accept-Language: uz
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

HTTPS = HTTP + TLS shifrlash. Server sertifikat ko'rsatadi — u saytning haqiqatan bank.uz ekanini tasdiqlaydi. Brauzer va server maxfiy kalit kelishib oladi va keyingi barcha ma'lumot shifrlanadi.

O'xshatish: ochiq otkritka va muhrlangan konvert HTTP — ochiq otkritka: pochtachi ham, qo'shni ham o'qiy oladi. HTTPS — muhrlangan, faqat qabul qiluvchi ochadigan seyf-konvert.
🔒 ≠ "sayt halol" Qulf belgisi faqat ulanish shifrlanganini bildiradi. Firibgar sayt ham HTTPS bo'lishi mumkin. Domen nomini harfma-harf tekshiring: paynne.uz, c1ick.uz kabi soxta nomlar bor.

Hammasi birgalikda: Enter bosilgandan keyin

  1. Siz https://maktab.uz deb yozib Enter bosasiz.
  2. DNS maktab.uz ni IP-manzilga aylantiradi.
  3. Brauzer shu IP-manzildagi serverga TCP ulanish o'rnatadi (443-port).
  4. TLS "qo'l siqish": sertifikat tekshiriladi, shifrlash kaliti kelishiladi.
  5. Brauzer HTTP so'rov yuboradi: GET /.
  6. Server (hosting) sahifani tayyorlab, 200 OK + HTML qaytaradi.
  7. Brauzer HTML'ni o'qiydi va CSS, rasmlar, JavaScript uchun qo'shimcha so'rovlar yuboradi.
  8. Hammasini birlashtirib, sahifani ekranga chizadi (rendering).

Bularning hammasi odatda 1 soniyadan kam vaqtda bo'ladi!
