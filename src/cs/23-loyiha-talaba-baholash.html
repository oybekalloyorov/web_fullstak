Python'da

def ball_ol(nom, maks):
    """Ballni 0..maks oralig'ida bo'lguncha qayta so'raydi."""
    while True:
        x = int(input(f"{nom} (0–{maks}): "))
        if 0 <= x <= maks:
            return x
        print("❌ Noto'g'ri! Qayta kiriting.")

ism = input("Ism: ")
jami = (ball_ol("Davomat", 10) + ball_ol("Uyga vazifa", 20)
        + ball_ol("Amaliy ish", 30) + ball_ol("Test", 40))
foiz = jami / 100 * 100
if foiz >= 86:
    baho = "5 — A'lo"
elif foiz >= 71:
    baho = "4 — Yaxshi"
elif foiz >= 56:
    baho = "3 — Qoniqarli"
else:
    baho = "2 — Qoniqarsiz"
print(f"{ism}: {jami}/100 ({foiz:.0f}%) → {baho}")

Python'da takrorlanuvchi kiritish funksiyaga (ball_ol) chiqarildi — bir marta yozib, 4 marta chaqiramiz. Flowgorithm'da ham funksiyalar bor (Program → Add Function) — qiziqqanlar uchun bonus topshiriq!

Test bali 0–40 oralig'ida bo'lishi uchun Do sikli sharti qanday?

  1. test >= 0 and test <= 40
  2. test < 0 or test > 40
  3. test == 40
  4. test != 0

Do "noto'g'ri ekan" takrorlanadi.

Jami 120, maksimal 160. Foiz?

  1. 120%
  2. 60%
  3. 75%
  4. 40%

120 / 160 × 100 = 75.

"Garbage In — Garbage Out" nimani anglatadi?

  1. Noto'g'ri kiritilgan ma'lumot noto'g'ri natija beradi
  2. Dastur axlatni o'chiradi
  3. Kompyuter tozalash kerak
  4. Fayllarni savatga tashlash
