2-qism: 5 ta ochiq topshiriq (har biri 5 ball)

Har bir topshiriqni avval o'zingiz daftarda yoki Flowgorithm'da bajaring, keyin yechim bilan solishtiring. Baholash: to'g'ri mantiq (3 ball), tekshiruvlar va to'liqlik (1 ball), tushunarli kiritish/chiqarish (1 ball).

1-topshiriq. Trassirovka

Quyidagi algoritm n = 5 uchun nima chiqaradi? O'zgaruvchilar jadvalini to'ldiring.

p = 1
i = 1
While i <= n
    p = p * 2
    i = i + 1
Output p
Yechim
i (boshida)p = p * 2
12
24
38
416
532

Natija: 32 = 25. Algoritm 2 ning n-darajasini hisoblaydi.

2-topshiriq. Chiziqli algoritm

Do'konda mahsulot narxi va soni kiritiladi. Xarid 10% chegirma bilan. To'lanadigan summani chiqaruvchi blok-sxema tuzing.

Yechim
xarid.fprg
Main
DeclareReal narx, jami
DeclareInteger soni
Inputnarx
Inputsoni
Assignjami = narx * soni * 0.9
Output"To'lov: " & jami
End

Test: 20 000 × 3 = 60 000; −10% → 54 000.

3-topshiriq. Tarmoqlanuvchi algoritm

Uchburchakning uch tomoni kiritiladi. Uchburchak mavjudmi va agar mavjud bo'lsa, u teng tomonlimi, teng yonlimi yoki turli tomonlimi — aniqlang.

Yechim 
Input a, b, c
If a + b > c and a + c > b and b + c > a
    If a == b and b == c
        Output "Teng tomonli"
    Else If a == b or b == c or a == c
        Output "Teng yonli"
    Else
        Output "Turli tomonli"
Else
    Output "Bunday uchburchak mavjud emas"

Testlar: 3,3,3 → teng tomonli; 5,5,8 → teng yonli; 3,4,5 → turli tomonli; 1,2,10 → mavjud emas.

4-topshiriq. Takrorlanuvchi algoritm

Foydalanuvchi 0 kiritmaguncha sonlarni kiritadi. Kiritilgan musbat sonlar soni va yig'indisini chiqaring (0 hisobga olinmaydi).

Yechim
musbatlar.fprg
Main
DeclareInteger x, soni, s
Assignsoni = 0
Assigns = 0
Inputx
While x != 0
x > 0
Assignsoni = soni + 1
Assigns = s + x
Inputx
Outputsoni & " ta, yig'indi " & s
End

Muhim: birinchi Input sikldan oldin, keyingisi sikl oxirida — shunda 0 hech qachon hisobga qo'shilmaydi. Test: 5, -2, 7, 0 → 2 ta, yig'indi 12.

5-topshiriq. Xatoni toping

Dastur 1 dan 10 gacha bo'lgan juft sonlar yig'indisini (30) chiqarishi kerak edi, lekin noto'g'ri ishlayapti. Ikkita xatoni toping.

For i = 1 to 10
    s = 0
    If i % 2 == 1
        s = s + i
Output s
Yechim
  1. s = 0 sikl ichida — har iteratsiyada yig'indi o'chadi. Uni sikldan oldin qo'yish kerak.
  2. Shart i % 2 == 1 — toq sonlarni tanlaydi. To'g'risi: i % 2 == 0.

Tuzatilgan: s = 0 → For i = 1 to 10 → If i % 2 == 0: s = s + i → Output s → 2+4+6+8+10 = 30. (Muqobil: For i = 2 to 10 step 2 — shartsiz.)
