Flowgorithm nima?

Flowgorithm — blok-sxemalar asosida dastur tuzish uchun bepul o'quv muhiti. Uning eng katta afzalligi: chizgan blok-sxemangiz shunchaki rasm emas — u haqiqiy dastur, uni ishga tushirish mumkin! Bundan tashqari, Flowgorithm sxemangizni avtomatik ravishda Python, C++, Java, JavaScript kabi 30 dan ortiq tilga tarjima qilib ko'rsatadi.

O'xshatish: LEGOKod yozish — loydan haykal yasashga o'xshaydi: har bir harfni o'zingiz yozasiz, bitta vergul tushib qolsa — xato. Flowgorithm esa LEGO: tayyor bloklarni bir-biriga ulaysiz. Sintaksis xatosi deyarli bo'lmaydi — siz faqat mantiq haqida o'ylaysiz.

O'rnatish

  1. Rasmiy sayt: flowgorithm.org → Download bo'limi.
  2. Windows uchun o'rnatuvchini (.msi yoki .zip) yuklab oling va ishga tushiring — Next → Next → Install.
  3. Ish stoli yoki Pusk menyusidan Flowgorithm'ni oching.
macOS / Linux / ChromebookFlowgorithm rasman Windows uchun. Boshqa tizimlarda Wine orqali ishlaydi yoki maktab kompyuterlaridan foydalaning.

Ranglar yordam beradi: Flowgorithm'da har bir blok turi o'z rangida — kiritish (yashil), chiqarish (ko'k), hisoblash (sariq), shart (to'q sariq), sikl (binafsha). Sxemaga bir qarashda qaysi qism nima qilayotgani ko'rinadi.

Strelkalar bajarilish tartibini ko'rsatadi: yuqoridan pastga. Decision'dan keyin ikki yo'l: True (shart bajarildi) va False (bajarilmadi), keyin ular yana bitta yo'lga qo'shiladi.

& belgisiFlowgorithm'da matnlarni ulash (birlashtirish) uchun & ishlatiladi: "Salom, " & ism → Salom, Ali.

Bloklar bilan ishlash

  1. Blok qo'shish: ikki blok orasidagi strelka ustiga sichqonchani bosing → bloklar menyusi chiqadi → keraklisini tanlang.
  2. Tahrirlash: blokni ikki marta bosing → oyna ochiladi, ichiga kerakli narsani yozing (o'zgaruvchi nomi, ifoda) → OK.
  3. O'chirish: blokni tanlab Delete.
  4. Ko'chirish: Ctrl+X (kesish) → kerakli strelkani bosib → Paste (yoki Ctrl+V).
  5. Nusxa: Ctrl+C / Ctrl+V. Bekor qilish: Ctrl+Z.
Ulash avtomatikFlowgorithm'da strelkalarni qo'lda chizish shart emas — blok strelkaga qo'shilgani zahoti avtomatik ulanadi. Shuning uchun sxema doim "to'g'ri" tuzilgan bo'ladi: uzilib qolgan blok bo'lmaydi.

Birinchi dastur: "Salom, dunyo!"

  1. File → New. Main va End orasidagi strelkani bosing → Output.
  2. Output blokini ikki marta bosing va yozing: "Salom, dunyo!" (qo'shtirnoq bilan — bu matn).
  3. Asboblar panelidagi ▶ Run tugmasini bosing. Console oynasida natija chiqadi.
  4. File → Save → nom: 01_salom.fprg. .fprg — Flowgorithm fayllari kengaytmasi.

Ikkinchi dastur: tanishuv

Endi dastur foydalanuvchidan ismini so'rasin. Buning uchun ism saqlanadigan "quti" — o'zgaruvchi kerak (18-mavzuda batafsil).

Dasturni tekshirish: Step va Variable Watch

Dastur noto'g'ri ishlasa, uni qadamma-qadam bajaring:

  • ⏭ Step — har bosishda bitta blok bajariladi; bajarilayotgan blok rang bilan yoritiladi.
  • Variable Watch oynasi — har bir o'zgaruvchining joriy qiymati. Qaysi qadamda qiymat "buzilganini" darhol ko'rasiz.
  • Tezlik slayderi — Run paytida bloklar qanchalik tez bajarilishini sozlaydi (sekinlashtirib kuzatish uchun).
O'xshatish: futbol VAR'iO'yin tez o'tadi, xatoni ko'rish qiyin. VAR epizodni sekin, kadrma-kadr ko'rsatadi — va qoidabuzarlik darhol aniqlanadi. Step + Variable Watch — dasturning VAR'i.

Foydali sozlamalar

  • Tools → Layout Windows yoki asboblar panelidagi tugmalar — konsol, Variable Watch va kodni yonma-yon joylash.
  • Tools → Chart Style — blok-sxema ko'rinishini (rang, shakl uslubi) o'zgartirish.
  • File → Attributes — dastur muallifi va tavsifi (loyihalarda to'ldiring!).
  • File → Export → Image — sxemani rasm sifatida saqlash (taqdimot yoki README uchun).

Amaliy topshiriqlar

  1. Vizitka: 4 ta Output bilan ismingiz, sinfingiz, maktabingiz va sevimli faningizni chiqaring.
  2. Salomlashuv: foydalanuvchidan ism va shahar so'rab, "Ali, Toshkentdan salom!" ko'rinishida javob bering.
  3. Xato ovchisi: o'qituvchi bergan "buzilgan" .fprg faylni oching, Step bilan yurib, 3 ta xatoni toping va tuzating.
  4. Barcha fayllarni 12-mavzudagi GitHub repo'ngizdagi flowgorithm/ papkasiga commit qiling.

Ko'p uchraydigan xatolar

  • ❌ Output Salom (qo'shtirnoqsiz) → ✅ Matn doim "Salom"; qo'shtirnoqsiz yozilsa — o'zgaruvchi deb qabul qilinadi.
  • ❌ Declare'siz Input → ✅ Avval Declare, keyin Input.
  • ❌ Matnni + bilan ulash → ✅ Flowgorithm'da &.
  • ❌ Faylni saqlamasdan yopish → ✅ Ctrl+S ni odat qiling.
