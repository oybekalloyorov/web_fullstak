1-bosqich: rejalashtirish

Professional dasturchilar kod yozishdan oldin texnik topshiriq tuzadi. Biz ham shunday qilamiz:

2-bosqich: 1-versiya — to'rt amal

Muammolar: (1) b = 0 va / — dastur xato bilan to'xtaydi. (2) Foydalanuvchi x yozsa — oxirgi False tarmoq bo'lishni bajaradi! Chunki "+ emas, − emas, * emas" — bu hali "/" degani emas. Tuzatamiz.

3-bosqich: 2-versiya — xatolarni tekshirish

Ikkita yangi qoida: bo'lishdan oldin b != 0 ni tekshir; oxirgi False tarmoqda "noma'lum amal" xabari. Natija hisoblanganini bilish uchun Boolean xato bayrog'i (flag) ishlatamiz:

Bayroq (flag) usuliBoolean o'zgaruvchi — "bayroq": boshida tushirilgan (false), muammo bo'lsa ko'tariladi (true). Oxirida bayroqqa qarab natijani chiqaramiz yoki chiqarmaymiz. Bu usul 23–25-loyihalarda ham kerak bo'ladi.

4-bosqich: 3-versiya — menyu va sikl

Flowgorithm'da har bir Input bloki bitta o'zgaruvchi oladi — sxemada qisqartirib bitta blokda ko'rsatildi; dasturingizda a, amal, b uchun alohida Output + Input juftliklarini qo'ying.

To'liq Python versiyasi

Flowgorithm'ning Source Code Viewer'i bergan kodni soddalashtirsak, shunday bo'ladi:

javob = "ha"
while javob == "ha":
    print("=== KALKULYATOR ===")
    a = float(input("1-son: "))
    amal = input("Amal (+ - * /): ")
    b = float(input("2-son: "))
    xato = False
    if amal == "+":
        natija = a + b
    elif amal == "-":
        natija = a - b
    elif amal == "*":
        natija = a * b
    elif amal == "/":
        if b == 0:
            print("Nolga bo'lish mumkin emas!")
            xato = True
        else:
            natija = a / b
    else:
        print("Noma'lum amal:", amal)
        xato = True
    if not xato:
        print(a, amal, b, "=", natija)
    javob = input("Yana? (ha/yo'q) ")
print("Xayr! 👋")

Qo'shimcha imkoniyatlar (yuqori ball uchun)

  • Daraja (^), qoldiq (%, b ≠ 0), ildiz (Sqrt(a), a ≥ 0 tekshiruvi bilan).
  • Hisoblashlar sonini sanash va oxirida chiqarish: "Siz 5 ta amal bajardingiz".
  • Barcha natijalar yig'indisi yoki oxirgi natijani keyingi hisobda a sifatida ishlatish ("xotira" tugmasi).
  • Amallarni raqamli menyu bilan tanlash: 1 — Qo'shish, 2 — Ayirish ...

Himoyada 2 daqiqa: 1) loyiha maqsadi; 2) sxemani ko'rsatib, mantiqni tushuntirish; 3) jonli demo: oddiy holat + xato holat; 4) qaysi qiyinchilik bo'ldi va qanday hal qildingiz.

Ko'p uchraydigan xatolar

  • ❌ Oxirgi False tarmoqda shartsiz bo'lish → ✅ Har bir amalni aniq tekshiring; qolgani — "Noma'lum amal".
  • ❌ amal ni Integer qilish → ✅ + — belgi, demak String.
  • ❌ amal == + (qo'shtirnoqsiz) → ✅ amal == "+".
  • ❌ Xato bo'lganda ham eski natija ni chiqarish → ✅ Bayroq bilan tekshirish.
  • ❌ Do sharti javob == "Ha", foydalanuvchi ha yozdi → ✅ Aniq ko'rsatma: "(ha/yo'q)".
