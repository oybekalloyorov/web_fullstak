2. Mobile dasturlash

Nima qiladi: telefon va planshet ilovalari (Telegram, Click, Payme, o'yinlar).

  • Android: Kotlin, Java — Google Play Market'ga joylanadi.
  • iOS: Swift — Apple App Store'ga joylanadi.
  • Kross-platforma (bir kod — ikki platforma): Flutter (Dart), React Native (JavaScript).

Mobil dasturchi kamera, GPS, push-xabarnoma, batareya tejamkorligi kabi telefonning o'ziga xos imkoniyatlari bilan ishlaydi.

4. Sun'iy intellekt (AI) va Machine Learning (ML)

Sun'iy intellekt — odatda inson aqlini talab qiladigan ishlarni bajaradigan kompyuter tizimlari: nutqni tanish, tarjima, rasmdagi narsani aniqlash, matn yozish.

Machine Learning (mashinani o'rgatish) — AI'ning asosiy usuli: dasturga qoidalarni qo'lda yozish o'rniga, unga ko'plab misollar ko'rsatiladi va u qonuniyatni o'zi topadi.

Misollar: ChatGPT/Claude kabi til modellari, Google Translate, yuzni tanib telefonni ochish, YouTube tavsiyalari, avtopilot. Vositalar: Python, TensorFlow, PyTorch, Google Teachable Machine (brauzerda 5 daqiqada o'z modelingizni o'rgating!).

5. DevOps va bulutli infratuzilma

DevOps = Development (dasturlash) + Operations (ekspluatatsiya). Dasturchilar yozgan kodni serverlarga tez, xavfsiz va avtomatik yetkazish, tizimning 24/7 ishlashini ta'minlash.

  • Serverlar — Linux, ma'lumot markazlari, bulut: AWS, Azure, Google Cloud (11-mavzudagi IaaS).
  • CI/CD — kod GitHub'ga push qilinsa, avtomatik test qilinib, saytga chiqariladi (GitHub Actions).
  • Konteynerlar — Docker: dasturni "qutiga" solib, istalgan serverda bir xil ishlatish.
  • Monitoring — server yuklamasi, xatolar, tezlikni kuzatish.
O'xshatish: aeroport xizmatiUchuvchi (dasturchi) samolyotni boshqaradi, lekin uchish yo'lagi, yoqilg'i, dispetcherlik, xavfsizlik nazorati — DevOps muhandislari ishi. Ularsiz hech bir reys uchmaydi.

6. Cybersecurity — axborot xavfsizligi

Nima qiladi: tizimlar, tarmoqlar va ma'lumotlarni xakerlardan himoya qiladi.

  • Pentester (oq xaker) — ruxsat bilan tizimga "hujum qilib", zaif joylarni topadi.
  • SOC tahlilchisi — hujumlarni real vaqtda kuzatadi va to'xtatadi.
  • Xavfsizlik muhandisi — himoya tizimlarini quradi: shifrlash, firewall, 2FA.

Boshlash: 6- va 14-mavzular, tarmoq asoslari, Linux, CTF musobaqalari (picoCTF — maktab o'quvchilari uchun).

QonunRuxsatsiz birovning akkaunti yoki tizimiga kirish — jinoyat. Kiberxavfsizlik faqat ruxsat etilgan o'quv platformalarida (CTF, laboratoriyalar) mashq qilinadi.
