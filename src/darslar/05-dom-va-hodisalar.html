Oldingi darsda JavaScript tilini o'rgandik. Endi uni sahifa bilan bog'laymiz. DOM (Document Object Model) — brauzer HTML'dan quradigan va JavaScript orqali boshqarish mumkin bo'lgan obyektlar daraxti. Tugma bosilganda oyna ochilishi, forma tekshirilishi, ro'yxatga element qo'shilishi — barchasi DOM bilan ishlash.

            └── li

  • Daraxtdagi har bir narsa — tugun (node): element tugunlari, matn tugunlari, izoh tugunlari.
  • document — daraxtning ildizi va DOM bilan ishlashning kirish nuqtasi.
  • Elementlar o'rtasida oilaviy munosabatlar bor: ota (parent), farzand (child), aka-uka (sibling).
DOM ≠ HTML manba kodi DOM — "jonli" tuzilma. JavaScript uni o'zgartirsa, sahifa darhol yangilanadi, lekin serverdagi HTML fayl o'zgarmaydi. DevTools'dagi Elements paneli manba kodni emas, aynan joriy DOM'ni ko'rsatadi.

Elementlarni topish

// Zamonaviy va universal usul — CSS selektorlari bilan
const title = document.querySelector('#title');          // birinchi mos element yoki null
const firstItem = document.querySelector('.list li');
const items = document.querySelectorAll('.list li');     // NodeList (barcha moslar)
items.forEach(li => console.log(li.textContent));
const arr = [...items];                                  // haqiqiy massivga aylantirish

// Klassik usullar
document.getElementById('title');
document.getElementsByClassName('list');   // "jonli" HTMLCollection
document.getElementsByTagName('li');

// Element ichidan qidirish
const list = document.querySelector('.list');
list.querySelectorAll('li');

// Daraxt bo'ylab harakatlanish
const li = list.firstElementChild;
li.parentElement;              // ul
li.nextElementSibling;         // ikkinchi li
li.closest('.list');           // eng yaqin mos ajdod (o'zi ham kiradi) — juda foydali!
list.children;                 // farzand elementlar

Elementlarni o'zgartirish

Mazmun

const el = document.querySelector('#title');

el.textContent = 'Yangi sarlavha';             // faqat matn — XAVFSIZ
el.innerHTML = 'Bugungi vazifalar';   // HTML sifatida talqin qilinadi — EHTIYOT BO'LING

// ❌ Hech qachon foydalanuvchi kiritgan ma'lumotni innerHTML ga qo'ymang:
const izoh = '';
// el.innerHTML = izoh;   // XSS hujumi! Skript bajariladi
el.textContent = izoh;    // ✅ shunchaki matn sifatida ko'rinadi
XSS (Cross-Site Scripting) innerHTML ga tekshirilmagan ma'lumot qo'yish — webdagi eng keng tarqalgan zaifliklardan biri. Hujumchi izoh, ism yoki qidiruv so'zi orqali o'z skriptini boshqa foydalanuvchilar brauzerida bajarishi mumkin. Foydalanuvchi ma'lumoti uchun doim textContent dan foydalaning (14-darsda batafsil).
