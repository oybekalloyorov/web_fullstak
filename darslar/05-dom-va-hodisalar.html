DOM va hodisalar

DOM daraxti, elementlarni topish va o'zgartirish, hodisalar (events), bubbling va delegatsiya, formalar bilan ishlash, localStorage.

O'rta · ~120 daqiqa

Oldingi darsda JavaScript tilini o'rgandik. Endi uni sahifa bilan bog'laymiz. DOM (Document Object Model) — brauzer HTML'dan quradigan va JavaScript orqali boshqarish mumkin bo'lgan obyektlar daraxti. Tugma bosilganda oyna ochilishi, forma tekshirilishi, ro'yxatga element qo'shilishi — barchasi DOM bilan ishlash.

#DOM daraxti

Quyidagi HTML:

HTML
<body>
  <h1 id="title">Vazifalar</h1>
  <ul class="list">
    <li>Non olish</li>
    <li>Dars qilish</li>
  </ul>
</body>

brauzerda shunday daraxtga aylanadi:

Matn
document
└── html
    ├── head
    └── body
        ├── h1#title
        │   └── "Vazifalar"          (matn tuguni)
        └── ul.list
            ├── li
            │   └── "Non olish"
            └── li
                └── "Dars qilish"
  • Daraxtdagi har bir narsa — tugun (node): element tugunlari, matn tugunlari, izoh tugunlari.
  • document — daraxtning ildizi va DOM bilan ishlashning kirish nuqtasi.
  • Elementlar o'rtasida oilaviy munosabatlar bor: ota (parent), farzand (child), aka-uka (sibling).
DOM ≠ HTML manba kodi DOM — "jonli" tuzilma. JavaScript uni o'zgartirsa, sahifa darhol yangilanadi, lekin serverdagi HTML fayl o'zgarmaydi. DevTools'dagi Elements paneli manba kodni emas, aynan joriy DOM'ni ko'rsatadi.

#Hodisalar (Events)

Hodisa — brauzerda sodir bo'lgan narsa: bosish, klavish bosilishi, forma yuborilishi, sahifa yuklanishi, scroll. Biz hodisaga tinglovchi (listener) — funksiya biriktiramiz.

JavaScript
const btn = document.querySelector('#save');

function saqlash(event) {
  console.log('Hodisa turi:', event.type);          // 'click'
  console.log('Bosilgan element:', event.target);
  console.log('Koordinatalar:', event.clientX, event.clientY);
}

btn.addEventListener('click', saqlash);
btn.removeEventListener('click', saqlash);   // olib tashlash uchun AYNI funksiya kerak

// Variantlar
btn.addEventListener('click', saqlash, { once: true });   // faqat bir marta
window.addEventListener('scroll', onScroll, { passive: true }); // scroll unumdorligi uchun

// ❌ Eskicha usul (bitta hodisaga faqat bitta ishlovchi):
// btn.onclick = saqlash;
// <button onclick="saqlash()">  — HTML va JS aralashib ketadi

#Hodisa tarqalishi: capturing va bubbling

Ichma-ich elementlardan biri bosilganda hodisa uch bosqichdan o'tadi:

  1. Capturing — window dan maqsad elementga qarab pastga tushadi;
  2. Target — maqsad elementga yetadi;
  3. Bubbling — maqsad elementdan window gacha yuqoriga "ko'tariladi" (pufakchadek).
HTML
<div id="karta">
  <button id="tugma">Bos</button>
</div>
<script>
  karta.addEventListener('click', () => console.log('2. karta'));
  tugma.addEventListener('click', () => console.log('1. tugma'));
  document.body.addEventListener('click', () => console.log('3. body'));
  // Tugma bosilsa: 1. tugma → 2. karta → 3. body
</script>
  • event.target — hodisa haqiqatda sodir bo'lgan element (bosilgan tugma).
  • event.currentTarget — tinglovchi biriktirilgan element.
  • event.stopPropagation() — ko'tarilishni to'xtatadi (kamdan-kam va ehtiyotkorlik bilan ishlating).

Hodisa delegatsiyasi (event delegation)

Bubbling tufayli 100 ta tugmaning har biriga tinglovchi qo'yish shart emas — ularning umumiy otasiga bittasini qo'yish yetarli. Bu usul dinamik qo'shilgan elementlar uchun ham avtomatik ishlaydi.

JavaScript
// ❌ Har bir tugmaga alohida — yangi qo'shilgan elementlar ishlamaydi
document.querySelectorAll('.delete-btn').forEach(btn =>
  btn.addEventListener('click', ...)
);

// ✅ Delegatsiya — bitta tinglovchi
document.querySelector('#todo-list').addEventListener('click', (e) => {
  const btn = e.target.closest('button[data-action]');
  if (!btn) return;                                  // tugmadan boshqa joy bosildi
  const item = btn.closest('li');
  const id = item.dataset.id;

  if (btn.dataset.action === 'delete') deleteTodo(id);
  if (btn.dataset.action === 'edit') editTodo(id);
});

todo/app.js
// ===== Holat (state) =====
const STORAGE_KEY = 'todos-v1';
let todos = load();
let filter = 'all';

function load() {
  try { return JSON.parse(localStorage.getItem(STORAGE_KEY)) ?? []; }
  catch { return []; }
}
function save() {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
}

// ===== Amallar: holatni o'zgartirib, keyin render =====
function addTodo(text) {
  todos.unshift({ id: crypto.randomUUID(), text, done: false, createdAt: Date.now() });
  update();
}
function toggleTodo(id) {
  todos = todos.map(t => (t.id === id ? { ...t, done: !t.done } : t));
  update();
}
function deleteTodo(id) {
  todos = todos.filter(t => t.id !== id);
  update();
}
function editTodo(id, text) {
  todos = todos.map(t => (t.id === id ? { ...t, text } : t));
  update();
}
function update() { save(); render(); }

// ===== Render: holatdan DOM chizish =====
const list = document.querySelector('#todo-list');
const counter = document.querySelector('#counter');

function render() {
  const visible = todos.filter(t =>
    filter === 'all' ? true : filter === 'done' ? t.done : !t.done
  );

  list.replaceChildren(...visible.map(createItem));

  if (visible.length === 0) {
    const empty = document.createElement('li');
    empty.className = 'empty';
    empty.textContent = 'Hozircha vazifa yo\'q 🎉';
    list.append(empty);
  }

  const left = todos.filter(t => !t.done).length;
  counter.textContent = `${left} ta faol vazifa`;

  document.querySelectorAll('[data-filter]').forEach(b =>
    b.classList.toggle('active', b.dataset.filter === filter)
  );
}

function createItem(todo) {
  const li = document.createElement('li');
  li.dataset.id = todo.id;
  li.classList.toggle('done', todo.done);

  const checkbox = document.createElement('input');
  checkbox.type = 'checkbox';
  checkbox.checked = todo.done;
  checkbox.dataset.action = 'toggle';

  const span = document.createElement('span');
  span.className = 'text';
  span.textContent = todo.text;           // ✅ textContent — XSS'dan himoya
  span.title = 'Tahrirlash uchun ikki marta bosing';

  const del = document.createElement('button');
  del.dataset.action = 'delete';
  del.setAttribute('aria-label', 'O\'chirish');
  del.textContent = '✕';

  li.append(checkbox, span, del);
  return li;
}

// ===== Hodisalar =====
document.querySelector('#todo-form').addEventListener('submit', (e) => {
  e.preventDefault();
  const input = e.target.elements.text;
  const text = input.value.trim();
  if (!text) return;
  addTodo(text);
  input.value = '';
  input.focus();
});

// Delegatsiya: bitta tinglovchi barcha elementlar uchun
list.addEventListener('click', (e) => {
  const li = e.target.closest('li[data-id]');
  if (!li) return;
  const action = e.target.dataset.action;
  if (action === 'toggle') toggleTodo(li.dataset.id);
  if (action === 'delete') deleteTodo(li.dataset.id);
});

// Ikki marta bosib tahrirlash
list.addEventListener('dblclick', (e) => {
  const span = e.target.closest('.text');
  if (!span) return;
  const li = span.closest('li');
  const input = document.createElement('input');
  input.value = span.textContent;
  input.className = 'edit';
  span.replaceWith(input);
  input.focus();

  const finish = (saveIt) => {
    const value = input.value.trim();
    if (saveIt && value) editTodo(li.dataset.id, value);
    else render();
  };
  input.addEventListener('keydown', (ev) => {
    if (ev.key === 'Enter') finish(true);
    if (ev.key === 'Escape') finish(false);
  });
  input.addEventListener('blur', () => finish(true), { once: true });
});

document.querySelector('.filters').addEventListener('click', (e) => {
  const btn = e.target.closest('[data-filter]');
  if (!btn) return;
  filter = btn.dataset.filter;
  render();
});

document.querySelector('#clear-done').addEventListener('click', () => {
  todos = todos.filter(t => !t.done);
  update();
});

render();

Modal oyna (accessibility bilan)

HTML'ning o'rnatilgan <dialog> elementi fokusni boshqarish va Esc bilan yopishni o'zi bajaradi.

HTML
<button id="open-modal">Buyurtmani tasdiqlash</button>

<dialog id="confirm-modal" aria-labelledby="modal-title">
  <form method="dialog">
    <h2 id="modal-title">Buyurtmani tasdiqlaysizmi?</h2>
    <p>Jami: <b>1 105 200 so'm</b>. Buyurtma 2 kun ichida yetkaziladi.</p>
    <menu>
      <button value="cancel">Bekor qilish</button>
      <button value="confirm" class="primary">Tasdiqlash</button>
    </menu>
  </form>
</dialog>

<p id="status"></p>

<style>
  dialog { border: 0; border-radius: 16px; padding: 28px; max-width: 420px; box-shadow: 0 20px 60px rgb(0 0 0 / .25); }
  dialog::backdrop { background: rgb(15 23 42 / .55); backdrop-filter: blur(3px); }
  dialog[open] { animation: pop .2s ease; }
  @keyframes pop { from { opacity: 0; transform: scale(.95); } }
  menu { display: flex; justify-content: flex-end; gap: 8px; padding: 0; }
  .primary { background: #4f46e5; color: #fff; border: 0; padding: 8px 16px; border-radius: 8px; }
</style>

<script>
  const modal = document.querySelector('#confirm-modal');
  const status = document.querySelector('#status');

  document.querySelector('#open-modal').addEventListener('click', () => modal.showModal());

  // Fon (backdrop) bosilganda yopish
  modal.addEventListener('click', (e) => {
    if (e.target === modal) modal.close('cancel');
  });

  // Qaysi tugma bilan yopilganini bilish
  modal.addEventListener('close', () => {
    status.textContent = modal.returnValue === 'confirm'
      ? '✅ Buyurtma qabul qilindi!'
      : 'Buyurtma bekor qilindi.';
  });
</script>

<form method="dialog"> ichidagi tugma bosilganda dialog avtomatik yopiladi va tugmaning valuesi modal.returnValue ga yoziladi. showModal() orqa fondagi sahifani "faolsizlantiradi" — klaviatura fokusi oynadan tashqariga chiqmaydi.

      !/^[a-z0-9_]{3,20}$/i.test(v) ? '3–20 ta lotin harf, raqam yoki _' : null,
    email: (v) =>
      !v ? 'Majburiy maydon' :
      !/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/.test(v) ? 'Email noto\'g\'ri' : null,
    password: (v) =>
      v.length < 8 ? 'Kamida 8 ta belgi' :
      !/\d/.test(v) || !/[A-Za-z]/.test(v) ? 'Harf va raqam bo\'lishi shart' : null,
    confirm: (v, all) => v !== all.password ? 'Parollar mos emas' : null,
  };

  function validateField(name) {
    const values = Object.fromEntries(new FormData(form));
    const error = rules[name](values[name] ?? '', values);
    const field = form.elements[name].closest('.field');
    field.querySelector('.error').textContent = error ?? '';
    field.classList.toggle('invalid', !!error);
    field.classList.toggle('valid', !error);
    return !error;
  }

  function passwordStrength(p) {
    let score = 0;
    if (p.length >= 8) score++;
    if (p.length >= 12) score++;
    if (/[A-Z]/.test(p) && /[a-z]/.test(p)) score++;
    if (/\d/.test(p)) score++;
    if (/[^A-Za-z0-9]/.test(p)) score++;
    return score; // 0..5
  }

  form.addEventListener('input', (e) => {
    const name = e.target.name;
    validateField(name);
    if (name === 'password') {
      if (form.elements.confirm.value) validateField('confirm');
      const s = passwordStrength(e.target.value);
      const bar = form.querySelector('.meter span');
      bar.style.width = `${s * 20}%`;
      bar.style.background = ['#ef4444', '#ef4444', '#f59e0b', '#eab308', '#22c55e', '#16a34a'][s];
    }
  });

  form.addEventListener('submit', (e) => {
    e.preventDefault();
    const ok = Object.keys(rules).map(validateField).every(Boolean);
    if (!ok) {
      form.querySelector('.invalid input').focus();
      return;
    }
    const { confirm, ...data } = Object.fromEntries(new FormData(form));
    console.log('Serverga yuboriladi:', data);   // 6-darsda fetch() bilan yuboramiz
  });
</script>

Diqqat qiling: barcha maydonlar uchun bitta input tinglovchisi (delegatsiya); qoidalar ma'lumot sifatida (rules obyekti) saqlangan — yangi maydon qo'shish uchun faqat bitta qoida yozish kifoya. novalidate esa brauzerning standart xabarlarini o'chirib, o'zimiznikini ko'rsatishga imkon beradi.

<script>
  // Tablar: sichqoncha va klaviatura (← →) bilan
  document.querySelectorAll('[data-tabs]').forEach((root) => {
    const tabs = [...root.querySelectorAll('[role="tab"]')];

    function select(tab) {
      tabs.forEach((t) => {
        const active = t === tab;
        t.setAttribute('aria-selected', active);
        t.tabIndex = active ? 0 : -1;
        root.querySelector('#' + t.getAttribute('aria-controls')).hidden = !active;
      });
      tab.focus();
    }

    root.addEventListener('click', (e) => {
      const tab = e.target.closest('[role="tab"]');
      if (tab) select(tab);
    });

    root.addEventListener('keydown', (e) => {
      const i = tabs.indexOf(document.activeElement);
      if (i === -1) return;
      if (e.key === 'ArrowRight') select(tabs[(i + 1) % tabs.length]);
      if (e.key === 'ArrowLeft') select(tabs[(i - 1 + tabs.length) % tabs.length]);
    });
  });

  // Akkordeon: bir vaqtda faqat bitta savol ochiq bo'lsin
  const faq = document.querySelector('.faq');
  faq.addEventListener('toggle', (e) => {
    if (!e.target.open) return;
    faq.querySelectorAll('details[open]').forEach((d) => {
      if (d !== e.target) d.open = false;
    });
  }, true);   // toggle hodisasi bubbling qilmaydi — capturing bosqichida ushlaymiz
</script>

Bu yerda ARIA atributlari (role, aria-selected, aria-controls) ekran o'quvchilarga komponent tuzilishini tushuntiradi, tabIndex esa "roving tabindex" usuli bilan klaviatura navigatsiyasini to'g'ri qiladi. Akkordeonda toggle hodisasi ko'tarilmagani uchun addEventListener ning uchinchi argumenti true (capturing) ishlatilgan.
