HTML — sahifa tuzilishi

Teglar, atributlar, semantik HTML, formalar, jadvallar, media, accessibility va SEO uchun meta-teglar.

Boshlang'ich · ~90 daqiqa

HTML (HyperText Markup Language) — veb-sahifaning skeleti. U dasturlash tili emas, balki belgilash (markup) tili: biz matnning qaysi qismi sarlavha, qaysisi paragraf, qaysisi havola yoki tugma ekanini brauzerga tushuntiramiz. Yaxshi yozilgan HTML — tez ishlaydigan, qidiruv tizimlarida yuqorida chiqadigan va ko'zi ojiz foydalanuvchilar ham bemalol ishlata oladigan saytning asosi.

#Element, teg va atribut

HTML hujjati elementlardan tashkil topadi. Element odatda ochuvchi teg, mazmun va yopuvchi tegdan iborat:

HTML
<a href="https://kun.uz" target="_blank" title="Yangiliklar">Kun.uz saytiga o'tish</a>
<!-- └ochuvchi teg ┘ └──── atributlar ────────────────┘ └─── mazmun ──────┘└yopuvchi┘ -->
  • Teg — burchak qavslar ichidagi nom: <p>, </p>.
  • Atribut — elementga qo'shimcha ma'lumot: nom="qiymat". Har doim ochuvchi tegda yoziladi.
  • Bo'sh (void) elementlar — mazmuni bo'lmaydi va yopilmaydi: <img>, <br>, <input>, <meta>, <link>, <hr>.
  • Ichma-ich joylashish (nesting) — elementlar to'g'ri tartibda yopilishi kerak: <p><b>matn</b></p> ✅, <p><b>matn</p></b> ❌.

Global atributlar

Istalgan elementda ishlatiladigan atributlar:

AtributVazifasi
idSahifada yagona identifikator. CSS, JS va #havola uchun
classBir yoki bir nechta sinf nomi (bo'sh joy bilan). CSS uslublari uchun asosiy vosita
styleInline CSS (kamdan-kam ishlating)
titleSichqoncha ustiga olib borilganda chiqadigan izoh
hiddenElementni yashiradi
data-*O'z ma'lumotingizni saqlash: data-product-id="42" → JS'da el.dataset.productId
langMazmun tili: lang="uz"
tabindexKlaviatura (Tab) bilan fokus tartibi

#HTML hujjatining asosiy tuzilishi

Har bir HTML sahifa quyidagi skeletdan boshlanadi. VS Code'da bo'sh .html faylga ! yozib Tab bossangiz, u avtomatik yaratiladi.

HTML
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Sahifa haqida 150–160 belgili qisqa tavsif (Google natijalarida chiqadi)">
  <title>Sahifa sarlavhasi — Sayt nomi</title>
  <link rel="icon" href="/favicon.ico">
  <link rel="stylesheet" href="css/style.css">
  <script src="js/app.js" defer></script>
</head>
<body>
  <!-- Foydalanuvchi ko'radigan barcha narsa shu yerda -->
</body>
</html>
  • <!DOCTYPE html> — brauzerga "bu zamonaviy HTML5 hujjat" deydi. Usiz brauzer eski "quirks mode"ga o'tadi va CSS g'alati ishlaydi.
  • <html lang="uz"> — ildiz element; lang ekran o'quvchilar va tarjimonlar uchun muhim.
  • <head> — ko'rinmaydigan meta-ma'lumotlar: kodlash, sarlavha, CSS, skriptlar.
  • <meta charset="UTF-8"> — o'zbekcha o', g', kirill harflari va emoji to'g'ri chiqishi uchun. Har doim birinchi qatorlarda.
  • <meta name="viewport"> — telefonlarda sahifa kichraytirilmasdan, ekran kengligida ko'rsatilishi uchun. Usiz responsiv dizayn ishlamaydi.
  • defer — skript HTML to'liq o'qilgandan keyin bajariladi va parsing'ni bloklamaydi.

#Matn bilan ishlash

Sarlavhalar

<h1> dan <h6> gacha. Ular hujjatning mazmun tuzilishini (kitobning mundarijasi kabi) bildiradi, shrift o'lchamini emas.

  • Sahifada odatda bitta <h1> bo'ladi — sahifaning asosiy mavzusi.
  • Darajalarni sakrab o'tmang: h2 dan keyin to'g'ridan-to'g'ri h4 emas.
  • Matnni katta qilish uchun sarlavha tegi ishlatmang — buning uchun CSS bor.

#Semantik HTML

Semantik — "ma'noli" degani. 2000-yillarda saytlar faqat <div> lardan qurilgan ("div sho'rva"). HTML5 sahifa qismlarining vazifasini bildiruvchi teglar qo'shdi:

TegMa'nosi
<header>Sahifa yoki bo'limning kirish qismi: logo, sarlavha, navigatsiya
<nav>Asosiy navigatsiya havolalari bloki
<main>Sahifaning asosiy, noyob mazmuni (sahifada bitta)
<article>Mustaqil, alohida tarqatsa bo'ladigan mazmun: maqola, post, mahsulot kartasi, izoh
<section>Mavzu bo'yicha guruhlangan qism (odatda sarlavhasi bilan)
<aside>Asosiy mazmunga bilvosita aloqador: yon panel, reklama, "o'xshash maqolalar"
<footer>Pastki qism: mualliflik, aloqa, havolalar
<time>Sana/vaqt: <time datetime="2026-10-03">3-oktabr</time>
<address>Aloqa ma'lumotlari
<div>, <span>Ma'nosiz konteynerlar — faqat uslub berish uchun (blok va qator ichi)

Nega semantika muhim?

  1. SEO — Google sahifaning qaysi qismi asosiy mazmun ekanini tushunadi.
  2. Accessibility (a11y) — ekran o'quvchi dasturlar "navigatsiyaga o'tish", "asosiy mazmunga o'tish" imkonini beradi.
  3. O'qilishi — kodni ko'rgan dasturchi tuzilmani darhol tushunadi.

Blok va qator ichi (inline) elementlar

  • Blok elementlar (div, p, h1–h6, ul, section, article, form) yangi qatordan boshlanadi va butun kenglikni egallaydi.
  • Inline elementlar (span, a, strong, em, img, code) matn oqimida qatorda turadi va faqat kerakli kenglikni egallaydi.

Bu xatti-harakatni CSS'dagi display xususiyati bilan o'zgartirish mumkin (3-dars).

#Formalar — foydalanuvchidan ma'lumot olish

Formalar — frontend va backend o'rtasidagi ko'prik. Ro'yxatdan o'tish, qidiruv, buyurtma — barchasi forma orqali.

HTML
<form action="/api/register" method="POST">
  <label for="email">Email</label>
  <input type="email" id="email" name="email" required placeholder="siz@mail.uz">

  <label for="password">Parol</label>
  <input type="password" id="password" name="password" required minlength="8">

  <button type="submit">Ro'yxatdan o'tish</button>
</form>
  • action — ma'lumot yuboriladigan URL. method — GET (ma'lumot URL'ga qo'shiladi, qidiruv uchun) yoki POST (tanada yuboriladi, maxfiy ma'lumotlar uchun).
  • name — eng muhim atribut: serverga name=qiymat ko'rinishida yuboriladi. namesiz maydon yuborilmaydi!
  • <label for="id"> — yozuvni maydonga bog'laydi: yozuv bosilganda maydon fokuslanadi va ekran o'quvchi uni o'qiydi.

Input turlari

typeKo'rinishi / vazifasi
textOddiy matn
emailEmail formatini tekshiradi; telefonda @ bor klaviatura chiqadi
passwordBelgilar yashiriladi
numberRaqam; min, max, step
tel, url, searchTelefon, manzil, qidiruv
date, time, datetime-localSana/vaqt tanlagich
checkboxBir nechtasini belgilash mumkin
radioBir guruhdan (bir xil name) faqat bittasi
fileFayl tanlash; accept="image/*", multiple

Brauzerning o'rnatilgan validatsiyasi

  • required — majburiy maydon
  • minlength, maxlength — matn uzunligi
  • min, max — son/sana chegarasi
  • pattern="[0-9]{9}" — regex bo'yicha tekshirish
Brauzer validatsiyasi faqat foydalanuvchiga qulaylik uchun. Uni DevTools orqali osongina o'chirish mumkin. Server tomonda albatta qayta tekshiring (9-dars).

#Accessibility (a11y) va SEO asoslari

Accessibility — hamma uchun qulay sayt

  • Semantik teglardan foydalaning; tugma uchun <button>, havola uchun <a> (<div onclick> emas — u klaviaturadan ishlamaydi).
  • Har bir rasmda mazmunli alt, har bir input'da <label>.
  • Sarlavhalar ierarxiyasini buzmang.
  • Faqat ikonkadan iborat tugmalarga aria-label qo'shing: <button aria-label="Yopish">✕</button>.
  • Saytni sichqonchasiz, faqat Tab, Enter, Space bilan ishlatib ko'ring.

🏋️ Mustaqil ish

  1. O'zingiz uchun 1-misoldagi kabi portfolio sahifasi yarating — kamida 3 ta loyiha, ko'nikmalar ro'yxati va aloqa bo'limi bilan.
  2. Kitob do'koni uchun "Buyurtma berish" formasini yarating: kitob tanlash (select), soni (number, 1–10), yetkazish usuli (radio), manzil (textarea), yetkazish sanasi (date).

  4. Sahifangizni validator.w3.org orqali tekshiring va barcha xatolarni tuzating.
  5. Chrome DevTools → Lighthouse → "Accessibility" va "SEO" bo'yicha audit o'tkazing. 90+ ball olishga harakat qiling.

✅ Xulosa

  • HTML — mazmun va tuzilma; ko'rinish CSS'ga, xatti-harakat JS'ga tegishli.
  • <!DOCTYPE>, charset, viewport — har bir sahifada majburiy.
  • Semantik teglar (header, nav, main, article, section, aside, footer) SEO va accessibility uchun muhim.
  • Formalarda name, label, to'g'ri type va validatsiya atributlarini ishlating; serverda baribir qayta tekshiring.
  • Rasmlarda doim alt, width/height va kerak bo'lsa loading="lazy".
