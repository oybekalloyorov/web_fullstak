CSS — dizayn va maket

Selektorlar, kaskad va spetsifiklik, box model, Flexbox, Grid, pozitsiyalash, responsiv dizayn, CSS o'zgaruvchilari va animatsiyalar.

Boshlang'ich · ~120 daqiqa
📄 PDF yuklab olish

CSS (Cascading Style Sheets) HTML elementlarining ko'rinishini boshqaradi: rang, shrift, o'lcham, joylashuv, animatsiya. HTML — uyning g'ishtlari bo'lsa, CSS — uning bo'yog'i, mebeli va xonalar rejasi. CSS'ni "oson" deb o'ylash xato: kaskad, spetsifiklik va maket algoritmlarini tushunmasdan yozilgan CSS tezda boshqarib bo'lmaydigan tartibsizlikka aylanadi. Bu darsda CSS'ni tizimli tushunamiz.

#CSS'ni ulash usullari

HTML
<!-- 1. Tashqi fayl (eng to'g'ri usul — keshlanadi, qayta ishlatiladi) -->
<link rel="stylesheet" href="css/style.css">

<!-- 2. Ichki <style> bloki (bitta sahifaga xos uslublar) -->
<style>
  h1 { color: navy; }
</style>

<!-- 3. Inline (eng yuqori ustuvorlik, lekin qo'llab-quvvatlash qiyin) -->
<p style="color: red; font-weight: bold;">Diqqat!</p>

Qoida sintaksisi

CSS
/* selektor   { xususiyat: qiymat; } */
.card-title {
  color: #1e293b;          /* deklaratsiya */
  font-size: 1.25rem;
  margin-bottom: 8px;
}

#Kaskad, spetsifiklik va meros

Bitta elementga bir nechta qoida to'g'ri kelsa, qaysi biri g'olib bo'ladi? Brauzer quyidagi tartibda hal qiladi (bu "Cascading" so'zining ma'nosi):

  1. Muhimlik (importance) — !important belgilangan deklaratsiya ustun turadi.
  2. Spetsifiklik — aniqroq selektor yutadi.
  3. Manba tartibi — spetsifiklik teng bo'lsa, keyinroq yozilgan qoida yutadi.

Spetsifiklikni hisoblash

Spetsifiklik uchta raqam bilan o'lchanadi: (ID, Sinf, Teg).

Selektor(ID, Sinf/atribut/psevdo-sinf, Teg/psevdo-element)
p(0, 0, 1)
.card p(0, 1, 1)
.card .title:hover(0, 3, 0)
#main .card p(1, 1, 1)
style="..."har qanday selektordan yuqori

Raqamlar chapdan o'ngga solishtiriladi: (1,0,0) har doim (0,15,0) dan katta.

CSS
#app p      { color: blue;  }  /* (1,0,1) — G'OLIB */
.text.big   { color: green; }  /* (0,2,0) */
p           { color: red;   }  /* (0,0,1) */
Amaliy maslahat Uslublar uchun deyarli faqat sinflardan foydalaning. ID selektorlari va !important spetsifiklikni keskin oshiradi va keyinchalik uslubni o'zgartirishni qiyinlashtiradi. Spetsifiklikni past va bir tekis saqlash — toza CSS'ning siri.

Meros (inheritance)

Ba'zi xususiyatlar ota elementdan farzandlarga avtomatik o'tadi: asosan matn bilan bog'liqlar — color, font-family, font-size, line-height, text-align. O'lcham va joylashuv xususiyatlari (margin, padding, border, width) meros qilinmaydi. Shuning uchun shriftni bir marta body ga berish yetarli.

CSS
body { font-family: "Inter", sans-serif; color: #222; line-height: 1.6; }
button { font: inherit; }   /* tugmalar odatda shriftni meros olmaydi — majburlaymiz */

#Box model — har bir element bu quti

Brauzer har bir elementni to'rtburchak quti sifatida chizadi. Quti to'rt qatlamdan iborat:

margin (tashqi bo'shliq)
border (chegara)
padding (ichki bo'shliq)
content (mazmun)
CSS
.box {
  width: 300px;
  padding: 20px;              /* ichki bo'shliq: barcha tomonlar */
  border: 2px solid #333;
  margin: 16px auto;          /* tepa/past 16px, chap/o'ng auto = gorizontal markazlash */
}

/* Qisqa yozuv tartibi: tepa → o'ng → past → chap (soat strelkasi bo'yicha) */
.a { padding: 10px 20px 30px 40px; }
.b { padding: 10px 20px; }   /* tepa/past 10, chap/o'ng 20 */

box-sizing — eng muhim bitta qator

Standart holatda (content-box) width: 300px faqat mazmunga tegishli: yuqoridagi quti haqiqatda 300 + 2×20 + 2×2 = 344px keng bo'ladi. Bu hisob-kitobni qiyinlashtiradi. border-box da esa width padding va border'ni o'z ichiga oladi:

CSS
/* Deyarli har bir loyihaning birinchi qatorlari */
*, *::before, *::after {
  box-sizing: border-box;
}
Margin collapse Ikki blok element ustma-ust tursa, ularning vertikal marginlari qo'shilmaydi, balki kattasi olinadi: margin-bottom: 30px va margin-top: 20px orasidagi masofa 50 emas, 30px bo'ladi. Flex va Grid ichida bu hodisa yuz bermaydi.

#Flexbox — bir o'lchamli maket

Flexbox elementlarni bir yo'nalish bo'yicha (qator yoki ustun) joylashtirish uchun. Navigatsiya, tugmalar guruhi, kartaning ichki qismi, markazlash — barchasi Flexbox bilan oson.

Ikki tushuncha: flex-konteyner (display: flex berilgan ota) va flex-elementlar (uning bevosita farzandlari). Shuningdek ikki o'q: asosiy o'q (main axis) — flex-direction yo'nalishi, va kesishgan o'q (cross axis) — unga perpendikulyar.

Konteyner xususiyatlari

CSS
.container {
  display: flex;
  flex-direction: row;          /* row | row-reverse | column | column-reverse */
  flex-wrap: wrap;              /* sig'masa keyingi qatorga o'tish */
  justify-content: space-between; /* ASOSIY o'q bo'yicha: flex-start | center | flex-end | space-between | space-around | space-evenly */
  align-items: center;          /* KESISHGAN o'q bo'yicha: stretch | flex-start | center | flex-end | baseline */
  gap: 16px;                    /* elementlar orasidagi masofa */
}

Element xususiyatlari

CSS
.item {
  flex-grow: 1;      /* bo'sh joydan qancha ulush olish (0 — olmaydi) */
  flex-shrink: 1;    /* joy yetmasa qanchalik qisqarish (0 — qisqarmaydi) */
  flex-basis: 200px; /* boshlang'ich o'lcham */
  /* qisqa yozuv: */
  flex: 1 1 200px;
}
.sidebar { flex: 0 0 260px; }   /* qat'iy 260px, cho'zilmaydi, qisqarmaydi */
.main    { flex: 1; }           /* qolgan barcha joyni egallaydi */
.special { align-self: flex-end; order: -1; } /* alohida tekislash va tartibni o'zgartirish */
Markazlashning eng oson usuli .parent { display: flex; justify-content: center; align-items: center; min-height: 100vh; } — element ekranning qoq o'rtasiga joylashadi. Grid bilan esa yanada qisqa: display: grid; place-items: center;

#CSS Grid — ikki o'lchamli maket

Grid qator va ustunlarni bir vaqtda boshqaradi. Sahifa maketi, rasm galereyasi, mahsulotlar katalogi, dashboard — Grid'ning ishi.

CSS
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;     /* 3 ustun: 200px va qolgani teng ikkiga */
  grid-template-rows: auto 1fr auto;
  gap: 20px;                                  /* row-gap va column-gap */
}

/* repeat() va minmax() */
.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);                        /* 4 ta teng ustun */
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); /* ✨ media query'siz responsiv! */
}

/* Element bir nechta katakni egallashi */
.featured {
  grid-column: 1 / 3;     /* 1-chiziqdan 3-chiziqqacha = 2 ustun */
  grid-column: span 2;    /* yoki: 2 ustun egallash */
  grid-row: span 2;
}

Nomlangan hududlar (grid-template-areas)

CSS
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 64px 1fr 48px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}
.page > header { grid-area: header; }
.page > aside  { grid-area: sidebar; }
.page > main   { grid-area: main; }
.page > footer { grid-area: footer; }

@media (max-width: 768px) {
  .page {
    grid-template-columns: 1fr;
    grid-template-areas: "header" "main" "sidebar" "footer";
  }
}

Ular raqobatchi emas — odatda birga ishlatiladi: sahifa Grid bilan, uning ichidagi komponentlar Flexbox bilan.

#Responsiv dizayn

Bugun trafikning 60%+ qismi telefonlardan keladi. Responsiv dizayn — sayt har qanday ekranga moslashishi.

Mobile-first yondashuv

Avval eng kichik ekran uchun oddiy uslub yoziladi, keyin min-width media so'rovlari bilan katta ekranlar uchun kengaytiriladi.

CSS
/* Standart: telefon (bitta ustun) */
.products { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* Planshet: 640px va undan keng */
@media (min-width: 640px) {
  .products { grid-template-columns: repeat(2, 1fr); }
}

/* Noutbuk: 1024px va undan keng */
@media (min-width: 1024px) {
  .products { grid-template-columns: repeat(4, 1fr); }
}

/* Boshqa foydali media so'rovlar */
@media (prefers-color-scheme: dark) { /* tizim tungi rejimda */ }
@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }
@media (hover: hover) { .card:hover { transform: translateY(-4px); } } /* faqat sichqonchali qurilmalarda */
@media print { nav, footer { display: none; } }
Responsivlik uchun nazorat ro'yxati viewport meta-tegi bor · rasmlarga max-width: 100% · qat'iy width: 1200px o'rniga max-width · rem va clamp() · Grid'da auto-fill + minmax · DevTools'dagi "Toggle device toolbar" (Ctrl+Shift+M) bilan sinash.

Sass o'zgaruvchilaridan farqli, CSS o'zgaruvchilari ishlash vaqtida (runtime) ishlaydi: ularni JavaScript bilan o'zgartirish, media query ichida qayta belgilash va meros qilib berish mumkin. Bu tungi rejim yasashning eng qulay usuli (4-misol).

#Transition, transform va animatsiya

CSS
.btn {
  transition: background-color .2s ease, transform .2s ease;
}
.btn:hover {
  background-color: #4338ca;
  transform: translateY(-2px) scale(1.02);   /* siljitish, kattalashtirish, rotate(45deg), skew() */

/* Kalit kadrlar bilan animatsiya */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
.loader {
  width: 40px; height: 40px;
  border: 4px solid #e5e7eb;
  border-top-color: #4f46e5;

Unumdorlik transform va opacity ni animatsiya qilish arzon (faqat Composite bosqichi). width, top, margin ni animatsiya qilish esa har kadrda Layout'ni qayta hisoblaydi va sekinlashtiradi (1-darsdagi rendering bosqichlarini eslang).

  :root {
    --bg: #ffffff;
    --surface: #f3f4f6;
    --text: #111827;
    --muted: #6b7280;
    --primary: #4f46e5;
  }
  /* Tizim tungi rejimda bo'lsa (foydalanuvchi qo'lda tanlamagan bo'lsa) */
  @media (prefers-color-scheme: dark) {
    :root:not([data-theme="light"]) {
      --bg: #0f172a; --surface: #1e293b; --text: #e2e8f0; --muted: #94a3b8; --primary: #818cf8;
    }
  }
  /* Foydalanuvchi qo'lda tungi rejimni tanlagan */
  :root[data-theme="dark"] {
    --bg: #0f172a; --surface: #1e293b; --text: #e2e8f0; --muted: #94a3b8; --primary: #818cf8;
  }

  body {
    margin: 0; min-height: 100vh;
    display: grid; place-items: center;
    background: var(--bg); color: var(--text);
    font-family: system-ui, sans-serif;
    transition: background .3s, color .3s;
  }
  .card { background: var(--surface); padding: 32px; border-radius: 16px; max-width: 360px; }
  .card p { color: var(--muted); }
  button {
    background: var(--primary); color: #fff; border: 0;
    padding: 10px 18px; border-radius: 10px; font: inherit; cursor: pointer;
  }

<body>
  <div class="card">
    <h2>Salom! 👋</h2>

    const btn = document.getElementById('toggle');
    btn.addEventListener('click', () => {
      const root = document.documentElement;
      const dark = root.dataset.theme === 'dark';
      root.dataset.theme = dark ? 'light' : 'dark';
