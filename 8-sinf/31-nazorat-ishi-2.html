1-topshiriq (5 ball). JavaScript: DOM

Sahifada <input id="ism">, <button id="btn"> va <p id="javob"> bor. Tugma bosilganda, agar maydon bo'sh bo'lsa — "Ismingizni kiriting!" qizil rangda, aks holda "Salom, [ism]!" yashil rangda chiqsin.

Namuna javob va baholash
HTML
<input id="ism" placeholder="Ism">
<button id="btn">Salomlash</button>
<p id="javob"></p>
<script>
  document.querySelector("#btn").addEventListener("click", () => {
    const ism = document.querySelector("#ism").value.trim();
    const javob = document.querySelector("#javob");
    if (ism === "") {
      javob.textContent = "Ismingizni kiriting!";
      javob.style.color = "red";
    } else {
      javob.textContent = `Salom, ${ism}!`;
      javob.style.color = "green";
    }
  });
</script>

Baholash: elementlarni topish — 1; hodisa tinglovchisi — 1; bo'sh tekshiruvi (trim bilan) — 1; textContent bilan chiqarish — 1; ranglar — 1.

2-topshiriq (5 ball). Python: funksiya va ro'yxat

statistika(ballar) funksiyasini yozing: u ballar ro'yxatini olib, o'rtacha (2 xona kasr), eng yuqori, eng past ball va 86 dan yuqori ballar sonini dict ko'rinishida qaytarsin. Bo'sh ro'yxat uchun None qaytarsin.

Namuna javob
Python
def statistika(ballar):
    if not ballar:
        return None
    return {
        "ortacha": round(sum(ballar) / len(ballar), 2),
        "eng_yuqori": max(ballar),
        "eng_past": min(ballar),
        "alo": len([b for b in ballar if b > 86]),
    }

print(statistika([90, 75, 88, 60]))
# {'ortacha': 78.25, 'eng_yuqori': 90, 'eng_past': 60, 'alo': 2}

Baholash: def va return — 1; bo'sh holat — 1; o'rtacha va yaxlitlash — 1; max/min — 1; shartli sanash — 1.

3-topshiriq (5 ball). Python OOP

Tortburchak klassini yozing: konstruktor eni va bo'yini oladi; yuza(), perimetr() metodlari va __str__ ("Tortburchak 4×5"). Undan meros olgan Kvadrat klassi faqat bitta tomonni oladi.

Namuna javob
Python
class Tortburchak:
    def __init__(self, eni, boyi):
        self.eni = eni
        self.boyi = boyi

    def yuza(self):
        return self.eni * self.boyi

    def perimetr(self):
        return 2 * (self.eni + self.boyi)

    def __str__(self):
        return f"Tortburchak {self.eni}×{self.boyi}"


class Kvadrat(Tortburchak):
    def __init__(self, tomon):
        super().__init__(tomon, tomon)


k = Kvadrat(4)
print(k, k.yuza(), k.perimetr())   # Tortburchak 4×4 16 16

Baholash: klass va __init__ — 1; metodlar — 2; __str__ — 1; meros va super() — 1.

4-topshiriq (5 ball). SQL: jadval va CRUD

kitoblar jadvalini yarating (id, nomi — majburiy, muallif, yil — 1450 dan katta, narx — pul, mavjud — boolean, standart TRUE). 3 ta kitob qo'shing; 2000-yildan keyin chiqqan kitoblarni narx bo'yicha kamayish tartibida chiqaring; bitta kitob narxini 10% oshiring.

Namuna javob
SQL
CREATE TABLE kitoblar (
    id      SERIAL PRIMARY KEY,
    nomi    VARCHAR(200) NOT NULL,
    muallif VARCHAR(100),
    yil     INTEGER CHECK (yil > 1450),
    narx    NUMERIC(10, 2),
    mavjud  BOOLEAN DEFAULT TRUE
);

INSERT INTO kitoblar (nomi, muallif, yil, narx) VALUES
    ('O''tkan kunlar', 'Abdulla Qodiriy', 1926, 65000),
    ('Ufq', 'Said Ahmad', 1976, 48000),
    ('Python asoslari', 'Muallif X', 2021, 90000);

SELECT nomi, yil, narx FROM kitoblar WHERE yil > 2000 ORDER BY narx DESC;

UPDATE kitoblar SET narx = narx * 1.1 WHERE id = 1;

Baholash: jadval va turlar — 1; cheklovlar — 1; INSERT (apostrof to'g'ri) — 1; SELECT + WHERE + ORDER BY — 1; UPDATE + WHERE — 1.

5-topshiriq (5 ball). SQL: JOIN va GROUP BY

sinflar(id, nomi), oquvchilar(id, ism, sinf_id), baholar(id, oquvchi_id, baho) jadvallari berilgan. Har bir sinfning nomi, o'quvchilar soni va o'rtacha bahosini chiqaring; faqat o'rtacha bahosi 4 dan yuqori sinflar, o'rtacha baho bo'yicha kamayish tartibida.

Namuna javob
SQL
SELECT s.nomi,
       COUNT(DISTINCT o.id) AS oquvchilar,
       ROUND(AVG(b.baho), 2) AS ortacha
FROM sinflar s
JOIN oquvchilar o ON o.sinf_id = s.id
JOIN baholar b    ON b.oquvchi_id = o.id
GROUP BY s.nomi
HAVING AVG(b.baho) > 4
ORDER BY ortacha DESC;

Baholash: JOIN'lar to'g'ri — 2; GROUP BY va agregatlar — 1 (DISTINCT'ni bilgani — ustiga rag'bat); HAVING — 1; ORDER BY — 1.
