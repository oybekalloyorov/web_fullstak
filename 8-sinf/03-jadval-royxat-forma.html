Jadval, ro'yxat va forma elementlari

Tartibli va tartibsiz ro'yxatlar, jadvallar (thead, tbody, colspan, rowspan), forma va uning elementlari: input turlari, label, select, textarea, tugmalar.

1 soat · amaliy
🎞️ Taqdimotni ochish⬇ PowerPoint (.pptx)📄 PDF yuklab olish

🎯 Bu darsda nimani o'rganasiz

  • Tartibli va tartibsiz ro'yxatlar yaratishni;
  • Dars jadvali kabi jadvallarni, kataklarni birlashtirishni;
  • Foydalanuvchidan ma'lumot oluvchi formalarni: matn, parol, email, tanlash, belgilash maydonlari va tugmalarni;
  • Forma ma'lumoti qayerga va qanday yuborilishini.

#Ro'yxatlar

Tartibsiz ro'yxat — <ul>

ul = unordered list. Tartib muhim bo'lmaganda: xarid ro'yxati, ko'nikmalar, menyu. Har bir band — <li> (list item).

HTML
<h3>Bozorlik ro'yxati</h3>
<ul>
  <li>Non</li>
  <li>Sut</li>
  <li>Olma</li>
</ul>

Tartibli ro'yxat — <ol>

ol = ordered list. Tartib muhim bo'lganda: retsept qadamlari, reyting, ko'rsatmalar.

HTML
<h3>Choy damlash</h3>
<ol>
  <li>Suvni qaynating</li>
  <li>Choynakni issiq suv bilan chayib oling</li>
  <li>Choy soling va qaynoq suv quying</li>
  <li>5 daqiqa damlang</li>
</ol>

<h3>Olimpiada g'oliblari (Rim raqamlari bilan)</h3>
<ol type="I">
  <li>Malika</li>
  <li>Jasur</li>
  <li>Dilnoza</li>
</ol>

<h3>3-dan boshlanuvchi, teskari ro'yxat</h3>
<ol start="3" reversed>
  <li>Uchinchi</li>
  <li>Ikkinchi</li>
  <li>Birinchi</li>
</ol>
Atribut (ol uchun)Natija
type="1"1, 2, 3 (standart)
type="a" / type="A"a, b, c / A, B, C
type="i" / type="I"i, ii, iii / I, II, III
start="5"5 dan boshlaydi
reversedTeskari tartibda sanaydi

Ichma-ich ro'yxat

Ro'yxat ichida ro'yxat — <li> ichiga yangi ul/ol yoziladi:

HTML
<ul>
  <li>Aniq fanlar
    <ul>
      <li>Matematika</li>
      <li>Informatika</li>
    </ul>
  </li>
  <li>Tabiiy fanlar
    <ul>
      <li>Fizika</li>
      <li>Kimyo</li>
    </ul>
  </li>
</ul>

Ta'riflar ro'yxati — <dl>

Lug'at yoki "atama — izoh" juftliklari uchun: dt — atama, dd — izoh.

HTML
<dl>
  <dt>HTML</dt>
  <dd>Sahifa tuzilishini yaratuvchi til</dd>
  <dt>CSS</dt>
  <dd>Sahifa dizaynini beruvchi til</dd>
</dl>

#Jadvallar

Jadval — qator va ustunlardan iborat ma'lumot: dars jadvali, baholar, narxlar. Asosiy teglar:

TegMa'nosi
<table>Butun jadval
<tr>table row — qator
<td>table data — oddiy katak
<th>table header — sarlavha katagi (qalin, markazda)
<caption>Jadval nomi
<thead>, <tbody>, <tfoot>Jadvalning bosh, asosiy va pastki qismlari
Eslab qolish uchun Jadval qatorma-qator yoziladi: avval <tr> (qator) ochasiz, uning ichiga chapdan o'ngga kataklarni (<td>) yozasiz. Ustun degan alohida teg yo'q — ustunlar har qatordagi kataklar tartibidan hosil bo'ladi.
HTML
<table border="1">
  <caption>8-"A" sinf baholari</caption>
  <thead>
    <tr>
      <th>O'quvchi</th>
      <th>Matematika</th>
      <th>Informatika</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ali</td>
      <td>5</td>
      <td>5</td>
    </tr>
    <tr>
      <td>Zarina</td>
      <td>4</td>
      <td>5</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th>O'rtacha</th>
      <td>4.5</td>
      <td>5</td>
    </tr>
  </tfoot>
</table>
border="1" — eski usul, faqat hozircha chegaralarni ko'rish uchun. 7-mavzudan boshlab chegaralarni CSS bilan chiroyli qilamiz.

Kataklarni birlashtirish: colspan va rowspan

  • colspan="2" — katak gorizontal bo'yicha 2 ta ustunni egallaydi.
  • rowspan="2" — katak vertikal bo'yicha 2 ta qatorni egallaydi.
HTML
<table border="1">
  <caption>Dars jadvali</caption>
  <tr>
    <th>Vaqt</th><th>Dushanba</th><th>Seshanba</th>
  </tr>
  <tr>
    <td>08:30</td><td>Matematika</td><td rowspan="2">Informatika<br>(juft dars)</td>
  </tr>
  <tr>
    <td>09:20</td><td>Ona tili</td>
    <!-- Seshanba katagi yo'q: tepadagi rowspan uni egallab turibdi -->
  </tr>
  <tr>
    <td>10:10</td><td colspan="2">🍎 Katta tanaffus</td>
  </tr>
</table>
Birlashtirilgan katak egallagan joyga keyingi qatorlarda katak yozilmaydi, aks holda jadval "siljib" ketadi. Har bir qatordagi kataklar soni (birlashtirishlarni hisobga olganda) teng bo'lishi kerak.
Jadvalni faqat jadval ko'rinishidagi ma'lumot uchun ishlating. Sahifa maketini (menyu, ustunlar) jadval bilan qurish — eskirgan usul; buning uchun Flexbox va Grid bor (8-mavzu).

#Formalar — foydalanuvchidan ma'lumot olish

Ro'yxatdan o'tish, qidiruv, izoh qoldirish, test topshirish — barchasi forma orqali. Forma — frontend va backend o'rtasidagi ko'prik: foydalanuvchi ma'lumot kiritadi, forma uni serverga yuboradi.

HTML
<form action="/royxatdan-otish" method="POST">
  <label for="ism">Ismingiz:</label>
  <input type="text" id="ism" name="ism" placeholder="Masalan: Aziz" required>

  <button type="submit">Yuborish</button>
</form>
QismVazifasi
<form>Barcha maydonlarni o'rab turuvchi "konvert"
actionMa'lumot qaysi manzilga (serverdagi qaysi sahifaga) yuboriladi
methodGET — ma'lumot manzil satriga qo'shiladi (qidiruv uchun); POST — yashirin yuboriladi (parollar, ro'yxatdan o'tish)
<label>Maydon yozuvi. for atributi input'ning idsiga teng bo'lsa, yozuv bosilganda maydon faollashadi
nameEng muhim atribut! Serverga ma'lumot name=qiymat ko'rinishida boradi. namesiz maydon yuborilmaydi
placeholderMaydon bo'sh turganda ko'rinadigan kulrang maslahat
requiredMajburiy maydon — to'ldirilmasa forma yuborilmaydi

Input turlari

Bitta <input> tegi type atributiga qarab butunlay boshqacha ko'rinadi:

HTML
<form>
  <p>Matn: <input type="text" name="ism"></p>
  <p>Parol: <input type="password" name="parol"></p>
  <p>Email: <input type="email" name="email"></p>
  <p>Son (1–10): <input type="number" name="son" min="1" max="10"></p>
  <p>Telefon: <input type="tel" name="tel" placeholder="+998 90 123 45 67"></p>
  <p>Sana: <input type="date" name="sana"></p>
  <p>Vaqt: <input type="time" name="vaqt"></p>
  <p>Rang: <input type="color" name="rang" value="#4f46e5"></p>
  <p>Diapazon: <input type="range" name="daraja" min="0" max="100"></p>
  <p>Fayl: <input type="file" name="rasm" accept="image/*"></p>

  <p>Jinsingiz:
    <label><input type="radio" name="jins" value="o'g'il"> O'g'il bola</label>
    <label><input type="radio" name="jins" value="qiz"> Qiz bola</label>
  </p>

  <p>Qiziqishlar:
    <label><input type="checkbox" name="qiziqish" value="sport"> Sport</label>
    <label><input type="checkbox" name="qiziqish" value="musiqa" checked> Musiqa</label>
    <label><input type="checkbox" name="qiziqish" value="kitob"> Kitob</label>
  </p>
</form>
typeQachon ishlatiladi
textOddiy matn: ism, shahar
passwordParol — belgilar nuqta bo'lib ko'rinadi
emailEmail — @ borligini brauzer o'zi tekshiradi
numberFaqat son; min, max, step
radioBir nechta variantdan faqat bittasi. Bir guruh radiolarda name bir xil bo'lishi shart!
checkboxBir nechtasini belgilash mumkin; checked — oldindan belgilangan
date, time, color, range, fileSana, vaqt, rang, slayder, fayl tanlash
submit, resetYuborish va tozalash tugmalari (eski usul; hozir <button>)

Tanlash ro'yxati va katta matn maydoni

HTML
<form>
  <label for="viloyat">Viloyat:</label>
  <select id="viloyat" name="viloyat">
    <option value="">— Tanlang —</option>
    <option value="toshkent">Toshkent</option>
    <option value="samarqand" selected>Samarqand</option>
    <option value="buxoro">Buxoro</option>
    <option value="xorazm">Xorazm</option>
  </select>

  <br><br>
  <label for="fikr">Fikringiz:</label><br>
  <textarea id="fikr" name="fikr" rows="5" cols="40" placeholder="Bu yerga yozing..."></textarea>

  <br>
  <button type="submit">Yuborish</button>
  <button type="reset">Tozalash</button>
</form>
  • <select> — ochiladigan ro'yxat; har bir variant <option>. Serverga value qiymati yuboriladi, foydalanuvchi esa teg ichidagi matnni ko'radi.
  • <textarea> — ko'p qatorli matn (izoh, xat). rows — balandlik (qatorlarda), cols — kenglik.
  • <button type="submit"> — formani yuboradi; type="reset" — barcha maydonlarni tozalaydi.

Brauzer tekshiruvi (validatsiya)

Brauzer ba'zi tekshiruvlarni o'zi bajaradi va xato bo'lsa formani yubormaydi:

  • required — bo'sh bo'lmasin;
  • minlength="8", maxlength="20" — matn uzunligi;
  • min, max — son yoki sana chegarasi;
  • type="email" — email formati.
Bu tekshiruvlar faqat foydalanuvchiga qulaylik uchun. Ayyor foydalanuvchi ularni chetlab o'tishi mumkin, shuning uchun ma'lumotlar serverda ham tekshiriladi (37-mavzu, Django Forms).

#Ko'p uchraydigan xatolar

  • ❌ <li> ni ul/ol siz yozish — ro'yxat bandi doim ro'yxat ichida bo'ladi.
  • ❌ Radio tugmalarga turli name berish — hammasini birdaniga belgilash mumkin bo'lib qoladi.
  • ❌ <label for="..."> dagi qiymat input'ning idsiga mos kelmasligi.
  • ❌ Input'da name yo'qligi — ma'lumot serverga bormaydi.
  • ❌ Jadvalda <td> ni <tr> siz to'g'ridan-to'g'ri <table> ichiga yozish.

#O'zingizni tekshiring

Retsept qadamlari uchun qaysi ro'yxat mos?

  1. <ul>
  2. <ol>
  3. <dl>
  4. <table>

Qadamlar tartibi muhim — shuning uchun tartibli ro'yxat (ol).

Jadvalda yangi qator qaysi teg bilan boshlanadi?

  1. <td>
  2. <th>
  3. <tr>
  4. <row>

tr = table row. Kataklar (td/th) uning ichida.

Katakni ikki ustun kengligida birlashtirish uchun qaysi atribut kerak?

  1. colspan="2"
  2. rowspan="2"
  3. span="2"
  4. width="2"

col = ustun (gorizontal), row = qator (vertikal).

"Jinsingiz" savoliga faqat bitta javob tanlash uchun qaysi input turi kerak?

  1. checkbox
  2. text
  3. select multiple
  4. radio

Radio — bir guruhdan bitta tanlov. Guruhdagi barcha radiolarning namei bir xil bo'lishi kerak.

Forma ma'lumoti serverga qaysi atribut nomi bilan boradi?

  1. id
  2. name
  3. placeholder
  4. class

Server name=qiymat juftliklarini oladi. id esa label va CSS uchun.

Parol yuboradigan forma uchun qaysi method to'g'ri?

  1. GET
  2. SEND
  3. POST
  4. PUT

GET'da ma'lumot manzil satrida ochiq ko'rinadi va brauzer tarixida saqlanadi.

🏠 Uyga vazifa

  1. O'z sinfingizning to'liq haftalik dars jadvalini HTML jadval sifatida yarating (caption, thead, tanaffuslar uchun colspan).
  2. 2-mavzudagi retsept sahifangizni yangilang: masalliqlarni ul, tayyorlash bosqichlarini ol bilan yozing.
  3. "Kutubxonaga a'zo bo'lish" formasini yarating: ism, tug'ilgan sana, email, sevimli janr (select), qaysi tillarda o'qiydi (checkbox), izoh (textarea).

✅ Yodda tuting

  • ul — tartibsiz, ol — tartibli ro'yxat; bandlar li.
  • Jadval: table → tr (qator) → td/th (katak); colspan — gorizontal, rowspan — vertikal birlashtirish.
  • Forma: action (qayerga), method (GET/POST), har bir maydonda name va label.
  • radio — bitta tanlov (bir xil name), checkbox — bir nechta, select — ro'yxatdan, textarea — ko'p qatorli matn.
