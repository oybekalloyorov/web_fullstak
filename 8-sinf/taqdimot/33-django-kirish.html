Framework nima?

  • Veb-sayt uchun kerak: so'rovlar, URL'lar, HTML, formalar, login, parollar, admin panel... Noldan — oylar!
Framework — sinalgan tayyor "karkas": siz faqat loyihangizga xos qismni yozasiz
💡
Uy qurish: noldan dastur — g'ishtni o'zingiz pishirish. Framework — tayyor karkas (poydevor, devor, quvurlar) ustida xonalarni bezash. Tezroq, xavfsizroq, sifatliroq.

Nima uchun Django?

  • 🔋 "Batareyalar bilan birga" — admin panel, foydalanuvchilar, formalar, ORM tayyor
  • 🔐 Xavfsiz — SQL injection, XSS, CSRF'dan avtomatik himoya
  • 📈 Masshtablanadi — Instagram, Pinterest, Spotify, Mozilla
  • 📚 Ajoyib hujjatlar, katta jamiyat
"Muddati bor perfeksionistlar uchun veb-framework"

Loyiha va ilova

  • Loyiha (project) — butun sayt: umumiy sozlamalar, asosiy URL'lar. Bitta
  • Ilova (app) — mustaqil qism, bitta vazifa: blog, accounts, shop. Bir nechta
💡
Maktab binosi: loyiha — bino (umumiy qoidalar, qo'ng'iroq). Ilovalar — xonalar: kutubxona, sport zali, oshxona. Har biri o'z ishini qiladi, lekin bitta binoda.

O'rnatish va loyiha yaratish

Terminal
mkdir maktab_blog && cd maktab_blog
python -m venv venv
venv\Scripts\activate
pip install django "psycopg[binary]" python-dotenv

django-admin startproject config .     # nuqta — joriy papkada!
python manage.py runserver             # http://127.0.0.1:8000 🚀
python manage.py startapp blog
config/settings.py
INSTALLED_APPS = [
    "django.contrib.admin",
    # ...
    "blog",          # ⬅ ilovamizni ro'yxatdan o'tkazamiz
]

settings.py — asosiy sozlamalar

Python
import os
from pathlib import Path
from dotenv import load_dotenv

BASE_DIR = Path(__file__).resolve().parent.parent
load_dotenv(BASE_DIR / ".env")

SECRET_KEY = os.getenv("SECRET_KEY")                 # MAXFIY!
DEBUG = os.getenv("DEBUG", "True") == "True"         # serverda False
ALLOWED_HOSTS = os.getenv("ALLOWED_HOSTS", "127.0.0.1,localhost").split(",")

LANGUAGE_CODE = "uz"
TIME_ZONE = "Asia/Tashkent"
⚠️
SECRET_KEY — GitHub'ga yuklanmaydi; DEBUG = True — faqat o'rganishda, internetda doim False

DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.postgresql",
        "NAME": os.getenv("DB_NAME"),
        "USER": os.getenv("DB_USER"),
        "PASSWORD": os.getenv("DB_PASSWORD"),
        "HOST": os.getenv("DB_HOST"),
        "PORT": os.getenv("DB_PORT"),
    }
}

  • ❌ Ilova INSTALLED_APPS ga qo'shilmagan
  • ❌ That port is already in use — server boshqa terminalda ishlayapti
  • ❌ password authentication failed — .env paroli xato
