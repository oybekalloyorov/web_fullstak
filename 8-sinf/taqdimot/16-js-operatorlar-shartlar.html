JavaScript'da operatorlar va ifodalar. Shart operatorlari

Arifmetik, tayinlash, taqqoslash va mantiqiy operatorlar; == va === farqi; if, else if, else; ternary operator; switch; amaliy dasturlar: baho aniqlash, juft-toq, kirish tizimi.

8-sinf · Web Full-stack dasturlash

Bugun nimani o'rganamiz?

  • Arifmetik amallar va qoldiq (%)
  • Taqqoslash: == va === farqi
  • Mantiqiy operatorlar: VA, YOKI, EMAS
  • Dasturga "qaror qabul qildirish": if, else if, else, switch
  • Baho hisoblovchi, kirish tizimi va boshqa dasturlar

Arifmetik operatorlar

JavaScript
const a = 17, b = 5;
a + b      // 22
a - b      // 12
a * b      // 85
a / b      // 3.4
a % b      // 2   ← QOLDIQ: 17 = 5·3 + 2
a ** 2     // 289 daraja
(a + b) * 2  // 44 — qavslar avval
  • % juda foydali:
  • son % 2 === 0 → juft
  • son % 3 === 0 → 3 ga bo'linadi
  • 1234 % 10 → 4 (oxirgi raqam)
  • 135 daqiqa → Math.floor(135/60) soat, 135 % 60 daqiqa

if / else — dastur qaror qabul qiladi

JavaScript
const harorat = 28;

if (harorat > 25) {
  console.log("Issiq! Kepka kiying 🧢");
} else {
  console.log("Havo salqin 🧥");
}
  • Shart true bo'lsa — birinchi blok, false bo'lsa — else bloki

else if — bir nechta variant

JavaScript
const ball = 78;
let baho;
if (ball >= 86) {
  baho = 5;
} else if (ball >= 71) {
  baho = 4;
} else if (ball >= 56) {
  baho = 3;
} else {
  baho = 2;
}
  • Yuqoridan pastga tekshiriladi
  • Birinchi rost shart bajariladi — qolganlari tekshirilmaydi
  • 78 ≥ 86? yo'q → 78 ≥ 71? HA → baho = 4
⚠️
Tartib muhim! >= 56 birinchi yozilsa, 95 ball ham "3" bo'ladi

Ichma-ich shart va ternary

JavaScript
if (login === "admin") {
  if (parol === "12345") {
    console.log("✅ Xush kelibsiz!");
  } else {
    console.log("❌ Parol noto'g'ri");
  }
}

// Ternary: shart ? rost : yolg'on
const holat = yosh >= 18 ? "katta" : "voyaga yetmagan";
console.log(`${son} — ${son % 2 === 0 ? "juft" : "toq"}`);
  • Ternary — oddiy ikki variantli tanlov uchun

switch — ko'p aniq variant

JavaScript
switch (kun) {
  case 1:
    kunNomi = "Dushanba";
    break;
  case 2:
    kunNomi = "Seshanba";
    break;
  case 6:
  case 7:
    kunNomi = "Dam olish kuni 🎉";
    break;
  default:
    kunNomi = "Noto'g'ri kun";
}
  • Bitta qiymatni ko'p aniq variant bilan solishtirish
  • Qat'iy taqqoslash (===)
  • default — hech biri mos kelmasa
⚠️
break unutilsa — keyingi case lar ham bajariladi!

Amaliyot: kirish tizimi

JavaScript
const TOGRI_LOGIN = "malika";
const TOGRI_PAROL = "qwerty123";
const login = prompt("Login:");
const parol = prompt("Parol:");

if (login === null || parol === null) {
  alert("Kirish bekor qilindi");
} else if (login === "" || parol === "") {
  alert("⚠️ Bo'sh bo'lmasin");
} else if (login.toLowerCase() === TOGRI_LOGIN && parol === TOGRI_PAROL) {
  alert(`✅ Xush kelibsiz, ${login}!`);
} else {
  alert("❌ Login yoki parol noto'g'ri");
}

Amaliyot: topshiriqlar

1
Juft yoki toq: juft/toq, musbat/manfiy/nol
2
Baho aniqlovchi: 0–100 tekshiruvi + baho va izoh
3
Kabisa yili: 4 ga bo'linsa va 100 ga bo'linmasa, yoki 400 ga
4

5

Ko'p uchraydigan xatolar

  • ❌ if (ball = 100) — tayinlash! To'g'risi ===
  • ❌ if (10 < son < 20) — son > 10 && son < 20 bo'lishi kerak
  • ❌ "9" > "10" → true — matnlar alifbo bo'yicha; Number()!
  • ❌ switch da break unutilgan
  • ❌ { } qavslar yopilmagan
