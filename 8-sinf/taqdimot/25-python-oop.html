Birinchi klass

Python
class Oquvchi:                          # PascalCase
    def __init__(self, ism, sinf):      # konstruktor
        self.ism = ism                  # atributlar
        self.sinf = sinf
        self.baholar = []

    def baho_qosh(self, baho):          # metod
        self.baholar.append(baho)

    def ortacha(self):
        if not self.baholar:
            return 0
        return round(sum(self.baholar) / len(self.baholar), 2)

ali = Oquvchi("Ali", "8-A")             # obyekt yaratish
ali.baho_qosh(5)
ali.baho_qosh(4)
print(ali.ortacha())                    # 4.5

__init__ va self

  • __init__ — konstruktor: Oquvchi("Ali", "8-A") yozilganda avtomatik chaqiriladi va atributlarni to'ldiradi
  • self — "shu obyektning o'zi": ali.baho_qosh(5) da self = ali, zarina.baho_qosh(5) da — zarina
💡
self — "men": har bir o'quvchi "mening ismim", "mening daftarim" deydi. So'z bir xil, lekin har biri uchun boshqa narsa. self.ism — "mening ismim".
⚠️
Har metodning birinchi parametri — self. Chaqirganda esa self berilmaydi — Python o'zi qo'yadi

__str__ — obyektni chiroyli chiqarish

Python
class Kitob:
    def __init__(self, nomi, muallif, yil):
        self.nomi = nomi
        self.muallif = muallif
        self.yil = yil

    def __str__(self):                  # print(obyekt) chaqirilganda
        return f"«{self.nomi}» — {self.muallif} ({self.yil})"

k = Kitob("O'tkan kunlar", "Abdulla Qodiriy", 1926)
print(k)    # «O'tkan kunlar» — Abdulla Qodiriy (1926)
  • __str__ siz: <__main__.Kitob object at 0x7f...> 😕
  • Django modellarida __str__ ni albatta yozamiz (36-mavzu)

Inkapsulyatsiya · Merosxo'rlik · Polimorfizm

1. Inkapsulyatsiya — ichki ishlarni yashirish

Python
class BankHisobi:
    def __init__(self, egasi, balans=0):
        self.egasi = egasi
        self._balans = balans       # _ — "tashqaridan tegmang"

    def toldirish(self, summa):
        if summa <= 0:
            print("❌ Summa musbat bo'lsin")
            return
        self._balans += summa

    def yechish(self, summa):
        if summa > self._balans:
            print("❌ Mablag' yetarli emas")
            return
        self._balans -= summa
💡
Bankomat: pulni qo'lingiz bilan olmaysiz — faqat tugmalar (metodlar) orqali; bankomat qoidalarni tekshiradi.

2. Merosxo'rlik (inheritance)

Python
class Odam:
    def __init__(self, ism, yosh):
        self.ism = ism
        self.yosh = yosh
    def tanishtir(self):
        return f"Men {self.ism}, {self.yosh} yoshdaman"

class Oquvchi(Odam):                   # Odam'dan meros
    def __init__(self, ism, yosh, sinf):
        super().__init__(ism, yosh)    # ota konstruktori
        self.sinf = sinf
    def dars_qil(self):
        return f"{self.ism} uy vazifasini bajaryapti 📚"

m = Oquvchi("Madina", 14, "8-A")
m.tanishtir()    # meros olingan metod!
  • Django'da: class Kitob(models.Model): — yuzlab imkoniyat "tekinga"

3. Polimorfizm — bir buyruq, turli xatti-harakat

Python
class Hayvon:
    def ovoz(self):
        return "..."

class Mushuk(Hayvon):

        return "Miyov 🐱"

for h in [Mushuk(), It()]:
