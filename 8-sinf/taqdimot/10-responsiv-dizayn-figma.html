Responsiv dizayn nima?

Sayt har qanday ekran o'lchamiga o'zi moslashadi
  • Foydalanuvchilarning 60%+ telefondan kiradi
  • 1200px sayt 390px ekranda yo mayda, yo yonga sig'maydi
💡
Suv: qaysi idishga quyilsa — stakan, choynak, chelak — o'sha shaklni oladi. Responsiv sayt ham har ekranga moslashadi.
  • 3 vosita: moslashuvchan maket (%, fr, flex, grid) + moslashuvchan rasmlar + media query

1-qadam: viewport meta-tegi

HTML
<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width — sahifa kengligi = qurilma ekran kengligi
⚠️
Bu qator bo'lmasa telefon sahifani "980px kompyuter" deb kichraytiradi va media query'lar ishlamaydi
  • VS Code'dagi ! shabloni uni avtomatik qo'shadi

2-qadam: moslashuvchan o'lchamlar

CSS
/* ❌ Qattiq — telefonda sig'maydi */
.konteyner { width: 1100px; }

/* ✅ Moslashuvchan */
.konteyner {
  width: 100%;
  max-width: 1100px;
  margin: 0 auto;
  padding: 0 16px;
}

/* ✅ Rasm hech qachon chiqib ketmasin */
img { max-width: 100%; height: auto; }
  • repeat(auto-fill, minmax(220px, 1fr)) — ustunlar soni o'zi o'zgaradi

3-qadam: media so'rovlar

CSS
@media (max-width: 768px) {
  /* FAQAT ekran 768px yoki KICHIK bo'lsa */
  .menyu { flex-direction: column; }
  h1 { font-size: 1.8rem; }
}

@media (min-width: 1024px) {
  /* FAQAT ekran 1024px yoki KATTA bo'lsa */
  .kartalar { grid-template-columns: repeat(4, 1fr); }
}
  • max-width — "ko'pi bilan", min-width — "kamida"
  • Birlashtirish: @media (min-width: 600px) and (max-width: 900px)

Mobile-first yondashuvi

CSS
/* 1. Standart — telefon: 1 ustun */
.kartalar { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* 2. Planshet */
@media (min-width: 640px) {
  .kartalar { grid-template-columns: repeat(2, 1fr); }
}

/* 3. Kompyuter */
@media (min-width: 1024px) {
  .kartalar { grid-template-columns: repeat(4, 1fr); }
}
  • Avval oddiy (telefon), keyin min-width bilan murakkab
  • Eng ko'p foydalanuvchi — telefonda

Responsiv navigatsiya: "burger" menyu

CSS
#burger, .burger-tugma { display: none; }

@media (max-width: 640px) {
  .burger-tugma { display: block; cursor: pointer; }
  .menyu { display: none; flex-direction: column; width: 100%; }
  #burger:checked ~ .menyu { display: flex; }
}
HTML
<input type="checkbox" id="burger">
<label for="burger" class="burger-tugma">☰</label>
<nav class="menyu">...</nav>
  • Yashirin checkbox + label = tugma; 19-mavzuda JavaScript bilan
