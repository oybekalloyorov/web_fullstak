padding va margin yozish usullari

CSS
padding: 20px;                 /* 4 tomon */
padding: 10px 20px;            /* tepa-past | chap-o'ng */
padding: 10px 20px 30px;       /* tepa | chap-o'ng | past */
padding: 10px 20px 30px 40px;  /* tepa o'ng past chap */
padding-top: 10px;             /* bitta tomon */

margin: 0 auto;                /* blokni GORIZONTAL markazlash */
  • padding — ichki bo'shliq, fon rangi shu yerga ham tarqaladi
  • margin — tashqi bo'shliq, doim shaffof
  • Markazlash: width: 600px; margin: 0 auto;

box-sizing — eng muhim bitta qator

  • width: 250px + padding: 20px + border: 5px = aslida 300px 😕
CSS
/* Har bir loyihaning CSS faylini shu bilan boshlang */
* {
  box-sizing: border-box;
}
border-box: width = content + padding + border → 250px haqiqatan 250px

Flexbox

Elementlarni bir yo'nalishda — qator yoki ustunga terish

Flexbox: bitta qator hammasini o'zgartiradi

CSS
.konteyner {
  display: flex;    /* ⬅ farzandlar bir qatorga tiziladi */
  gap: 10px;        /* oralaridagi masofa */
}
  • Flex konteyner — display: flex berilgan ota
  • Flex elementlar — uning bevosita farzandlari
  • Menyu, tugmalar qatori, kartalar, markazlash — Flexbox'ning ishi

CSS Grid

Qator va ustunlardan iborat to'r — ikki o'lchamli maket

Grid asoslari

CSS
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 3 ta teng ustun */
  gap: 12px;
}
  • fr — bo'sh joy ulushi: 1fr 2fr — ikkinchisi 2 barobar keng
  • repeat(4, 1fr) = 1fr 1fr 1fr 1fr
  • 250px 1fr — qat'iy yon panel + qolgani
💡
Shaxmat taxtasi / Excel: avval nechta ustun va qatorligini belgilaysiz, keyin elementlarni kataklarga joylaysiz.

✨ Sehrli qator: moslashuvchi galereya

CSS
.galereya {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
  gap: 10px;
}
.galereya img { width: 100%; height: 120px; object-fit: cover; }
  • "Har ustun kamida 150px, nechta sig'sa shuncha, ortgan joyni teng taqsimla"
  • Telefonda 2, planshetda 4, kompyuterda 6 ustun — qo'shimcha kodsiz

Elementni bir nechta katakka cho'zish

CSS
.g     { display: grid; grid-template-columns: repeat(4, 1fr); gap: 10px; }
.katta { grid-column: span 2; grid-row: span 2; }  /* 2×2 */
.keng  { grid-column: 1 / 5; }                     /* 1-chiziqdan 5-chiziqqacha */

Nomlangan hududlar — sahifa maketi

CSS
.sahifa {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: 70px 1fr 50px;
  grid-template-areas:
    "header header"
    "aside  main"
    "footer footer";
  min-height: 100vh;
}
header { grid-area: header; }
aside  { grid-area: aside; }
main   { grid-area: main; }
footer { grid-area: footer; }
  • Maketni so'zlar bilan chizish
  • Har bir qo'shtirnoq — bitta qator
  • Har bir so'z — bitta ustun

Ko'p uchraydigan xatolar

  • ❌ display: flex ni farzandga yozish — u otaga yoziladi
  • ❌ justify-content: center vertikal markazlamaydi — align-items kerak (va balandlik!)
  • ❌ box-sizing: border-box unutilgan — elementlar qatorga sig'maydi
  • ❌ a, span ga width/height — inline-block yoki block kerak
  • ❌ grid-template-columns: 1fr, 1fr — vergul qo'yilmaydi
