https://maktab.uz yozilganda sahifa ekranga chiqquncha nima bo'ladi?

2-topshiriq: 5 ta xatoni toping

HTML
<head>
  <title>Kutubxona
</head>
<body>
  <h1>Kitoblarimiz</h1>
  <img src="rasmlar/kitob.jpg">
  <ul>
    <li>O'tkan kunlar</li>
    <li>Mehrobdan chayon
  </ul>
  <a href="www.kitob.uz">Kitob do'koni</a>
  <p><strong>Telefon:</p></strong>
</body>
  • </title> yopilmagan
  • img da alt yo'q
  • 2-<li> yopilmagan
  • href da https:// yo'q
  • strong va p noto'g'ri tartibda yopilgan
  • ⭐ Bonus: meta charset va viewport yo'q

4–5-topshiriqlar: Flexbox va Grid

  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
.karta {
  border-radius: 14px;
  box-shadow: 0 6px 18px rgba(0,0,0,.1);
}

  .kartalar { grid-template-columns: 1fr; }
}
