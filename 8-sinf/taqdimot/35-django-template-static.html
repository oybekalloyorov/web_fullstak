render() va kontekst

Python
from django.shortcuts import render
from django.http import Http404

def bosh_sahifa(request):
    kontekst = {
        "sarlavha": "Maktab blogi",
        "maqolalar": MAQOLALAR,
    }
    return render(request, "blog/bosh_sahifa.html", kontekst)

def maqola(request, id):
    for m in MAQOLALAR:
        if m["id"] == id:
            return render(request, "blog/maqola.html", {"maqola": m})
    raise Http404("Maqola topilmadi")
  • render() — shablonni topadi, kontekst bilan to'ldiradi, tayyor HTML qaytaradi

if va for

Django shablon
{% if maqolalar %}
  <p>Jami {{ maqolalar|length }} ta maqola</p>
{% else %}
  <p>Hozircha maqola yo'q 😔</p>
{% endif %}

<ul>
  {% for m in maqolalar %}
    <li>
      {{ forloop.counter }}.
      <a href="{% url 'blog:maqola' m.id %}">{{ m.sarlavha }}</a>
    </li>
  {% empty %}
    <li>Maqolalar yo'q</li>
  {% endfor %}
</ul>
  • {% url 'blog:maqola' m.id %} — manzillarni qo'lda yozmang!
  • forloop.counter, forloop.first, forloop.last

Shablonda faqat ko'rsatish mantiqi; hisob-kitob va bazaga so'rov — view'ning ishi

Filtrlar

Django shablon

Shablon merosi

Umumiy skelet bir marta yoziladi

base.html — umumiy skelet

💡
Daftar varag'i: har varaqda bir xil chiziqlar va hoshiya (base.html). Har varaqqa faqat o'sha kunning darsi yoziladi (block content).
blog/templates/blog/base.html
{% load static %}
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="UTF-8">
  <title>{% block title %}Maktab blogi{% endblock %}</title>
  <link rel="stylesheet" href="{% static 'blog/css/style.css' %}">
</head>
<body>
  <header class="header">
    <a class="logo" href="{% url 'blog:bosh' %}">📰 Maktab blogi</a>
    <nav><a href="{% url 'blog:haqida' %}">Biz haqimizda</a></nav>
  </header>
  <main class="konteyner">
    {% block content %}{% endblock %}
  </main>
  <footer class="footer">© 2026 Maktab blogi</footer>
</body>
</html>

extends, block, include

bosh_sahifa.html
{% extends "blog/base.html" %}
{% block title %}Bosh sahifa{% endblock %}

{% block content %}
  <h1>So'nggi maqolalar</h1>
  <div class="kartalar">
    {% for m in maqolalar %}
      {% include "blog/_karta.html" %}
    {% endfor %}
  </div>
{% endblock %}
_karta.html
<article class="karta">
  <span class="belgi">
    {{ m.kategoriya }}
  </span>
  <h3>
    <a href="{% url 'blog:maqola' m.id %}">
      {{ m.sarlavha }}
    </a>
  </h3>
</article>
TegVazifasi
{% extends %}Ota shablondan meros (birinchi qator)
{% block %}O'zgaradigan joy
{% include %}Bo'lakni qo'shish (karta, menyu)

Ko'p uchraydigan xatolar

  • ❌ TemplateDoesNotExist — yo'l xato yoki papka template (s siz); to'g'risi blog/templates/blog/
  • ❌ Invalid block tag 'static' — {% load static %} yo'q
  • ❌ {% endfor %}, {% endif %}, {% endblock %} unutilgan
  • ❌ {% extends %} birinchi qatorda emas
  • ❌ {{ maqola[sarlavha] }} — DTL'da faqat nuqta: {{ maqola.sarlavha }}
