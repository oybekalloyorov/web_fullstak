Git branch — parallel ish

💡
Daraxt shoxlari: main — tana. Har dasturchi o'z vazifasi uchun shox o'stiradi. Ish tugagach shox tanaga "payvand" qilinadi (merge). Shoxdagi xato tanaga zarar bermaydi.
Matn
             o──o──o        ← feature/galereya (Madina)
            /        \
main  o──o──o──────────o──o  ← merge
            \            /
             o──o──o───o     ← feature/forma (Javohir)

Branch buyruqlari

Terminal
git branch                       # barcha branch'lar (* — joriysi)
git switch -c feature/galereya   # yangi branch yaratib o'tish
# ... ishlash, git add, git commit ...
git switch main                  # asosiy branch'ga qaytish
git merge feature/galereya       # birlashtirish
  • main da doim ishlaydigan kod turadi

Konflikt — ikki kishi bitta qatorni o'zgartirsa

Matn
<<<<<<< HEAD
<h1>Bizning maktab</h1>
=======
<h1>5-maktab rasmiy sayti</h1>
>>>>>>> feature/forma
  • HEAD dan ======= gacha — sizning variant
  • ======= dan >>>>>>> gacha — birlashtirilayotgan variant
1
Jamoa bilan kelishib, keraklisini qoldiring
2
Barcha belgilarni o'chiring
3
git add . → git commit
⚠️
Konfliktni kamaytirish: har kim turli fayllarda ishlasin, tez-tez git pull

GitHub'da hamkorlik

  • Hamkor qo'shish: Settings → Collaborators → Add people
  • Pull Request — "mening branch'imni main'ga qo'shing" degan so'rov:
1
git push -u origin feature/galereya
2
GitHub'da "Compare & pull request"
3
Sarlavha, tavsif, skrinshot yozing
4
Jamoadoshlar Files changed da izoh qoldiradi
5
Tuzatib push qilasiz — PR avtomatik yangilanadi
6
Merge pull request → hamma git pull

Code review madaniyati

  • Kodni tanqid qiling, odamni emas: "Bu yerda alt yo'q" ✅ — "Sen hech narsa bilmaysan" ❌

  • Taklif sifatida yozing: "Bu yerda Grid ishlatsak qanday bo'ladi?"
