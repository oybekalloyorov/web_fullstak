Jadval, ro'yxat va forma elementlari

Tartibli va tartibsiz ro'yxatlar, jadvallar (thead, tbody, colspan, rowspan), forma va uning elementlari: input turlari, label, select, textarea, tugmalar.

8-sinf · Web Full-stack dasturlash

Bugun nimani o'rganamiz?

  • Ro'yxatlar: tartibli va tartibsiz
  • Jadvallar: dars jadvali, kataklarni birlashtirish
  • Formalar: matn, parol, email, tanlash, belgilash, tugmalar
  • Forma ma'lumoti qayerga va qanday yuboriladi

Ro'yxatlar: ul va ol

HTML
<h3>Bozorlik ro'yxati</h3>
<ul>
  <li>Non</li>
  <li>Sut</li>
</ul>

<h3>Choy damlash</h3>
<ol>
  <li>Suvni qaynating</li>
  <li>Choy soling</li>
</ol>
  • ul — tartibsiz (unordered): tartib muhim emas
  • ol — tartibli (ordered): qadamlar, reyting
  • Har bir band — <li> (list item)
  • ol atributlari: type="A", type="I", start="5", reversed

Kataklarni birlashtirish

HTML

  • rowspan="2" — vertikal: 2 qatorni egallaydi

Formalar

Forma tuzilishi

HTML
<form action="/royxat" method="POST">
  <label for="ism">Ismingiz:</label>
  <input type="text" id="ism" name="ism"
         placeholder="Masalan: Ali" required>
  <button type="submit">Yuborish</button>
</form>
  • action — qayerga yuboriladi
  • method — GET (manzilda ochiq) yoki POST (yashirin)
  • label for = input id → yozuv bosilsa maydon faollashadi
  • name — eng muhim! Serverga name=qiymat boradi
  • required — majburiy maydon

select, textarea va tugmalar

HTML

<select id="viloyat" name="viloyat">
  <option value="">— Tanlang —</option>
  <option value="tosh">Toshkent</option>
  <option value="sam">Samarqand</option>
</select>

<textarea name="fikr" rows="4" cols="40"></textarea>
<button type="submit">Yuborish</button>
<button type="reset">Tozalash</button>
  • select — ochiladigan ro'yxat; serverga value boradi
  • textarea — ko'p qatorli matn

Brauzer tekshiruvi (validatsiya)

  • required — bo'sh bo'lmasin
  • minlength="8", maxlength="20" — matn uzunligi
  • min, max — son yoki sana chegarasi
  • type="email" — email formati
