Serializer — tarjimon

  • Serializatsiya: model obyekti → dict → JSON (javob yuborish)
  • Deserializatsiya: JSON → tekshirish → model obyekti (saqlash)
💡
Forma bilan o'xshash: serializer — API uchun forma. U ham maydonlarni belgilaydi, tekshiradi va saqlaydi. Form ↔ Serializer, ModelForm ↔ ModelSerializer.

ModelSerializer

blog/serializers.py
from rest_framework import serializers
from .models import Maqola

class MaqolaSerializer(serializers.ModelSerializer):
    muallif = serializers.ReadOnlyField(source="muallif.username")
    kategoriya_nomi = serializers.ReadOnlyField(source="kategoriya.nomi")

    class Meta:
        model = Maqola
        fields = ["id", "sarlavha", "matn", "kategoriya", "kategoriya_nomi",
                  "muallif", "chop_etilgan", "korishlar", "yaratilgan"]
        read_only_fields = ["korishlar", "yaratilgan"]

    def validate_sarlavha(self, qiymat):
        if len(qiymat.strip()) < 5:
            raise serializers.ValidationError("Sarlavha kamida 5 belgi bo'lsin")
        return qiymat

API View: @api_view

blog/api_views.py
from rest_framework import status
from rest_framework.decorators import api_view
from rest_framework.response import Response

@api_view(["GET", "POST"])
def maqolalar_api(request):
    if request.method == "GET":
        maqolalar = Maqola.objects.filter(chop_etilgan=True)
        return Response(MaqolaSerializer(maqolalar, many=True).data)     # 200

    serializer = MaqolaSerializer(data=request.data)                     # POST
    if serializer.is_valid():
        serializer.save(muallif=request.user)
        return Response(serializer.data, status=status.HTTP_201_CREATED) # 201
    return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
  • Kelgan JSON — request.data (request.POST emas!)

API View: APIView (klass)

Python
from rest_framework.views import APIView

class MaqolalarAPI(APIView):
    def get(self, request):
        maqolalar = Maqola.objects.filter(chop_etilgan=True)
        return Response(MaqolaSerializer(maqolalar, many=True).data)

    def post(self, request):
        serializer = MaqolaSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)     # xato → avtomatik 400
        serializer.save(muallif=request.user)
        return Response(serializer.data, status=status.HTTP_201_CREATED)

Ko'p uchraydigan xatolar

  • ❌ Object of type Maqola is not JSON serializable — serializer'siz
  • ❌ Ro'yxat uchun many=True unutilgan
  • ❌ serializer.data ni is_valid() dan oldin o'qish
  • ❌ "rest_framework" INSTALLED_APPS da yo'q
  • ❌ POST → 403 — tizimga kirilmagan (IsAuthenticatedOrReadOnly)
