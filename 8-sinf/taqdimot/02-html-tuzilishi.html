HTML hujjatining tuzilishi, asosiy teglar va atributlar

HTML nima, teg va element, hujjat skeleti (html, head, body), sarlavhalar, paragraflar, matn teglari va atributlar. Birinchi veb-sahifani yaratish.

8-sinf · Web Full-stack dasturlash

Bugun nimani o'rganamiz?

  • HTML nima va nima uchun kerak
  • Teg, element, atribut tushunchalari
  • Har bir sahifaning majburiy skeleti
  • Sarlavha, paragraf va matn formatlash teglari
  • VS Code'da birinchi veb-sahifa yaratish

HTML nima?

HTML — veb-sahifa tuzilishini yaratuvchi belgilash tili
  • HyperText Markup Language
  • Dasturlash tili emas: hisob-kitob ham, shart ham yo'q
  • Brauzerga faqat aytadi: "bu — sarlavha, bu — paragraf, bu — rasm"
💡
O'xshatish — uy: HTML — g'isht va devorlar, CSS — bo'yoq va mebel, JavaScript — elektr va suv (harakat).

Teg va element

HTML
<p>Bu paragraf matni.</p>
  • <p> — ochuvchi teg, </p> — yopuvchi teg (oldida /)
  • Element = ochuvchi teg + mazmun + yopuvchi teg
  • Yolg'iz teglar yopilmaydi: <br> <hr> <img> <input> <meta>

Atribut — elementga qo'shimcha ma'lumot

HTML
<a href="https://kun.uz" title="Yangiliklar">Kun.uz ga o'tish</a>
  • Doim ochuvchi tegda, nom="qiymat" ko'rinishida
AtributVazifasi
idYagona nom (takrorlanmaydi)
classGuruh nomi (CSS uchun)
titleSichqoncha ustiga kelganda izoh
langMatn tili: lang="uz"

HTML hujjatining skeleti

index.html
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mening birinchi sahifam</title>
</head>
<body>
  <h1>Salom, dunyo!</h1>
  <p>Bu mening birinchi veb-sahifam.</p>
</body>
</html>
  • VS Code'da ! + Enter — skelet o'zi yoziladi
  • <!DOCTYPE html> — "bu HTML5 hujjat"
  • <head> — ko'rinmaydigan ma'lumotlar
  • charset="UTF-8" — o', g', emoji to'g'ri chiqadi
  • <title> — brauzer yorlig'idagi nom
  • <body> — ko'rinadigan hamma narsa

head va body

💡
O'xshatish — odam: <head> — pasport (ismi, tili — ko'rinmaydi, lekin muhim). <body> — odamning o'zi: ko'rinishi, kiyimi, harakatlari.
  • Matnni <head> ichiga yozsangiz — ko'rinmaydi
  • viewport qatori — telefonda to'g'ri o'lcham uchun (10-mavzu)

Ichma-ich joylashish (nesting)

HTML
<!-- ✅ To'g'ri -->
<p>Bu <strong>juda muhim</strong> gap.</p>

<!-- ❌ Noto'g'ri -->
<p>Bu <strong>juda muhim</p></strong> gap.
Oxirgi ochilgan teg — birinchi yopiladi
  • Matryoshka qo'g'irchoqlari kabi
  • Ichki elementlarni 2 bo'sh joy bilan suring; Shift+Alt+F — avtomatik tartiblash

Sarlavhalar: h1 dan h6 gacha

HTML
<h1>Maktabimiz yangiliklari</h1>
<h2>Sport</h2>
<h3>Futbol bo'yicha musobaqa</h3>
<p>8-"A" sinf jamoasi g'olib bo'ldi.</p>
<h2>Fanlar</h2>
<p>Olimpiadaga ro'yxatdan o'tish boshlandi.</p>
  • Sahifada odatda bitta <h1>
  • Darajalarni sakramang: h2 → h3, h4 emas
  • Sarlavha — ma'no (kitob mundarijasi), kattalik uchun CSS bor
⚠️
HTML bo'sh joylarni "yutadi": 5 ta bo'sh joy = 1 ta. Yangi qator uchun <br>, abzats uchun yangi <p>.
