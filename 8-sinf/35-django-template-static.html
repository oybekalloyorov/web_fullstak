Django Template tizimi va dinamik sahifalar. Template va statik fayllar

render() va kontekst, Django Template Language: o'zgaruvchilar, {% if %}, {% for %}, filtrlar, {% url %}; shablon merosi (extends, block, include); CSS, JavaScript va rasmlar — static fayllar.

2 soat · 1 nazariy + 1 amaliy

🎯 Bu darsda nimani o'rganasiz

  • HTML'ni view'dan ajratib, shablon (template) fayllarda saqlashni;
  • View'dan shablonga ma'lumot uzatishni (render va kontekst);
  • Django shablon tili: o'zgaruvchilar, shartlar, sikllar, filtrlar;
  • Shablon merosi — umumiy sahifa "skeleti"ni bir marta yozishni;
  • CSS, JavaScript va rasmlarni (static fayllar) ulashni.

Bu dars I–II boblardagi HTML/CSS/JS bilimlaringizni Django bilan birlashtiradi!

#Template nima?

34-mavzuda HTML'ni Python satri ichida yozdik — noqulay va xavfli. Template (shablon) — oddiy HTML fayl, lekin unda "bo'sh joylar" bor, ularni Django ma'lumot bilan to'ldiradi.

O'xshatish: tabriknoma shabloni Do'konda tayyor tabriknoma: "Hurmatli ________, sizni ________ bilan tabriklaymiz!" Siz faqat bo'sh joylarni to'ldirasiz. Shablon bir xil, ism va sabab har safar boshqa. Django template ham shunday: <h1>{{ sarlavha }}</h1> — har bir maqola uchun o'z sarlavhasi qo'yiladi.

#Shablonlar papkasi va render()

  1. Papkalar tuzilmasini yarating (ilova nomini ikki marta takrorlash — nomlar to'qnashmasligi uchun Django an'anasi):
    Matn
    blog/
└── templates/
    └── blog/
        ├── bosh_sahifa.html
        └── maqola.html
  2. View'da render ishlating:
    blog/views.py
    from django.shortcuts import render
from django.http import Http404

MAQOLALAR = [ ... ]   # 34-mavzudagi ro'yxat

def bosh_sahifa(request):
    kontekst = {                                  # shablonga yuboriladigan ma'lumotlar (dict)
        "sarlavha": "Maktab blogi",
        "maqolalar": MAQOLALAR,
    }
    return render(request, "blog/bosh_sahifa.html", kontekst)

def maqola(request, id):
    for m in MAQOLALAR:
        if m["id"] == id:
            return render(request, "blog/maqola.html", {"maqola": m})
    raise Http404("Maqola topilmadi")

render(request, shablon_yo'li, kontekst) — shablonni topadi, kontekstdagi ma'lumotlar bilan to'ldiradi va tayyor HTML javob qaytaradi.

Shartlar: {% if %}

Django shablon

  <p>Jami {{ maqolalar|length }} ta maqola</p>
{% else %}
  <p>Hozircha maqola yo'q 😔</p>
{% endif %}

Sikllar: {% for %}

blog/templates/blog/bosh_sahifa.html
<h1>{{ sarlavha }}</h1>
<ul>
  {% for m in maqolalar %}
    <li>
      {{ forloop.counter }}.                                   {# 1, 2, 3 — tartib raqami #}
      <a href="{% url 'blog:maqola' m.id %}">{{ m.sarlavha }}</a>
      <small>({{ m.kategoriya }})</small>
    </li>
  {% empty %}
    <li>Maqolalar yo'q</li>                                    {# ro'yxat bo'sh bo'lsa #}
  {% endfor %}
</ul>
  • {% url 'blog:maqola' m.id %} — 34-mavzudagi nomlangan URL'dan havola yasaydi. Manzillarni qo'lda yozmang!
  • forloop.counter (1 dan), forloop.first, forloop.last — sikl haqida ma'lumot.
Shablonda faqat ko'rsatish mantiqi bo'lsin. Murakkab hisob-kitob, bazaga so'rov — view'ning ishi. DTL ataylab cheklangan: unda Python funksiyalarini to'g'ridan-to'g'ri chaqirib bo'lmaydi.

Filtrlar

Django shablon
{{ ism|upper }}                       → ALI
{{ ism|lower }}                       → ali
{{ ism|title }}                       → Ali Valiyev
{{ matn|truncatewords:20 }}           → birinchi 20 so'z...
{{ matn|truncatechars:100 }}          → birinchi 100 belgi…
{{ maqolalar|length }}                → 3
{{ sana|date:"d.m.Y" }}               → 06.10.2026
{{ sana|date:"d E Y, H:i" }}          → 06 oktabr 2026, 15:30
{{ narx|floatformat:2 }}              → 12500.00
{{ izoh|default:"Izoh yo'q" }}        → qiymat bo'sh bo'lsa
{{ matn|linebreaks }}                 → qator o'tishlarini <p> va <br> ga aylantiradi

#Shablon merosi — eng muhim imkoniyat

Saytning har bir sahifasida bir xil header, menyu, footer va CSS bor. Ularni har bir shablonga nusxalash — xato. Shablon merosi: umumiy skelet bitta base.html da yoziladi, boshqa sahifalar faqat o'zgaruvchi qismlarini to'ldiradi.

O'xshatish: daftar varag'i Maktab daftarining har bir varag'ida bir xil chiziqlar va hoshiya bor (base.html). Har bir varaqqa faqat o'sha kunning darsi yoziladi (block content). Hoshiyani har safar qayta chizmaysiz.
blog/templates/blog/base.html
{% load static %}
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>{% block title %}Maktab blogi{% endblock %}</title>
  <link rel="stylesheet" href="{% static 'blog/css/style.css' %}">
</head>
<body>
  <header class="header">
    <a class="logo" href="{% url 'blog:bosh' %}">📰 Maktab blogi</a>
    <nav>
      <a href="{% url 'blog:bosh' %}">Bosh sahifa</a>
      <a href="{% url 'blog:haqida' %}">Biz haqimizda</a>
    </nav>
  </header>

  <main class="konteyner">
    {% block content %}{% endblock %}         {# ⬅ har bir sahifa shu joyni to'ldiradi #}
  </main>

  <footer class="footer">© 2026 5-maktab o'quvchilari</footer>
  <script src="{% static 'blog/js/main.js' %}"></script>
</body>
</html>
blog/templates/blog/bosh_sahifa.html
{% extends "blog/base.html" %}

{% block title %}Bosh sahifa — Maktab blogi{% endblock %}

{% block content %}
  <h1>So'nggi maqolalar</h1>
  <div class="kartalar">
    {% for m in maqolalar %}
      {% include "blog/_karta.html" %}
    {% empty %}
      <p>Hozircha maqola yo'q.</p>
    {% endfor %}
  </div>
{% endblock %}

#Static fayllar: CSS, JavaScript, rasmlar

CSS, JS va logotip kabi o'zgarmaydigan fayllar Django'da static fayllar deyiladi.

Matn
blog/
└── static/
    └── blog/
        ├── css/style.css
        ├── js/main.js
        └── img/logo.png
Django shablon
{% load static %}                                         {# shablon boshida bir marta #}
<link rel="stylesheet" href="{% static 'blog/css/style.css' %}">
<img src="{% static 'blog/img/logo.png' %}" alt="Logo">
<script src="{% static 'blog/js/main.js' %}"></script>

STATIC_URL = "static/"                     # brauzerdagi manzil boshlanishi
STATICFILES_DIRS = [BASE_DIR / "static"]   # (ixtiyoriy) loyiha darajasidagi umumiy static papka
STATIC_ROOT = BASE_DIR / "staticfiles"     # serverga joylashda yig'iladigan joy (41-mavzu)

Media fayllar — foydalanuvchilar yuklaydigan fayllar (maqola rasmlari, avatarlar). Ular static'dan farq qiladi va MEDIA_URL/MEDIA_ROOT bilan sozlanadi — 36-mavzuda ImageField bilan birga ko'ramiz.
Static fayl o'zgarishi ko'rinmasa — brauzer eski nusxani keshlagan. Ctrl+F5 bilan sahifani to'liq yangilang. Yangi static papka qo'shganda serverni qayta ishga tushiring.

#Amaliy mashg'ulot

  1. base.html, bosh_sahifa.html, _karta.html, maqola.html shablonlarini yarating va view'larni render ga o'tkazing.
  2. Static papkada style.css yarating va ulang. Sahifa 8-mavzudagi portfolio kabi chiroyli ko'rinishiga erishing.
  3. haqida.html sahifasini base.html dan meros olib yarating.
  4. main.js da kichik interaktivlik qo'shing: "🌙" tugmasi bosilganda tungi rejim (19-mavzu).
  5. Kategoriya sahifasini (kategoriya.html) yarating: sarlavha {{ nomi|title }} va shu kategoriyadagi maqolalar (_karta.html ni include qilib).
  6. Bosh sahifada maqolalar sonini ko'rsating va oxirgi kartadan keyin chiziq chizilmasin (forloop.last).

#Ko'p uchraydigan xatolar

  • ❌ TemplateDoesNotExist — shablon yo'li noto'g'ri yoki papka nomi template (s harfisiz). To'g'risi: blog/templates/blog/fayl.html.
  • ❌ Invalid block tag 'static' — shablon boshida {% load static %} yo'q.
  • ❌ {% endfor %}, {% endif %}, {% endblock %} ni unutish — TemplateSyntaxError.
  • ❌ {% extends %} birinchi qatorda emas.
  • ❌ {{ maqola[sarlavha] }} — DTL'da kvadrat qavs yo'q, faqat nuqta: {{ maqola.sarlavha }}.

#O'zingizni tekshiring

Shablonda o'zgaruvchi qiymatini chiqarish sintaksisi?

  1. {% ism %}
  2. {{ ism }}
  3. ${ism}
  4. <?= ism ?>

View'dan shablonga ma'lumot qanday uzatiladi?

  1. Global o'zgaruvchi orqali
  2. URL orqali
  3. render(request, "shablon.html", kontekst_dict)
  4. localStorage orqali

Umumiy skeletdan meros olish uchun qaysi teg?

  1. {% extends "base.html" %}
  2. {% include "base.html" %}
  3. {% import base %}
  4. {% inherit base %}

Shablonda CSS faylni to'g'ri ulash?

  1. href="style.css"
  2. href="/blog/style.css"
  3. href="{{ static.css }}"
  4. href="{% static 'blog/css/style.css' %}"

{{ matn|truncatewords:10 }} nima qiladi?

  1. Matnni 10 marta takrorlaydi
  2. Matnning birinchi 10 so'zini ko'rsatadi
  3. 10 ta belgini o'chiradi
  4. Matnni 10 ga bo'ladi

Sikl ichida ro'yxat bo'sh bo'lgandagi holat uchun qaysi teg?

  1. {% else %}
  2. {% none %}
  3. {% empty %}
  4. {% null %}

  2. Maxsus 404 sahifa: templates/404.html yarating (u DEBUG=False bo'lganda ko'rinadi — 41-mavzuda tekshiramiz).

✅ Yodda tuting

  • Shablonlar: ilova/templates/ilova/*.html; view'da render(request, "ilova/fayl.html", {...}).
  • DTL: {{ o'zgaruvchi }}, {% teg %}, {{ x|filtr }}; {% if %}, {% for %}...{% empty %}, {% url 'app:nom' arg %}.
  • Meros: base.html da {% block content %}; bolada {% extends %} + {% block %}; bo'laklar — {% include %}.
  • Static: ilova/static/ilova/..., shablonda {% load static %} + {% static 'yo'l' %}.
  • Django matnni avtomatik ekranlaydi — XSS'dan himoya.
