CSS pseudo-class va pseudo-elementlar. CSS position

:hover, :focus, :active, :nth-child kabi holat selektorlari; ::before, ::after, ::first-letter pseudo-elementlari; static, relative, absolute, fixed, sticky pozitsiyalari va z-index.

1 soat · amaliy

🎯 Bu darsda nimani o'rganasiz

  • Element holatiga qarab uslub berishni: sichqoncha ustida, bosilganda, tanlanganda;
  • Ro'yxatning birinchi, oxirgi, juft-toq elementlarini tanlashni;
  • HTML'siz "virtual" elementlar yaratishni (::before, ::after);
  • Elementlarni aniq joyga qo'yish: relative, absolute, fixed, sticky;
  • Ustma-ust tushgan elementlar tartibini z-index bilan boshqarishni.

#Pseudo-class — element holati

Pseudo-class (soxta sinf) — elementning holatini yoki o'rnini bildiruvchi selektor. U bitta ikki nuqta bilan yoziladi: a:hover.

O'xshatish: svetofor Svetofor bitta, lekin holati o'zgaradi: qizil, sariq, yashil. Tugma ham bitta, lekin holatlari bor: oddiy, sichqoncha ustida (:hover), bosilgan payt (:active), klaviatura bilan tanlangan (:focus). Har bir holatga alohida "rang" beramiz.

Foydalanuvchi harakati holatlari

HTML
<style>
  .tugma {
    background: #4f46e5; color: white; border: none;
    padding: 12px 24px; border-radius: 8px; font-size: 16px; cursor: pointer;
  }
  .tugma:hover  { background: #4338ca; }                  /* sichqoncha ustida */
  .tugma:active { transform: scale(0.95); }               /* bosilgan payt */
  .tugma:focus  { outline: 3px solid #fbbf24; }           /* Tab bilan tanlanganda */

  input { padding: 8px; border: 2px solid #cbd5e1; border-radius: 6px; }
  input:focus { border-color: #4f46e5; outline: none; background: #eef2ff; }

  a:link    { color: #2563eb; }     /* hali bosilmagan havola */
  a:visited { color: #7c3aed; }     /* ilgari bosilgan havola */
  a:hover   { color: #dc2626; }

  button:disabled { background: #9ca3af; cursor: not-allowed; }
</style>

#Pseudo-element — virtual qism

Pseudo-element — elementning bir qismini tanlaydi yoki HTML'da yo'q yangi qism yaratadi. U ikki nuqta ikki marta bilan yoziladi: ::before.

HTML
<style>
  /* ::before va ::after — element ichida, boshida/oxirida virtual "bola" yaratadi.
     content xossasi MAJBURIY (hatto bo'sh bo'lsa ham: content: "") */
  .majburiy::after { content: " *"; color: red; font-weight: bold; }
  .yangi::before { content: "🔥 YANGI "; color: #f97316; font-size: 12px; font-weight: bold; }
  .tel::before { content: "📞 "; }

  /* Bezak chiziq: sarlavha ostida qisqa rangli chiziq */
  h2.chiziqli::after {
    content: "";
    display: block;
    width: 60px; height: 4px;
    background: #4f46e5; border-radius: 2px; margin-top: 6px;
  }

  p.kitob::first-letter { font-size: 2.5em; color: #4f46e5; font-weight: bold; float: left; margin-right: 6px; line-height: 1; }
  p.kitob::first-line { font-variant: small-caps; }
  ::selection { background: #fde047; }       /* sichqoncha bilan belgilangan matn */
  input::placeholder { color: #a78bfa; font-style: italic; }
</style>

#Position — elementni aniq joyga qo'yish

Odatda elementlar oqim bo'yicha — yuqoridan pastga, birin-ketin joylashadi. position xossasi bu tartibni o'zgartirishga imkon beradi. Joy top, right, bottom, left xossalari bilan ko'rsatiladi.

QiymatXatti-harakatNimaga nisbatan siljiydiMisol
staticStandart — oddiy oqimdaSiljimaydiHamma elementlar
relativeOqimda qoladi, joyi saqlanadiO'zining asl joyigaKichik siljitish; absolute uchun "langar"
absoluteOqimdan chiqadi (joy egallamaydi)Eng yaqin positionli ajdodigaKartadagi "-20%" belgisi
fixedOqimdan chiqadi, scroll qilinganda qimirlamaydiEkranga (brauzer oynasiga)"Yuqoriga" tugmasi, chat tugmasi
stickyOddiy turadi, scroll paytida chegaraga yetgach yopishib qoladiScroll konteynerigaYopishqoq menyu

O'xshatish: muzlatgichdagi magnit position: relative berilgan karta — muzlatgich eshigi. position: absolute berilgan belgi — magnit: siz uni eshikning istalgan burchagiga yopishtirasiz (top, left...). Eshik (karta) qayerga borsa, magnit ham u bilan birga ketadi. Agar ota elementda position: relative bo'lmasa, "magnit" butun sahifa burchagiga uchib ketadi!

z-index — qatlamlar tartibi

Elementlar ustma-ust tushsa, qaysi biri yuqorida ko'rinadi? z-index — "qavat raqami": kattasi yuqorida. U faqat position berilgan (static bo'lmagan) elementlarda ishlaydi.

HTML
<style>
  .q { position: absolute; width: 120px; height: 120px; color: white; font-weight: bold; padding: 8px; border-radius: 10px; }
  .a { background: #ef4444; top: 20px; left: 20px; z-index: 1; }
  .b { background: #22c55e; top: 60px; left: 70px; z-index: 3; }
  .c { background: #3b82f6; top: 100px; left: 120px; z-index: 2; }
  .sahna { position: relative; height: 260px; }
</style>
<div class="sahna">
  <div class="q a">z-index: 1</div>
  <div class="q b">z-index: 3 (eng yuqorida)</div>
  <div class="q c">z-index: 2</div>
</div>

#Amaliy mashg'ulot: maktab sahifasi (3-loyiha)

  1. maktab/ papkasida index.html va style.css yarating.
  2. Sticky header: maktab logotipi va menyu, position: sticky; top: 0; z-index: 100;. Menyu havolalariga :hover holatini qo'shing.
  3. Hero bo'lim: maktab rasmi fonda (7-mavzu), ustida sarlavha.
  4. "Yangiliklar": 3–4 ta karta (Grid, 8-mavzu). Har bir kartaning burchagida position: absolute bilan sana belgisi (masalan, "15 OKT"). Kartaga :hover da soya kuchaysin.
  5. "Ustozlarimiz": doira shaklidagi rasmlar va ism; :hover bo'lganda rasm atrofida rangli chegara paydo bo'lsin.
  6. Dars jadvali: tr:nth-child(even) bilan "zebra" uslubi, tr:hover bilan qatorni ajratib ko'rsatish.
  7. "Yuqoriga" tugmasi: position: fixed bilan o'ng pastki burchakda.
  8. Sarlavhalar ostiga ::after bilan qisqa rangli chiziq qo'shing.

#Ko'p uchraydigan xatolar

  • ❌ absolute element butun sahifa burchagiga "uchib ketdi" — ota elementga position: relative berilmagan.
  • ❌ ::before ko'rinmayapti — content xossasi yozilmagan.
  • ❌ sticky ishlamayapti — top: 0 berilmagan yoki ota elementda overflow: hidden bor.
  • ❌ z-index: 9999 ham yordam bermayapti — elementda position yo'q (static).
  • ❌ a:hover ni a :hover deb yozish (orada bo'sh joy) — bu butunlay boshqa selektor bo'lib qoladi.

#O'zingizni tekshiring

Sichqoncha element ustiga kelganda ishlaydigan pseudo-class qaysi?

  1. :active
  2. :hover
  3. :focus
  4. :over

Jadvalning faqat juft qatorlarini tanlash uchun?

  1. tr:even
  2. tr:nth(2)
  3. tr:first-child
  4. tr:nth-child(even)

::after ishlashi uchun qaysi xossa majburiy?

  1. content
  2. display
  3. position
  4. color

Sahifa aylantirilganda ham ekranning bir joyida qimirlamay turadigan tugma uchun qaysi position?

  1. relative
  2. absolute
  3. fixed
  4. static

Kartaning burchagidagi "-20%" belgisi kartaga nisbatan joylashishi uchun kartaga nima beriladi?

  1. position: absolute
  2. position: relative
  3. position: fixed
  4. z-index: 1

Ota — relative (langar), belgi — absolute.

z-index: 5 va z-index: 2 bo'lgan elementlar ustma-ust tushdi. Qaysi biri ko'rinadi?

  1. z-index: 2
  2. HTML'da birinchi yozilgani
  3. z-index: 5
  4. Ikkalasi ham ko'rinmaydi

🏠 Uyga vazifa

  1. Maktab sahifasini yakunlang va barcha interaktiv holatlarni (:hover, :focus) qo'shing.
  2. 5 xil tugma dizaynini yarating: har birida :hover, :active va :disabled holatlari bo'lsin.
  3. Faqat CSS bilan "tooltip" yasang: sichqoncha so'z ustiga borganda uning tepasida izoh chiqsin (position: absolute + :hover).

✅ Yodda tuting

  • Pseudo-class (:) — holat: :hover, :focus, :active, :nth-child(), :first-child, :not().
  • Pseudo-element (::) — virtual qism: ::before, ::after (content majburiy), ::first-letter, ::placeholder.
  • relative — langar; absolute — langarga nisbatan; fixed — ekranga; sticky — yopishqoq.
  • z-index — qatlamlar tartibi (faqat position berilganlarda).
