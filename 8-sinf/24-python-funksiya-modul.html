Parametrlar turlari

Python
# Standart qiymat
def darajaga(son, daraja=2):
    return son ** daraja

print(darajaga(5))          # 25  — daraja=2 (standart)
print(darajaga(2, 10))      # 1024

# Nomlangan (kalitli) argumentlar — tartibni eslash shart emas
def anketa(ism, yosh, shahar="Toshkent"):
    print(f"{ism}, {yosh} yosh, {shahar}")

anketa("Ali", 14)
anketa(yosh=15, ism="Laylo", shahar="Xiva")

# Istalgan sonli argumentlar
def ortacha(*sonlar):              # *sonlar — barcha argumentlar tuple'ga yig'iladi
    return sum(sonlar) / len(sonlar)

print(ortacha(4, 5, 5, 3))          # 4.25

# Bir nechta qiymat qaytarish (aslida tuple)
def min_max(royxat):
    return min(royxat), max(royxat)

eng_kichik, eng_katta = min_max([7, 2, 9, 4])
print(eng_kichik, eng_katta)        # 2 9

lambda — kichik, nomsiz funksiya

Python
kvadrat = lambda x: x * x
print(kvadrat(7))                    # 49

oquvchilar = [("Ali", 85), ("Vali", 92), ("Gani", 78)]
oquvchilar.sort(key=lambda o: o[1], reverse=True)   # ball bo'yicha saralash
print(oquvchilar)                    # [('Vali', 92), ('Ali', 85), ('Gani', 78)]

lambda asosan saralash (sort(key=...)), max(key=...) kabi joylarda "bir martalik" funksiya sifatida ishlatiladi.

json — ma'lumotlarni saqlash va almashish

JSON — dasturlar o'rtasida ma'lumot almashishning eng mashhur formati. Python dict/list ↔ JSON matn.

oquvchilar = [{"ism": "Ali", "baho": 5}, {"ism": "Zarina", "baho": 4}]

# Faylga saqlash
with open("oquvchilar.json", "w", encoding="utf-8") as f:

# Fayldan o'qish
with open("oquvchilar.json", encoding="utf-8") as f:

#Ko'p uchraydigan xatolar

  • ❌ Funksiyani e'lon qilishdan oldin chaqirish — Python faylni yuqoridan pastga o'qiydi.
  • ❌ return unutilgan — funksiya None qaytaradi.
  • ❌ O'z faylingizni standart modul nomi bilan atash: random.py, math.py — Python sizning faylingizni import qilib, xato beradi!
  • ❌ ModuleNotFoundError: No module named 'requests' — paket o'rnatilmagan: pip install requests.
