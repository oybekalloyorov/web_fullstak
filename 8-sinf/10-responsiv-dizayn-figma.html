10-mavzu · 31 tadan · I bob. HTML va CSS

Moslashuvchan (responsiv) dizayn va media so'rovlar. Figma bilan ishlash

Responsiv dizayn nima, viewport, moslashuvchan rasmlar, media query sintaksisi, mobile-first yondashuv, breakpointlar, DevTools'da telefon rejimi; Figma'da maket bilan ishlash va uni kodga o'tkazish.

3 soat · 1 nazariy + 2 amaliy

🎯 Bu darsda nimani o'rganasiz

  • Nima uchun saytlar telefon, planshet va kompyuterda turlicha ko'rinishi kerakligini;
  • viewport meta-tegi va moslashuvchan rasmlarni;
  • Media query — ekran o'lchamiga qarab turli CSS yozishni;
  • Mobile-first yondashuvini va breakpointlarni;
  • Figma dasturida maket bilan ishlash va uni HTML/CSS'ga aylantirishni;
  • To'liq responsiv Landing Page yaratishni (4 va 5-loyihalar).

#Responsiv dizayn nima?

Bugun internetdan foydalanuvchilarning 60% dan ortig'i telefondan kiradi. Kompyuter uchun yasalgan 1200 piksellik sayt 390 piksellik telefon ekranida yo juda mayda ko'rinadi, yo yonga sig'may qoladi. Responsiv (moslashuvchan) dizayn — sayt har qanday ekran o'lchamiga o'zi moslashishi.

O'xshatish: suv Suv qaysi idishga quyilsa — stakan, choynak yoki chelak — o'sha shaklni oladi. Responsiv sayt ham suvga o'xshaydi: telefon, planshet yoki katta monitor — har biriga moslashadi. Bunga erishishning 3 asosiy vositasi bor: moslashuvchan maket (%, fr, flex, grid), moslashuvchan rasmlar va media so'rovlar.

Istalgan katta saytni (masalan, kun.uz) oching va brauzer oynasini asta-sekin toraytiring — menyu, ustunlar va rasmlar qanday o'zgarishini kuzating.

#1-qadam: viewport meta-tegi

HTML
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Bu qator bo'lmasa, telefon brauzeri sahifani "980 piksellik kompyuter ekrani" deb o'ylaydi va hammasini kichraytirib ko'rsatadi — media query'lar umuman ishlamaydi. width=device-width — "sahifa kengligi = qurilma ekran kengligi". Bu qatorni har bir sahifaga yozing (VS Code'dagi ! shabloni uni avtomatik qo'shadi).

#2-qadam: moslashuvchan o'lchamlar va rasmlar

CSS
/* ❌ Qattiq o'lcham — telefonda sig'maydi */
.konteyner { width: 1100px; }

/* ✅ Moslashuvchan: kengligi ekranga qarab, lekin 1100px dan oshmaydi */
.konteyner {
  width: 100%;
  max-width: 1100px;
  margin: 0 auto;
  padding: 0 16px;     /* telefonda matn ekran chetiga yopishmasin */
}

/* ✅ Rasmlar hech qachon konteynerdan chiqib ketmasin */
img {
  max-width: 100%;
  height: auto;        /* proporsiya saqlansin */
}

/* ✅ Shrift o'lchami ekranga qarab silliq o'zgaradi: kamida 1.8rem, ko'pi bilan 3.5rem */
h1 { font-size: clamp(1.8rem, 5vw, 3.5rem); }

8-mavzudagi repeat(auto-fill, minmax(220px, 1fr)) ham responsivlikning kuchli vositasi — ustunlar soni o'zi o'zgaradi.

#3-qadam: media so'rovlar (media queries)

Media query — "agar ekran shunday bo'lsa, quyidagi CSS'ni qo'lla" degan shart.

CSS
@media (max-width: 768px) {
  /* Bu qoidalar FAQAT ekran kengligi 768px yoki undan KICHIK bo'lganda ishlaydi */
  .menyu { flex-direction: column; }
  h1 { font-size: 1.8rem; }
}

@media (min-width: 1024px) {
  /* FAQAT ekran 1024px yoki undan KATTA bo'lganda */
  .kartalar { grid-template-columns: repeat(4, 1fr); }
}
  • max-width: 768px — "ko'pi bilan 768px" (ya'ni 768 va undan kichik ekranlar).
  • min-width: 1024px — "kamida 1024px" (1024 va undan katta).
  • Shartlarni birlashtirish: @media (min-width: 600px) and (max-width: 900px) { ... }
HTML
<style>
  body { font-family: sans-serif; background: #e0e7ff; transition: background .3s; }
  .xabar::after { content: "💻 Katta ekran (900px dan katta)"; }

  @media (max-width: 900px) {
    body { background: #fef3c7; }
    .xabar::after { content: "📟 O'rta ekran (600–900px)"; }
  }
  @media (max-width: 600px) {
    body { background: #dcfce7; }
    .xabar::after { content: "📱 Kichik ekran (600px gacha)"; }
  }
</style>
<h2 class="xabar"></h2>
<p>"⧉ Yangi oynada" bosing va brauzer oynasini toraytirib-kengaytirib ko'ring — fon rangi va yozuv o'zgaradi.</p>

Breakpointlar (to'xtash nuqtalari)

Breakpoint — dizayn o'zgaradigan ekran kengligi. Ko'p ishlatiladiganlari:

QurilmaTaxminiy kenglikOdatiy maket
📱 Telefon360–480px1 ustun, "burger" menyu
📱 Katta telefon / kichik planshet481–768px1–2 ustun
📟 Planshet769–1024px2–3 ustun
💻 Noutbuk / kompyuter1025px+3–4 ustun, to'liq menyu
Breakpointlarni qurilmalarga emas, dizayningizga qarab tanlang: oynani toraytiring va dizayn "buzila boshlagan" joyda breakpoint qo'ying.

Mobile-first yondashuvi

Ikki yo'l bor:

  • Desktop-first: avval katta ekran uchun yozasiz, keyin max-width bilan kichraytirasiz.
  • Mobile-first ✅: avval telefon uchun oddiy CSS, keyin min-width bilan katta ekranlar uchun qo'shimchalar.
CSS
/* MOBILE-FIRST */

/* 1. Standart — telefon: hammasi bitta ustunda */
.kartalar { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* 2. Planshet va undan katta */
@media (min-width: 640px) {
  .kartalar { grid-template-columns: repeat(2, 1fr); }
}

/* 3. Kompyuter */
@media (min-width: 1024px) {
  .kartalar { grid-template-columns: repeat(4, 1fr); }
}

Nima uchun mobile-first yaxshiroq? Telefon uchun dizayn odatda oddiyroq (bitta ustun) — undan murakkabga o'tish osonroq. Telefonlar kamroq CSS yuklaydi va eng ko'p foydalanuvchi aynan telefonda.

DevTools'da telefon rejimi

  1. Sahifangizni Chrome'da oching, F12 bosing.
  2. Chap yuqoridagi telefon-planshet belgisini bosing (Toggle device toolbar, Ctrl+Shift+M).
  3. Tepadan qurilmani tanlang: iPhone SE, Pixel 7, iPad... yoki "Responsive" rejimida chetini sudrab o'lchamni o'zgartiring.
  4. Eng muhim tekshiruv: gorizontal scroll (yonga aylantirish) paydo bo'lmasligi kerak.

#Responsiv navigatsiya

Kompyuterda menyu gorizontal, telefonda esa sig'magani uchun "☰ burger" tugmasi orqali ochiladi. JavaScript'siz, faqat CSS bilan:

HTML
<style>
  * { box-sizing: border-box; margin: 0; }
  body { font-family: sans-serif; }

#Figma — dizayndan kodga

Professional jamoalarda sayt avval dizayner tomonidan maxsus dasturda chiziladi, keyin frontend dasturchi uni kodga aylantiradi. Eng mashhur dastur — Figma. U brauzerda ishlaydi va o'quvchilar uchun bepul tarifi bor.

Figma bilan tanishish

  1. figma.com da Gmail orqali ro'yxatdan o'ting.
  2. Figma Community bo'limidan bepul "Landing page" yoki "Portfolio" shablonini toping va Open in Figma bosing (nusxa sizning akkauntingizga tushadi).
  3. Asosiy tushunchalar:
    • Frame — ekran yoki sahifa (masalan, "Desktop 1440", "iPhone 14"). Ichidagi elementlarning "konteyneri".
    • Layers (chap panel) — barcha elementlar daraxti. HTML tuzilmasiga juda o'xshaydi!
    • Design (o'ng panel) — tanlangan elementning o'lchami, rangi, shrifti, radiusi, soyasi.
    • Auto layout — Figma'dagi Flexbox! Elementlarni qator yoki ustunga teradi, gap va padding beradi.

Dizayndan qiymatlarni olish

Elementni tanlang va o'ng paneldan o'qing — yoki yuqoridagi Dev Mode (Shift+D) ni yoqing, Figma tayyor CSS ko'rsatadi:

Rasmlarni eksport qilish

Rasm yoki ikonkani tanlang → o'ng paneldagi Export → formatni tanlang (rasmlar uchun PNG/JPG, ikonkalar uchun SVG) → Export.

Maketni kodlash tartibi

  1. Dizaynni "bloklarga" bo'ling: header, hero, xizmatlar, sharhlar, footer. Har biri — HTML'da section.
  2. Avval faqat HTML tuzilmasini yozing (dizaynsiz).
  3. Ranglar va shriftlarni bir joyga yig'ing (CSS boshida izoh sifatida yoki keyinchalik CSS o'zgaruvchilari bilan).
  4. Bloklarni yuqoridan pastga ketma-ket uslublang. Avval katta maket (flex/grid), keyin detallar.
  5. Oxirida telefon versiyasini (Figma'da mobil frame bo'lsa — unga qarab) media query bilan qo'shing.

Topshiriq:

  1. Kodni o'z mavzungizga moslang (ranglar, matnlar, rasmlar). Kamida 5 ta bo'lim: header, hero, xizmatlar/mahsulotlar, raqamlar yoki sharhlar, footer.

  3. Telefonda menyu yashiringan — yuqoridagi "burger" usulini qo'shing.

#Ko'p uchraydigan xatolar

  • ❌ viewport meta-tegini unutish — telefonda media query'lar ishlamaydi.
  • ❌ width: 1200px kabi qattiq kengliklar — gorizontal scroll paydo bo'ladi. max-width ishlating.
  • ❌ Media query'ni CSS faylning boshiga yozish — keyingi oddiy qoidalar uni "bosib" ketadi. Media query'lar asosiy qoidalardan keyin yoziladi.
  • ❌ @media (max-width: 768) — birlik (px) unutilgan.
  • ❌ Faqat kompyuterda tekshirish. Haqiqiy telefonda ham oching (Live Server + bir Wi-Fi tarmog'ida telefondan kompyuter IP-manziliga kirish mumkin).

#O'zingizni tekshiring

  2. Ekran 600px yoki undan kichik bo'lganda
  3. Faqat aynan 600px da
  4. Har doim

Mobile-first yondashuvida asosan qaysi shart ishlatiladi?

  1. min-width
  2. max-width
  3. orientation
  4. max-height

Avval telefon uchun yoziladi, keyin "kamida shuncha keng bo'lsa" deb katta ekranlar qo'shiladi.

🏠 Uyga vazifa
