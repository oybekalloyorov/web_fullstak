Internet qanday ishlaydi? DNS, hosting, domen

Mijoz-server arxitekturasi, IP-manzil, DNS, domen va hosting tushunchalari, veb-sayt internetda qanday "yashaydi", Front-end va Back-end farqi.

1 soat · nazariy

🎯 Bu darsda nimani o'rganasiz

  • Internet nima ekanini va ma'lumot unda qanday "sayohat" qilishini;
  • Mijoz (client) va server nima ekanini;
  • IP-manzil, domen, DNS va hosting tushunchalarini;
  • Brauzerga manzil yozganda nima sodir bo'lishini bosqichma-bosqich;
  • Front-end va Back-end dasturchilar nima bilan shug'ullanishini.

#Internet nima?

Internet — butun dunyodagi millionlab kompyuterlar, telefonlar va serverlarni bir-biriga bog'lagan ulkan tarmoq. Ular kabellar (dengiz tubidagi optik kabellar ham!), Wi-Fi, mobil aloqa minoralari va sun'iy yo'ldoshlar orqali ulangan.

O'xshatish: pochta xizmati Internetni butun dunyo bo'ylab ishlaydigan pochta deb tasavvur qiling. Siz xat (ma'lumot) yuborasiz, unga manzil (IP-manzil) yoziladi, pochta bo'limlari (routerlar) uni bir-biriga uzatib, kerakli uyga yetkazadi. Farqi — internet "xati" bir soniyadan ham kamroq vaqtda yetib boradi.

Internet va Web bir narsami?

Yo'q! Bu ko'p uchraydigan xato.

  • Internet — "yo'llar tizimi" (tarmoqning o'zi).
  • Web (World Wide Web, WWW) — shu yo'llarda ishlaydigan xizmatlardan biri: bir-biriga havolalar bilan bog'langan veb-sahifalar. Uni 1989-yilda olim Tim Berners-Li ixtiro qilgan.

Internetda boshqa xizmatlar ham bor: elektron pochta, Telegram'dagi xabarlar, onlayn o'yinlar, video qo'ng'iroqlar.

Ma'lumot qanday yuboriladi? Paketlar

Siz katta rasm yuborganingizda u bir butun holda emas, mayda bo'laklarga — paketlarga bo'linib ketadi. Har bir paketga qabul qiluvchining manzili yoziladi. Paketlar turli yo'llar bilan ketishi mumkin, manzilda esa yana to'g'ri tartibda yig'iladi.

O'xshatish: mebelni ko'chirish Katta shkafni bir mashinaga sig'dira olmasangiz, uni qismlarga ajratib, bir nechta mashinada jo'natasiz. Yangi uyda qismlar raqami bo'yicha qaytadan yig'iladi. Internet paketlari ham xuddi shunday.

#Mijoz va server

Web mijoz-server (client-server) arxitekturasi asosida ishlaydi:

  • Mijoz (client) — ma'lumot so'rovchi tomon. Ko'pincha bu sizning brauzeringiz (Chrome, Edge) yoki telefondagi ilova.
  • Server — so'rovni qabul qilib, javob beruvchi kuchli kompyuter. U kechayu kunduz yoqiq turadi va bir vaqtning o'zida minglab foydalanuvchiga xizmat qiladi.
🧑‍💻 Mijoz (brauzer)"Menga bosh sahifani ber"
— so'rov (request) →
🖥️ Serversahifani tayyorlaydi
— javob (response) →
🧑‍💻 Mijozsahifani ko'rsatadi
O'xshatish: oshxona Restoranda siz — mijoz, ofitsiantga buyurtma berasiz (so'rov). Oshxona — server: taomni tayyorlab, ofitsiant orqali qaytaradi (javob). Siz oshxonaga kirib ko'rmaysiz — faqat natijani olasiz. Veb-sayt ham xuddi shunday: siz serverni ko'rmaysiz, faqat u yuborgan sahifani ko'rasiz.

HTTP va HTTPS

Mijoz va server bir-biri bilan HTTP (HyperText Transfer Protocol) degan "til"da gaplashadi. Protokol — kelishilgan qoidalar to'plami.

  • http:// — ma'lumot ochiq holda uzatiladi. Yo'lda kimdir uni o'qishi mumkin.
  • https:// — S = Secure (xavfsiz). Ma'lumot shifrlanadi. Brauzerdagi 🔒 qulf belgisi shuni bildiradi.
Parol yoki karta raqamini faqat https:// bilan boshlanadigan saytlarga kiriting!

Server javobida uch xonali status kod bo'ladi. Eng mashhurlari:

#IP-manzil

Internetga ulangan har bir qurilmaning o'z IP-manzili bor — xuddi uyning pochta manzili kabi. U nuqtalar bilan ajratilgan to'rtta sondan iborat: 142.250.74.46. Har bir son 0 dan 255 gacha bo'ladi.

Lekin odamlar uchun bunday raqamlarni eslab qolish qiyin. Siz Google'ga kirish uchun 142.250.74.46 deb yozasizmi? Albatta yo'q — google.com deb yozasiz. Bu yerda domen va DNS yordamga keladi.

#Domen nomi

Domen — saytning odamlar uchun qulay, eslab qolinadigan nomi: kun.uz, google.com, wikipedia.org.

Matn
  https://  www  .  maktab  .  uz  /  sinflar/8-sinf
  └──┬──┘   └┬┘     └──┬─┘     └┬┘   └──────┬──────┘
 protokol subdomen  domen nomi  zona       yo'l (sahifa)
  • Yuqori darajali domen (zona): .uz (O'zbekiston), .com (tijorat), .org (tashkilotlar), .edu (ta'lim).
  • Domen nomi: siz tanlagan nom — maktab.
  • Subdomen: asosiy domen ichidagi bo'lim — www, mail, blog.

Domen registrator deb ataladigan kompaniyalardan odatda bir yilga ijaraga olinadi (sotib olinmaydi!) va har yili uzaytiriladi. .uz domenlari O'zbekistondagi registratorlar orqali ro'yxatdan o'tkaziladi.

#DNS — internetning telefon kitobi

DNS (Domain Name System) — domen nomini IP-manzilga "tarjima" qiluvchi tizim.

O'xshatish: telefondagi kontaktlar Do'stingizga qo'ng'iroq qilganda raqamini yodlab yozmaysiz — kontaktlardan "Aziz"ni tanlaysiz, telefon esa uning raqamini o'zi topadi. DNS ham shunday: siz kun.uz deysiz, DNS esa uning IP-manzilini topib beradi.

DNS qanday ishlaydi? (soddalashtirilgan)

  1. Siz brauzerga kun.uz deb yozasiz.
  2. Brauzer avval o'z xotirasini (keshini) tekshiradi: "Bu saytga yaqinda kirganmidim? IP-manzili esimdami?"
  3. Esida bo'lmasa, internet provayderingizning DNS serveridan so'raydi.
  4. DNS serveri kerak bo'lsa boshqa DNS serverlardan so'rab, javobni topadi: kun.uz → 185.xxx.xxx.xxx.
  5. Brauzer shu IP-manzil bo'yicha serverga ulanadi.

Bu jarayon odatda bir necha millisoniya davom etadi.

#Hosting

Hosting — saytingiz fayllari saqlanadigan va kechayu kunduz internetga ulangan turadigan serverdagi joy.

O'xshatish: uy va manzil Domen — uyingizning manzili (ko'cha va raqam). Hosting — uyning o'zi, ichida mebellar (fayllar) turadi. DNS esa manzil bo'yicha uyni topib beruvchi xarita. Manzil bor-u, uy bo'lmasa — mehmon hech narsa topmaydi.

#Brauzerga manzil yozganda nima bo'ladi?

Endi barcha tushunchalarni bitta zanjirga bog'laymiz. Siz https://maktab.uz deb yozib Enter bosdingiz:

  1. DNS maktab.uz ni IP-manzilga aylantiradi.
  2. Brauzer shu IP-manzildagi serverga ulanadi (HTTPS bo'lsa — xavfsiz, shifrlangan ulanish o'rnatiladi).
  3. Brauzer serverga HTTP so'rov yuboradi: "Bosh sahifani ber".
  4. Server (hosting) kerakli faylni topadi yoki tayyorlaydi va javob qaytaradi (status 200 + HTML kod).
  5. Brauzer HTML'ni o'qiydi va unda ko'rsatilgan CSS, rasmlar, JavaScript fayllari uchun qo'shimcha so'rovlar yuboradi.
  6. Brauzer hammasini birlashtirib, sahifani ekranga chizadi.

#Front-end va Back-end

Har bir veb-sayt ikki qismdan iborat:

Qayerda ishlaydiFoydalanuvchi brauzeridaServerda

O'xshatish: restoran Front-end — restoranning zali: chiroyli stollar, menyu, ofitsiant. Back-end — oshxona va ombor: oshpaz, retseptlar, mahsulotlar zaxirasi. Ma'lumotlar bazasi — ombor. Full-stack dasturchi — zalni ham, oshxonani ham yarata oladigan usta.

Masalan, siz Telegram'da xabar yozdingiz: matn kiritiladigan maydon va "Yuborish" tugmasi — front-end; xabarni qabul qilib, saqlab, do'stingizga yetkazish — back-end.

#Amaliy mashg'ulot

  1. Saytning IP-manzilini toping. Windows'da Win+R → cmd → Enter. Ochilgan oynaga yozing:
    Terminal
    nslookup google.com
nslookup kun.uz
    Natijadagi Address qatori — saytning IP-manzili. (macOS/Linux'da ham nslookup ishlaydi.)
  2. Serverga "ping" yuboring — server javob beradimi va qancha vaqtda:
    Terminal
    ping google.com
    time=25ms — paket serverga borib-kelishi uchun ketgan vaqt (millisoniya).
  3. Brauzer so'rovlarini kuzating. Chrome'da istalgan saytni oching, F12 bosing → Network yorlig'i → sahifani F5 bilan yangilang. Har bir qator — brauzerning serverga yuborgan alohida so'rovi. Status ustunida 200 larni toping. Birinchi qatorni bosib, Remote Address (server IP-manzili)ni ko'ring.
  4. 404 xatoni ko'ring. Istalgan saytda mavjud bo'lmagan sahifani oching, masalan https://github.com/bu-sahifa-yoq-12345. Network panelida status 404 ekanini tekshiring.
  5. Jadval to'ldiring. Daftaringizga 3 ta sevimli saytingiz uchun: domen nomi, zonasi (.uz/.com), IP-manzili, HTTPS bormi-yo'qmi va saytda nimalar front-end, nimalar back-end ekanini yozing.

#Ko'p uchraydigan xato tushunchalar

  • ❌ "Internet va Google bir narsa" → ✅ Google — internetdagi saytlardan (xizmatlardan) biri.
  • ❌ "Domen sotib olinsa, sayt tayyor bo'ladi" → ✅ Domen — faqat manzil. Saytning fayllari uchun hosting ham kerak.
  • ❌ "Brauzer = Internet" → ✅ Brauzer — internetdagi sahifalarni ochuvchi dastur (mijoz).
  • ❌ "HTTPS saytlar hammasi ishonchli" → ✅ HTTPS faqat ma'lumot yo'lda shifrlanishini kafolatlaydi; firibgar sayt ham HTTPS bo'lishi mumkin. Domen nomini diqqat bilan tekshiring!

#O'zingizni tekshiring

DNS'ning asosiy vazifasi nima?

  1. Saytni chiroyli qilish
  2. Domen nomini IP-manzilga aylantirish
  3. Fayllarni saqlash
  4. Viruslardan himoyalash

DNS — "telefon kitobi": kun.uz kabi nomlarni kompyuter tushunadigan IP-manzilga aylantiradi.

Saytning fayllari saqlanadigan, doim internetga ulangan server joyi nima deyiladi?

  1. Domen
  2. Brauzer
  3. Hosting
  4. Protokol

Hosting — "uy", domen — "manzil".

Quyidagilardan qaysi biri front-end'ga tegishli?

  1. Saytdagi "Ro'yxatdan o'tish" tugmasining rangi
  2. Parolni ma'lumotlar bazasida tekshirish
  3. Buyurtmani serverda saqlash
  4. Server IP-manzili

Foydalanuvchi ko'radigan hamma narsa — front-end. Qolganlari serverda bajariladi (back-end).

Server "404" status kodini qaytardi. Bu nimani bildiradi?

  1. Hammasi yaxshi
  2. Serverda dastur xatosi
  3. Sahifa boshqa manzilga ko'chgan
  4. So'ralgan sahifa topilmadi

404 — "Not Found". 200 — muvaffaqiyat, 500 — server xatosi, 301 — ko'chirilgan.

https://blog.maktab.uz/maqolalar manzilida subdomen qaysi?

  1. https
  2. blog
  3. uz
  4. maqolalar

blog — subdomen, maktab — domen nomi, uz — zona, /maqolalar — yo'l.

HTTPS'dagi "S" harfi nimani bildiradi?

  1. Speed — tezlik
  2. Server
  3. Secure — xavfsiz (shifrlangan)
  4. Simple — oddiy

HTTPS ma'lumotni shifrlab uzatadi — yo'lda uni hech kim o'qiy olmaydi.
