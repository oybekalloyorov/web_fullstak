#Django Admin — tayyor boshqaruv paneli

Har bir saytga "orqa eshik" kerak: maqolalarni qo'shish, tahrirlash, foydalanuvchilarni boshqarish. Boshqa frameworklarda buni haftalab yozish kerak — Django'da u tayyor. Bu Django'ning eng mashhur imkoniyatlaridan biri.

3. Admin'ni sozlash

blog/admin.py
from django.contrib import admin
from .models import Kategoriya, Maqola


@admin.register(Kategoriya)
class KategoriyaAdmin(admin.ModelAdmin):
    list_display = ["nomi", "slug"]
    prepopulated_fields = {"slug": ("nomi",)}         # nom yozilganda slug avtomatik to'ladi


@admin.register(Maqola)
class MaqolaAdmin(admin.ModelAdmin):
    list_display = ["sarlavha", "kategoriya", "muallif", "chop_etilgan", "korishlar", "yaratilgan"]
    list_filter = ["chop_etilgan", "kategoriya", "yaratilgan"]    # o'ng tomonda filtrlar
    search_fields = ["sarlavha", "matn"]                           # qidiruv maydoni
    list_editable = ["chop_etilgan"]                               # ro'yxatning o'zida tahrirlash
    list_per_page = 20
    date_hierarchy = "yaratilgan"                                  # sana bo'yicha navigatsiya
    readonly_fields = ["korishlar", "yaratilgan", "yangilangan"]
    actions = ["chop_etish"]

    @admin.action(description="Tanlanganlarni chop etish")
    def chop_etish(self, request, queryset):
        soni = queryset.update(chop_etilgan=True)
        self.message_user(request, f"{soni} ta maqola chop etildi")


admin.site.site_header = "Maktab blogi — boshqaruv paneli"

#Django Forms — nima uchun?

Admin panel — faqat ma'murlar uchun. Oddiy foydalanuvchilar (izoh qoldirish, ro'yxatdan o'tish, maqola yuborish) uchun sayt ichida formalar kerak. 3-mavzuda HTML formalarni yozdik va 20-mavzuda JavaScript bilan tekshirdik. Lekin brauzerdagi tekshiruvni chetlab o'tish oson — server ham tekshirishi shart.

Django Forms uchta ishni bajaradi:

  1. HTML yaratadi — input'lar, label'lar avtomatik;
  2. Tekshiradi (validatsiya) — majburiy maydonlar, email formati, uzunlik, o'z qoidalaringiz;
  3. Tozalaydi — matnni kerakli turga (son, sana) aylantiradi va xavfsiz qiladi.

#Oddiy Form: "Aloqa" formasi

blog/forms.py (yangi fayl)
from django import forms


class AloqaForm(forms.Form):
    ism = forms.CharField(label="Ismingiz", max_length=100)
    email = forms.EmailField(label="Email")
    mavzu = forms.ChoiceField(label="Mavzu", choices=[
        ("taklif", "Taklif"),
        ("xato", "Xato haqida xabar"),
        ("boshqa", "Boshqa"),
    ])
    xabar = forms.CharField(label="Xabar", widget=forms.Textarea(attrs={"rows": 5}), min_length=10)

    def clean_ism(self):                              # bitta maydon uchun o'z tekshiruvimiz
        ism = self.cleaned_data["ism"].strip()
        if any(belgi.isdigit() for belgi in ism):
            raise forms.ValidationError("Ismda raqam bo'lmasligi kerak")
        return ism.title()
blog/views.py
from django.contrib import messages
from django.shortcuts import render, redirect
from .forms import AloqaForm


def aloqa(request):
    if request.method == "POST":                      # forma yuborildi
        form = AloqaForm(request.POST)                # kelgan ma'lumot bilan to'ldiramiz
        if form.is_valid():                           # ✅ hamma tekshiruvdan o'tdi
            data = form.cleaned_data                  # tozalangan ma'lumot (dict)
            print("Yangi xabar:", data["ism"], data["email"], data["xabar"])
            messages.success(request, "Rahmat! Xabaringiz yuborildi.")
            return redirect("blog:aloqa")             # qayta yuborilmasligi uchun redirect
        # ❌ xato bo'lsa — forma xatolar bilan qayta ko'rsatiladi
    else:                                             # GET — sahifa birinchi marta ochildi
        form = AloqaForm()                            # bo'sh forma
    return render(request, "blog/aloqa.html", {"form": form})

CSRF nima? CSRF (Cross-Site Request Forgery) — yovuz sayt sizning brauzeringiz nomidan boshqa saytga yashirin forma yuboradigan hujum (masalan, siz tizimga kirgan blogga "barcha maqolalarni o'chir" so'rovi). {% csrf_token %} formaga yashirin maxfiy kod qo'shadi; Django POST so'rovni faqat shu kod to'g'ri bo'lsa qabul qiladi. Usiz: 403 Forbidden — CSRF verification failed.

#ModelForm — modeldan avtomatik forma

Agar forma modelga ma'lumot saqlasa, maydonlarni qayta yozish shart emas — ModelForm ularni modeldan o'zi oladi.

blog/forms.py
from .models import Maqola


class MaqolaForm(forms.ModelForm):
    class Meta:
        model = Maqola
        fields = ["sarlavha", "kategoriya", "matn"]          # foydalanuvchi to'ldiradigan maydonlar
        widgets = {
            "sarlavha": forms.TextInput(attrs={"placeholder": "Qiziqarli sarlavha..."}),
            "matn": forms.Textarea(attrs={"rows": 8}),
        }

    def clean_sarlavha(self):
        s = self.cleaned_data["sarlavha"]
        if len(s) < 5:
            raise forms.ValidationError("Sarlavha kamida 5 belgidan iborat bo'lsin")
        return s
blog/views.py
from django.contrib.auth.decorators import login_required
from .forms import MaqolaForm


@login_required                                       # faqat tizimga kirganlar uchun
def maqola_yozish(request):
    if request.method == "POST":
        form = MaqolaForm(request.POST)
        if form.is_valid():
            maqola = form.save(commit=False)          # hali bazaga yozmay turamiz
            maqola.muallif = request.user             # muallifni o'zimiz qo'yamiz
            maqola.chop_etilgan = False               # admin tasdiqlaguncha yashirin
            maqola.save()                             # endi saqlaymiz
            messages.success(request, "Maqola yuborildi! Admin tasdiqlagach chop etiladi.")
            return redirect("blog:bosh")
    else:
        form = MaqolaForm()
    return render(request, "blog/maqola_form.html", {"form": form})

commit=False — formadan obyekt yaratadi, lekin bazaga saqlamaydi: shunda formada bo'lmagan maydonlarni (muallif) qo'shib, keyin saqlash mumkin.

Ro'yxatdan o'tish

blog/views.py
from django.contrib.auth import login
from django.contrib.auth.forms import UserCreationForm


def royxatdan_otish(request):
    if request.method == "POST":
        form = UserCreationForm(request.POST)      # tayyor forma: username + parol + tasdiqlash
        if form.is_valid():
            user = form.save()                     # parol avtomatik xeshlanadi
            login(request, user)                   # darhol tizimga kiritamiz
            messages.success(request, f"Xush kelibsiz, {user.username}!")
            return redirect("blog:bosh")
    else:
        form = UserCreationForm()
    return render(request, "blog/royxat.html", {"form": form})

#Amaliy mashg'ulot

  1. Admin'ni sozlang (yuqoridagi KategoriyaAdmin, MaqolaAdmin) va admin orqali 5 ta maqola qo'shing. Filtr, qidiruv va ommaviy amalni sinang.
  2. "Aloqa" formasini yarating. Bo'sh, noto'g'ri email va raqamli ism bilan yuborib, xato xabarlarini ko'ring. {% csrf_token %} ni olib tashlab, 403 xatoni ko'ring — keyin qaytaring.
  3. Aloqa xabarlarini bazada saqlang: Xabar modeli (ism, email, mavzu, matn, sana) → ModelForm → admin'da ko'rinsin.
  4. Ro'yxatdan o'tish (24-loyiha) va kirish/chiqish (25-loyiha) tizimini qo'shing; menyuda foydalanuvchi holatiga qarab havolalar o'zgarsin.
  5. "Maqola yozish" sahifasini (@login_required) yarating. Tizimga kirmasdan /yozish/ ga kirib ko'ring — login sahifasiga yo'naltiradi.

#Ko'p uchraydigan xatolar

  • ❌ CSRF verification failed — formada {% csrf_token %} yo'q yoki method="post" yozilmagan.
  • ❌ Forma yuborilgach sahifa yangilansa, ma'lumot qayta yuboriladi — muvaffaqiyatli POST'dan keyin doim redirect.
  • ❌ form.cleaned_data ni is_valid() dan oldin ishlatish — AttributeError.
  • ❌ Admin'da model ko'rinmayapti — admin.py da ro'yxatdan o'tkazilmagan yoki server qayta ishga tushirilmagan.
  • ❌ ModelForm'da fields ko'rsatilmagan — Django xato beradi (xavfsizlik uchun barcha maydonlarni avtomatik ochmaydi).

🏠 Uyga vazifa

  1. Izohlar: Izoh modeli (maqola FK, muallif FK, matn, sana). Maqola sahifasida izohlar ro'yxati va faqat tizimga kirganlar uchun izoh formasi.

  • Admin: createsuperuser; @admin.register(Model) + ModelAdmin (list_display, list_filter, search_fields...).

  • ModelForm + save(commit=False); messages — foydalanuvchiga xabar.
  • Auth: include("django.contrib.auth.urls"), UserCreationForm, login(), @login_required, user.is_authenticated.
