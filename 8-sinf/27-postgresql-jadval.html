PostgreSQL bilan tanishish. Jadval yaratish va ma'lumot turlari

PostgreSQL va pgAdmin'ni o'rnatish, psql konsoli, ma'lumotlar bazasi yaratish, CREATE TABLE, asosiy ma'lumot turlari (INTEGER, NUMERIC, VARCHAR, TEXT, BOOLEAN, DATE, TIMESTAMP), SERIAL, ALTER TABLE va DROP TABLE.

#PostgreSQL nima?

PostgreSQL (qisqacha "Postgres", belgisi — fil 🐘) — dunyodagi eng ishonchli va kuchli bepul, ochiq kodli relyatsion DBMS. Uni Apple, Instagram, Spotify, Reddit kabi kompaniyalar ishlatadi. U 35 yildan ortiq rivojlanib kelmoqda.

PostgreSQL server sifatida ishlaydi: kompyuteringizda fonda yoqiq turadi va dasturlar (pgAdmin, Python, Django) unga ulanib, SQL so'rovlar yuboradi.

#O'rnatish

  1. postgresql.org/download → operatsion tizimingizni tanlang → Download the installer (EDB) → eng so'nggi versiya.
  2. O'rnatish oynasida barcha komponentlarni qoldiring: PostgreSQL Server, pgAdmin 4, Command Line Tools.
  3. Parol so'raladi — bu postgres (bosh administrator) foydalanuvchisi paroli. Uni yozib qo'ying! Unutsangiz, qayta o'rnatishga to'g'ri keladi.
  4. Port: 5432 (standart) — o'zgartirmang.
  5. O'rnatish tugagach, "Stack Builder" ni ishga tushirish shart emas.
O'rnatib bo'lmasa Maktab kompyuterida ruxsat bo'lmasa, brauzerda ishlaydigan bepul onlayn muharrirlardan foydalaning: db-fiddle.com (PostgreSQL'ni tanlang) yoki onecompiler.com/postgresql. Bu darsdagi barcha SQL'lar ularda ishlaydi.

#pgAdmin bilan ishlash

  1. pgAdmin 4 ni oching (birinchi marta pgAdmin uchun "master parol" so'rashi mumkin).
  2. Chap panelda Servers → PostgreSQL ni oching — o'rnatishdagi parolni kiriting.
  3. Databases ustida o'ng tugma → Create → Database... → nom: maktab → Save.
  4. maktab bazasini tanlang va yuqoridagi Query Tool (⚡ yoki SQL belgisi) tugmasini bosing — SQL yozish oynasi ochiladi.
  5. SQL yozib, F5 (yoki ▶ Execute) bilan bajaring. Natija pastki panelda ko'rinadi.

psql — buyruqlar qatori orqali

Terminal
psql -U postgres                 # ulanish (parol so'raladi)
SQL
CREATE DATABASE maktab;          -- baza yaratish
\l                               -- barcha bazalar ro'yxati
\c maktab                        -- maktab bazasiga o'tish
\dt                              -- jadvallar ro'yxati
\d oquvchilar                    -- jadval tuzilmasini ko'rish
\q                               -- chiqish
SQL yozish qoidalari
  • Har bir buyruq ; (nuqta-vergul) bilan tugaydi.
  • SQL kalit so'zlari katta-kichik harfni farqlamaydi (select = SELECT), lekin kalit so'zlarni KATTA, nomlarni kichik yozish odat.
  • Matnlar bitta qo'shtirnoqda: 'Ali'. O'zbekcha apostrof ikkilantiriladi: 'O''zbekiston'.
  • Izoh: -- bir qatorli yoki /* ko'p qatorli */.
  • Jadval va ustun nomlari: kichik lotin harflar va pastki chiziq — oquvchilar, tugilgan_sana.

#Ma'lumot turlari

Jadval yaratishda har bir ustunning turini ko'rsatish shart. To'g'ri tanlangan tur xatolarning oldini oladi va joyni tejaydi.

TurNima uchunMisol qiymat

SMALLINTKichik butun son (±32 767)baho: 5
BIGINTJuda katta butun sontelefon raqami yoki katta id

REAL, DOUBLE PRECISIONTaqribiy kasr son (ilmiy hisoblar)3.14159

Turni tanlashdagi muhim qoidalar
  • Pul uchun REAL emas, NUMERIC — kasr sonlar kompyuterda aniq saqlanmaydi (0.1 + 0.2 ≠ 0.3!).
  • Telefon raqami uchun INTEGER emas, VARCHAR(20) — unda + belgisi va boshidagi 0 bo'lishi mumkin, u bilan hisob-kitob qilinmaydi.
  • Sanani matn sifatida saqlamang — DATE bilan sanalarni solishtirish va hisoblash mumkin.

#Jadval yaratish: CREATE TABLE

SQL
CREATE TABLE sinflar (
    id            SERIAL PRIMARY KEY,
    nomi          VARCHAR(10) NOT NULL UNIQUE,
    sinf_rahbari  VARCHAR(100),
    xona          SMALLINT
);

CREATE TABLE oquvchilar (
    id             SERIAL PRIMARY KEY,                 -- avtomatik id, birlamchi kalit
    ism            VARCHAR(50) NOT NULL,               -- bo'sh bo'lishi mumkin emas
    familiya       VARCHAR(50) NOT NULL,
    tugilgan_sana  DATE,
    telefon        VARCHAR(20),
    email          VARCHAR(100) UNIQUE,                -- takrorlanmasin
    alochi         BOOLEAN DEFAULT FALSE,              -- standart qiymat
    sinf_id        INTEGER REFERENCES sinflar(id),     -- tashqi kalit!
    yaratilgan     TIMESTAMP DEFAULT NOW()             -- qo'shilgan vaqt avtomatik
);

Cheklovlar (constraints)

CheklovMa'nosi
PRIMARY KEYBirlamchi kalit: noyob va bo'sh emas
NOT NULLMajburiy maydon — bo'sh qoldirib bo'lmaydi
UNIQUETakrorlanmas qiymat (ikki o'quvchida bir xil email bo'lmaydi)
DEFAULT qiymatQiymat berilmasa — shu qo'yiladi
CHECK (shart)Qiymat shartga mos bo'lishi kerak: CHECK (baho BETWEEN 2 AND 5)
REFERENCES jadval(ustun)Tashqi kalit — boshqa jadvalga bog'lanish
SQL
CREATE TABLE baholar (
    id          SERIAL PRIMARY KEY,
    oquvchi_id  INTEGER NOT NULL REFERENCES oquvchilar(id) ON DELETE CASCADE,
    fan         VARCHAR(50) NOT NULL,
    baho        SMALLINT NOT NULL CHECK (baho BETWEEN 2 AND 5),
    sana        DATE NOT NULL DEFAULT CURRENT_DATE
);

ON DELETE CASCADE — o'quvchi o'chirilsa, uning barcha baholari ham avtomatik o'chadi (yetim baholar qolmaydi).

Jadvallar tartib bilan yaratiladi: avval bog'lanish ko'rsatiladigan (sinflar), keyin unga ishora qiluvchi (oquvchilar), keyin baholar. Aks holda "relation does not exist" xatosi chiqadi.

#Jadvalni o'zgartirish va o'chirish

SQL
-- Yangi ustun qo'shish
ALTER TABLE oquvchilar ADD COLUMN manzil TEXT;

-- Ustun nomini o'zgartirish
ALTER TABLE oquvchilar RENAME COLUMN manzil TO yashash_joyi;

-- Ustun turini o'zgartirish
ALTER TABLE oquvchilar ALTER COLUMN telefon TYPE VARCHAR(30);

-- Ustunni o'chirish
ALTER TABLE oquvchilar DROP COLUMN yashash_joyi;

-- Jadval nomini o'zgartirish (umumiy ko'rinishi)
-- ALTER TABLE eski_nom RENAME TO yangi_nom;

-- Jadvalni BUTUNLAY o'chirish (ehtiyot bo'ling — qaytarib bo'lmaydi!)
DROP TABLE IF EXISTS vaqtinchalik;
DROP TABLE va DROP DATABASE jadval/bazani barcha ma'lumotlari bilan birga o'chiradi. "Ctrl+Z" yo'q! Bajarishdan oldin ikki marta o'ylang (va zaxira nusxangiz borligiga ishonch hosil qiling — 29-mavzu).

#Amaliy mashg'ulot

  1. PostgreSQL va pgAdmin'ni o'rnating (yoki db-fiddle.com'ni oching).
  2. maktab bazasini yarating.
  3. Yuqoridagi sinflar, oquvchilar, baholar jadvallarini yarating. pgAdmin'da Schemas → public → Tables ni yangilab (F5), jadvallarni ko'ring.
  4. oquvchilar jadvali ustida o'ng tugma → Properties → Columns: ustunlar va turlarini tekshiring.
  5. Mustaqil: togaraklar (id, nomi, rahbar, joylar_soni — musbat bo'lsin) va ko'pga-ko'p uchun azoliklar (oquvchi_id, togarak_id, qoshilgan_sana) jadvallarini yarating. azoliklar da bitta o'quvchi bir to'garakka ikki marta yozilmasligi uchun PRIMARY KEY (oquvchi_id, togarak_id) qo'llang.
  6. oquvchilar jadvaliga jinsi ustunini qo'shing: faqat 'o'g'il' yoki 'qiz' bo'lishi mumkin (CHECK ... IN (...)).
5 va 6-topshiriqlar javobi
SQL
CREATE TABLE togaraklar (
    id           SERIAL PRIMARY KEY,
    nomi         VARCHAR(100) NOT NULL UNIQUE,
    rahbar       VARCHAR(100),
    joylar_soni  INTEGER CHECK (joylar_soni > 0)
);

CREATE TABLE azoliklar (
    oquvchi_id      INTEGER REFERENCES oquvchilar(id) ON DELETE CASCADE,
    togarak_id      INTEGER REFERENCES togaraklar(id) ON DELETE CASCADE,
    qoshilgan_sana  DATE DEFAULT CURRENT_DATE,
    PRIMARY KEY (oquvchi_id, togarak_id)
);

ALTER TABLE oquvchilar ADD COLUMN jinsi VARCHAR(10) CHECK (jinsi IN ('o''g''il', 'qiz'));

#Ko'p uchraydigan xatolar

  • ❌ relation "oquvchilar" does not exist — jadval yaratilmagan yoki boshqa bazaga ulangansiz.
  • ❌ syntax error at or near ")" — oxirgi ustundan keyin ortiqcha vergul qoldirilgan.
  • ❌ Matnni qo'sh qo'shtirnoqda yozish: "Ali" — SQL'da qo'sh qo'shtirnoq ustun nomlari uchun; matn — 'Ali'.
  • ❌ password authentication failed — o'rnatishdagi parol noto'g'ri kiritilgan.

#O'zingizni tekshiring

Pul summasini saqlash uchun eng to'g'ri tur?

  1. REAL
  2. VARCHAR
  3. NUMERIC(12, 2)
  4. BOOLEAN

Avtomatik 1, 2, 3... deb o'suvchi id ustuni uchun tur?

  1. SERIAL
  2. AUTO
  3. COUNTER
  4. TEXT

Ustunni majburiy (bo'sh bo'lmaydigan) qiluvchi cheklov?

  1. UNIQUE
  2. DEFAULT
  3. CHECK
  4. NOT NULL

Mavjud jadvalga yangi ustun qo'shuvchi buyruq?

  1. UPDATE TABLE ... ADD
  2. ALTER TABLE ... ADD COLUMN
  3. INSERT COLUMN
  4. CREATE COLUMN

Telefon raqami (+998901234567) uchun eng mos tur?

  1. INTEGER
  2. NUMERIC
  3. VARCHAR(20)
  4. DATE

SQL'da matn qiymati qanday yoziladi?

  1. 'Ali'
  2. "Ali"
  3. `Ali`
  4. Ali
