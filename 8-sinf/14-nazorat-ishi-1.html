#2-qism: Ochiq savollar va amaliy topshiriqlar (5 × 5 = 25 ball)

1-topshiriq (5 ball). Nazariy savol

Brauzerga https://maktab.uz deb yozilganda sahifa ekranda paydo bo'lgunicha qanday bosqichlar bo'lishini ketma-ket tushuntiring. Javobda DNS, server, so'rov, javob tushunchalari bo'lsin.

Namuna javob va baholash

(1) DNS maktab.uz ni IP-manzilga aylantiradi; (2) brauzer shu IP'dagi serverga xavfsiz (HTTPS) ulanadi; (3) brauzer HTTP so'rov yuboradi; (4) server (hosting) sahifani topib, status 200 va HTML bilan javob qaytaradi; (5) brauzer HTML'ni o'qiydi, CSS, rasm va JS fayllarni qo'shimcha so'raydi; (6) hammasini birlashtirib, sahifani chizadi.

Baholash: 5 — barcha bosqichlar to'g'ri tartibda; 3–4 — 1–2 bosqich tushib qolgan; 1–2 — faqat umumiy tasavvur; 0 — javob yo'q yoki noto'g'ri.

2-topshiriq (5 ball). Kodni tuzating

Quyidagi kodda 5 ta xato bor. Ularni toping va to'g'rilangan kodni yozing.

HTML
<!DOCTYPE html>
<html lang="uz">
<head>
  <title>Kutubxona<title>
</head>
<body>
  <h1>Kitoblarimiz</h1>
  <img src="rasmlar/kitob.jpg">
  <ul>
    <li>O'tkan kunlar</li>
    <li>Mehrobdan chayon
  </ul>
  <a href="www.kitob.uz">Kitob do'koni</a>
  <p>Telefon: <strong>+998 90 123 45 67</p></strong>
</body>
</html>
Javob
  1. <title> yopilmagan: </title> bo'lishi kerak.
  2. <img> da alt atributi yo'q: alt="Kitob muqovasi".
  3. Ikkinchi <li> yopilmagan.
  4. Tashqi havolada protokol yo'q: href="https://www.kitob.uz".
  5. Teglar noto'g'ri yopilgan: <strong>...</strong></p>.

Qo'shimcha: <meta charset="UTF-8"> va viewport meta-tegi ham yo'q (topgan o'quvchiga rag'bat).

Baholash: har bir topilgan va to'g'ri tuzatilgan xato — 1 ball.

3-topshiriq (5 ball). Forma yarating

"Olimpiadaga ro'yxatdan o'tish" formasini yozing: to'liq ism (majburiy), sinf (select: 7, 8, 9), fan (radio: matematika, informatika, fizika), email (majburiy), izoh (textarea) va "Yuborish" tugmasi. Har bir maydonda label bo'lsin.

Namuna javob
HTML
<form action="/olimpiada" method="POST">
  <p><label for="ism">To'liq ism</label><br>
     <input type="text" id="ism" name="ism" required></p>
  <p><label for="sinf">Sinf</label><br>
     <select id="sinf" name="sinf"><option>7</option><option>8</option><option>9</option></select></p>
  <p>Fan:<br>
     <label><input type="radio" name="fan" value="matematika" required> Matematika</label>
     <label><input type="radio" name="fan" value="informatika"> Informatika</label>
     <label><input type="radio" name="fan" value="fizika"> Fizika</label></p>
  <p><label for="email">Email</label><br>
     <input type="email" id="email" name="email" required></p>
  <p><label for="izoh">Izoh</label><br>
     <textarea id="izoh" name="izoh" rows="3"></textarea></p>
  <button type="submit">Yuborish</button>
</form>

Baholash: forma va method — 1; barcha maydonlar to'g'ri turda — 2; label va name'lar — 1; required va radio'larda bir xil name — 1.

4-topshiriq (5 ball). Flexbox maket

Header yarating: chapda logotip, o'ngda 3 ta havoladan iborat menyu, vertikal markazda. Menyu havolalariga sichqoncha borganda rang silliq o'zgarsin.

Namuna javob
HTML
<style>
  .header { display: flex; justify-content: space-between; align-items: center; padding: 16px 32px; background: #1e1b4b; }
  .logo { color: white; font-weight: bold; font-size: 1.4rem; }
  .menyu { display: flex; gap: 24px; }
  .menyu a { color: #c7d2fe; text-decoration: none; transition: color .3s; }
  .menyu a:hover { color: #fbbf24; }
</style>
<header class="header">
  <div class="logo">Kutubxona</div>
  <nav class="menyu"><a href="#">Bosh sahifa</a><a href="#">Kitoblar</a><a href="#">Aloqa</a></nav>
</header>

Baholash: semantik teglar — 1; display:flex + space-between — 1; align-items: center — 1; menyu ichida flex/gap — 1; transition + :hover — 1.

5-topshiriq (5 ball). Responsiv kartalar

3 ta mahsulot kartasidan iborat bo'lim yarating: kompyuterda 3 ustun, 768px va undan kichik ekranda 1 ustun. Kartalarda rasm, nom, narx, yumaloq burchak va soya bo'lsin.

Namuna javob
HTML
<style>
  * { box-sizing: border-box; }
  .kartalar { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; padding: 20px; }
  .karta { border-radius: 14px; box-shadow: 0 6px 18px rgba(0,0,0,.1); overflow: hidden; font-family: sans-serif; }
  .karta img { width: 100%; height: 150px; object-fit: cover; display: block; }
  .karta h3, .karta p { margin: 10px 14px; }
  .narx { color: #4f46e5; font-weight: bold; }
  @media (max-width: 768px) {
    .kartalar { grid-template-columns: 1fr; }
  }
</style>
<section class="kartalar">
  <article class="karta"><img src="https://picsum.photos/seed/k1/400/300" alt="Daftar"><h3>Daftar</h3><p class="narx">5 000 so'm</p></article>
  <article class="karta"><img src="https://picsum.photos/seed/k2/400/300" alt="Ruchka"><h3>Ruchka</h3><p class="narx">3 000 so'm</p></article>
  <article class="karta"><img src="https://picsum.photos/seed/k3/400/300" alt="Sumka"><h3>Sumka</h3><p class="narx">150 000 so'm</p></article>
</section>

Baholash: Grid 3 ustun — 1; media query to'g'ri — 2; karta dizayni (radius, soya) — 1; rasm alt va o'lchami to'g'ri — 1.
