Django Models va ORM texnologiyasi. Model yaratish va migratsiyalar

Model — jadvalning Python klassi, maydon turlari, ForeignKey bog'lanishlari, __str__ va Meta; makemigrations va migrate; ORM bilan CRUD: create, all, filter, get, order_by, update, delete; get_object_or_404; view'larni bazaga ulash.

2 soat · amaliy

🎯 Bu darsda nimani o'rganasiz

  • Model — ma'lumotlar bazasi jadvalini Python klassi sifatida yozishni;
  • Maydon turlari va jadvallar o'rtasidagi bog'lanishlarni (ForeignKey);
  • Migratsiya — modelni haqiqiy jadvalga aylantirish jarayonini;
  • ORM yordamida SQL yozmasdan ma'lumot qo'shish, o'qish, filtrlash, o'zgartirish va o'chirishni;
  • Blog sahifalarini haqiqiy PostgreSQL bazasiga ulashni.

#ORM nima?

III bobda SQL yozdik, 32-mavzuda esa uni Python ichida satr sifatida yubordik. Django'da yanada qulay yo'l bor — ORM (Object-Relational Mapping): jadvallar — klasslar, qatorlar — obyektlar, SQL o'rniga — Python kodi.

O'xshatish: tarjimon Siz o'zbekcha (Python) gapirasiz, baza esa faqat inglizcha (SQL) tushunadi. ORM — tarjimon: sizning Maqola.objects.filter(...) gapingizni to'g'ri va xavfsiz SQL'ga o'giradi. #Model yaratish

blog/models.py
from django.db import models
from django.contrib.auth.models import User
from django.urls import reverse


class Kategoriya(models.Model):
    nomi = models.CharField("Nomi", max_length=100, unique=True)
    slug = models.SlugField(unique=True)

    class Meta:
        verbose_name = "Kategoriya"
        verbose_name_plural = "Kategoriyalar"
        ordering = ["nomi"]

    def __str__(self):
        return self.nomi


class Maqola(models.Model):
    sarlavha = models.CharField("Sarlavha", max_length=200)
    matn = models.TextField("Matn")
    kategoriya = models.ForeignKey(
        Kategoriya,
        on_delete=models.PROTECT,          # kategoriyada maqola bo'lsa — o'chirib bo'lmaydi
        related_name="maqolalar",
    )
    muallif = models.ForeignKey(User, on_delete=models.CASCADE, related_name="maqolalar")
    chop_etilgan = models.BooleanField("Chop etilgan", default=True)
    korishlar = models.PositiveIntegerField(default=0)
    yaratilgan = models.DateTimeField(auto_now_add=True)    # yaratilganda avtomatik
    yangilangan = models.DateTimeField(auto_now=True)       # har saqlanganda avtomatik

    class Meta:
        verbose_name = "Maqola"
        verbose_name_plural = "Maqolalar"
        ordering = ["-yaratilgan"]                          # yangilari birinchi

    def __str__(self):
        return self.sarlavha

    def get_absolute_url(self):
        return reverse("blog:maqola", args=[self.id])

Har bir model — models.Model dan meros olgan klass (25-mavzu!). Har bir atribut — jadval ustuni. id ustunini yozmaymiz — Django uni avtomatik qo'shadi.

O'xshatish: qurilish chizmasi models.py — uyning yangi loyihasi. makemigrations — quruvchilar uchun "nimani o'zgartirish kerak" degan ish rejasini yozish ("2-qavatga xona qo'shilsin"). migrate — rejani haqiqatda bajarish. Migratsiya fayllari — barcha o'zgarishlar tarixi (Git kabi!).

pgAdmin'da blog_kategoriya va blog_maqola jadvallarini toping (nom: ilova_model). blog_maqola da kategoriya_id va muallif_id FK ustunlariga e'tibor bering. Django qanday SQL yozganini ko'rish: python manage.py sqlmigrate blog 0001.

Qoida models.py ni har o'zgartirganingizda (maydon qo'shish, nomini o'zgartirish) — makemigrations va migrate. Migratsiya fayllarini qo'lda tahrirlamang va Git'ga commit qiling.

#View'larni bazaga ulash

Endi 34–35-mavzulardagi MAQOLALAR ro'yxatini o'chirib, haqiqiy modeldan foydalanamiz:

blog/views.py
from django.shortcuts import render, get_object_or_404
from django.db.models import Q, F
from .models import Maqola, Kategoriya


def bosh_sahifa(request):
    maqolalar = Maqola.objects.filter(chop_etilgan=True).select_related("kategoriya", "muallif")
    return render(request, "blog/bosh_sahifa.html", {"maqolalar": maqolalar})


def maqola(request, id):
    m = get_object_or_404(Maqola, id=id, chop_etilgan=True)    # topilmasa — avtomatik 404
    Maqola.objects.filter(id=m.id).update(korishlar=F("korishlar") + 1)   # ko'rishlar +1
    return render(request, "blog/maqola.html", {"maqola": m})


def kategoriya(request, nomi):
    kat = get_object_or_404(Kategoriya, slug=nomi)
    return render(request, "blog/kategoriya.html", {
        "kategoriya": kat,
        "maqolalar": kat.maqolalar.filter(chop_etilgan=True),
    })


def qidiruv(request):
    q = request.GET.get("q", "").strip()
    natija = Maqola.objects.none()
    if q:
        natija = Maqola.objects.filter(
            Q(sarlavha__icontains=q) | Q(matn__icontains=q),    # Q — YOKI shart
            chop_etilgan=True,
        )
    return render(request, "blog/qidiruv.html", {"q": q, "maqolalar": natija})

#Ko'p uchraydigan xatolar

  • ❌ no such table / relation "blog_maqola" does not exist — migrate bajarilmagan.
  • ❌ No changes detected — ilova INSTALLED_APPS da yo'q yoki fayl saqlanmagan.
  • ❌ Maqola matching query does not exist — get() hech narsa topmadi; view'larda get_object_or_404 ishlating.
  • ❌ get() returned more than one — get faqat bitta natija uchun; ko'p bo'lsa filter.
  • ❌ Yangi majburiy maydon qo'shganda migratsiya standart qiymat so'raydi — default=... yoki null=True bering.
