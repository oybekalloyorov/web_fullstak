06-mavzu · 31 tadan · I bob. HTML va CSS

CSS ulash usullari, selektorlar va sintaksis. Matn va shriftlar

CSS nima, Inline, Internal va External usullar, qoida sintaksisi, teg/class/id va boshqa selektorlar, kaskad va ustuvorlik, ranglar, matn va shrift xossalari, Google Fonts.

2 soat · 1 nazariy + 1 amaliy

🎯 Bu darsda nimani o'rganasiz

  • CSS nima va u HTML bilan qanday ishlashini;
  • CSS'ni sahifaga ulashning 3 usulini va qaysi biri eng to'g'ri ekanini;
  • CSS qoidasining tuzilishi va asosiy selektorlarni;
  • Bir elementga bir nechta qoida to'g'ri kelsa, qaysi biri "g'olib" bo'lishini;
  • Ranglar, matn va shriftlar bilan ishlashni.

#CSS nima?

CSS (Cascading Style Sheets) — "kaskadli uslublar jadvali". HTML sahifaning tuzilishini yaratsa, CSS uning ko'rinishini belgilaydi: ranglar, shriftlar, o'lchamlar, joylashuv, animatsiyalar.

O'xshatish HTML — odamning skeleti va tanasi. CSS — kiyimi, soch turmagi, rangi. Bir odam turli kiyimda butunlay boshqacha ko'rinadi — xuddi shunday, bitta HTML sahifa turli CSS bilan butunlay boshqacha ko'rinadi. Buni CSS Zen Garden saytida o'zingiz ko'ring: HTML bir xil, faqat CSS fayl almashadi!

#CSS qoidasining tuzilishi

CSS
h1 {
  color: blue;
  font-size: 32px;
}
/*
 h1             — selektor: QAYSI elementlarga
 { ... }        — deklaratsiyalar bloki
 color          — xossa (property): NIMANI o'zgartiramiz
 blue           — qiymat (value): QANDAY qilib
 color: blue;   — bitta deklaratsiya. Oxirida nuqta-vergul (;) majburiy!
*/
CSS'da izohlar /* ... */ ko'rinishida yoziladi (HTML'dagi <!-- --> emas).

#CSS'ni ulashning 3 usuli

1. Inline — teg ichida

HTML
<p style="color: red; font-size: 20px;">Bu paragraf qizil va katta.</p>

Faqat bitta elementga ta'sir qiladi. Tez sinab ko'rish uchun qulay, lakin 100 ta paragrafni qizil qilish uchun 100 marta yozish kerak — noqulay.

2. Internal — <style> tegi ichida

HTML
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="UTF-8">
  <title>Internal CSS</title>
  <style>
    p {
      color: green;
    }
  </style>
</head>
<body>
  <p>Birinchi paragraf yashil.</p>
  <p>Ikkinchisi ham yashil!</p>
</body>
</html>

Butun bitta sahifaga ta'sir qiladi. Lekin saytda 10 ta sahifa bo'lsa, har biriga nusxalash kerak.

3. External — alohida .css fayl ✅

index.html
<head>
  <meta charset="UTF-8">
  <title>External CSS</title>
  <link rel="stylesheet" href="style.css">
</head>
style.css
p {
  color: purple;
}

Eng to'g'ri usul. Bitta style.css fayli barcha sahifalarga ulanadi. Dizaynni o'zgartirish uchun bitta faylni tahrirlash kifoya. Brauzer faylni bir marta yuklab, xotirada saqlaydi — sayt tezroq ishlaydi.

#Selektorlar — "kimga?" savoliga javob

Asosiy selektorlar

HTML
<style>
  /* 1. Teg selektori — BARCHA <p> lar */
  p { color: #333; }

  /* 2. Class selektori — class="muhim" bo'lgan BARCHA elementlar (nuqta bilan) */
  .muhim { color: crimson; font-weight: bold; }

  /* 3. ID selektori — id="sarlavha" bo'lgan BITTA element (panjara bilan) */
  #sarlavha { color: navy; text-decoration: underline; }

  /* 4. Universal selektor — sahifadagi HAMMA narsa */
  * { font-family: Arial, sans-serif; }

  /* 5. Guruh selektori — bir nechtasiga birdan (vergul bilan) */
  h2, h3 { color: teal; }
</style>

<h1 id="sarlavha">Maktab gazetasi</h1>
<h2>Yangiliklar</h2>
<p>Oddiy paragraf.</p>
<p class="muhim">Muhim e'lon: ertaga dars yo'q!</p>
<h3>Sport</h3>
<p>Yana oddiy paragraf, lekin <span class="muhim">bu so'z muhim</span>.</p>

class yoki id? Dizayn uchun deyarli doim class ishlating. Bitta elementga bir nechta class berish mumkin: class="tugma katta qizil". id esa sahifada takrorlanmaydi va asosan havolalar (#bo'lim) va JavaScript uchun kerak.

Kombinatsiyalangan selektorlar

HTML
<style>
  /* Avlod: <nav> ichidagi BARCHA <a> lar (istalgan chuqurlikda) — bo'sh joy bilan */
  nav a { color: white; background: #4f46e5; padding: 4px 10px; text-decoration: none; }

  /* Bevosita farzand: faqat birinchi darajadagi <li> — ">" bilan */
  .menyu > li { font-weight: bold; }

  /* Teg + class: faqat class="eslatma" bo'lgan <p> lar */
  p.eslatma { background: lightyellow; }

  /* Atribut bo'yicha */
  input[type="email"] { border: 2px solid green; }
</style>

  </li>

<div class="eslatma">Bu div — sariq bo'lmaydi</div>

#Kaskad: qaysi qoida g'olib?

Bir elementga bir nechta qoida to'g'ri kelsa, brauzer quyidagi tartibda hal qiladi:

  1. Aniqlik (spetsifiklik) — aniqroq selektor yutadi: inline > id > class > teg.
  2. Tartib — aniqlik teng bo'lsa, keyinroq yozilgan qoida yutadi.
HTML
<style>
  p { color: blue; }          /* teg — eng kuchsiz */
  .matn { color: green; }     /* class — kuchliroq */
  #asosiy { color: orange; }  /* id — yanada kuchliroq */
  p { color: red; }           /* teg, keyinroq yozilgan — lekin class va id dan baribir kuchsiz */
</style>

<p>Men qizilman (ikkala teg qoidasidan keyingisi yutdi)</p>
<p class="matn">Men yashilman (class tegdan kuchli)</p>
<p class="matn" id="asosiy">Men to'q sariqman (id class'dan kuchli)</p>
<p class="matn" id="asosiy" style="color: purple">Men binafshaman (inline eng kuchli)</p>
O'xshatish: ko'rsatmalar Direktor (inline) "Ali, sen bugun navbatchisan" desa, bu sinf rahbari (id) yoki sinf sardori (class) aytganidan ustun. Umumiy maktab qoidasi (teg) esa eng kuchsiz — maxsus ko'rsatma bo'lmagandagina amal qiladi.

Meros (inheritance)

Ba'zi xossalar (asosan matnga oid: color, font-family, font-size) ota elementdan ichidagi elementlarga meros bo'lib o'tadi. Shuning uchun shriftni bir marta body ga berish kifoya — butun sahifaga tarqaladi.

#Ranglar

HTML
<style>
  .r1 { color: tomato; }                 /* nom bilan (140+ ta tayyor nom) */
  .r2 { color: #4f46e5; }                /* HEX: #RRGGBB (qizil, yashil, ko'k) */
  .r3 { color: #f00; }                   /* qisqa HEX = #ff0000 */
  .r4 { color: rgb(16, 185, 129); }      /* RGB: har biri 0–255 */
  .r5 { color: rgba(0, 0, 0, 0.4); }     /* RGBA: 4-son — shaffoflik 0..1 */
  .r6 { color: hsl(280, 70%, 50%); }     /* HSL: rang tusi, to'yinganlik, yorqinlik */
  .fon { background-color: #fef3c7; color: #92400e; padding: 8px; }
</style>
<p class="r1">tomato</p>
<p class="r2">#4f46e5</p>
<p class="r3">#f00</p>
<p class="r4">rgb(16, 185, 129)</p>
<p class="r5">rgba — yarim shaffof</p>
<p class="r6">hsl(280, 70%, 50%)</p>
<p class="fon">Fon rangi va matn rangi</p>

HEX kodda har bir juft — 16 lik sanoq sistemasidagi son (00–ff): #ff0000 — to'liq qizil, #000000 — qora, #ffffff — oq. Ranglarni tanlash uchun VS Code'da rang ustiga sichqonchani olib boring yoki coolors.co saytidan tayyor palitralardan foydalaning.

Matn va fon o'rtasida yetarli kontrast bo'lsin: och kulrang fonda och sariq matnni hech kim o'qiy olmaydi.

#Matn xossalari

HTML
<style>
  .demo p { border-bottom: 1px dashed #ccc; padding: 4px; }
  .a { text-align: center; }                  /* left | right | center | justify */
  .b { text-decoration: underline; }          /* none | underline | line-through */
  .c { text-transform: uppercase; }           /* uppercase | lowercase | capitalize */
  .d { letter-spacing: 4px; }                 /* harflar orasidagi masofa */
  .e { word-spacing: 15px; }                  /* so'zlar orasidagi masofa */
  .f { line-height: 2; }                      /* qatorlar orasidagi masofa (shrift o'lchamiga nisbatan) */
  .g { text-indent: 40px; }                   /* xatboshi */
  .h { text-shadow: 2px 2px 4px rgba(0,0,0,.4); }  /* soya: o'ngga, pastga, xiralik, rang */
  a.i { text-decoration: none; }              /* havola tagidagi chiziqni olib tashlash */
</style>
<div class="demo">
  <p class="a">Markazga tekislangan matn</p>
  <p class="b">Tagi chizilgan matn</p>

  <p class="g">Xatboshi bilan boshlangan abzats. Kitoblardagi kabi birinchi qator ichkariga surilgan.</p>
  <p class="h">Soyali matn</p>
  <p><a class="i" href="#">Tagida chizig'i yo'q havola</a></p>
</div>

#Shriftlar

CSS
body {
  font-family: "Segoe UI", Arial, sans-serif;  /* birinchisi bo'lmasa — keyingisi (zaxira) */
  font-size: 16px;                             /* shrift o'lchami */
  font-weight: 400;                            /* qalinlik: 100..900 (400 = normal, 700 = bold) */
  font-style: normal;                          /* normal | italic */
  line-height: 1.6;                            /* o'qish uchun qulay qator oralig'i */
}
h1 {
  font-family: Georgia, "Times New Roman", serif;
  font-weight: 700;
}

Shrift oilalari:

  • serif — harflarida "oyoqchalari" bor (Times New Roman, Georgia). Kitob uslubi.
  • sans-serif — oyoqchasiz, zamonaviy (Arial, Roboto). Ekranda o'qish uchun qulay.
  • monospace — har bir harf bir xil kenglikda (Courier). Dastur kodi uchun.

Ro'yxat oxiriga doim umumiy oilani (sans-serif) yozing — agar foydalanuvchi kompyuterida birorta shrift bo'lmasa, brauzer shu oiladan biror shriftni tanlaydi.

Google Fonts — bepul chiroyli shriftlar

  1. fonts.google.com saytiga kiring va shrift tanlang (masalan, Montserrat). O'zbekcha harflar uchun Latin Extendedni qo'llab-quvvatlaydiganini tanlang.
  2. "Get font" → "Get embed code" bosing va <link> kodini nusxalang.
  3. Uni HTML'ning <head> qismiga, o'z CSS faylingizdan oldin qo'ying:
    HTML
    <link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="style.css">
  4. CSS'da ishlating: body { font-family: "Montserrat", sans-serif; }

O'lcham birliklari (qisqacha)

  • px — piksel, aniq o'lcham.
  • em — ota element shrift o'lchamiga nisbatan (2em = 2 barobar).
  • rem — sahifaning asosiy shrifti (odatda 16px) ga nisbatan: 1.5rem = 24px. Shriftlar uchun tavsiya etiladi.
  • % — ota elementga nisbatan foiz.

Batafsil 8-mavzuda.

#Ko'p uchraydigan xatolar

  • ❌ Nuqta-vergulni unutish: color: red font-size: 20px; — ikkala xossa ham ishlamaydi.
  • ❌ Class selektorida nuqtani unutish: muhim { } o'rniga .muhim { }.
  • ❌ HTML'da class=".muhim" deb yozish — HTML'da nuqtasiz: class="muhim".
  • ❌ CSS fayl yo'li noto'g'ri — F12 → Console'da "404 style.css" xatosini ko'rasiz.
  • ❌ Xossa nomida xato: colour, font-colour, text-color — to'g'risi color.

#O'zingizni tekshiring

Butun saytga bitta dizayn berishning eng to'g'ri usuli qaysi?

  1. Inline CSS
  2. Internal CSS
  3. External CSS (alohida .css fayl)
  4. Har sahifaga <style>

Bitta fayl — barcha sahifalar. O'zgartirish oson va brauzer faylni keshlaydi.

class="karta" bo'lgan elementlarni tanlovchi selektor qaysi?

  1. #karta
  2. .karta
  3. karta
  4. *karta

Nuqta — class, panjara — id.

<p class="a" id="b"> uchun p {color:red}, .a {color:green}, #b {color:blue} yozilgan. Matn qanday rangda?

  1. Qizil
  2. Yashil
  3. Qora
  4. Ko'k

ID selektori class va tegdan kuchliroq.

nav a selektori nimani tanlaydi?

  1. nav ichidagi barcha havolalarni
  2. nav va barcha a larni
  3. Faqat birinchi havolani
  4. a ichidagi nav ni

Bo'sh joy — "ichidagi" (avlod) selektori. Vergul esa "va" (guruh) bo'lardi.

Matnni markazga tekislovchi xossa qaysi?

  1. align: center
  2. font-align: center
  3. text-align: center
  4. center: true

font-family: "Roboto", Arial, sans-serif; — agar kompyuterda Roboto bo'lmasa?

  1. Matn ko'rinmaydi
  2. Arial ishlatiladi
  3. Xato chiqadi
  4. Times New Roman ishlatiladi

Ro'yxat — zaxira shriftlar ketma-ketligi.

🏠 Uyga vazifa

  1. CSS Diner o'yinida kamida 12-darajagacha o'ting (selektorlarni o'yin orqali mashq qilish).
  2. Vizitka saytingiz uchun 4–5 rangdan iborat palitra tanlang (coolors.co) va barcha sahifalarga qo'llang.
  3. 5-mavzudagi "Sinfimiz gazetasi" sahifasiga gazeta uslubida dizayn bering: serif shrift, markazdagi katta sarlavha, ustunlar orasida chiziq.

✅ Yodda tuting

  • Qoida: selektor { xossa: qiymat; }.
  • External CSS (<link rel="stylesheet" href="style.css">) — asosiy usul.
  • Selektorlar: teg, .class, #id, *, a, b (guruh), a b (ichidagi), a > b (bevosita farzand).
  • Ustuvorlik: inline > id > class > teg; teng bo'lsa — keyingisi yutadi.
  • Matn: color, text-align, text-decoration, line-height; shrift: font-family, font-size, font-weight.
