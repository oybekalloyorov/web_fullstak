2-topshiriq (5 ball). Model va admin

Kitob modelini yozing: nomi (200 belgi), muallif (100 belgi), janr (tanlov: roman, she'riyat, ilmiy), yil, narx (pul), mavjud (standart — ha), qo'shilgan sana (avtomatik). __str__ nomini qaytarsin. Admin'da ro'yxatda nomi, muallif, janr, mavjud ko'rinsin; janr va mavjudlik bo'yicha filtr, nom va muallif bo'yicha qidiruv.

Namuna javob
Python
from django.db import models
from django.contrib import admin


class Kitob(models.Model):
    JANRLAR = [("roman", "Roman"), ("sheriyat", "She'riyat"), ("ilmiy", "Ilmiy")]
    nomi = models.CharField(max_length=200)
    muallif = models.CharField(max_length=100)
    janr = models.CharField(max_length=20, choices=JANRLAR)
    yil = models.PositiveIntegerField()
    narx = models.DecimalField(max_digits=10, decimal_places=2)
    mavjud = models.BooleanField(default=True)
    qoshilgan = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.nomi


@admin.register(Kitob)
class KitobAdmin(admin.ModelAdmin):
    list_display = ["nomi", "muallif", "janr", "mavjud"]
    list_filter = ["janr", "mavjud"]
    search_fields = ["nomi", "muallif"]

Baholash: maydon turlari to'g'ri — 2; choices va default/auto_now_add — 1; __str__ — 1; admin sozlamalari — 1.

3-topshiriq (5 ball). View va shablon

Mavjud kitoblar ro'yxatini ko'rsatuvchi view va shablon yozing: ?q= parametri bo'lsa, nomi bo'yicha qidirsin; ro'yxat bo'sh bo'lsa "Kitob topilmadi" chiqsin; har bir kitob nomi batafsil sahifaga havola bo'lsin.

Namuna javob
Python
def kitoblar(request):
    q = request.GET.get("q", "").strip()
    qs = Kitob.objects.filter(mavjud=True)
    if q:
        qs = qs.filter(nomi__icontains=q)
    return render(request, "kutubxona/kitoblar.html", {"kitoblar": qs, "q": q})

4-topshiriq (5 ball). DRF API

Kitob uchun to'liq CRUD API yarating (/api/kitoblar/): o'qish — hammaga, o'zgartirish — faqat tizimga kirganlarga; narx musbat bo'lishi tekshirilsin; nom bo'yicha qidiruv.

Namuna javob
Python
from rest_framework import serializers, viewsets, permissions, filters
from rest_framework.routers import DefaultRouter


class KitobSerializer(serializers.ModelSerializer):
    class Meta:
        model = Kitob
        fields = "__all__"

    def validate_narx(self, v):
        if v <= 0:
            raise serializers.ValidationError("Narx musbat bo'lishi kerak")
        return v


class KitobViewSet(viewsets.ModelViewSet):
    queryset = Kitob.objects.all()
    serializer_class = KitobSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]
    filter_backends = [filters.SearchFilter]
    search_fields = ["nomi"]


router = DefaultRouter()
router.register("kitoblar", KitobViewSet)
# urls.py: path("api/", include(router.urls))

Baholash: serializer — 1; validatsiya — 1; ViewSet — 1; ruxsat — 1; router va qidiruv — 1.

5-topshiriq (5 ball). Deploy

Django loyihasini Render'ga joylash uchun bajariladigan asosiy qadamlarni va production sozlamalarini sanab, har birini qisqa tushuntiring.

  5. Deploy'dan keyin: superuser yaratish, tekshiruv ro'yxati, Logs orqali xatolarni topish.
