Box model va o'lcham birliklari. Flexbox va Grid

Har bir element — quti: content, padding, border, margin; box-sizing; px, %, em, rem, vw, vh; display; Flexbox bilan bir o'lchamli va CSS Grid bilan ikki o'lchamli sahifa maketlari.

3 soat · 1 nazariy + 2 amaliy
🎞️ Taqdimotni ochish⬇ PowerPoint (.pptx)📄 PDF yuklab olish

🎯 Bu darsda nimani o'rganasiz

  • Brauzer har bir elementni qanday "quti" sifatida ko'rishini (box model);
  • margin, padding, border va box-sizing ni;
  • O'lcham birliklari: px, %, em, rem, vw, vh;
  • Flexbox bilan menyu, kartalar qatori, markazlash;
  • CSS Grid bilan butun sahifa maketi va galereya yaratishni.

Bu kursdagi eng muhim CSS mavzusi — 3 soat ajratilgan. Shoshilmang, har bir misolni ▶ tugmasi bilan o'zgartirib ko'ring.

#Box model — har bir element quti

Brauzer sahifadagi har bir elementni (sarlavha, paragraf, rasm, tugma) to'rtburchak quti sifatida chizadi. Bu quti 4 qatlamdan iborat:

margin — tashqi bo'shliq (qo'shnilardan masofa)
border — chegara
padding — ichki bo'shliq
content — mazmun (matn, rasm)
O'xshatish: rasmli ramka Devordagi rasmni tasavvur qiling. Content — rasmning o'zi. Padding — rasm atrofidagi oq qog'oz hoshiya (paspartu). Border — yog'och ramka. Margin — devorda shu ramka bilan qo'shni ramka orasidagi bo'sh joy.
HTML
<style>
  .quti {
    width: 250px;
    padding: 20px;               /* ichki bo'shliq — fon rangi shu yerga ham tarqaladi */
    border: 5px solid #4f46e5;
    margin: 30px;                /* tashqi bo'shliq — har doim shaffof */
    background: #e0e7ff;
  }
</style>
<div class="quti">Men qutiman. F12 bosib, meni tanlang va "Computed" panelidagi box model chizmasiga qarang!</div>
<div class="quti">Men ikkinchi qutiman</div>

padding va margin yozish usullari

CSS
padding: 20px;                 /* 4 tomon ham 20px */
padding: 10px 20px;            /* tepa-past 10px, chap-o'ng 20px */
padding: 10px 20px 30px;       /* tepa 10, chap-o'ng 20, past 30 */
padding: 10px 20px 30px 40px;  /* tepa, o'ng, past, chap (soat strelkasi bo'yicha) */
padding-top: 10px;             /* faqat bitta tomon: -top, -right, -bottom, -left */

margin: 0 auto;                /* tepa-past 0, chap-o'ng auto → blokni GORIZONTAL MARKAZLASH */
Blokni markazga qo'yish Kengligi berilgan blokni sahifa o'rtasiga qo'yish uchun: width: 600px; margin: 0 auto;. Brauzer chap va o'ng bo'shliqni teng taqsimlaydi.

box-sizing — eng muhim bitta qator

Yuqoridagi .quti ning kengligi aslida necha piksel? width: 250px deb yozdik, lekin brauzer standart holatda padding va border'ni qo'shib hisoblaydi:

250 + 20 + 20 (padding) + 5 + 5 (border) = 300px 😕

Bu hisob-kitobni juda chalkashtiradi. Yechim:

CSS
/* Har bir loyihaning CSS faylini shu qoida bilan boshlang */
* {
  box-sizing: border-box;   /* endi width = padding + border + content. 250px — haqiqatan 250px */
}
HTML
<style>
  div { width: 250px; padding: 20px; border: 5px solid; margin: 10px 0; }
  .content-box { box-sizing: content-box; border-color: tomato; }
  .border-box  { box-sizing: border-box;  border-color: green; }
</style>
<div class="content-box">content-box: men 300px kenglikdaman</div>
<div class="border-box">border-box: men aynan 250px kenglikdaman</div>

#Flexbox — elementlarni bir qatorga terish

Flexbox — elementlarni bir yo'nalishda (qator yoki ustun) joylashtirish tizimi. Navigatsiya menyusi, tugmalar qatori, kartalarni yonma-yon qo'yish, biror narsani markazga joylash — Flexbox'ning ishi.

Ikki asosiy tushuncha

  • Flex konteyner — display: flex berilgan ota element.
  • Flex elementlar — uning bevosita farzandlari. Ular avtomatik ravishda bir qatorga tiziladi.
HTML
<style>
  .konteyner {
    display: flex;               /* ⬅ shu bitta qator hammasini o'zgartiradi */
    gap: 10px;                   /* elementlar orasidagi masofa */
    background: #f1f5f9;
    padding: 10px;
  }
  .element { background: #4f46e5; color: white; padding: 20px; border-radius: 8px; }
</style>
<div class="konteyner">
  <div class="element">1</div>
  <div class="element">2</div>
  <div class="element">3</div>
</div>
<p>display: flex ni o'chirib ko'ring — elementlar yana ustma-ust tushadi.</p>

Asosiy va kesishgan o'q

O'xshatish: avtobus bekati Odamlar bekatda navbatga turdi. Navbat yo'nalishi — asosiy o'q (main axis): justify-content odamlarni shu chiziq bo'ylab taqsimlaydi (boshida to'planish, o'rtada, oralari teng...). Navbatga perpendikulyar yo'nalish — kesishgan o'q (cross axis): align-items odamlarni bo'yi bo'yicha tekislaydi (tepasi, o'rtasi, pastki qismi bo'yicha).

Konteyner xossalari

#CSS Grid — panjara (to'r) maketi

Grid — elementlarni qator va ustunlardan iborat to'rga joylashtiradi (ikki o'lchamli). Butun sahifa maketi, rasm galereyasi, mahsulotlar katalogi uchun ideal.

O'xshatish: shaxmat taxtasi yoki Excel jadvali Grid — bu katakli taxta. Siz avval nechta ustun va qator bo'lishini belgilaysiz, keyin elementlarni kataklarga joylashtirasiz. Ba'zi elementlar bir nechta katakni egallashi mumkin — Excel'dagi kataklarni birlashtirish kabi.
HTML
<style>
  .grid {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;   /* 3 ta teng ustun */
    gap: 12px;
  }
  .grid div { background: #10b981; color: white; padding: 24px; border-radius: 8px; text-align: center; font-weight: bold; }
</style>
<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
  <div>7</div>
</div>

fr birligi va repeat()

  • fr (fraction) — bo'sh joyning ulushi. 1fr 2fr — ikkinchi ustun birinchisidan 2 barobar keng.
  • repeat(4, 1fr) = 1fr 1fr 1fr 1fr.
  • Aralash: grid-template-columns: 250px 1fr; — chapda qat'iy 250px yon panel, qolgani asosiy qism.

#Ko'p uchraydigan xatolar

  • ❌ display: flex ni farzandga yozish — u otaga (konteynerga) yoziladi.
  • ❌ justify-content: center vertikal markazlamayapti — vertikal uchun align-items kerak (va konteynerning balandligi bo'lishi kerak!).
  • ❌ box-sizing: border-box ni unutish — elementlar kutilganidan kengroq chiqib, qatorga sig'may qoladi.
  • ❌ inline elementga (a, span) width/height berish — ishlamaydi; display: inline-block yoki block kerak.
  • ❌ Grid'da grid-template-columns: 1fr, 1fr — vergul qo'yilmaydi: 1fr 1fr.

#O'zingizni tekshiring

Element chegarasi bilan mazmuni orasidagi bo'shliq nima deyiladi?

  1. margin
  2. border
  3. padding
  4. gap

padding — ichki, margin — tashqi bo'shliq.

width: 200px; padding: 10px; border: 5px solid; + box-sizing: border-box. Elementning to'liq kengligi?

  1. 230px
  2. 200px
  3. 215px
  4. 210px

border-box'da width padding va border'ni o'z ichiga oladi.

Menyuda logotipni chapga, havolalarni o'ngga surish uchun konteynerga nima yoziladi?

  1. display:flex; justify-content: space-between
  2. display:flex; align-items: center
  3. display:grid; gap: 10px
  4. text-align: justify

Root shrift 16px bo'lsa, 2rem necha piksel?

  1. 2px
  2. 16px
  3. 18px
  4. 32px

grid-template-columns: 1fr 3fr; — konteyner 800px bo'lsa (gap yo'q), birinchi ustun necha piksel?

  1. 400px
  2. 100px
  3. 200px
  4. 267px

Jami 4 ulush: 800/4 = 200px; ikkinchisi 600px.

Butun sahifa maketi (header, yon panel, asosiy qism, footer) uchun eng qulay vosita?

  1. Faqat Flexbox
  2. CSS Grid (grid-template-areas)
  3. HTML jadval
  4. float

✅ Yodda tuting

  • Box model: content + padding + border + margin. Har doim * { box-sizing: border-box; }.
  • Birliklar: px (aniq), % (otaga), rem (shriftlar), vw/vh (ekranga).
  • Flexbox (konteynerga display:flex): justify-content — asosiy o'q, align-items — kesishgan o'q, gap, flex: 1.
  • Grid: grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)), span, grid-template-areas.
