Ma'lumotlarni qo'shish, ko'rish va saqlash. CRUD operatsiyalari

CRUD konsepsiyasi; INSERT bilan qo'shish, SELECT bilan o'qish (ustunlarni tanlash, WHERE, ORDER BY, LIMIT), UPDATE bilan yangilash, DELETE bilan o'chirish; WHERE'siz UPDATE/DELETE xavfi; o'quvchilar bazasi loyihasi.

2 soat · amaliy
🎞️ Taqdimotni ochish⬇ PowerPoint (.pptx)📄 PDF yuklab olish

🎯 Bu darsda nimani o'rganasiz

  • CRUD — har qanday dasturning to'rtta asosiy amalini;
  • INSERT — ma'lumot qo'shish;
  • SELECT — ma'lumotni o'qish, tanlash va saralash;
  • UPDATE — o'zgartirish va DELETE — o'chirish;
  • Eng xavfli xato — WHEREsiz UPDATE/DELETE — dan qanday saqlanishni;
  • To'liq ishlaydigan o'quvchilar bazasini (18-loyiha).

#CRUD nima?

Deyarli har qanday dastur ma'lumot bilan to'rtta amal bajaradi. Ularning bosh harflaridan CRUD so'zi hosil bo'lgan:

#Create — INSERT

SQL
-- Bitta qator qo'shish
INSERT INTO sinflar (nomi, sinf_rahbari, xona)
VALUES ('8-A', 'Karimova Nodira', 204);

-- Bir nechta qatorni birdan
INSERT INTO sinflar (nomi, sinf_rahbari, xona) VALUES
    ('8-B', 'Rasulov Akmal', 206),
    ('8-V', 'Yusupova Malika', 210);

-- O'quvchilar (id avtomatik — SERIAL; alochi va yaratilgan — DEFAULT)
INSERT INTO oquvchilar (ism, familiya, tugilgan_sana, email, sinf_id) VALUES
    ('Ali',     'Valiyev',   '2012-03-15', 'ali@mail.uz',     1),
    ('Zarina',  'Karimova',  '2012-07-02', 'zarina@mail.uz',  1),
    ('Bobur',   'Toshmatov', '2011-11-20', 'bobur@mail.uz',   2),
    ('Madina',  'Ergasheva', '2012-01-09', 'madina@mail.uz',  2),
    ('Sardor',  'Qodirov',   '2012-05-30', NULL,              3),
    ('Dilnoza', 'Aminova',   '2011-12-12', 'dilnoza@mail.uz', 1);

-- Qo'shilgan qatorni darhol ko'rish (PostgreSQL imkoniyati)
INSERT INTO oquvchilar (ism, familiya, sinf_id)
VALUES ('Jasur', 'Rahimov', 3)
RETURNING id, ism;
  • Ustunlar ro'yxati va qiymatlar ro'yxati bir xil tartib va sonda bo'lishi kerak.
  • id ni yozmaymiz — SERIAL uni o'zi beradi.
  • NULL — "qiymat yo'q" (bo'sh). Faqat NOT NULL bo'lmagan ustunlarga.

Baza cheklovlarni tekshiradi — quyidagilar xato beradi:

SQL
INSERT INTO oquvchilar (familiya) VALUES ('Aliyev');
-- ❌ null value in column "ism" violates not-null constraint

INSERT INTO oquvchilar (ism, familiya, email) VALUES ('Vali', 'Aliyev', 'ali@mail.uz');
-- ❌ duplicate key value violates unique constraint (email band)

INSERT INTO oquvchilar (ism, familiya, sinf_id) VALUES ('Vali', 'Aliyev', 99);
-- ❌ violates foreign key constraint (99-sinf yo'q)

INSERT INTO baholar (oquvchi_id, fan, baho) VALUES (1, 'Matematika', 7);
-- ❌ violates check constraint (baho 2..5 bo'lishi kerak)
Bu xatolar — yaxshi narsa! Baza noto'g'ri ma'lumot yozilishiga yo'l qo'ymayapti. Xato xabarini diqqat bilan o'qing — u aniq qaysi qoida buzilganini aytadi.

#Read — SELECT

SQL
-- Barcha ustunlar va barcha qatorlar
SELECT * FROM oquvchilar;

-- Faqat kerakli ustunlar
SELECT ism, familiya, tugilgan_sana FROM oquvchilar;

-- Ustunga boshqa nom berish (AS) va hisoblangan ustun
SELECT ism || ' ' || familiya AS toliq_ism,              -- || — matnlarni birlashtirish
       EXTRACT(YEAR FROM AGE(tugilgan_sana)) AS yoshi    -- yoshni hisoblash
FROM oquvchilar;

WHERE — shart bo'yicha tanlash

SQL
SELECT * FROM oquvchilar WHERE sinf_id = 1;                     -- 8-A o'quvchilari
SELECT * FROM oquvchilar WHERE ism = 'Bobur';
SELECT * FROM oquvchilar WHERE tugilgan_sana < '2012-01-01';    -- 2012-yildan oldin tug'ilganlar
SELECT * FROM oquvchilar WHERE email IS NULL;                   -- emaili yo'qlar (= NULL emas!)
SELECT * FROM oquvchilar WHERE sinf_id = 1 AND alochi = TRUE;   -- VA
SELECT * FROM oquvchilar WHERE sinf_id = 2 OR sinf_id = 3;      -- YOKI

Batafsil filtrlash (LIKE, IN, BETWEEN) — 30-mavzuda.

ORDER BY va LIMIT

SQL
SELECT ism, familiya FROM oquvchilar ORDER BY familiya;                  -- A dan Z gacha
SELECT ism, tugilgan_sana FROM oquvchilar ORDER BY tugilgan_sana DESC;   -- eng yoshi birinchi
SELECT ism FROM oquvchilar ORDER BY sinf_id, familiya;                  -- avval sinf, keyin familiya
SELECT * FROM oquvchilar ORDER BY id LIMIT 3;                          -- faqat birinchi 3 tasi
SELECT * FROM oquvchilar ORDER BY id LIMIT 3 OFFSET 3;                 -- keyingi 3 tasi (2-sahifa)
SELECT qismlari tartibi SELECT ustunlar → FROM jadval → WHERE shart → ORDER BY saralash → LIMIT son. Tartib qat'iy: WHERE ni ORDER BY dan keyin yozib bo'lmaydi.

#Update — UPDATE

SQL
-- Bitta o'quvchining emailini o'zgartirish
UPDATE oquvchilar
SET email = 'sardor@mail.uz'
WHERE id = 5;

-- Bir nechta ustunni birdan
UPDATE oquvchilar
SET alochi = TRUE, telefon = '+998901234567'
WHERE id = 2;

-- Hisob bilan: 8-A sinfi boshqa xonaga ko'chdi
UPDATE sinflar SET xona = xona + 100 WHERE nomi = '8-A';

-- O'zgargan qatorni ko'rish
UPDATE oquvchilar SET sinf_id = 2 WHERE id = 6 RETURNING *;

#Delete — DELETE

SQL
DELETE FROM oquvchilar WHERE id = 7;

DELETE FROM baholar WHERE sana < '2025-09-01';    -- eski baholarni tozalash
⚠️ ENG XAVFLI XATO: WHERE'ni unutish
SQL
UPDATE oquvchilar SET sinf_id = 1;      -- 😱 BARCHA o'quvchilar 8-A ga ko'chdi!
DELETE FROM oquvchilar;                 -- 😱 BARCHA o'quvchilar o'chdi!

Baza "Ishonchingiz komilmi?" deb so'ramaydi. Xavfsizlik qoidasi: UPDATE yoki DELETE yozishdan oldin, xuddi shu WHERE bilan avval SELECT qiling va qaysi qatorlar o'zgarishini ko'ring:

SQL
SELECT * FROM baholar WHERE sana < '2025-09-01';   -- 1) avval ko'ramiz: 12 qator
DELETE FROM baholar WHERE sana < '2025-09-01';     -- 2) keyin o'chiramiz

#Tranzaksiya — "hammasi yoki hech biri"

Ba'zan bir nechta o'zgarish faqat birgalikda ma'noga ega. Masalan, o'quvchini boshqa sinfga ko'chirish va bu haqda yozuv qoldirish:

SQL
BEGIN;                                               -- tranzaksiya boshlandi
UPDATE oquvchilar SET sinf_id = 3 WHERE id = 1;
INSERT INTO baholar (oquvchi_id, fan, baho) VALUES (1, 'Matematika', 5);
COMMIT;                                              -- hammasini saqlash
-- Xato bo'lsa: ROLLBACK;  — barcha o'zgarishlar bekor qilinadi
O'xshatish: pul o'tkazmasi Do'stingizga 50 000 so'm o'tkazyapsiz: sizning hisobingizdan yechiladi VA do'stingiznikiga tushadi. Agar birinchisi bajarilib, ikkinchisida elektr o'chsa — pul "yo'qolib" qoladi. Tranzaksiya ikkalasi birga bajarilishini yoki ikkalasi ham bekor qilinishini kafolatlaydi.

#Ko'p uchraydigan xatolar

  • ❌ WHERE email = NULL — hech narsa qaytarmaydi. NULL bilan taqqoslash: IS NULL / IS NOT NULL.
  • ❌ Matn qiymatini qo'shtirnoqsiz yozish: WHERE ism = Ali — column "ali" does not exist.
  • ❌ INSERT da ustunlar va qiymatlar soni mos emas: INSERT has more expressions than target columns.
  • ❌ WHEREsiz UPDATE/DELETE. Avval SELECT!

#O'zingizni tekshiring

CRUD'dagi "R" qaysi SQL buyrug'iga mos keladi?

  1. INSERT
  2. SELECT
  3. UPDATE
  4. REMOVE

DELETE FROM oquvchilar; nima qiladi?

  1. Faqat birinchi qatorni o'chiradi
  2. Jadvalni o'chiradi
  3. Xato beradi
  4. Jadvaldagi BARCHA qatorlarni o'chiradi

Emaili kiritilmagan o'quvchilarni topuvchi to'g'ri shart?

  1. WHERE email IS NULL
  2. WHERE email = NULL
  3. WHERE email = ''
  4. WHERE NOT email

Natijani kamayish tartibida saralash uchun?

  1. ORDER BY ... ASC
  2. SORT BY ... DOWN
  3. ORDER BY ... DESC
  4. ORDER DESC BY ...

Faqat birinchi 5 ta natijani olish uchun?

  1. TOP 5
  2. LIMIT 5
  3. FIRST 5
  4. COUNT 5

Bir nechta o'zgarishni "hammasi yoki hech biri" tarzida bajarish nima deyiladi?

  1. Indeks
  2. JOIN
  3. Cheklov
  4. Tranzaksiya

✅ Yodda tuting

  • CRUD: Create (INSERT), Read (SELECT), Update (UPDATE), Delete (DELETE).
  • INSERT INTO t (a, b) VALUES (1, 'x');
  • SELECT ustunlar FROM t WHERE shart ORDER BY u DESC LIMIT n;
  • UPDATE t SET a = 1 WHERE id = 5; / DELETE FROM t WHERE id = 5; — WHERE'ni unutmang, avval SELECT!
  • IS NULL; tranzaksiya — BEGIN ... COMMIT / ROLLBACK.
