20-mavzu · 42 tadan · II bob. JavaScript asoslari

HTML eventlari va sahifaga interaktivlik. JavaScript mini loyiha

Loyihani rejalashtirish, "holat → chizish" usuli, forma tekshirish; To-Do List (localStorage bilan), mini test tizimi va interaktiv komponentlar — bosqichma-bosqich.

2 soat · amaliy

🎯 Bu darsda nimani o'rganasiz

  • Loyihani boshlashdan oldin rejalashtirishni;
  • Professional usul: ma'lumotni massivda saqlab, sahifani undan chizish (render);
  • Formani JavaScript bilan tekshirish (validatsiya);
  • To'liq To-Do List ilovasini (11-loyiha);
  • Mini test tizimini (12-loyiha) yaratishni.

Bu dars — II bobning yakuni: o'zgaruvchilar, shartlar, sikllar, funksiyalar, massivlar, DOM va hodisalar bitta loyihada birlashadi.

#Loyihani qanday boshlash kerak?

Yangi boshlovchilarning eng katta xatosi — darhol kod yozishga tushish. Tajribali dasturchi avval o'ylaydi:

  1. Nima qilishi kerak? Funksiyalar ro'yxatini yozing: "vazifa qo'shish", "bajarildi deb belgilash", "o'chirish"...
  2. Qanday ko'rinadi? Qog'ozga chizib oling: input, tugma, ro'yxat.
  3. Qanday ma'lumot saqlanadi? Har bir vazifa — obyekt: { id, matn, bajarildi }; hammasi — massiv.
  4. Qaysi hodisalar bor? Forma yuborildi → qo'shish; checkbox bosildi → belgilash; 🗑 bosildi → o'chirish.
  5. Kichik qadamlar bilan yozing va har qadamdan keyin tekshiring.

#"Holat → Chizish" usuli

Ro'yxatga element qo'shganda ham, o'chirganda ham DOM'ni qo'lda "yamash" chalkashlikka olib keladi. Professional usul:

👆 Hodisatugma bosildi
→
📦 Holat (massiv) o'zgaradipush / filter / map
→
🎨 render()sahifa massivdan qaytadan chiziladi
→
💾 saqlashlocalStorage
O'xshatish: doska va daftar Daftar — holat (haqiqiy ma'lumot). Doska — ekran. O'qituvchi doskaga to'g'ridan-to'g'ri yozib-o'chirib o'tirmaydi: avval daftarni yangilaydi, keyin doskani artib, daftardagini qaytadan yozadi. Shunda doska va daftar hech qachon farq qilmaydi.

Aynan shu g'oya React kabi zamonaviy kutubxonalarning asosida yotadi.

2-qadam: JavaScript — bosqichma-bosqich

todo/app.js
// ========== 1. HOLAT (ma'lumotlar) ==========
let vazifalar = JSON.parse(localStorage.getItem("vazifalar")) || [];
let filtr = "hammasi";

// ========== 2. ELEMENTLAR ==========
const forma = document.querySelector("#forma");
const kiritish = document.querySelector("#kiritish");
const royxat = document.querySelector("#royxat");
const xato = document.querySelector("#xato");
const hisob = document.querySelector("#hisob");

// ========== 3. AMALLAR (holatni o'zgartiradi) ==========
function qoshish(matn) {
  vazifalar.push({ id: Date.now(), matn: matn, bajarildi: false });
  yangilash();
}

function belgilash(id) {
  vazifalar = vazifalar.map(v => v.id === id ? { ...v, bajarildi: !v.bajarildi } : v);
  yangilash();
}

function ochirish(id) {
  vazifalar = vazifalar.filter(v => v.id !== id);
  yangilash();
}

function yangilash() {
  localStorage.setItem("vazifalar", JSON.stringify(vazifalar));  // saqlash
  render();                                                         // chizish
}

// ========== 4. CHIZISH (holatdan sahifa) ==========
function render() {
  royxat.innerHTML = "";                         // eski ro'yxatni tozalash

  const korinadigan = vazifalar.filter(v => {
    if (filtr === "faol") return !v.bajarildi;
    if (filtr === "bajarilgan") return v.bajarildi;
    return true;
  });

  if (korinadigan.length === 0) {
    royxat.innerHTML = '<li class="bosh">Bu yerda hozircha hech narsa yo\'q 🎉</li>';
  }

  korinadigan.forEach(v => {
    const li = document.createElement("li");
    if (v.bajarildi) li.classList.add("bajarildi");

    const checkbox = document.createElement("input");
    checkbox.type = "checkbox";
    checkbox.checked = v.bajarildi;
    checkbox.addEventListener("change", () => belgilash(v.id));

    const span = document.createElement("span");
    span.textContent = v.matn;                   // ✅ textContent — xavfsiz

    const ochirishTugma = document.createElement("button");
    ochirishTugma.textContent = "🗑";
    ochirishTugma.title = "O'chirish";
    ochirishTugma.addEventListener("click", () => ochirish(v.id));

    li.append(checkbox, span, ochirishTugma);
    royxat.append(li);
  });

  const qolgan = vazifalar.filter(v => !v.bajarildi).length;
  hisob.textContent = `${qolgan} ta vazifa qoldi`;
}

// ========== 5. HODISALAR ==========
forma.addEventListener("submit", (e) => {
  e.preventDefault();
  const matn = kiritish.value.trim();

  // Validatsiya
  if (matn === "") {
    xato.textContent = "⚠️ Vazifa matnini kiriting";
    return;
  }
  if (vazifalar.some(v => v.matn.toLowerCase() === matn.toLowerCase())) {
    xato.textContent = "⚠️ Bunday vazifa allaqachon bor";
    return;
  }

  xato.textContent = "";
  qoshish(matn);
  kiritish.value = "";
  kiritish.focus();
});

document.querySelectorAll("[data-filtr]").forEach(tugma => {
  tugma.addEventListener("click", () => {
    filtr = tugma.dataset.filtr;                 // data-filtr atributining qiymati
    document.querySelectorAll("[data-filtr]").forEach(t => t.classList.remove("faol"));
    tugma.classList.add("faol");
    render();
  });
});

document.querySelector("#tozalash").addEventListener("click", () => {
  vazifalar = vazifalar.filter(v => !v.bajarildi);
  yangilash();
});

// ========== 6. BOSHLASH ==========
render();

  const qoidalar = {
    email: v => /^\S+@\S+\.\S+$/.test(v) ? "" : "Email noto'g'ri",
    parol: v => v.length < 8 ? "Kamida 8 belgi" : !/\d/.test(v) ? "Kamida bitta raqam bo'lsin" : "",

/^\S+@\S+\.\S+$/ — muntazam ifoda (regex): "bo'sh joysiz belgilar, @, belgilar, nuqta, belgilar". Regex'lar matnni naqsh bo'yicha tekshirish uchun ishlatiladi.

#Ko'p uchraydigan xatolar

  • ❌ Holatni o'zgartirib, render() ni chaqirishni unutish — massiv o'zgardi, lekin ekran eski holicha.
  • ❌ localStorage ga massivni JSON.stringifysiz saqlash — "[object Object]" saqlanib qoladi.
  • ❌ render() da ro'yxatni tozalamaslik (innerHTML = "") — har safar elementlar ikki baravar ko'payadi.
  • ❌ Foydalanuvchi matnini innerHTML bilan qo'shish — XSS xavfi. textContent!

#O'zingizni tekshiring

"Holat → Chizish" usulida tugma bosilganda birinchi nima o'zgaradi?

  1. Sahifadagi HTML
  2. CSS fayl
  3. Ma'lumotlar massivi (holat)
  4. localStorage

Massivni localStorage'da saqlash uchun avval nima qilinadi?

  1. JSON.stringify() bilan matnga aylantiriladi
  2. toString() chaqiriladi
  3. Hech narsa, to'g'ridan-to'g'ri saqlanadi
  4. Number() bilan songa aylantiriladi

<button data-filtr="faol"> dagi qiymatni JS'da qanday o'qiysiz?

  1. tugma.filtr
  2. tugma.data
  3. tugma.value
  4. tugma.dataset.filtr

Vazifani o'chirishning eng qulay usuli (id bo'yicha)?

  1. vazifalar.pop(id)
  2. vazifalar = vazifalar.filter(v => v.id !== id)
  3. delete vazifalar[id]
  4. vazifalar.remove(id)

🏠 Uyga vazifa (bob yakunlovchi loyiha)
