Ma'lumot tuzilmalari: list, tuple, set va dictionary

Ro'yxat (list) va uning metodlari, kesish (slicing), list comprehension; o'zgarmas tuple; takrorlanmas set; kalit-qiymatli dictionary; qaysi birini qachon tanlash; o'quvchilar ma'lumotlarini boshqarish dasturi.

1 soat · nazariy

🎯 Bu darsda nimani o'rganasiz

  • Python'ning to'rtta asosiy "konteyneri": list, tuple, set, dict;
  • Har birining xususiyatlari va qachon qaysi birini tanlash kerakligini;
  • Ro'yxatlarni kesish (slicing) va list comprehension;
  • O'quvchilar ma'lumotlarini boshqaruvchi dasturni (16-loyiha).

Kesish (slicing) — Python'ning "super kuchi"

Python
harflar = ["a", "b", "c", "d", "e", "f"]
#            0    1    2    3    4    5
print(harflar[1:4])     # ['b', 'c', 'd']   — 1 dan 4 gacha (4 kirmaydi)
print(harflar[:3])      # ['a', 'b', 'c']   — boshidan
print(harflar[3:])      # ['d', 'e', 'f']   — oxirigacha
print(harflar[-2:])     # ['e', 'f']        — oxirgi ikkitasi
print(harflar[::2])     # ['a', 'c', 'e']   — har ikkinchisi
print(harflar[::-1])    # teskari tartibda!
print("Python"[::-1])   # nohtyP — satrlarda ham ishlaydi

#Tuple — o'zgarmas ro'yxat

Python
sana = (1, 9, 2026)               # kun, oy, yil
koordinata = (41.31, 69.28)       # Toshkent kengligi va uzunligi
print(sana[2])                    # 2026
# sana[0] = 5                     # ❌ TypeError: tuple o'zgartirilmaydi

kun, oy, yil = sana               # "ochish" (unpacking)
print(f"{kun}.{oy}.{yil}")

a, b = 5, 10
a, b = b, a                       # qiymatlarni almashtirish — aslida tuple!
print(a, b)                       # 10 5

Qachon tuple? Ma'lumot o'zgarmasligi kerak bo'lsa: sanalar, koordinatalar, RGB ranglar (255, 0, 0), haftaning kunlari. Tuple list'dan biroz tezroq va "tasodifan o'zgartirib qo'yish"dan himoya qiladi.

# Takrorlarni olib tashlashning eng oson usuli
royxat = [1, 2, 2, 3, 3, 3, 4]

# To'plamlar ustida amallar (matematikadagi kabi)
futbol = {"Ali", "Vali", "Sardor"}

print(futbol & shaxmat)     # kesishma — ikkalasida ham: {'Vali', 'Sardor'}
print(futbol | shaxmat)     # birlashma — hammasi
print(futbol - shaxmat)     # ayirma — faqat futbolda: {'Ali'}

#Amaliy mashg'ulot: o'quvchilar ma'lumotlarini boshqarish (16-loyiha)

oquvchilar.py
oquvchilar = {
    "ali": {"ism": "Ali Valiyev", "sinf": "8-A", "baholar": [5, 4, 5]},
    "zarina": {"ism": "Zarina Karimova", "sinf": "8-B", "baholar": [5, 5, 4]},
}

def ortacha(baholar):
    return round(sum(baholar) / len(baholar), 2) if baholar else 0

def royxat():
    if not oquvchilar:
        print("Ro'yxat bo'sh")
        return
    print(f"\n{'Login':<10}{'Ism':<20}{'Sinf':<6}{'O‘rtacha':>8}")
    print("-" * 44)
    for login, o in oquvchilar.items():
        print(f"{login:<10}{o['ism']:<20}{o['sinf']:<6}{ortacha(o['baholar']):>8}")

def qoshish():
    login = input("Login: ").strip().lower()
    if login in oquvchilar:
        print("❌ Bunday login band")
        return
    ism = input("To'liq ism: ").strip()
    sinf = input("Sinf: ").strip()
    oquvchilar[login] = {"ism": ism, "sinf": sinf, "baholar": []}
    print("✅ Qo'shildi")

def baho_qoyish():
    login = input("Login: ").strip().lower()
    if login not in oquvchilar:
        print("❌ Topilmadi")
        return
    try:
        baho = int(input("Baho (2–5): "))
    except ValueError:
        print("❌ Son kiriting")
        return
    if baho not in (2, 3, 4, 5):
        print("❌ Baho 2 dan 5 gacha")
        return
    oquvchilar[login]["baholar"].append(baho)
    print("✅ Baho qo'yildi")

def statistika():
    if not oquvchilar:
        return
    eng_yaxshi = max(oquvchilar.values(), key=lambda o: ortacha(o["baholar"]))
    sinflar = {o["sinf"] for o in oquvchilar.values()}          # set comprehension
    print(f"Jami o'quvchilar: {len(oquvchilar)}")
    print(f"Sinflar: {', '.join(sorted(sinflar))}")
    print(f"Eng yuqori o'rtacha: {eng_yaxshi['ism']} ({ortacha(eng_yaxshi['baholar'])})")

MENYU = {
    "1": ("Ro'yxatni ko'rish", royxat),
    "2": ("O'quvchi qo'shish", qoshish),
    "3": ("Baho qo'yish", baho_qoyish),
    "4": ("Statistika", statistika),
}

while True:
    print("\n===== O'QUVCHILAR TIZIMI =====")
    for kalit, (nom, _) in MENYU.items():
        print(f"{kalit}. {nom}")
    print("0. Chiqish")
    tanlov = input("Tanlang: ").strip()
    if tanlov == "0":
        print("Xayr!")
        break
    if tanlov in MENYU:
        MENYU[tanlov][1]()          # dict'dan funksiyani olib, chaqiramiz
    else:
        print("❌ Noto'g'ri tanlov")

Kodni o'rganing: o'quvchilar dictda (login bo'yicha tez topish), baholar listda, menyu ham dict (raqam → nom va funksiya tuple), sinflar setda (takrorlanmas). To'rtala tuzilma bitta dasturda!

  1. "O'quvchini o'chirish" va "Ism bo'yicha qidirish" menyu bandlarini qo'shing.
  2. Dastur yopilganda ma'lumot yo'qolmasligi uchun JSON faylga saqlang (24-mavzuda json modulini o'rganamiz — oldindan sinab ko'ring!).

#Ko'p uchraydigan xatolar

  • ❌ IndexError: list index out of range — mavjud bo'lmagan indeks (3 elementli ro'yxatda [3]).
  • ❌ KeyError — dict'da yo'q kalit; .get() ishlating.
  • ❌ x = ro'yxat.sort() — sort() hech narsa qaytarmaydi (None); yangi ro'yxat kerak bo'lsa sorted().
  • ❌ Bo'sh set uchun {} yozish — bu dict.

✅ Yodda tuting

  • list [] — tartibli, o'zgaruvchan: append, remove, pop, sort, slicing [a:b], [-1].
  • tuple () — o'zgarmas; unpacking: a, b = (1, 2).
  • set {} — takrorsiz; & | - amallari.
  • dict {"k": v} — kalit bo'yicha: d["k"], d.get("k"), .items(), .keys(), .values().
  • List comprehension: [ifoda for x in to'plam if shart].
