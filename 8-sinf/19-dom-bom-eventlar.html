DOM va BOM bilan ishlash. JavaScript'da eventlar

DOM daraxti, elementlarni topish (querySelector), matn, atribut, uslub va class'larni o'zgartirish, element yaratish va o'chirish; BOM: window, location, localStorage, setTimeout; hodisalar va addEventListener; valyuta konvertori.

2 soat · amaliy
🎞️ Taqdimotni ochish⬇ PowerPoint (.pptx)

🎯 Bu darsda nimani o'rganasiz

  • DOM nima va JavaScript sahifadagi elementlarni qanday "ko'radi";
  • Elementlarni topish, matnini, rangini, class'ini o'zgartirishni;
  • Yangi elementlar yaratish va o'chirishni;
  • BOM: brauzer oynasi, manzil, xotira (localStorage), taymerlar;
  • Hodisalar (events): tugma bosilishi, matn kiritilishi va boshqalarga javob berishni;
  • Haqiqiy interaktiv dastur — valyuta konvertorini (13-loyiha).

#DOM nima?

Brauzer HTML faylni o'qiganda, uni xotirada daraxt ko'rinishidagi obyektlarga aylantiradi. Bu daraxt DOM (Document Object Model) deyiladi. JavaScript sahifani aynan DOM orqali o'zgartiradi.

HTML
<body>
  <h1 id="sarlavha">Salom</h1>
  <ul class="royxat">
    <li>Olma</li>
    <li>Nok</li>
  </ul>
</body>
Matn
document
└── html
    └── body
        ├── h1#sarlavha  →  "Salom"
        └── ul.royxat
            ├── li  →  "Olma"
            └── li  →  "Nok"
O'xshatish: oila shajarasi DOM — oila daraxti. body — bobo, ul — ota, li lar — bolalar (va o'zaro aka-uka). JavaScript shu daraxtdagi istalgan "qarindosh"ni topib, uning kiyimini (uslub), ismini (matn) o'zgartirishi, yangi farzand qo'shishi yoki olib tashlashi mumkin.

document — butun sahifani ifodalovchi obyekt, DOM bilan ishlashning kirish nuqtasi.

#Elementlarni topish

JavaScript
// querySelector — CSS selektori bilan BIRINCHI mos elementni topadi
const sarlavha = document.querySelector("#sarlavha");   // id bo'yicha
const royxat   = document.querySelector(".royxat");     // class bo'yicha
const birinchiLi = document.querySelector("li");        // teg bo'yicha

// querySelectorAll — BARCHA mos elementlar (ro'yxat)
const hammaLi = document.querySelectorAll("li");
hammaLi.forEach(li => console.log(li.textContent));

// Eski, lekin ko'p uchraydigan usul
const s = document.getElementById("sarlavha");          // # belgisisiz!
CSS'da qanday selektor yozsangiz (#id, .class, nav a), querySelector ga ham xuddi shunday yozasiz. 6-mavzudagi bilimlar shu yerda ham ishlaydi!

#Elementlarni o'zgartirish

HTML
<h1 id="sarlavha">Eski sarlavha</h1>
<p class="matn">Oddiy paragraf</p>
<img id="rasm" src="https://picsum.photos/seed/bir/200/120" alt="Rasm">
<a id="havola" href="#">Havola</a>

<script>
  const h1 = document.querySelector("#sarlavha");
  h1.textContent = "Yangi sarlavha ✨";            // matnni almashtirish

  const p = document.querySelector(".matn");
  p.innerHTML = "Endi <b>qalin</b> so'z bor";      // HTML bilan almashtirish

  // Uslub (inline CSS) — xossa nomlari camelCase: background-color → backgroundColor
  h1.style.color = "white";
  h1.style.backgroundColor = "#4f46e5";
  h1.style.padding = "10px";
  h1.style.borderRadius = "8px";

  // Atributlar
  document.querySelector("#rasm").src = "https://picsum.photos/seed/ikki/200/120";
  const a = document.querySelector("#havola");
  a.href = "https://uz.wikipedia.org";
  a.textContent = "Vikipediya";
  a.setAttribute("target", "_blank");
</script>
textContent yoki innerHTML? Foydalanuvchi kiritgan matnni (ism, izoh) doim textContent bilan qo'ying. innerHTML esa matn ichidagi HTML va skriptlarni ham bajaradi — yomon niyatli odam izoh sifatida zararli kod yozishi mumkin (bu XSS hujumi deyiladi).

Class'lar bilan ishlash — eng to'g'ri usul

Uslubni style orqali birma-bir o'zgartirgandan ko'ra, CSS'da tayyor class yozib, JavaScript bilan uni qo'shish/olib tashlash yaxshiroq:

HTML
<style>
  .quti { padding: 20px; border-radius: 10px; background: #e5e7eb; transition: .3s; font-family: sans-serif; }
  .faol { background: #22c55e; color: white; transform: scale(1.05); }
  .yashirin { display: none; }
</style>
<div class="quti" id="q">Men qutiman</div>
<p id="sir" class="yashirin">🤫 Sir matn topildi!</p>

<script>
  const q = document.querySelector("#q");
  q.classList.add("faol");              // class qo'shish
  // q.classList.remove("faol");        // olib tashlash
  // q.classList.toggle("faol");        // bor bo'lsa olib tashlaydi, yo'q bo'lsa qo'shadi
  console.log(q.classList.contains("faol"));   // true — bormi?

  document.querySelector("#sir").classList.remove("yashirin");
</script>

Element yaratish va o'chirish

HTML
<ul id="royxat"><li>Non</li></ul>

<script>
  const royxat = document.querySelector("#royxat");
  const mahsulotlar = ["Sut", "Tuxum", "Olma"];

  mahsulotlar.forEach(nom => {
    const li = document.createElement("li");   // 1. yaratish (hali sahifada yo'q)
    li.textContent = nom;                        // 2. to'ldirish
    royxat.append(li);                           // 3. sahifaga qo'shish
  });

  royxat.firstElementChild.remove();             // birinchi elementni o'chirish
</script>

#BOM — brauzer bilan ishlash

BOM (Browser Object Model) — sahifaning o'zi emas, brauzer oynasi bilan ishlash vositalari. Ularning "boshlig'i" — window obyekti.

JavaScript
console.log(window.innerWidth, window.innerHeight);  // oyna o'lchami
console.log(location.href);         // joriy sahifa manzili
// location.href = "https://kun.uz"; // boshqa sahifaga o'tish
// location.reload();                 // sahifani yangilash
console.log(navigator.language);    // brauzer tili, masalan "uz" yoki "ru"
// history.back();                    // "Orqaga" tugmasi

// Taymerlar
setTimeout(() => {
  console.log("3 soniya o'tdi ⏰");
}, 3000);                            // bir marta, 3000 ms dan keyin

let soniya = 0;
const taymer = setInterval(() => {
  soniya++;
  console.log(`${soniya} soniya`);
  if (soniya === 5) clearInterval(taymer);   // to'xtatish
}, 1000);                            // har 1000 ms da

localStorage — brauzer xotirasi

Sahifa yangilansa, JavaScript o'zgaruvchilari "unutiladi". localStorage esa ma'lumotni brauzerda doimiy saqlaydi (brauzer yopilsa ham).

JavaScript
localStorage.setItem("ism", "Malika");          // saqlash (faqat matn!)
console.log(localStorage.getItem("ism"));       // o'qish → "Malika"
localStorage.removeItem("ism");                 // o'chirish

// Massiv yoki obyektni saqlash uchun — JSON ga aylantirish
const vazifalar = ["Dars qilish", "Kitob o'qish"];
localStorage.setItem("vazifalar", JSON.stringify(vazifalar));
const qaytaOlingan = JSON.parse(localStorage.getItem("vazifalar"));
console.log(qaytaOlingan[0]);

#Hodisalar (events)

Hodisa — sahifada sodir bo'ladigan narsa: tugma bosildi, klavish bosildi, sichqoncha ustiga keldi, forma yuborildi. JavaScript hodisani "tinglab" turadi va sodir bo'lganda belgilangan funksiyani bajaradi.

O'xshatish: eshik qo'ng'irog'i Siz eshik oldida doim kutib turmaysiz. Qo'ng'iroq chalinganda (hodisa) eshikni ochishga borasiz (funksiya). addEventListener — "qo'ng'iroq chalinsa, menga ayt" degan kelishuv.
HTML
<button id="tugma">Meni bosing!</button>
<p id="natija">Hali bosilmadi</p>

<script>
  const tugma = document.querySelector("#tugma");
  const natija = document.querySelector("#natija");
  let soni = 0;

  tugma.addEventListener("click", () => {
    soni++;
    natija.textContent = `Siz ${soni} marta bosdingiz 🎉`;
  });
</script>
JavaScript
element.addEventListener("hodisa_turi", funksiya);
HodisaQachon sodir bo'ladi
clickElement bosilganda
dblclickIkki marta bosilganda
mouseenter / mouseleaveSichqoncha ustiga kelganda / ketganda
inputMaydonga har bir belgi kiritilganda
changeQiymat o'zgarib, maydondan chiqilganda (select, checkbox)
submitForma yuborilganda
keydownKlaviaturada tugma bosilganda
loadSahifa to'liq yuklanganda
scroll / resizeSahifa aylantirilganda / oyna o'lchami o'zgarganda

Hodisa obyekti (event)

HTML
<input id="matn" placeholder="Bu yerga yozing...">
<p>Belgilar soni: <b id="soni">0</b></p>
<p id="oxirgi"></p>

<script>
  const input = document.querySelector("#matn");

  input.addEventListener("input", (event) => {
    // event.target — hodisa sodir bo'lgan element
    document.querySelector("#soni").textContent = event.target.value.length;
  });

  document.addEventListener("keydown", (e) => {
    document.querySelector("#oxirgi").textContent = `Oxirgi bosilgan tugma: ${e.key}`;
    if (e.key === "Escape") input.value = "";
  });
</script>

Forma yuborilishini ushlash

HTML
<form id="forma">
  <input name="ism" placeholder="Ismingiz" required>
  <button>Yuborish</button>
</form>
<p id="javob"></p>

<script>
  document.querySelector("#forma").addEventListener("submit", (e) => {
    e.preventDefault();                 // ⬅ sahifa qayta yuklanishini TO'XTATADI
    const ism = e.target.ism.value.trim();
    document.querySelector("#javob").textContent = `Rahmat, ${ism}! Ma'lumot qabul qilindi.`;
    e.target.reset();                   // formani tozalash
  });
</script>
e.preventDefault() — brauzerning odatiy harakatini bekor qiladi. Forma uchun bu sahifa qayta yuklanishining oldini oladi va ma'lumotni JavaScript bilan o'zimiz qayta ishlaymiz.

<script>
  // 1 birlik valyuta necha so'm (namuna kurslar)
  const KURSLAR = {
    UZS: { nomi: "🇺🇿 So'm", kurs: 1 },
    USD: { nomi: "🇺🇸 Dollar", kurs: 12700 },
    EUR: { nomi: "🇪🇺 Yevro", kurs: 13900 },
    RUB: { nomi: "🇷🇺 Rubl", kurs: 155 },
    KZT: { nomi: "🇰🇿 Tenge", kurs: 25 },
  };

    const miqdor = Number(miqdorEl.value);
    const dan = danEl.value;
    const ga = gaEl.value;

    if (miqdor < 0 || miqdorEl.value === "") {
      natijaEl.textContent = "Miqdorni kiriting";
      return;

  danEl.addEventListener("change", hisobla);
  gaEl.addEventListener("change", hisobla);

    [danEl.value, gaEl.value] = [gaEl.value, danEl.value];   // qiymatlarni almashtirish
    hisobla();
  });

  hisobla();   // sahifa ochilganda birinchi hisob

Qo'shimcha mashqlar

  • Tungi rejim tugmasi: bosilganda body ga dark class qo'shilsin/olinsin, tanlov localStorage da saqlansin.
  • Burger menyu: 10-mavzudagi menyuni endi JavaScript bilan oching: ☰ bosilganda .menyu ga ochiq class.
  • Sekundomer: Start/Stop/Reset tugmalari va setInterval.

#Ko'p uchraydigan xatolar

  • ❌ Cannot read properties of null — querySelector elementni topmadi: selektorda xato (# yoki . unutilgan) yoki skript HTML'dan oldin ulangan.
  • ❌ addEventListener("click", hisobla()) — qavs qo'yilsa funksiya darhol bajariladi. To'g'risi: hisobla (qavssiz).
  • ❌ input.value ni son deb o'ylash — u doim matn. Number()!
  • ❌ Formada e.preventDefault() unutilgan — sahifa yangilanib, natija bir lahzada yo'qoladi.
  • ❌ style.background-color — JS'da defisli nomlar camelCase bo'ladi: style.backgroundColor.

#O'zingizni tekshiring

class="karta" bo'lgan birinchi elementni topuvchi kod?

  1. document.querySelector("karta")
  2. document.querySelector(".karta")
  3. document.getElementById(".karta")
  4. document.find("karta")

Element matnini xavfsiz o'zgartiruvchi xossa?

  1. innerHTML
  2. value
  3. src
  4. textContent

  1. classList.toggle()
  2. classList.add()
  3. classList.switch()
  4. className.change()

Maydonga har bir belgi kiritilganda sodir bo'ladigan hodisa?

  1. click
  2. submit
  3. input
  4. load

Ma'lumotni brauzer yopilsa ham saqlab qoluvchi BOM vositasi?

  1. setTimeout
  2. localStorage
  3. console
  4. location

Forma yuborilganda sahifa qayta yuklanmasligi uchun nima chaqiriladi?

  1. e.stop()
  2. return false
  3. form.reset()
  4. e.preventDefault()
