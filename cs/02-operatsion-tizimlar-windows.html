#Operatsion tizim nima?

Operatsion tizim (OT, inglizcha OS — Operating System) — kompyuter yoqilganda birinchi yuklanadigan va boshqa barcha dasturlar ishlashi uchun "zamin" yaratadigan asosiy dastur. U kompyuterning apparat qismini (protsessor, xotira, disk, printer) boshqaradi va foydalanuvchiga qulay muloqot oynasini taqdim etadi.

O'xshatish: maktab direktori Maktabda o'qituvchilar (dasturlar) dars o'tadi, lekin qaysi xona kimga berilishini, qo'ng'iroq qachon chalinishini, kim qaysi jihozdan foydalanishini direktor (operatsion tizim) boshqaradi. Direktor bo'lmasa — hamma bir vaqtda bitta xonaga kirib, tartibsizlik bo'ladi.

Oynalar bilan ishlash

Windows nomi ("derazalar") bejiz emas — har bir dastur o'z oynasida ochiladi. Oynaning o'ng yuqori burchagida uchta tugma bor:

  • — Yig'ish (minimize) — oyna vazifalar paneliga yashirinadi;
  • ☐ Yoyish (maximize) — butun ekranni egallaydi;
  • ✕ Yopish (close) — dastur yopiladi.

Sozlamalar va Boshqaruv paneli

Sozlamalar (Settings) — Win+I. Bu yerda:

  • Tizim — ekran yorqinligi, tovush, bildirishnomalar, "Haqida" (kompyuter xususiyatlari);
  • Shaxsiylashtirish — fon rasmi, ranglar, tungi rejim;
  • Vaqt va til — klaviatura tillari (o'zbekcha lotin, rus, ingliz qo'shish);
  • Hisoblar — foydalanuvchilar va parollar;
  • Windows Update — tizim yangilanishlari (xavfsizlik uchun muhim!);
  • Ilovalar — o'rnatilgan dasturlar ro'yxati va ularni o'chirish.

Boshqaruv paneli (Control Panel) — eski uslubdagi sozlamalar oynasi; Start'da "Control Panel" deb qidirib topiladi. Ba'zi eski sozlamalar faqat shu yerda bor.

#Dasturlarni o'rnatish va o'chirish

O'rnatish

  1. Dasturni faqat rasmiy saytdan yoki Microsoft Storedan yuklab oling. Masalan: flowgorithm.org, code.visualstudio.com, git-scm.com.
  2. Yuklangan .exe yoki .msi faylni ishga tushiring.
  3. O'rnatuvchi (installer) savollarini o'qib javob bering. "Qo'shimcha dasturlar" (brauzer paneli, reklama) taklif qilinsa — belgini olib tashlang.
  4. O'rnatish tugagach, dastur Start menyusida paydo bo'ladi.
Xavfli manbalar "Bepul yuklab olish", "crack", "keygen" kabi noma'lum saytlardagi dasturlar ko'pincha virus yoki ayg'oqchi dastur bilan keladi (6-mavzu). Pullik dasturning bepul muqobilini qidiring: masalan, Microsoft Office o'rniga LibreOffice yoki Google Docs.

O'chirish

  1. Sozlamalar → Ilovalar → O'rnatilgan ilovalar (Apps → Installed apps).
  2. Dasturni toping, yonidagi ⋯ tugmasi → O'chirish (Uninstall).

Dastur papkasini qo'lda o'chirish to'g'ri emas — tizimda "chiqindi" qoladi.

#Amaliy mashg'ulot

  1. Sozlamalarda klaviaturaga O'zbek (lotin) tilini qo'shing. Tillar orasida Win+Probel bilan almashing.
  2. Ish stoli fon rasmini va mavzu rangini o'zgartiring; tungi rejimni yoqing.
  3. Bloknot (Notepad) va Kalkulyatorni Start qidiruvi orqali oching. Ularni Win+←/→ bilan yonma-yon joylang.
  4. Alt+Tab bilan oynalar orasida o'ting, Win+D bilan ish stoliga qayting.
  5. Vazifalar dispetcherida eng ko'p xotira ishlatayotgan 3 ta dasturni aniqlang.
  6. Mentor bilan birga Flowgorithm dasturini rasmiy saytdan o'rnating — III bobda kerak bo'ladi.

#Ko'p uchraydigan xatolar

  • ❌ Ish stolidagi yorliqni o'chirib, "dastur o'chdi" deb o'ylash → ✅ Dastur faqat Sozlamalar → Ilovalar orqali o'chiriladi.
  • ❌ Kompyuterni quvvat tugmasini uzoq bosib o'chirish → ✅ Start → O'chirish. Aks holda saqlanmagan ma'lumot va tizim fayllari buzilishi mumkin.
  • ❌ Windows yangilanishlarini doim o'chirib qo'yish → ✅ Yangilanishlar xavfsizlik teshiklarini yopadi.
  • ❌ Noma'lum saytdan dastur yuklash → ✅ Faqat rasmiy sayt yoki Microsoft Store.

#O'zingizni tekshiring

Operatsion tizimning asosiy vazifasi nima?

  1. Faqat o'yin o'ynash
  2. Kompyuter resurslarini boshqarish va dasturlar uchun muhit yaratish
  3. Internetga ulanish
  4. Matn yozish

OT — dasturlar va apparat qismi o'rtasidagi "direktor".

Quyidagilardan qaysi biri ochiq kodli operatsion tizim?

  1. Windows
  2. macOS
  3. iOS
  4. Linux

Linux'ning kodi ochiq va bepul tarqatiladi.

Ochiq oynalar orasida tez o'tish uchun qaysi tugmalar ishlatiladi?

  1. Alt + Tab
  2. Ctrl + C
  3. Win + L
  4. Alt + F4

Alt+Tab — oynalar almashinuvi; Win+L — qulflash; Alt+F4 — yopish.

Qurilma (printer) bilan ishlash uchun OTga kerak bo'ladigan kichik dastur?

  1. Brauzer
  2. Antivirus
  3. Drayver
  4. Arxivator

Drayver OTga qurilma bilan qanday ishlashni "o'rgatadi".

Dasturni to'g'ri o'chirish usuli qaysi?

  1. Ish stolidagi yorlig'ini o'chirish
  2. Sozlamalar → Ilovalar → O'chirish
  3. Papkasini savatga tashlash
  4. Kompyuterni qayta yoqish

Shunda dastur barcha fayllari va sozlamalari bilan to'g'ri o'chiriladi.

  3. Windows, Linux va Android'ning 3 tadan afzalligi va kamchiligini yozing.
