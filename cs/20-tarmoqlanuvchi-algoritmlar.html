20-mavzu · 26 tadan · III bob. Algoritmlash, Flowgorithm va dasturlash asoslari

Flowgorithm'da tarmoqlanuvchi algoritmlar va shartlar

Tarmoqlanuvchi algoritm va shartli bajarilish; Decision (If) bloki; taqqoslash operatorlari > < >= <= == !=; to'liq va qisqa If, ichma-ich shartlar; juft-toq son, musbat-manfiy son, bahoni aniqlash; mantiqiy operatorlar AND, OR, NOT va rostlik jadvallari. 9- va 10-loyihalar.

2 dars · 1 nazariy + 1 amaliy
📄 PDF yuklab olish

🎯 Bu mavzuda nimani o'rganasiz

  • Tarmoqlanuvchi algoritm nima va dastur qanday "qaror qabul qilishini";
  • If (Decision) bloki: True va False yo'llari;
  • Oltita taqqoslash operatori: > < >= <= == !=;
  • Ichma-ich shartlar va "zinapoya" usuli (baho aniqlash);
  • Murakkab shartlar: AND, OR, NOT va rostlik jadvallari.
Dars rejasi (2 dars)1-dars (nazariy): shart, If, taqqoslash, ichma-ich shartlar, mantiqiy operatorlar. 2-dars (amaliy): juft-toq, musbat-manfiy, baho, kirish nazorati — Flowgorithm'da qurish va test qilish.

#Tarmoqlanuvchi algoritm nima?

Tarmoqlanuvchi algoritm — shartga qarab bir nechta yo'ldan biri tanlab bajariladigan algoritm. Chiziqli algoritm doim bir xil yo'ldan yursa, tarmoqlanuvchi algoritm chorrahaga keladi va vaziyatga qarab burilib ketadi.

O'xshatish: yo'l ayrisiSiz velosipedda ketyapsiz va yo'l ikkiga ayrildi. Belgida: "Agar maktabga borsangiz — o'ngga, aks holda — chapga". Siz faqat bitta yo'ldan ketasiz, ikkinchisi bu safar bajarilmaydi. Keyin yo'llar yana bir joyda qo'shiladi.

Hayotda: "Agar yomg'ir yog'sa — soyabon ol, aks holda — kepka kiy". Dasturlarda: "Agar parol to'g'ri bo'lsa — kirish, aks holda — xato xabari".

#If bloki

Flowgorithm'da shart If bloki (oltiburchak/romb) bilan yoziladi. Ichiga shart — natijasi true yoki false bo'ladigan ifoda yoziladi. Shart rost bo'lsa — True (o'ng) tarmoq, yolg'on bo'lsa — False (chap) tarmoq bajariladi.

To'liq If (if–else)
Main
DeclareInteger harorat
Inputharorat
harorat < 10
Output"Kurtka shart emas"
Output"Kurtka kiying!"
Output"Yaxshi kun!"
End
Qisqa If (faqat True tarmoq)
Main
DeclareInteger ball
Inputball
ball == 100
Output"🏆 Maksimal ball!"
Output"Ballingiz: " & ball
End

Ikkinchi sxemada False tarmoq bo'sh: shart bajarilmasa, dastur shunchaki davom etadi. "Yaxshi kun!" va "Ballingiz" — If'dan keyin turibdi, shuning uchun har doim bajariladi.

#Klassik masalalar

9-loyiha: juft yoki toq

Son 2 ga qoldiqsiz bo'linsa — juft. Qoldiq % amalidan foydalanamiz (18-mavzu).

juft_toq.fprg
Main
DeclareInteger son
Output"Son kiriting:"
Inputson
son % 2 == 0
Outputson & " — toq"
Outputson & " — juft"
End
Python
son = int(input("Son kiriting: "))
if son % 2 == 0:
    print(son, "— juft")
else:
    print(son, "— toq")
Testson % 2Natija
140juft ✅

00juft ✅ (0 — juft son)
-3-1toq ✅ (≠ 0)

E'tibor bering: shart son % 2 == 1 bo'lsa, manfiy toq sonlarda xato ishlaydi (-3 % 2 = -1). == 0 bilan tekshirish ishonchliroq.

Musbat, manfiy yoki nol — ichma-ich If

Uch holat bor, bitta If esa faqat ikki yo'l beradi. Yechim — If ichiga yana If qo'yish (ichma-ich shart):

ishora.fprg
Main
DeclareReal x
Inputx
x > 0
x < 0
Output"Nol"
Output"Manfiy"
Output"Musbat"
End
Python — elif bilan
x = float(input())
if x > 0:
    print("Musbat")
elif x < 0:
    print("Manfiy")
else:
    print("Nol")

Mantiq: birinchi If "musbatmi?" deb so'raydi. Yo'q bo'lsa — qolgan ikki holat uchun ikkinchi If. N ta holat uchun N − 1 ta If kerak.

10-loyiha: bahoni aniqlash — "zinapoya"

Foiz bo'yicha baho: 86–100 → 5 (a'lo), 71–85 → 4 (yaxshi), 56–70 → 3 (qoniqarli), 0–55 → 2 (qoniqarsiz). Shartlarni yuqoridan pastga tekshiramiz — har bir keyingi If'ga yetib kelgan bo'lsak, oldingi shartlar allaqachon yolg'on bo'lgan:

baho.fprg
Main
DeclareInteger f
Inputf
f >= 86
f >= 71
f >= 56
Output"2"
Output"3"
Output"4"
Output"5"
End

Nega f >= 71 and f <= 85 yozmadik? Chunki ikkinchi If'ga faqat f >= 86 yolg'on bo'lganda kelamiz — demak, f < 86 allaqachon ma'lum. Zinapoya usuli shartlarni qisqa va xatosiz qiladi.

TestKutilgan
100, 865, 5 (chegara!)
85, 714, 4
70, 563, 3
55, 02, 2
Tartib muhim!Agar avval f >= 56 ni tekshirsangiz, 95 ball ham "3" oladi — chunki 95 >= 56 rost. Zinapoyada eng qattiq shartdan boshlang.

#Mantiqiy operatorlar: AND, OR, NOT

Ba'zan bitta shart yetmaydi: "yoshi 7 dan 18 gacha", "shanba yoki yakshanba". Shartlarni mantiqiy operatorlar bilan birlashtiramiz:

Namuna: lagerga qabul

Yozgi IT-lagerga 12–16 yoshli va CS bahosi kamida 4 bo'lgan o'quvchilar qabul qilinadi. Yoki olimpiada g'olibi bo'lsa — yoshidan qat'i nazar.

Klassik xatoyosh >= 12 and <= 16 yoki 12 <= yosh <= 16 — xato! Har bir taqqoslash to'liq yoziladi: yosh >= 12 and yosh <= 16. Yana bir xato: kun == 6 or 7 → to'g'risi kun == 6 or kun == 7.

#2-dars: amaliy topshiriqlar

  1. Kattasi: ikki son kiritiladi — kattasini chiqaring; teng bo'lsa "Teng" deb yozing.
  2. Uchtadan kattasi: uch son — eng kattasi (maslahat: a >= b and a >= c).
  3. Kabisa yili: yil 4 ga bo'linsa va 100 ga bo'linmasa, yoki 400 ga bo'linsa — kabisa. Test: 2024 ✅, 1900 ❌, 2000 ✅.
  4. Uchburchak mavjudmi? Har bir tomon qolgan ikkitasi yig'indisidan kichik bo'lsa. Test: 3,4,5 ✅; 1,2,10 ❌.
  5. Kirish narxi: 7 yoshgacha — bepul, 7–17 — 10 000, 18–59 — 25 000, 60+ — 5 000 so'm.
  6. Mini test (16-loyiha boshlanishi): 3 ta savol bering, har bir to'g'ri javob uchun ball = ball + 1, oxirida natija.

#Ko'p uchraydigan xatolar

  • ❌ True va False tarmoqlarini adashtirish → ✅ Shartni ovoz chiqarib o'qing: "Son juftmi? — Ha (True) → juft".
  • ❌ Zinapoyada tartibni buzish → ✅ Eng katta chegaradan boshlang.
  • ❌ > o'rniga >= (yoki aksincha) → ✅ Chegaraviy qiymat bilan test.
  • ❌ Matnni taqqoslashda katta-kichik harf → ✅ "Ha" != "ha"; foydalanuvchiga aniq ko'rsatma bering.
  • ❌ If'dan keyingi umumiy blokni ikkala tarmoqqa takror qo'yish → ✅ Umumiy qism If'dan keyin, bir marta.

#O'zingizni tekshiring

x = 15 bo'lsa, x > 10 and x < 15 natijasi?

  1. true
  2. false
  3. 15
  4. Xato

15 < 15 yolg'on → AND ham yolg'on.

Son 3 ga ham, 5 ga ham bo'linishini tekshiruvchi shart?

  1. n % 3 == 0 or n % 5 == 0
  2. n / 15
  3. n % 3 == 5
  4. n % 3 == 0 and n % 5 == 0

"Ham ... ham" — AND.

4 ta holatni ajratish uchun kamida nechta If kerak?

  1. 3
  2. 4
  3. 2
  4. 1

N holat — N−1 ta If.

not (5 > 3) = ?

  1. true
  2. 5
  3. false
  4. 3

5 > 3 rost, NOT uni yolg'onga aylantiradi.

Baho zinapoyasida birinchi qaysi shart tekshirilishi kerak?

  1. f >= 56
  2. f >= 86
  3. f >= 71
  4. f < 56

Eng qattiq shartdan boshlanadi, aks holda 95 ham "3" oladi.
