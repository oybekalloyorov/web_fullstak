Loyiha: Flowgorithm'da "Mini bankomat tizimi"

Mini bankomat loyihasining maqsadi va ishlash mantig'i; menyu: balansni ko'rish, pul yechish, pul kiritish, chiqish; balans o'zgaruvchisi bilan ishlash; If orqali tanlovni va yetarli balansni tekshirish; While sikli bilan menyuni qayta ko'rsatish; PIN-kod, limit va tarix kabi kengaytmalar; test qilish.

2 dars · amaliy
📄 PDF yuklab olish

🎯 Bu loyihada nimani o'rganasiz

  • Menyu asosidagi dastur (menu-driven program) qurishni;
  • Dastur davomida holatni (balans) saqlash va o'zgartirishni;
  • Biznes-qoidalarni tekshirishni: yetarli mablag', musbat summa, karrali summa;
  • Sikl + ichma-ich shartlarni katta loyihada birlashtirishni;
  • Murakkab dasturni bosqichma-bosqich qurish va test qilishni.
Loyiha rejasi (2 dars)1-dars: rejalashtirish, menyu sikli, balans va pul kiritish. 2-dars: pul yechish (tekshiruvlar bilan), kengaytmalar (PIN, limit, statistika), test va himoya.

#1-bosqich: bankomat qanday ishlaydi?

Haqiqiy bankomatni eslang: karta qo'yasiz → PIN → menyu → amal → yana menyu → ... → "Kartani oling". Dastur foydalanuvchi "Chiqish"ni tanlaguncha menyuni qayta-qayta ko'rsatadi.

1 — BalansJoriy balansni ko'rsatadi—
2 — Pul yechishbalans = balans - summaSumma > 0; summa ≤ balans; 1000 ga karrali
3 — Pul kiritishbalans = balans + summaSumma > 0
4 — ChiqishSiklni tugatadi—
boshqa"Noto'g'ri tanlov"—
O'zgaruvchiTuriVazifasi
balansIntegerHisobdagi pul — dasturning holati; boshida masalan 500 000
tanlovIntegerMenyu bandi
summaIntegerYechiladigan / kiritiladigan miqdor
O'xshatish: hamyonbalans — hamyon. U dastur boshida bir marta to'ldiriladi va sikldan tashqarida e'lon qilinadi, shuning uchun menyu har safar qayta ko'rsatilganda ham ichidagi pul "esda qoladi". Agar uni sikl ichida balans = 500000 desangiz — har safar hamyon "sehrli" tarzda qayta to'lib qoladi.

#2-bosqich: menyu sikli

Menyu sikli uchun While ishlatamiz: tanlov != 4 ekan — davom et. Boshida tanlov = 0 qilib qo'yamiz, shunda sikl birinchi marta albatta boshlanadi.

bankomat.fprg — umumiy tuzilma
Main
DeclareInteger balans, summa
DeclareInteger tanlov
Assignbalans = 500000
Assigntanlov = 0
While tanlov != 4
Output"1-Balans 2-Yechish 3-Kiritish 4-Chiqish"
Inputtanlov

tanlov != 4

3KIRITISH

End

YECHISH va KIRITISH — hozircha "qora quti". Ularni alohida quramiz va keyin tegishli tarmoqqa joylaymiz. Bu — yuqoridan pastga loyihalash: avval umumiy skelet, keyin tafsilotlar.

#3-bosqich: pul kiritish

KIRITISH bloki
Output"Summa:"
Inputsumma
summa > 0
Output"Summa musbat bo'lsin"
Assignbalans = balans + summa
Output"✅ Yangi balans: " & balans

Nega summa > 0 tekshiruvi? Agar foydalanuvchi -100000 kiritsa, balans + (-100000) — bu aslida yechish, lekin hech qanday tekshiruvsiz! Bunday "teshik" haqiqiy bank tizimida jiddiy xavfsizlik zaifligi bo'lardi.

#4-bosqich: pul yechish — eng muhim qism

Uchta qoida tekshiriladi, har biri o'z xabari bilan:

YECHISH bloki
Output"Summa:"
Inputsumma
summa <= 0
summa % 1000 != 0
summa > balans
Assignbalans = balans - summa
Output"✅ Oling: " & summa
Output"Yetarli emas"
Output"Karrali emas"
Output"Xato summa"
"Himoya devorlari" usuliAvval barcha xato holatlarni birma-bir chiqarib tashlaymiz; har bir devordan o'tgan summa tobora "toza" bo'lib boradi. Eng oxirgi False tarmoqqa faqat barcha tekshiruvdan o'tgan summa yetib keladi — faqat o'sha yerda balansni o'zgartiramiz. Bu pattern professional dasturlashda "guard clauses" deyiladi.

<script>
let balans = 500000, faol = true;
const ekran = document.getElementById('ekran');
function amal(tanlov) {
  if (!faol) return;
  const summa = Number(document.getElementById('summa').value);
  if (tanlov === 1) ekran.textContent = 'Balans: ' + balans.toLocaleString() + " so'm";
  else if (tanlov === 2) {
    if (summa <= 0) ekran.textContent = "❌ Noto'g'ri summa";
    else if (summa % 1000 !== 0) ekran.textContent = "❌ 1000 ga karrali bo'lsin";
    else if (summa > balans) ekran.textContent = "❌ Mablag' yetarli emas";
    else { balans = balans - summa; ekran.textContent = '✅ Oling: ' + summa.toLocaleString() + " so'm"; }
  } else if (tanlov === 3) {
    if (summa > 0) { balans = balans + summa; ekran.textContent = '✅ Yangi balans: ' + balans.toLocaleString(); }
    else ekran.textContent = "❌ Summa musbat bo'lsin";
  } else { faol = false; ekran.textContent = 'Kartangizni oling. Xayr! 👋'; }
}
</script>

#Kengaytmalar (yuqori ball uchun)

  1. PIN-kod: menyudan oldin PIN so'rang; 3 marta xato — "Karta bloklandi" (25-loyiha mantiqi).
  2. Kunlik limit: yechildi o'zgaruvchisi; bir kunda 2 000 000 dan ortiq yechib bo'lmaydi.
  3. Komissiya: yechishda 1%: balans = balans - summa - Int(summa / 100) (yetarlilikni ham shu bilan tekshiring!).
  4. Statistika: chiqishda nechta amal bajarilgani, jami yechilgan va kiritilgan summa.
  5. Telefon to'lovi: 5-menyu bandi — raqam (String) va summa.

#Ko'p uchraydigan xatolar

  • ❌ balans = 500000 sikl ichida → ✅ Sikldan oldin; aks holda balans "tiklanib" qoladi.
  • ❌ tanlov ga boshlang'ich qiymat bermaslik → ✅ While shartida "has no value" xatosi; tanlov = 0.
  • ❌ Yetarlilikni tekshirmasdan yechish → ✅ Balans manfiy bo'lib ketadi.
  • ❌ summa >= balans → ✅ Aynan balansga teng summani yechish mumkin bo'lishi kerak: xato sharti summa > balans.
  • ❌ 4 tanlanganda ham "Noto'g'ri tanlov" chiqishi → ✅ Oxirgi If'da tanlov != 4.

#O'zingizni tekshiring

Balans o'zgaruvchisi qayerda boshlang'ich qiymat olishi kerak?

  1. Menyu sikli ichida
  2. Menyu siklidan oldin
  3. Pul yechish blokida
  4. Chiqishda

Holat butun dastur davomida saqlanishi kerak.

Balans 300 000. Qaysi summani yechib bo'ladi?

  1. 350 000
  2. -50 000
  3. 120 500
  4. 300 000

Musbat, 1000 ga karrali va balansdan oshmaydi.

Menyu foydalanuvchi "4" ni tanlaguncha takrorlanishi uchun shart?

  1. While tanlov != 4
  2. While tanlov == 4
  3. For tanlov = 1 to 4
  4. If tanlov == 4

"4 emas ekan — davom et".
