#Dastur mantiqi: Kirish → Qayta ishlash → Chiqish

Kalkulyatordan tortib Telegram'gacha — har qanday dastur uch qismdan iborat. Bu IPO modeli (Input — Process — Output):

⌨️ Kirish (Input)ma'lumot olish
→
⚙️ Qayta ishlash (Process)hisoblash, tekshirish
→
🖥️ Chiqish (Output)natijani ko'rsatish
DasturKirishQayta ishlashChiqish
Kalkulyator2 son, amalHisoblashNatija
Ob-havo ilovasiShahar, sanaServerdan ma'lumot olishHarorat, ikonka
NavigatorQayerdan, qayergaEng qisqa yo'lni topishXarita, vaqt
Kundalik.comLogin, parolTekshirish, baholarni topishBaholar jadvali
Dastur yozishdan oldin uchta savol 1) Nima beriladi? (kirish) 2) Nima topish kerak? (chiqish) 3) Qanday topiladi? (formula, qoida). Bu savollarga javob bergach, blok-sxema o'z-o'zidan chiziladi.

#Namuna 1: kvadrat yuzasi va perimetri

Masala: kvadrat tomoni berilgan. Yuza va perimetrni toping. Kirish: a. Chiqish: S, P. Formula: S = a × a, P = 4 × a.

kvadrat.fprg
Main
DeclareReal a, s, p
Output"Tomonni kiriting:"
Inputa
Assigns = a * a
Assignp = 4 * a
Output"Yuza: " & s
Output"Perimetr: " & p
End

Tahlil (IPO):

  • Kirish: 1 ta Input — a.
  • Qayta ishlash: 2 ta Assign — formulalar.
  • Chiqish: 2 ta Output.
Test: a = 5
Tomonni kiriting:
5
Yuza: 25
Perimetr: 20

Qo'lda tekshiramiz: 5 × 5 = 25 ✅, 4 × 5 = 20 ✅.

#Bitta sxema — ko'p til

Flowgorithm'da Source Code Viewer ni oching va tilni tanlang. Xuddi shu "kvadrat" dasturi:

Python
a = float(input("Tomonni kiriting: "))
s = a * a
p = 4 * a
print("Yuza: " + str(s))
print("Perimetr: " + str(p))
C++
#include <iostream>
using namespace std;

int main() {
    double a, s, p;
    cout << "Tomonni kiriting:" << endl;
    cin >> a;
    s = a * a;
    p = 4 * a;
    cout << "Yuza: " << s << endl;
    cout << "Perimetr: " << p << endl;
    return 0;
}
JavaScript
let a = Number(prompt("Tomonni kiriting:"));
let s = a * a;
let p = 4 * a;
console.log("Yuza: " + s);
console.log("Perimetr: " + p);

Xulosa: tillarning "grammatikasi" (sintaksisi) har xil, lekin mantiq bir xil: kiritish → ikkita hisoblash → ikkita chiqarish. Mantiqni o'rgangan odam istalgan tilni tez o'rganadi.

#Namuna 2 (11-loyiha): yoshni hisoblash

Masala: foydalanuvchi tug'ilgan yilini kiritadi, dastur uning yoshini va 18 yoshga to'lishiga necha yil qolganini chiqaradi.

yosh.fprg
Main
DeclareInteger yil, joriy, yosh
Assignjoriy = 2026
Output"Tug'ilgan yilingiz?"
Inputyil
Assignyosh = joriy - yil
Output"Siz " & yosh & " yoshdasiz"
yosh < 18
Output"Siz kattasiz!"
Output"18 ga " & (18 - yosh) & " yil qoldi"
End
Test: 2012
Tug'ilgan yilingiz?
2012
Siz 14 yoshdasiz
18 ga 4 yil qoldi

Tahlil:

  • joriy — konstanta vazifasini bajaradi: yil o'zgarsa, faqat bitta joyni tuzatamiz.
  • Bu yerda yangi element — If: dastur qaror qabul qiladi (20-mavzu).
  • (18 - yosh) — chiqarish ichida ham hisoblash mumkin.
Aniqroq variantFlowgorithm'da joriy yilni avtomatik olish uchun joriy = ... o'rniga qo'lda kiritish ham mumkin. Tug'ilgan oy hali kelmagan bo'lsa, yosh 1 ga kam — buni hisobga olish uchun oyni ham so'rash kerak. Sinab ko'ring!

#Dasturni tahlil qilish (o'qish) mashqi

Quyidagi sxema nima qiladi? Avval o'zingiz o'ylang, keyin javobni oching.

sirli.fprg
Main
DeclareInteger x, y, t
Inputx
Inputy
Assignt = x
Assignx = y
Assigny = t
Outputx & " " & y
End
Javob

Dastur ikki o'zgaruvchining qiymatini almashtiradi (swap). x = 3, y = 8 kiritilsa → 8 3 chiqadi. t — yordamchi "bo'sh stakan": ikki stakandagi sharbatni almashtirish uchun uchinchi stakan kerak bo'lganidek.

Qadamxyt
Input'lardan keyin38—
t = x383
x = y883
y = t833

Bunday jadval trassirovka jadvali deyiladi — dasturni qog'ozda "qo'lda bajarish". Variable Watch aynan shuni avtomatik qiladi.
