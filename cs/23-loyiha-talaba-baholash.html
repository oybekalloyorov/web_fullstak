Loyiha: Flowgorithm'da "Talaba baholash tizimi"

Loyiha maqsadi va baholash mezonlarini aniqlash; davomat, uy vazifasi, amaliy ish va test ballarini kiritish; noto'g'ri ball kiritilishini Do sikli bilan tekshirish; umumiy ball va foizni hisoblash; If zinapoyasi bilan bahoni aniqlash: a'lo, yaxshi, qoniqarli, qoniqarsiz; butun sinf uchun statistika; test qilish.

2 dars · amaliy
📄 PDF yuklab olish

🎯 Bu loyihada nimani o'rganasiz

  • Real hayotiy tizim uchun baholash mezonlarini loyihalashni;
  • Har bir kiritishni tekshirish (validatsiya) — noto'g'ri ballni qabul qilmaslikni;
  • Umumiy ball, foiz va bahoni hisoblashni;
  • Bitta o'quvchidan butun sinfga kengaytirish: sikl, hisoblagichlar, o'rtacha;
  • Avvalgi mavzulardagi barcha bilimlarni (o'zgaruvchi, shart, sikl) bitta loyihada birlashtirishni.
Loyiha rejasi (2 dars)1-dars: mezonlar, bitta o'quvchi uchun tizim (kiritish, tekshirish, hisob, baho). 2-dars: butun sinf uchun statistika, test, GitHub va himoya.

Nega foiz?Hozir maksimal ball 100 — foiz va ball bir xil. Lekin mezonlar o'zgarsa (masalan, maksimal 160 — bizning kurs kabi: 40 + 20 + 100), foiz = jami / maks * 100 formulasi bahoni to'g'ri saqlab qoladi. Dasturni moslashuvchan qilish uchun maks ni alohida o'zgaruvchida saqlaymiz.

#Python'da

baholash.py
def ball_ol(nom, maks):
    """Ballni 0..maks oralig'ida bo'lguncha qayta so'raydi."""
    while True:
        x = int(input(f"{nom} (0–{maks}): "))
        if 0 <= x <= maks:
            return x
        print("❌ Noto'g'ri! Qayta kiriting.")

ism = input("Ism: ")
jami = (ball_ol("Davomat", 10) + ball_ol("Uyga vazifa", 20)
        + ball_ol("Amaliy ish", 30) + ball_ol("Test", 40))
foiz = jami / 100 * 100
if foiz >= 86:
    baho = "5 — A'lo"
elif foiz >= 71:
    baho = "4 — Yaxshi"
elif foiz >= 56:
    baho = "3 — Qoniqarli"
else:
    baho = "2 — Qoniqarsiz"
print(f"{ism}: {jami}/100 ({foiz:.0f}%) → {baho}")

Python'da takrorlanuvchi kiritish funksiyaga (ball_ol) chiqarildi — bir marta yozib, 4 marta chaqiramiz. Flowgorithm'da ham funksiyalar bor (Program → Add Function) — qiziqqanlar uchun bonus topshiriq!

#Ko'p uchraydigan xatolar

  • ❌ Do sharti noto'g'ri: uy >= 0 and uy <= 20 → ✅ Do noto'g'ri holatda takrorlanadi: uy < 0 or uy > 20.
  • ❌ foiz ni Integer qilish → ✅ Real (bo'lish natijasi).
  • ❌ Statistika o'zgaruvchilarini sikl ichida nolga tenglash → ✅ Sikldan oldin.
  • ❌ Sinf o'rtachasini yigindi / 25 deb qotirib qo'yish → ✅ yigindi / n.

#O'zingizni tekshiring
