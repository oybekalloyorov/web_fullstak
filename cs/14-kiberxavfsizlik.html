Kiberxavfsizlik va shaxsiy ma'lumotlarni himoya qilish asoslari

Kiberxavfsizlik tushunchasi va asosiy xavf turlari; shaxsiy ma'lumotlar, raqamli iz va maxfiylik; kuchli parol, parol menejeri va 2FA; phishing, zararli havolalar va ijtimoiy muhandislik; qurilma, internet va bulutdan xavfsiz foydalanish. Interaktiv parol tekshirgich.

1 dars · amaliy
📄 PDF yuklab olish

🎯 Bu darsda nimani o'rganasiz

  • Kiberxavfsizlikning uch ustuni (CIA) va asosiy xavf turlarini;
  • Qaysi ma'lumotlar shaxsiy ekanini va ularni qanday himoya qilishni;
  • Parol kuchini matematik tushunishni va parol menejeri, 2FA bilan akkauntni himoyalashni;
  • Phishing xatni 7 belgisi bo'yicha tanishni;
  • Ijtimoiy muhandislik hiylalarini va ulardan saqlanishni.
Eslatma6-mavzuda viruslar, antivirus va parol asoslarini ko'rdik. Bu darsda odam va akkaunt xavfsizligiga chuqurroq kiramiz — chunki hujumlarning 80% dan ortig'i texnikani emas, aynan odamni aldashdan boshlanadi.

#Kiberxavfsizlik nima?

Kiberxavfsizlik — kompyuterlar, tarmoqlar, dasturlar va ma'lumotlarni ruxsatsiz kirish, o'g'irlash, buzish va o'chirishdan himoya qilish. U uchta maqsadga xizmat qiladi — CIA triadasi:

UstunMa'nosiBuzilsa...
🔒 Confidentiality — maxfiylikMa'lumotni faqat ruxsati borlar ko'radiYozishmalaringiz oshkor bo'ladi
✅ Integrity — butunlikMa'lumot ruxsatsiz o'zgartirilmaydiKundalikdagi baho "o'zgarib qoladi"
🟢 Availability — mavjudlikKerak bo'lganda tizim ishlaydiImtihon kuni sayt ochilmaydi (DDoS)

#Shaxsiy ma'lumotlar va maxfiylik

Shaxsiy ma'lumot — sizni aniqlash mumkin bo'lgan har qanday ma'lumot. O'zbekistonda bu "Shaxsga doir ma'lumotlar to'g'risida"gi qonun bilan himoyalanadi.

Lekin yovuz niyatli odam bo'laklarni yig'sa, sizning qayerda o'qishingiz, qayerda yashashingiz va uy qachon bo'sh qolishini biladi.

Maxfiylik sozlamalari (Telegram, Instagram)

  • Telefon raqami: "Hech kim" yoki "Kontaktlarim".
  • Profil: yopiq akkaunt; obunachilarni tasdiqlab qo'shish.
  • Geolokatsiya: rasmlarga joylashuv qo'shishni o'chiring; "jonli joylashuv"ni faqat oila bilan.
  • Ilovalar ruxsatlari: fonar ilovasiga kontaktlar va mikrofon nima uchun kerak? Sozlamalar → Ilovalar → Ruxsatlar.

#Kuchli parol — matematika bilan

Xaker parolni taxmin qilish uchun kompyuterda soniyasiga milliardlab variantni sinaydi. Variantlar soni = belgilar_soniuzunlik.

ParolBelgilar to'plamiVariantlarTaxminiy buzish vaqti*
12345610 (raqam)106 = 1 millionBir zumda (eng mashhur parol!)
ali201036~78 milliardSoniyalar — lug'atda bor
Kt7#mQ2p~94~6 × 1015Bir necha soat–kun
Olma-Kitob-Daryo-77!~94~1039Milliardlab yil

* soniyasiga 10 milliard urinish deb hisoblanganda.

Xulosa: uzunlik — eng muhimHar bir qo'shimcha belgi variantlarni ~94 marta oshiradi. Eng yaxshi usul — parol-ibora (passphrase): 4 ta tasodifiy so'z + raqam + belgi: Bulut-Tarvuz-Velosiped-48!. Eslash oson, buzish deyarli imkonsiz.

Interaktiv: parolingiz qanchalik kuchli?

Quyidagi tekshirgichda turli parollarni sinab ko'ring (haqiqiy parolingizni yozmang!). Bu 3-loyiha — "Kuchli parol generatori" uchun ham namuna.

HTML
<input id="p" placeholder="Parolni yozing..." style="font:18px monospace;padding:8px;width:100%;box-sizing:border-box">
<div id="bar" style="height:10px;border-radius:5px;margin:10px 0;background:#ddd"></div>
<div id="info" style="font:15px sans-serif;line-height:1.6"></div>
<button id="gen" style="font:15px sans-serif;padding:8px 14px;margin-top:6px">🎲 Kuchli parol yaratish</button>
<script>
const p = document.getElementById('p'), bar = document.getElementById('bar'), info = document.getElementById('info');
function tekshir() {
  const s = p.value;
  let to = 0;                                   // belgilar to'plami hajmi
  if (/[a-z]/.test(s)) to += 26;
  if (/[A-Z]/.test(s)) to += 26;
  if (/[0-9]/.test(s)) to += 10;
  if (/[^a-zA-Z0-9]/.test(s)) to += 32;
  const bit = s.length * Math.log2(to || 1);    // entropiya (bit)
  const soniya = Math.pow(2, bit) / 1e10;       // 10 mlrd urinish/soniya
  const vaqt = soniya < 1 ? 'bir zumda' : soniya < 3600 ? Math.round(soniya / 60) + ' daqiqa'
    : soniya < 3.15e7 ? Math.round(soniya / 86400) + ' kun' : (soniya / 3.15e7).toExponential(1) + ' yil';
  const rang = bit < 40 ? '#dc2626' : bit < 60 ? '#f59e0b' : '#16a34a';
  bar.style.background = 'linear-gradient(90deg,' + rang + ' ' + Math.min(100, bit) + '%, #ddd 0)';
  info.innerHTML = 'Uzunlik: <b>' + s.length + '</b> · To\'plam: <b>' + to + '</b> belgi · Entropiya: <b>' + Math.round(bit) +
    ' bit</b><br>Taxminiy buzish vaqti: <b style="color:' + rang + '">' + vaqt + '</b>';
}
document.getElementById('gen').onclick = () => {
  const sozlar = ['Olma','Bulut','Daryo','Kitob','Tarvuz','Yulduz','Velosiped','Chinor','Lola','Kompas','Shamol','Qalam'];
  const t = () => sozlar[Math.floor(Math.random() * sozlar.length)];
  p.value = t() + '-' + t() + '-' + t() + '-' + Math.floor(10 + Math.random() * 90) + '!';
  tekshir();
};
p.oninput = tekshir; tekshir();
</script>

Parol qoidalari

  1. Uzun: kamida 12 belgi, yaxshisi 16+.
  2. Noyob: har bir sayt uchun boshqa parol. Bitta sayt buzilsa — qolganlari xavfsiz qoladi.
  3. Shaxsiy emas: ism, tug'ilgan yil, uy hayvoni nomi, qwerty — yo'q.
  4. Parol menejeri: Bitwarden, Google Password Manager — yuzlab parolni o'zi saqlaydi, siz faqat bitta bosh parolni eslaysiz.
  5. Hech kimga aytmang — eng yaqin do'stga ham. O'qituvchi, bank, Telegram xodimi hech qachon parol so'ramaydi.

#Ikki bosqichli tasdiqlash (2FA)

2FA — kirish uchun ikki xil "kalit" kerak: bilgan narsangiz (parol) + sizdagi narsa (telefon). Parol o'g'irlansa ham, xaker telefoningizsiz kira olmaydi.

#Ijtimoiy muhandislik

Ijtimoiy muhandislik — texnikani emas, odam psixologiyasini "buzish". Hujumchi o'zini kimdir qilib ko'rsatadi va hissiyotlardan foydalanadi.

HiylaMisolTo'g'ri javob
Obro' (o'zini rasmiy shaxs qilib ko'rsatish)"Men bank xodimiman, kartangiz bloklandi, SMS-kodni ayting"Go'shakni qo'ying, bankning rasmiy raqamiga o'zingiz qo'ng'iroq qiling
Shoshilinch"Do'stingman, telefonim o'chdi, tezda 50 ming tashlab yubor!"Do'stga boshqa yo'l bilan (qo'ng'iroq) tekshiring
Ochko'zlik"Siz iPhone yutdingiz! Faqat yetkazish uchun 30 ming to'lang"Qatnashmagan konkursda yutib bo'lmaydi
Qiziqish"Bu videoda sen borsan 😱 👉 havola"Bosmang, yuboruvchidan so'rang
Yordam so'rash"Akkauntimga kod sening raqamingga keldi, aytib yuborasanmi?"Bu sizning akkauntingizni o'g'irlash usuli!
Oltin qoida: "To'xta — o'yla — tekshir"Har qanday xabar sizni shoshiltirsa va parol, kod yoki pul so'rasa — bu 99% firibgarlik. To'xtang, kattalardan maslahat so'rang, rasmiy kanal orqali tekshiring.

#Amaliy mashg'ulot

  1. Akkaunt auditi: Telegram'da Sozlamalar → Qurilmalar — barcha faol seanslarni ko'ring, notanishlarini yakunlang.
  2. Telegram'da ikki bosqichli tasdiqlashni yoqing (ota-ona bilan birga, zaxira email bilan).
  3. Google akkauntda myaccount.google.com/security → Xavfsizlik tekshiruvini o'tkazing.
  4. Yuqoridagi tekshirgich bilan 5 xil parolni sinab, natijalarni jadvalga yozing: qaysi omil eng ko'p ta'sir qildi?
  5. Juftlikda: biringiz phishing xat "yozadi" (o'quv maqsadida, qog'ozda), ikkinchisi 7 ta qizil bayroqni topadi.

#Ko'p uchraydigan xatolar

  • ❌ "Mendan nima olishadi, men oddiy o'quvchiman" → ✅ Akkauntingiz orqali do'stlaringizdan pul so'rashadi, spam tarqatishadi.
  • ❌ Barcha saytlarga bitta parol → ✅ Bitta sizish — hamma akkaunt ketadi.
  • ❌ SMS-kodni "Telegram xodimiga" aytish → ✅ Kod — kalit. Uni hech kim so'ramaydi.
  • ❌ "HTTPS bor — demak, sayt haqiqiy" → ✅ Phishing saytlarda ham 🔒 bo'ladi; domen nomini o'qing.

"Do'stingiz" yozdi: "Raqamingga kod keldi, aytib yuborgin". Nima qilasiz?

  1. Darhol aytaman — do'stim-ku
  2. Aytmayman; bu mening akkauntimni o'g'irlash usuli, do'stga qo'ng'iroq qilib tekshiraman

  4. Yarmini aytaman

Kod sizning akkauntingiz uchun keladi. Do'stning akkaunti allaqachon buzilgan bo'lishi mumkin.

2FA nima uchun foydali?

  1. Parol o'g'irlansa ham, ikkinchi kalitsiz (telefon) kirib bo'lmaydi
  2. Internetni tezlashtiradi
  3. Parolni esdan chiqarmaslikka yordam beradi
  4. Virusni o'chiradi

Bilgan narsa + sizdagi narsa.

Qaysi biri phishing belgisi EMAS?

  1. Shoshiltirish
  2. G'alati yuboruvchi domeni
  3. Parol so'rash
  4. Xatda ismingiz to'g'ri yozilgani va hech narsa so'ralmagani
