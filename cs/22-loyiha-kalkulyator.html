Loyiha: Flowgorithm'da "Kalkulyator"

Kalkulyator loyihasining maqsadi va ishlash mantig'ini rejalashtirish; foydalanuvchidan ikki son va amal turini kiritish; If bloklari orqali tanlangan amalni aniqlash; qo'shish, ayirish, ko'paytirish, bo'lish; nolga bo'lish va noto'g'ri amal xatolarini tekshirish; menyu sikli bilan takroriy hisoblash; test rejasi va loyiha himoyasi.

2 dars · amaliy
📄 PDF yuklab olish

🎯 Bu loyihada nimani o'rganasiz

  • Loyihani rejalashtirish: maqsad, kirish, chiqish, cheklovlar;
  • Bir nechta If bilan foydalanuvchi tanlovini aniqlashni;
  • Xatolarni oldindan ko'rish: nolga bo'lish, noto'g'ri amal;
  • Kalkulyatorni sikl bilan qayta-qayta ishlaydigan qilishni;
  • Loyihani test qilish va taqdim etishni.
Loyiha rejasi (2 dars)1-dars: rejalashtirish, 1-versiya (4 amal) va 2-versiya (xatolarni tekshirish). 2-dars: 3-versiya (menyu sikli), qo'shimcha amallar, test jadvali, GitHub'ga joylash va himoya.

#1-bosqich: rejalashtirish

Professional dasturchilar kod yozishdan oldin texnik topshiriq tuzadi. Biz ham shunday qilamiz:

SavolJavob
MaqsadIkki son ustida 4 ta arifmetik amalni bajaruvchi dastur
Kirisha (Real), b (Real), amal (String: + - * /)
Chiqisha amal b = natija, masalan 12 / 4 = 3

O'xshatish: kassirKassirga ikkita narsa beriladi — pul va buyurtma. U buyurtmaga qarab (choy, qahva, sharbat) tegishli ishni bajaradi. Menyuda yo'q narsani so'rasangiz — "Bunday mahsulot yo'q" deydi, jim turmaydi. Bizning kalkulyator ham shunday bo'lishi kerak.

#2-bosqich: 1-versiya — to'rt amal

Amalni tanlash uchun "zinapoya" usulidagi If'lar (20-mavzu): + mi? Yo'q — - mi? Yo'q — * mi? ...

Assignnatija = a - b
Assignnatija = a + b

Muammolar: (1) b = 0 va / — dastur xato bilan to'xtaydi. (2) Foydalanuvchi x yozsa — oxirgi False tarmoq bo'lishni bajaradi! Chunki "+ emas, − emas, * emas" — bu hali "/" degani emas. Tuzatamiz.

#3-bosqich: 2-versiya — xatolarni tekshirish

Ikkita yangi qoida: bo'lishdan oldin b != 0 ni tekshir; oxirgi False tarmoqda "noma'lum amal" xabari. Natija hisoblanganini bilish uchun Boolean xato bayrog'i (flag) ishlatamiz:

kalkulyator_v2.fprg — bo'lish qismi va bayroq

Bayroq (flag) usuliBoolean o'zgaruvchi — "bayroq": boshida tushirilgan (false), muammo bo'lsa ko'tariladi (true). Oxirida bayroqqa qarab natijani chiqaramiz yoki chiqarmaymiz. Bu usul 23–25-loyihalarda ham kerak bo'ladi.

#4-bosqich: 3-versiya — menyu va sikl

Haqiqiy kalkulyator bir hisobdan keyin yopilib qolmaydi. Dasturni Do sikliga o'raymiz: foydalanuvchi "ha" desa — davom etadi.

Flowgorithm'da har bir Input bloki bitta o'zgaruvchi oladi — sxemada qisqartirib bitta blokda ko'rsatildi; dasturingizda a, amal, b uchun alohida Output + Input juftliklarini qo'ying.

#To'liq Python versiyasi

Flowgorithm'ning Source Code Viewer'i bergan kodni soddalashtirsak, shunday bo'ladi:

kalkulyator.py
javob = "ha"
while javob == "ha":
    print("=== KALKULYATOR ===")
    a = float(input("1-son: "))
    amal = input("Amal (+ - * /): ")
    b = float(input("2-son: "))
    xato = False
    if amal == "+":
        natija = a + b
    elif amal == "-":
        natija = a - b
    elif amal == "*":
        natija = a * b
    elif amal == "/":
        if b == 0:
            print("Nolga bo'lish mumkin emas!")
            xato = True
        else:
            natija = a / b
    else:
        print("Noma'lum amal:", amal)
        xato = True
    if not xato:
        print(a, amal, b, "=", natija)
    javob = input("Yana? (ha/yo'q) ")
print("Xayr! 👋")

<script>
document.getElementById('hisob').onclick = () => {
  const a = Number(document.getElementById('a').value), b = Number(document.getElementById('b').value);
  const amal = document.getElementById('amal').value;
  let natija, xato = false;
  if (amal === '+') natija = a + b;
  else if (amal === '-') natija = a - b;
  else if (amal === '*') natija = a * b;
  else if (amal === '/') { if (b === 0) { xato = 'Nolga bo\'lish mumkin emas!'; } else natija = a / b; }
  else if (amal === '^') natija = a ** b;
  else if (amal === '%') { if (b === 0) xato = 'Nolga bo\'lish mumkin emas!'; else natija = a % b; }
  document.getElementById('natija').textContent = xato ? '⚠️ ' + xato : a + ' ' + amal + ' ' + b + ' = ' + natija;
};
</script>

#Qo'shimcha imkoniyatlar (yuqori ball uchun)

  • Daraja (^), qoldiq (%, b ≠ 0), ildiz (Sqrt(a), a ≥ 0 tekshiruvi bilan).
  • Hisoblashlar sonini sanash va oxirida chiqarish: "Siz 5 ta amal bajardingiz".
  • Barcha natijalar yig'indisi yoki oxirgi natijani keyingi hisobda a sifatida ishlatish ("xotira" tugmasi).
  • Amallarni raqamli menyu bilan tanlash: 1 — Qo'shish, 2 — Ayirish ...

#Ko'p uchraydigan xatolar

  • ❌ Oxirgi False tarmoqda shartsiz bo'lish → ✅ Har bir amalni aniq tekshiring; qolgani — "Noma'lum amal".
  • ❌ amal ni Integer qilish → ✅ + — belgi, demak String.
  • ❌ amal == + (qo'shtirnoqsiz) → ✅ amal == "+".
  • ❌ Xato bo'lganda ham eski natija ni chiqarish → ✅ Bayroq bilan tekshirish.
  • ❌ Do sharti javob == "Ha", foydalanuvchi ha yozdi → ✅ Aniq ko'rsatma: "(ha/yo'q)".

#O'zingizni tekshiring

Nolga bo'lish tekshiruvi qayerda turishi kerak?

  1. Dastur oxirida
  2. Input'dan oldin
  3. Bo'lish amalidan oldin
  4. Kerak emas

Xato sodir bo'lishidan oldin tekshiramiz.

Kalkulyatorni qayta-qayta ishlatish uchun qaysi sikl qulay?

  1. For 1 to 10
  2. Do … While javob == "ha"
  3. Sikl kerak emas
  4. For 10 to 1

Kamida bir marta hisoblash kerak, keyin foydalanuvchi qaror qiladi.
